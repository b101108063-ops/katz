Drug Receptors and Pharmacodynamics

章節導讀

藥效學研究藥物如何通過與受體結合產生作用，本章深入探討受體-效應器耦合、備用受體、競爭性與非競爭性拮抗等核心概念，並介紹部分激動劑與反向激動劑等特殊藥物類型。

受體的分子本質

受體的分類

藥物受體（Receptor）大多是蛋白質分子，根據結構與訊號傳導機制分為：

受體類型 例子 訊號機制
調節型受體 GPCR（G 蛋白偶聯受體） 透過 G 蛋白激活下游效應酶
離子通道型受體 nAChR、GABA_A 受體 直接控制離子流動
酪氨酸激酶受體 胰島素受體、EGF 受體 激活細胞內酪氨酸激酶活性
核內受體 類固醇、甲狀腺素受體 調節基因轉錄

藥物濃度-效應關係

濃度-效應曲線

在理想化系統中，藥物濃度與效應呈雙曲線關係：

  • E：在濃度 C 時觀察到的效應
  • E_max：藥物可產生的最大效應
  • EC_50：產生 50% 最大效應的藥物濃度

效應與劑量對數曲線

將效應對濃度對數作圖，雙曲線轉化為S 形曲線，擴展低濃度端的刻度而壓縮高濃度端。

受體結合

藥物與受體的結合關係：

  • B_max：受體總濃度
  • K_d：解離常數 — K_d 越低，代表受體對藥物的親和力越高
  • EC_50 與 K_d：兩者可以相同或不同，取決於受體-效應器耦合效率

受體-效應器耦合與備用受體

耦合機制

藥物佔據受體後需要經過耦合（Coupling）過程才能產生藥理效應。耦合效率決定相同受體佔據程度下的效應強度差異。

備用受體（Spare Receptors）

備用受體現象說明：即使 agonist 濃度不足以佔據全部受體，仍可達到最大生物效應。

臨床意義：改變受體數量可改變細胞對 agonist 的敏感度。例如使用不可逆拮抗劑移除部分受體後，需要更高濃度的 agonist 才能達到原有最大效應。

競爭性拮抗劑與不可逆拮抗劑

競爭性拮抗劑

競爭性拮抗劑與 agonist 競爭結合同一受體位置：

特性 說明
效應可逆性 高濃度 agonist 可逆轉其效應
曲線特徵 S 形曲線向右平行移動，最大效應不變
Schild 方程式 C’/C = 1 + [I]/K_i

Propranolol 是經典的競爭性 β 受體拮抗劑。

不可逆拮抗劑

不可逆拮抗劑以共價鍵與受體形成穩定鍵結：

  • 佔據部分受體後，即使高濃度 agonist 也無法達到原有最大效應
  • 若有備用受體存在，可維持最大效應但需要更高 agonist 濃度
  • Phenoxybenzamine 是 α 受體不可逆拮抗劑的代表藥物

部分激動劑（Partial Agonists）

部分激動劑佔據全部受體時仍無法產生最大效應：

特性 說明
內在活性低 只能 stabilizes 部分受體於活化構象
雙重行為 無完全 agonist 存在時表現 agonist 活性；有完全 agonist 存在時表現拮抗作用
臨床應用 Buprenorphine（μ-opioid 受體部分 agonist）比 Morphine 更安全，過量時呼吸抑制較輕

其他拮抗機制

化學性拮抗

Protamine 帶正電，臨床上用於中和帶負電的 Heparin。

生理性拮抗

不同受體系統間的對抗，例如 Insulin 對抗 Glucocorticoid hormones 的升血糖作用。

藥物動力學與藥效學的整合

時間歷程

過程 說明
分布相（α相） 藥物由血液分布到組織
消除相（β相） 藥物濃度在血液與組織間達平衡後的下降
終末半衰期 反映藥物從最深部組織清除的速率

臨床應用原則

  • 藥物效應持續時間取決於：受體佔據時間、耦合分子的存在時間、受體脫敏機制
  • 藥物從身體消除後，效應可能仍持續（因預存訊號分子的持續作用）
