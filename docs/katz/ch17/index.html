類二十烷酸

章節導讀

本章介紹類二十烷酸的生物合成途徑，包括環氧酶（COX）、脂肪氧酶（LOX）與細胞色素P450途徑，並涵蓋前列腺素、血栓烷、白三烯的生理作用與臨床藥理學。

類二十烷酸概述

類二十烷酸是多元不飽和脂肪酸（主要是花生四烯酸AA）的氧化產物。

生物合成途徑

途徑 產物
COX（環氧酶） 前列腺素、血栓烷、前列腺環素
LOX（脂肪氧酶） 白三烯、脂氧素
P450環氧酶 EETs（環氧二十碳三烯酸）

COX同功酶

COX類型 特性 功能
COX-1 結構型，「housekeeping」 胃黏膜保護、血小板功能
COX-2 誘導型 發炎、疼痛、發燒

各類前列腺素效應

PGE₂效應：

  • 發炎（血管擴張、水腫）
  • 發燒（經EP₃）
  • 疼痛敏感化
  • 胃黏膜保護（小劑量時）
  • 腎血流量與鈉排泄

PGF₂α效應：

  • 子宮收縮
  • 支氣管收縮
  • 血管平滑肌收縮

PGI₂（前列腺環素）效應：

  • 血管擴張
  • 抑制血小板聚集

TXA₂效應：

  • 血管收縮
  • 血小板聚集

白三烯（Leukotrienes）

生物合成

花生四烯酸（AA）→經5-LOX→LTA₄→LTA₄→LTB₄或LTC₄、LTD₄、LTE₄

半胱氨酰白三烯效應（LTC₄、LTD₄、LTE₄）

效應 說明
支氣管收縮 效力是組織胺的1000倍
血管通透性增加 導致水腫
黏液分泌 過多黏液產生

受體 配體 功能
BLT1、BLT2 LTB₄ 白血球趨化性
CysLT1、CysLT2 半胱氨酰白三烯 支氣管收縮

脂氧素（Lipoxins）

  • 抗發炎介質
  • 對抗白三烯作用
  • 促進發炎緩解

NSAIDs（非類固醇抗發炎藥物）

作用機轉

NSAIDs抑制COX-1和/或COX-2，減少前列腺素與血栓烷合成

NSAID類型 選擇性 代表藥物
非選擇性COX抑制 COX-1>COX-2 Aspirin、Ibuprofen、Naproxen
COX-2選擇性抑制 COX-2 Celecoxib

Aspirin（阿斯匹靈）特點

特性 說明
作用特點 不可逆COX抑制
臨床用途 止痛、退燒、抗發炎、心血管保護
重要副作用 胃腸道出血、抑制血小板功能

警告：血小板COX-1被Aspirin不可逆抑制後，需約7-10天才能恢復血小板功能
