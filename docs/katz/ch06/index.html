Introduction to Autonomic Pharmacology

章節導讀

自律神經系統調控心臟、血管、平滑肌、腺體等重要器官，本章建立自律神經藥理的基礎框架，涵蓋交感/副交感神經系統的解剖學基礎、神經傳導物質（ACh、NE）的合成與釋放，以及主要受體類型的特性。

自律神經系統的解剖學

兩大系統的對比

特性 交感神經 副交感神經
起源位置 胸腰髓（T1-L2） 腦幹/骶髓（CN III, VII, IX, X, S2-S4）
節後纖維長度 短（神經節接近椎旁） 長（神經節在效應器附近）
主要功能 「戰鬥或逃跑」 「休息與消化」
神經傳導物質 Norepinephrine（NE） Acetylcholine（ACh）

雙重神經支配（Dual Innervation）

多數器官同時接受交感與副交感神經支配，兩者通常產生相反的生理作用。

神經傳導物質化學

Acetylcholine（ACh）

項目 說明
合成 膽鹼 + Acetyl-CoA → ACh（由 ChAT 催化）
儲存 儲存於突觸囊泡
釋放 Ca²⁺依賴性胞泌
終止 Acetylcholinesterase（AChE）快速水解（數毫秒內）

ACh 是以下部位的神經傳導物質：

  • 交感和副交感節前纖維
  • 副交感節後纖維
  • 支配汗腺的交感纖維
  • 骨骼肌神經肌肉接合處

Norepinephrine（NE）

NE 是多數交感神經節後纖維的主要神經傳導物質。

合成途徑：酪氨酸 → L-DOPA → 多巴胺 → Norepinephrine → Epinephrine

終止方式：

  • 攝取 1（Uptake 1）：神經末梢再攝取（主要方式）
  • 攝取 2（Uptake 2）：周邊組織攝取
  • MAO 與 COMT 代謝

膽鹼性受體（Cholinoceptors）

Muscarinic 受體（M1-M5）

受體 訊號機制 主要位置
M1 G_q → PLC → IP₃/DAG CNS、神經節
M2 G_i → ↓cAMP 心臟（SA/AV node）
M3 G_q → PLC → IP₃/DAG 平滑肌、腺體、血管內皮
M4 G_i → ↓cAMP CNS
M5 G_q → PLC → IP₃/DAG CNS

Nicotinic 受體（N）

受體 說明
N_N1（神經節型） 自主神經節
N_N2（肌肉型） 神經肌肉接合處

腎上腺素性受體（Adrenoceptors）

α 受體

受體 訊號機制 主要位置與功能
α1 G_q → PLC → IP₃/DAG/Ca²⁺ 血管平滑肌（收縮）、泌尿生殖道平滑肌、肝臟
α2 G_i → ↓cAMP 突觸前終末（自體受體，抑制 NE 釋放）、血小板、脂肪細胞

β 受體

受體 訊號機制 主要位置與功能
β1 G_s → ↑cAMP 心臟（正性變時/變力）、腎臟（腎素釋放）
β2 G_s → ↑cAMP 支氣管平滑肌（擴張）、血管平滑肌（擴張）、骨骼肌血管
β3 G_s → ↑cAMP 脂肪細胞（脂肪分解）

自律神經藥物的分類

類別 作用
膽鹼激動劑 直接（M agonists）或間接（AChE 抑制劑）激活膽鹼受體
抗膽鹼藥物 競爭性阻斷 muscarinic 或 nicotinic 受體
擬交感神經藥物 直接（α/β agonists）或間接（促進 NE 釋放）激活腎上腺素受體
交感神經阻斷劑 α 或 β 受體拮抗劑

案例：Promethazine 引起的姿態性低血壓

Promethazine（phenothiazine 類抗組織胺）具有抗膽鹼和抗腎上腺素作用，抑制代償性血管收縮，故站立時血壓下降。

血壓下降刺激壓力受體反射，導致代償性心搏過速

臨床應用重點

臨床情況 代表藥物
支氣管痙攣 Albuterol（β2 agonist）
心搏過緩 Atropine（muscarinic antagonist）
高血壓 Prazosin（α1 blocker）、Propranolol（β blocker）
過敏性反應 Epinephrine（α, β agonist）
