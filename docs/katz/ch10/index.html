Antihypertensive Agents

章節導讀

抗高血壓藥物是心血管藥理的核心，本章涵蓋α受體阻斷劑（Prazosin 系列）與β受體阻斷劑（Propranolol、Metoprolol）的藥理特性，並涵蓋嗜鉻細胞瘤、高血壓、心絞痛、心衰竭與青光眼的臨床應用。

α-腎上腺素受體阻斷劑

分類與選擇性

藥物 受體選擇性
Phenoxybenzamine α1 > α2（不可逆）
Phentolamine α1 = α2（可逆）
Prazosin, Terazosin, Doxazosin α1 » α2（可逆）
Tamsulosin α1A > α1B, α1D
Yohimbine α2 » α1

Phenoxybenzamine

特性 說明
機轉 共價鍵結合 α 受體，不可逆阻斷
作用時間 14-48 小時
主要臨床用途 嗜鉻細胞瘤術前準備
副作用 姿勢性低血壓、心搏過速、鼻塞、射精抑制

注意：嗜鉻細胞瘤患者在 α 阻斷建立前禁止使用 β 阻斷劑

Phentolamine

特性 說明
機轉 競爭性 α1 = α2 阻斷
臨床用途 嗜鉻細胞瘤高血壓危象

心臟刺激作用可能導致心搏過速、心律不整、心肌缺血

Prazosin 系列（α1 選擇性阻斷劑）

藥物 半衰期 特性
Prazosin ~3 小時 需每日多次給藥
Terazosin 9-12 小時 可每日一次
Doxazosin ~22 小時 可每日一次
Tamsulosin 9-15 小時 α1A 高度選擇；對前列腺作用 > 對血管作用
共同臨床用途 說明
高血壓 血管擴張
良性前列腺增生（BPH） 放鬆前列腺/膀胱頸平滑肌

首劑效應（First-dose phenomenon）：初次給藥後可能發生姿勢性低血壓，建議首次劑量在睡前給予。

Propranolol

特性 說明
受體 非選擇性 β 阻斷
生體可用率 低且劑量依賴（首渡效應顯著）
藥物動力學 CYP2D6 代謝（慢代謝者血中濃度顯著較高）
臨床用途 高血壓、心絞痛、心律不整、偏頭痛

藥物動力學參數

參數 Propranolol
半衰期 3.5-6 小時
生體可用率 ~30%
脂溶性 高（易穿透 BBB）

β1 選擇性阻斷劑

藥物 半衰期 (h) 生體可用率 特殊特性
Metoprolol 3-4 ~50% CYP2D6 代謝；有心臟選択性
Atenolol 6-9 ~40% 腎排泄；每日一次
Bisoprolol 9-12 ~80% 高 β1 選擇性
Nebivolol 11-30 12-96% 高 β1 選擇性 + NO 介導血管擴張

Labetalol 與 Carvedilol

藥物 受體活性 說明
Labetalol α1 + β1, β2 口服後 β:α 阻斷比 ≈ 3:1
Carvedilol α1 + β1, β2 心衰竭標準治療之一

Esmolol

特性 說明
受體 β1 選擇性
半衰期 ~10 分鐘（RBC 酯酶快速代謝）
給藥方式 IV 輸液
臨床用途 手術中高血壓、室上性心律不整

臨床應用

高血壓

藥物類別 說明
β 阻斷劑 抑制腎素釋放；减少心輸出量
α1 阻斷劑 直接擴張血管
聯合治療 通常與利尿劑或血管擴張劑合用

β 阻斷劑對老年人與非裔美國人效果較差

嗜鉻細胞瘤

階段 藥物
術前準備 Phenoxybenzamine（不可逆 α 阻斷）
術前準備（替代） Prazosin、Doxazosin
高血壓危象 Phentolamine（IV）或 Nitroprusside
β 阻斷（α 阻斷建立後） Propranolol（控制心搏過速）

警告：先建立 α 阻斷，再使用 β 阻斷；未阻斷 α 時使用 β 阻斷會導致無對抗的 α 效應（血管強烈收縮）

心絞痛

β 阻斷劑減少心肌氧氣需求（↓ 心率、↓ 收縮力、↓ 血壓）。

心衰竭

Carvedilol、Metoprolol、Bisoprolol 被證明可減少心衰竭死亡率。

青光眼

Timolol（局部β 阻斷）減少房水生成，降低眼壓。

青光眼藥物 機轉
Timolol β 阻斷 → 減少房水生成
Betaxolol β1 選擇性，較少支氣管副作用
Pilocarpine M agonist → 開放小梁網絡
Latanoprost Prostaglandin analog → 增加房水排出

副作用與禁忌症

共同副作用

副作用 說明
心搏過緩 β 阻斷常見
支氣管痙攣 β2 阻斷；氣喘患者禁用
血糖控制惡化 糖尿病患者使用注意
勃起功能障礙 —
疲倦、噩夢 —

禁忌症

禁忌 β 阻斷劑
氣喘/COPD 所有 β 阻斷劑（相對禁忌於選擇性制劑）
心搏過緩 —
急性心衰竭 需謹慎
心傳導阻斷 —

藥物總整理

藥物 機轉 臨床用途 副作用
Phenoxybenzamine 不可逆性 α1, α2 阻斷 嗜鉻細胞瘤 姿勢性低血壓、心搏過速
Phentolamine 競爭性 α1, α2 阻斷 嗜鉻細胞瘤高血壓危象 心搏過速、心律不整
Prazosin 選擇性 α1 阻斷 高血壓、BPH 首劑效應、眩暈
Terazosin 選擇性 α1 阻斷 高血壓、BPH 姿勢性低血壓
Doxazosin 選擇性 α1 阻斷 高血壓、BPH 姿勢性低血壓
Tamsulosin α1A 高度選擇 BPH 逆行性射精，姿勢性低血壓少
Propranolol 非選擇性 β 阻斷 高血壓、心絞痛、心律不整、偏頭痛 支氣管痙攣、心搏過緩
Metoprolol β1 選擇性 高血壓、心絞痛、心衰竭 心搏過緩、支氣管痙攣（較少）
Atenolol β1 選擇性 高血壓、心絞痛 心搏過緩、疲倦
Nadolol 非選擇性 β 阻斷 高血壓、心絞痛 心搏過緩、支氣管痙攣
Timolol 非選擇性 β 阻斷（無局部麻醉） 高血壓、青光眼 心搏過緩、支氣管痙攣
Labetalol α1 + β1, β2 阻斷 高血壓急症 姿勢性低血壓、心搏過速
Carvedilol α1 + β1, β2 阻斷 心衰竭、高血壓 體重增加、低血壓
Esmolol 超短效 β1 選擇性 手術高血壓、室上性心律不整 低血壓、心搏過緩
Nebivolol 高 β1 選擇性 + NO 擴血管 高血壓 頭痛、疲倦
