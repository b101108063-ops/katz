組織胺、血清素與麥角生物鹼

章節導讀

本章介紹組織胺（H₁、H₂、H₃受體）與血清素（5-HT）受體的生理作用及相關藥物，並說明麥角生物鹼在偏頭痛治療與婦產科的應用。

組織胺（Histamine）

組織胺儲存於肥大細胞與嗜鹼性球中，過敏反應時釋放。

H₁受體效應

效應 說明
平滑肌收縮 支氣管、子宮、血管
血管通透性增加 導致水腫
癢感與疼痛 過敏反應常見

H₂受體效應

效應 說明
胃酸分泌增加 消化性潰疡主因
心率增加 正性頻率作用
抑制組織胺釋放 負回饋調節

H₃受體效應

  • 中樞神經突觸前自體受體，抑制組織胺釋放

抗組織胺藥物

H₁阻斷劑

第一代H₁阻斷劑（Diphenhydramine、Chlorpheniramine）

  • 可穿透血腦屏障（BBB） → 鎮靜
  • 具有抗膽鹼效應
  • 臨床用途：過敏、動暈症、失眠

第二代H₁阻斷劑（Loratadine、Cetirizine、Fexofenadine）

  • BBB穿透較少 → 鎮靜較輕微
  • 臨床用途：過敏性鼻炎、慢性蕁麻疹

H₂阻斷劑

藥物 臨床用途 特殊副作用
Cimetidine 消化性潰疡、胃食道逆流 抗雄激素作用
Ranitidine 消化性潰疡 CYP抑制較少
Famotidine 消化性潰疡 副作用較少

血清素（5-HT）

血清素分布於中樞神經系統、胃腸道（腸嗜鉻細胞）與血小板。

5-HT受體分類

受體 訊號途徑 主要功能
5-HT₁ Gi → 抑制腺苷酸環化酶 血管收縮、抑制釋放
5-HT₂ Gq → 增加IP₃/DAG 平滑肌收縮、血小板聚集
5-HT₃ 配體門控陽離子通道 嘔吐反射
5-HT₄ Gs → 刺激腺苷酸環化酶 平滑肌鬆弛
5-HT₇ Gs → 鬆弛平滑肌 血管擴張

相關藥物

藥物 機轉 臨床用途
Ondansetron 5-HT₃拮抗劑 化療/手術後噁心嘔吐
Sumatriptan 5-HT₁B/₁D激動劑 急性偏頭痛
SSRIs 增加突觸5-HT 憂鬱症

麥角生物鹼（Ergot Alkaloids）

麥角生物鹼由真菌Claviceps purpurea產生，對多個受體具有部分激動/拮抗活性。

麥角鹼類藥物

藥物 臨床用途 副作用/禁忌
Ergotamine 急性偏頭痛 血管收縮（周邊缺血）、噁心
Dihydroergotamine 急性偏頭痛 注射部位反應
Ergonovine 產後出血（，子宮收縮） 懷孕禁忌
Methylergonovine 產後出血 懷孕禁忌
Bromocriptine 帕金森氏症、高泌乳素血症 噁心、姿態性低血壓、精神症
Cabergoline 帕金森氏症、高泌乳素血症 噁心、低血壓

警告：麥角生物鹼具有血管收縮作用，過量可引起嚴重周邊缺血，禁忌於心血管疾病患者

偏頭痛治療藥物總整理

藥物 機轉 急性/預防 主要副作用
Sumatriptan 5-HT₁B/₁D激動劑 急性治療 冠狀血管痙攣、胸悶
Ergotamine 5-HT/多巴胺受體 急性治療 血管收縮、噁心
Propranolol β阻斷劑 預防 心搏過緩、疲倦
Topiramate 多重機轉 預防 認知障礙、腎結石
Flunarizine 鈣通道阻斷 預防 鎮靜、體重增加
