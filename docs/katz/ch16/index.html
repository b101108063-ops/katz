血管活性肽

章節導讀

本章介紹腎素-血管張力素系統（RAS）、激肽系統、心房利鈉肽（ANP、BNP）、內皮素及血管加壓素（ADH）的藥理學，並涵蓋相關受體拮抗劑的臨床應用。

血管張力素（Angiotensin）

腎素-血管張力素系統（RAS）是血壓與液體平衡的主要調節系統。

血管張力素受體

受體 訊號 主要功能
AT₁ Gq → 血管收縮 血管收縮、醛固酮釋放、鈉滯留、心肌肥大
AT₂ Gi → 血管擴張 血管擴張、鈉排泄、組織保護

ACE抑制劑 vs ARBs

特性 ACE抑制劑 ARBs
作用點 阻斷ACE（kininase II） 阻斷AT₁受體
效應 減少Ang II生成＋增加bradykinin 減少Ang II作用（無bradykinin效應）
優點 降低血壓、心衰竭、糖尿病腎病 較少乾咳
副作用 乾咳（bradykinin）、血管性水腫、高血鉀 血管性水腫（較少）

ACE抑制劑

藥物 特點
Captopril 短效，需每日多次
Enalapril 前驅藥，需肝臟活化
Lisinopril 長效，每日一次
Ramipril 長效，肝臟活化

警告：ACE抑制劑具致畸性，懷孕婦女絕對禁忌

ARBs（血管張力素受體阻斷劑）

藥物 特點
Losartan 第一代AT₁阻斷劑
Valsartan 高血壓、心衰竭
Candesartan 長效
Telmisartan 長效，PPARγ活化

緩激肽（Bradykinin）

合成途徑

激肽原（kininogen）→經kallikrein→緩激肽（bradykinin）

受體

受體 分布 功能
B₁ 發炎時誘導 疼痛、血管擴張
B₂ 結構型（主要） 大部分bradykinin效應

Bradykinin效應

  • 血管擴張（經NO、前列腺素）
  • 疼痛與痛覺過敏
  • 血管通透性增加
  • 支氣管收縮

重要：ACE抑制劑增加bradykinin（因ACE即kininase II），解釋了乾咳與血管性水腫副作用

心房利鈉肽（Natritetic Peptides）

類型

肽類 來源 主要功能
ANP 心房 鈉利尿、血管擴張
BNP 心室 心衰竭時升高
CNP 內皮細胞、腦 血管擴張

受體

  • NPR-A、NPR-B：鳥糞酸環化酶受體→增加cGMP
  • NPR-C：清除受體

Nesiritide（奈西立肽）

特性 說明
藥物類型 重組BNP
臨床用途 急性失代償性心衰竭
副作用 低血壓、腎功能惡化
