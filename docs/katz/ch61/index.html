生物製劑臨床藥理學

CH61 生物製劑臨床藥理學

章節導讀

生物製劑（Biologics）是目前發展最快的藥物類別之一，包括單株抗體、融合蛋白、重組蛋白、胜肽藥物及基因/細胞療法。本章節介紹生物製劑的定義與特性、重點藥物的藥理學（特別是腫瘤坏死因子抑制劑、免疫檢查點抑制劑），以及其不良反應與臨床應用概況。

生物製劑的定義與特性

什麼是生物製劑？

生物製劑是由生物來源（如細胞、微生物）或利用生物技術所製造的藥物，包括：

類別 代表藥物
單株抗體（Monoclonal antibodies） Infliximab、Adalimumab、Rituximab
融合蛋白（Fusion proteins） Etanercept、TNFR-Fc
重組蛋白（Recombinant proteins） Insulin、EPO、G-CSF
胜肽藥物（Peptides） GLP-1 agonists
基因/細胞療法 CAR-T、基因療法

生物製劑的命名

前綴 來源
-mab 單株抗體
-ximab 嵌合抗體（chimeric）
-zumab 人源化抗體（humanized）
-umab 全人源抗體（fully human）
中綴 標的/疾病應用
-li- 免疫相關
-tu- 腫瘤
-cir- 心血管
-kin- 白介素

範例：Infliximab = 嵌合（-ximab）抗TNF（inflix-）單株抗體；Adalimumab = 全人源（-umab）抗TNF（-ada-）單株抗體

腫瘤壞死因子-α抑制劑（TNF-α Inhibitors）

作用機轉：TNF-α是重要的促發炎細胞激素；TNF抑制劑結合並中和TNF-α，減少發炎反應。

主要製劑

藥物 結構 給藥途徑 半衰期
Infliximab 嵌合抗體 IV infusion 7-12天
Adalimumab 全人源抗體 SC injection 10-20天
Etanercept 融合蛋白（TNFR-Fc） SC injection 3-4天
Golimumab 全人源抗體 SC injection 7-20天
Certolizumab pegylated Fab fragment SC injection 14天

共同適應症

疾病 說明
類風濕關節炎（RA） 與MTX合併使用
僵直性脊椎炎 TNF抑制劑效果顯著
乾癬/乾癬性關節炎 皮膚及關節症狀
發炎性腸道疾病（IBD） Crohn病、潰痬性結腸炎
化膿性汗腺炎 Adalimumab已獲批准

不良反應

系統 表現
感染 機會性感染（TB再活化、侵襲性黴菌、PCP）；最常見嚴重不良反應
惡性腫瘤 淋巴瘤風險增加（特別是hepatosplenic T-cell lymphoma）
注射局部反應 紅斑、疼痛、瘙癢
抗核抗體（ANA）產生 少数出現藥物誘導性紅斑狼瘡
充血性心衰竭 可能惡化

⚠️ 用藥前篩查：結核菌素測驗（或IGRA）；B、C肝炎；心功能評估

免疫檢查點抑制劑（Immune Checkpoint Inhibitors）

作用機轉：抑制T細胞的「剎車」分子（CTLA-4或PD-1），恢復並增強抗腫瘤免疫反應。

CTLA-4抑制劑

藥物 說明
Ipilimumab 完全人源抗體；用於黑色素瘤；可與nivolumab合用

PD-1/PD-L1抑制劑

藥物 標的 主要適應症
Nivolumab PD-1 黑色素瘤、肺癌、腎細胞癌、膀胱癌
Pembrolizumab PD-1 肺癌、黑色素瘤、膀胱癌
Atezolizumab PD-L1 肺癌、膀胱癌
Durvalumab PD-L1 肺癌、膀胱癌

免疫相關不良反應（irAEs）

⚠️ 免疫檢查點抑制劑可誘發全身性免疫相關不良反應

系統 表現 處理原則
結腸 免疫媒介性結腸炎（腹瀉、血便） 皮質類固醇；必要時infliximab
肝 免疫媒介性肝炎（ALT/AST升高） 皮質類固醇
肺 免疫媒介性肺炎（咳嗽、呼吸困難） 皮質類固醇；高劑量必要
內分泌 甲狀腺炎（甲狀腺機能異常）；腎上腺炎 甲狀腺激素替代；皮質類固醇
皮膚 斑丘疹、Stevens-Johnson症候群 皮質類固醇

B細胞標靶治療

Rituximab（利妥昔單抗）

作用機轉：抗CD20單株抗體；結合B細胞表面的CD20→補體活化與ADCC→B細胞清除。

適應症 說明
B細胞淋巴瘤 CD20+ B-NHL；與化療合併
慢性淋巴球白血病（CLL） 與化療合併
類風濕關節炎 對TNF抑制劑反應不足時
肉芽腫性血管炎（GPA） 與皮質類固醇合併

不良反應

反應類型 說明
輸注反應 第一次輸注時常見；發燒、寒顫、低血壓；可用皮質類固醇預防
感染 特別是HBV再活化；進行性多病灶腦白質病（PML）
心臟 心律不整；有心臟病史者慎用

白介素抑制劑

Tocilizumab（托珠單抗）

作用機轉：抗IL-6受體單株抗體；IL-6是RA等疾病的重要促發炎細胞激素。

適應症 說明
類風濕關節炎 對TNF抑制劑反應不足；可單獨或與MTX合併
巨型細胞性動脈炎 已獲批准

不良反應

系統 說明
感染 侵襲性感染風險增加
肝功能 ALT/AST升高
血脂 膽固醇、三酸甘油酯升高
中性球減少 常見

整合素抑制劑

Vedolizumab（維得利珠單抗）

作用機轉：抗α4β7整合素單株抗體；阻斷α4β7與MAdCAM-1的結合→抑制淋巴球回到腸道→減少腸道發炎。

適應症 說明
克隆氏症 中-重度
潰痬性結腸炎 中-重度

優點：腸道選擇性；腸道外不良反應相對較少

免疫製劑的藥物交互作用

交互作用 臨床影響
TNF抑制劑 + 免疫抑制劑 感染風險相加
TNF抑制劑 + Anakinra/Abatacept 不建議合併（感染風險增加）
Rituximab + 順鉑等腎毒性藥物 增加腎毒性風險
免疫檢查點抑制劑 + 皮質類固醇 可能降低免疫治療效果

生物製劑的免疫原性

定義：生物製劑作為外來蛋白，可能誘發抗藥物抗體（ADA）

影響因素 說明
結構 嵌合抗體（infliximab）> 人源化 > 全人源
給藥途徑 皮下 > 靜脈
劑量 高劑量有時降低免疫原性（誘導免疫耐受）
合併免疫抑制 MTX等可減少ADA產生
臨床影響 說明
療效減退 ADA中和藥物→療效降低
過敏反應 注射局部或全身性過敏
血清病樣反應 寒顫、發燒、關節痛

懷孕與生物製劑

基本原則：TNF抑制劑在整個妊娠期通常被认为是相对安全的，但建議在妊娠晚期（尤其是第三孕期後）停用，以减少新生儿出生后的感染风险。

藥物 孕期安全性
Adalimumab 妊娠期可继续使用至妊娠晚期
Infliximab 相似建議
Etanercept 也有类似数据
Rituximab 计划妊娠前需停药；新生儿接种活疫苗需延迟

生物製劑的未來發展方向

  1. 雙特異性抗體（Bispecific antibodies）：同時結合兩個標的
  2. 抗體-藥物複合體（ADC）：將細胞毒性藥物導向腫瘤細胞
  3. Fc工程改造：改變抗體的效應功能
  4. 細胞療法：CAR-T、TCR-T、NK細胞療法
  5. 基因療法：一次性治療遺傳疾病
