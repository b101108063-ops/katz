# CH49 其他抗菌藥物

## 章節導讀

本章涵蓋臨床上常見但不屬於傳統大类的抗菌藥物，包括**硝基呋喃妥因**、**甲胺**等泌尿道抗菌劑，以及**消毒劑**、**防腐劑**與**滅菌剂**的藥理學。這些製劑在預防和治療特定感染中扮演重要角色，臨床使用時需注意其作用範圍、適應症及不良反應的差異。

---

##  nitrofurantoin（硝基呋喃妥因）

<span style="color:#60a5fa">**作用機轉**</span>：干擾細菌蛋白質合成及阻斷多種酶系統，導致細菌DNA受損。對多數**大腸桿菌**（<span style="color:#c084fc">*Escherichia coli*</span>）及**腸球菌**具抗菌活性。

### 臨床適應症

| 適應症 | 說明 |
|--------|------|
| 單純性泌尿道感染（UTI） | 口服100 mg，每日4次 |
| 慢性UTI抑制治療 | 單日劑量100 mg（睡前服用） |

<span style="color:#f87171">**禁忌**：肌酸酐清除率 < 60 mL/min之患者禁用；孕婦分娩前及新生兒禁用。</span>

### 不良反應

- <span style="color:#f87171">**胃腸道**：食慾不振、噁心、嘔吐</span>
- **神經**：周邊神經病變（葡萄糖-6-磷酸脫氫酶缺乏症患者風險較高）
- **血液**：溶血性貧血
- **肺部**：肺浸潤及肺纖維化（過敏反應）

---

##  methenamine（甲胺化合物）

<span style="color:#60a5fa">**作用機轉**</span>：在尿液pH < 5.5時釋出**甲醛**，發揮抗菌作用。

### 製劑比較

| 製劑 | 劑量 | 特點 |
|------|------|------|
| Methenamine mandelate | 1 g，每日4次 | 含孟德爾酸 |
| Methenamine hippurate | 1 g，每日2次 | 含馬尿酸 |

<span style="color:#34d399">**目標尿液pH**：< 5.5（可同時給予維生素C 4–12 g/日酸化尿液）</span>

### 臨床應用

- 僅用於**抑制**而非治療活動性泌尿道感染
- 酸性環境下效果最佳
- <span style="color:#f87171">**注意**：不可與磺胺類藥物同時使用（兩者可能形成沉澱）</span>

---

## 消毒劑、防腐劑與滅菌剂概述

### 名詞定義

| 術語 | 定義 |
|------|------|
| <span style="color:#22d3ee">防腐（Antisepsis）</span> | 應用於活組織以預防感染 |
| <span style="color:#22d3ee">消毒（Disinfection）</span> | 破壞大多數營養型微生物或病毒，但不含孢子 |
| <span style="color:#22d3ee">滅菌（Sterilization）</span> | 殺滅或移除所有類型微生物（含孢子）之過程 |
| <span style="color:#22d3ee">去污（Decontamination）</span> | 破壞或顯著減少微生物數量 |

---

##  醇類（Alcohols）

<span style="color:#60a5fa">**代表藥物**：乙醇（Ethanol）、異丙醇（Isopropanol）</span>

<span style="color:#60a5fa">**作用機轉**：蛋白質變性</span>

| 特性 | 說明 |
|------|------|
| 最佳濃度 | 60–90%（體積比）|
| 抗菌範圍 | 營養型細菌、<span style="color:#c084fc">*Mycobacterium tuberculosis*</span>、多數黴菌、亲脂性病毒 |
| 缺點 | <span style="color:#f87171">**非孢子殺滅**；對亲水性病毒無效；無殘留作用</span> |

### 臨床應用

- 手部消毒（酒精性乾洗手液）
- 器械初步消毒
- <span style="color:#f87171">**注意**：對<span style="color:#c084fc">*Clostridium difficile*</span>孢子無效；需配合肥皂水洗手</span>

---

##  氯己定（Chlorhexidine）

<span style="color:#60a5fa">**作用機轉**：帶正電的雙胍類，吸附於細菌細胞膜，使其滲透性改變並使胞質內容物洩漏</span>

| 特性 | 說明 |
|------|------|
| 抗菌範圍 | 格蘭氏陽性菌（高效）、格蘭氏陰性菌（中等）、黴菌（中等）|
| 殘留性 | 具殘留活性，重複使用可達與醇類相當的效能 |
| 製劑 | 2%或4%水溶液；70%酒精+氯己定（最佳組合）|

<span style="color:#34d399">**優點**：對血液及有機物干擾較碘劑不敏感；神經毒性低</span>

<span style="color:#f87171">**神經毒性**：中耳手術禁用（可能導致感音神經性聽力損失）</span>

---

##  鹵素類（Halogens）

### 碘製劑

| 製劑 | 特性 |
|------|------|
| 碘酊（Tincture of iodine）| 2%碘+2.4%碘化鈉；對<span style="color:#22d3ee">完整皮膚</span>抗菌效果最強，但易過敏及染色 |
| 碘伏（Iodophors，如Povidone-iodine）| 碘與表面活性劑之複合物；刺激性低於碘酊；需稀釋後使用 |

### 氯製劑

<span style="color:#60a5fa">**代表**：次氯酸鈉（漂白水）</span>

| 用途 | 濃度建議 |
|------|----------|
| 血液濺灑消毒 | 5000 ppm（1:10稀釋家用漂白水）|
| 一般表面 | 1000–10000 ppm |
| <span style="color:#f87171">**孢子殺滅**</span> | 需5000 ppm以上 |

<span style="color:#f87171">**注意**：被血液、血清、糞便及蛋白質材料中和活性；不可與甲醛混合（會形成致癌物）</span>

---

##  酚類（Phenolics）

<span style="color:#60a5fa">**作用機轉**：破壞細胞壁及細胞膜、蛋白質沉澱、酶系統去活化</span>

| 製劑 | 應用 |
|------|------|
| o-苯基苯酚 | 醫院及實驗室硬表面消毒 |
| o-苄基-對氯酚 | 表面清潔制 |
| 六氯酚（Hexachlorophene）| <span style="color:#f87171">**禁用**：早產兒使用曾致腦水腫及痙攣</span> |

---

##  季銨化合物（Quaternary Ammonium Compounds）

<span style="color:#60a5fa">**代表**：苯扎氯銨（Benzalkonium chloride）</span>

| 特性 | 說明 |
|------|------|
| 抗菌範圍 | 格蘭氏陽性菌（高效）；格蘭氏陰性菌（中等）；亲脂性病毒 |
| 缺點 | <span style="color:#f87171">**非結核菌殺滅**；非孢子殺滅；不活化亲水性病毒</span> |
| 干擾因素 | 被肥皂（陰離子介面活性劑）、鈣、鎂、鐵、鋁離子中和 |

<span style="color:#f87171">**院內感染風險**：曾有<span style="color:#c084fc">*Pseudomonas*</span>等格蘭氏陰性菌在季銨化合物溶液中生長並造成院內感染爆發之報告，故CDC建議**不要**將季銨化合物作為防腐劑使用。</span>

---

##  醛類（Aldehydes）

### 甲醛（Formaldehyde）

| 特性 | 說明 |
|------|------|
| 濃度 | 40%水溶液（福馬林）|
| 抗菌範圍 | 廣泛（包括孢子，需18小時）|
| 應用 | 醫療器材高水平消毒、血液透析器消毒、疫苗製備 |

<span style="color:#f87171">**職業暴露限制**：OSHA訂定8小時加權平均為0.75 ppm；為潛在致癌物。</span>

### 戊二醛（Glutaraldehyde）

| 特性 | 說明 |
|------|------|
| 濃度 | 2%水溶液（需鹼化至pH 7.4–8.5活化）|
| 抗菌範圍 | 细菌、孢子、黴菌、親脂性及亲水性病毒 |
| 穩定性 | 活化後14天內使用；超過則活性下降 |

<span style="color:#22d3ee">**應用**：光學內視鏡、呼吸治療器材、牙科手機、血液透析器</span>

### 鄰苯二甲醛（Ortho-phthalaldehyde, OPA）

- 0.55%溶液；不需活化
- 高水平消毒：室溫下12分鐘（vs. 戊二醛45分鐘）
- 對黏膜刺激性低；材料相容性佳

---

##  過氧化物類（Peroxygen Compounds）

### 過氧化氫（Hydrogen Peroxide）

<span style="color:#60a5fa">**作用機轉**：強氧化劑；接觸觸酶後分解為氧和水</span>

| 濃度 | 用途 |
|------|------|
| 3–6% | 表面消毒 |
| 6–90% | 工業及製藥用途 |
| 蒸氣態（VPHP）| 冷氣體滅菌（低溫4°C即有活性）|

### 過醋酸（Peracetic Acid）

- 250–500 ppm可有效對抗大多數细菌；孢子需500–30000 ppm
- 自動化系統（如Steris）用於醫療器材滅菌
- 產物為醋酸和過氧化氫，環境友善

---

##  重金屬類（Heavy Metals）

### 銀製劑

| 製劑 | 應用 |
|------|------|
| 硝酸銀（Silver nitrate）1:1000 | <span style="color:#f87171">**預防新生兒淋菌性眼炎**（但已被抗生素軟膏取代）|
| 磺胺嘧啶銀（Silver sulfadiazine）| 燒傷傷口抗菌 |

### 硫柳汞（Thimerosal）

- 0.001–0.004%作為疫苗及免疫血清之防腐劑
- <span style="color:#f87171">**過敏常見**（約40%人口）；目前兒科疫苗已逐步移除此成分</span>

---

##  灭菌剂（Sterilants）

| 方法 | 條件 | 備註 |
|------|------|------|
| 高壓滅菌（Autoclave）| 120°C，30分鐘 | 基礎方法 |
| 環氧乙烷（Ethylene oxide）| 440–1200 mg/L，45–60°C，相對濕度30–60% | 熱敏感器材；<span style="color:#f87171">**致突變及致癌物**；OSHA PEL為1 ppm |
| 氣態過氧化氫（VPHP）| 低溫滅菌 | 替代環氧乙烷之環保選項 |
| 過醋酸系統 | 自動化設備 | 透析器及內視鏡滅菌 |

##  其他抗菌劑摘要

| 藥物 | 作用機轉 | 臨床應用 | 藥動學/毒性 |
|------|----------|----------|-------------|
| <span style="color:#fb923c">Metronidazole</span> | 干擾電子傳遞鏈 | 厭氧菌感染、<span style="color:#c084fc">*C. difficile*</span>結腸炎、陰道炎 | 口服/IV；半衰期8h；常見金屬味、腸胃不適、神經病變 |
| <span style="color:#fb923c">Tinidazole</span> | 同上 | 滴蟲、梨形蟲、阿米巴痢疾 | 口服；每日一次；與metronidazole相似 |
| <span style="color:#fb923c">Nitrofurantoin</span> | 蛋白質合成抑制及DNA損傷 | 單純性UTI | 口服；半衰期0.5h；腎功能不全禁用 |
| <span style="color:#fb923c">Methenamine</span> | 酸性尿液中釋出甲醛 | UTI抑制（非治療）| 口服；需維持尿液pH < 5.5 |
| <span style="color:#fb923c">Fidaxomicin</span> | 抑制細菌RNA聚合酶 | <span style="color:#c084fc">*C. difficile*</span>結腸炎 | 口服；血中濃度極低；局部作用 |

##  防腐劑（Preservatives）

常用於製藥、實驗室試劑、化妝品及隱形眼鏡保存液。

| 類別 | 代表藥物 |
|------|----------|
| 有機酸 | 苯甲酸鹽、對羥基苯甲酸酯（Parabens）、山梨酸鹽 |
| 醇類 | 乙醇、苯氧乙醇 |
| 汞類 | 硫柳汞 |
| 季銨化合物 | 苯扎氯銨 |
