## 章節導讀

全身麻醉藥是現代外科手術不可或缺的藥物，透過抑制中樞神經系統而產生意識消失、鎮痛、遺忘、骨骼肌鬆弛等效果。本章節系統性探討全身麻醉藥的作用機轉、藥物動力學特性，並深入比較各類吸入性與靜脈注射麻醉藥物的臨床應用與不良反應管理。

---

## 第一節　全身麻醉的機轉

### 麻醉的五大核心效果

全身麻醉藥物產生的神經生理狀態包含五項主要效果：

- **意識消失**（Unconsciousness）
- **遺忘作用**（Amnesia）
- **鎮痛效果**（Analgesia）
- **自主神經反射抑制**（Inhibition of autonomic reflexes）
- **骨骼肌鬆弛**（Skeletal muscle relaxation）

臨床上，單一麻醉藥物通常無法同時達成上述所有效果，因此現代麻醉實踐採用平衡麻醉技術，結合吸入性麻醉劑、靜脈注射麻醉劑、鴉片類止痛藥與神經肌肉阻斷劑。

### 麻醉作用的神經機轉

全身麻醉藥的作用機轉至今尚未完全闡明，目前研究顯示麻醉藥物可作用於多種分子靶點：

- **抑制性離子通道**：GABA<sub>A</sub>受體（氯離子通道）、甘氨酸受體、鉀離子通道（K<sub>2P</sub>、K<sub>vATP</sub>）
- **興奮性離子通道**：NMDA受體、AMPA受體、KA受體、菸鹼型乙醯膽鹼受體（nAChR）、血清素受體（5-HT<sub>2</sub>、5-HT<sub>3</sub>）

這些離子通道分布於神經突觸的前突觸與後突觸位置，麻醉藥物透過強化抑制或減弱興奮來達成麻醉效果。

## 第二節　吸入性麻醉藥

### 藥物動力學：攝取與分布

吸入性麻醉藥（含揮發性與氣體性）經由肺泡氣體交換被人體攝取。肺泡濃度（F<sub>A</sub>）與吸入濃度（F<sub>I</sub>）的比值（F<sub>A</sub>/F<sub>I</sub>）是決定麻醉誘導速度的關鍵參數。

#### 影響肺胞濃度的因素

| 因素 | 作用機轉 |
|------|---------|
| **吸入濃度** | 吸入濃度越高，肺胞濃度上升越快 |
| **肺胞通氣量** | 通氣量增加加速麻醉藥物進入肺泡 |
| **血:氣分配係數** | 係數越低（低溶解度），誘導與恢復越快 |
| **心輸出量** | 心輸出量增加會稀釋血流中的麻醉藥物，延緩腦部達到有效濃度 |

#### 血:氣分配係數與藥物特性

| 麻醉藥物 | 血:氣分配係數 | 特性 |
|---------|------------|------|
| <span style="color:#fb923c">Nitrous oxide（笑氣）</span> | 0.47 | 低溶解度；誘導與恢復最快；不完全麻醉 |
| <span style="color:#fb923c">Desflurane</span> | 0.42 | 低溶解度；刺激性強；快速恢復 |
| <span style="color:#fb923c">Sevoflurane</span> | 0.69 | 中等溶解度；誘導快速；與鹼石灰反應 |
| <span style="color:#fb923c">Isoflurane</span> | 1.40 | 中等溶解度；中等誘導與恢復速度 |
| <span style="color:#fb923c">Enflurane</span> | 1.80 | 較高溶解度；恢復較慢 |
| <span style="color:#fb923c">Halothane</span> | 2.30 | 高溶解度；誘導慢但平穩；40%以上經肝臟代謝 |

<span style="color:#e2e8f0">**MAC（最小肺泡濃度）**</span> 是衡量吸入性麻醉藥效力的標準，指在1大氣壓下，使50%患者在皮膚切開時保持不動的肺泡濃度。

| 麻醉藥物 | MAC（%） |
|---------|---------|
| Nitrous oxide（笑氣） | >100 |
| Desflurane | 6–7 |
| Sevoflurane | 2.0 |
| Isoflurane | 1.40 |
| Enflurane | 1.7 |
| Halothane | 0.75 |

### 吸入性麻醉藥的藥效學

#### A. 腦部效應

吸入性麻醉藥對腦部血流與代謝的影響如下：

- **CMR（腦代謝率）**：所有吸入性麻醉藥均會降低腦代謝率
- **腦血流**：高MAC值時，鹵化烷類藥物引起腦血管擴張，可能增加顱內壓
- **腦電波圖（EEG）**：Isoflurane在2.0–2.5 MAC時可達電性沉默；Sevoflurane與Enflurane在1.0–2.0 MAC可能出現癲癇樣波形

<span style="color:#f87171">**臨床警告**：顱內壓升高患者應避免使用高濃度鹵化烷類麻醉藥，可採用過度換氣（降低PaCO<sub>2</sub>）減少腦血流。</span>

#### B. 心血管效應

| 藥物 | 心肌抑制 | 血管效應 | 心率 |
|------|--------|--------|------|
| <span style="color:#fb923c">Halothane</span> | 強（↓心輸出量） | 輕度血管擴張 | 不變/慢 |
| <span style="color:#fb923c">Enflurane</span> | 中等 | 輕度血管擴張 | 不變 |
| <span style="color:#fb923c">Isoflurane</span> | 輕度 | 明顯血管擴張（↓後負荷） | ↑ |
| <span style="color:#fb923c">Desflurane</span> | 輕度 | 血管擴張；快速濃度改變可誘發交感激活 | ↑ |
| <span style="color:#fb923c">Sevoflurane</span> | 輕度 | 輕度血管擴張 | 不變/慢 |

Halothane有心肌致敏作用，與<span style="color:#f87171">**Epinephrine（腎上腺素）**</span>併用可能引發心室心律不整。

#### C. 呼吸效應

- 所有吸入性麻醉藥（除N<sub>2</sub>O外）呈劑量依賴性呼吸抑制
- 降低潮氣量、增加呼吸頻率（快速淺呼吸模式）
- 降低對高二氧化碳血症與低氧血症的通氣反應
- <span style="color:#60a5fa">Sevoflurane</span>與<span style="color:#60a5fa">Halothane</span>支氣管擴張，適合氣管反應性患者

#### D. 惡性高熱

<span style="color:#f87171">**惡性高熱（Malignant Hyperthermia）**</span> 為罕見但危及生命的遺傳性疾病，由鹵化烷類或<span style="color:#fb923c">Succinylcholine（琥珀膽鹼）</span>誘發。

<span style="color:#f87171">典型症狀：肌肉強直、體溫急遽升高、心動過速、高二氧化碳血症、高血鉀、代謝性酸中毒。</span>

治療：給予<span style="color:#fb923c">Dantrolene</span>（抑制肌質網鈣離子釋放），同時降溫、纠正電解質與酸鹼失衡。

#### E. 肝毒性

<span style="color:#f87171">Halothane肝炎（Halothane Hepatitis）</span>：約50,000至35,000名接觸Halothane患者中有1例出現猛爆性肝衰竭，可能與自由基形成或免疫反應有關。

### 各類吸入性麻醉藥特性

| 藥物 | 優點 | 缺點/注意事項 |
|------|------|-------------|
| <span style="color:#fb923c">Sevoflurane</span> | 誘導快速；支氣管擴張；對心臟刺激小 | 與乾燥鹼石灰產生compound A；肝臟代謝約2–5% |
| <span style="color:#fb923c">Desflurane</span> | 恢復最快（低溶解度）；肝臟代謝<0.05% | 呼吸道刺激強；不適合誘導 |
| <span style="color:#fb923c">Isoflurane</span> | 心肌保護；良好肌肉鬆弛 | 心率增快；對呼吸道有刺激 |
| <span style="color:#fb923c">Halothane</span> | 平穩誘導；無呼吸道刺激；支氣管擴張 | 心肌致敏；肝毒性；恢復較慢 |
| <span style="color:#fb923c">N<sub>2</sub>O（笑氣）</span> | 不完全麻醉但鎮痛強；誘導快；不改變心肌 | 需與其他麻醉藥合用；骨髓抑制（長期暴露）；禁用於氣胸/腸阻塞 |

## 第三節　靜脈注射麻醉藥

### 作用概論

靜脈注射麻醉藥主要用於麻醉誘導，具有快速起效、可控制性強的特點。其終止作用主要依賴**再分布（Redistribution）**至低灌注組織（如骨骼肌、脂肪），而非代謝排除。

<span style="color:#e2e8f0">**目標控制輸注（Target-Controlled Infusion, TCI）**</span>：根據藥物動力學模型設定血漿或效果室目標濃度，實現精確給藥。

### Propofol

<span style="color:#60a5fa">**Propofol（丙泊酚）**</span>是目前全球最廣泛使用的靜脈注射麻醉藥，化學結構為2,6-二異丙基苯酚。

#### 作用機轉
透過強化<span style="color:#60a5fa">GABA<sub>A</sub>受體</span>的氯離子內流，產生抑制性突觸傳遞。

#### 藥物動力學

| 參數 | 數值 |
|------|------|
| 誘導劑量 | 1–2.5 mg/kg IV |
| 起效時間 | 15–30秒 |
| 分布半衰期（t<sub>½α</sub>） | 2–4分鐘 |
| 消除半衰期（t<sub>½β</sub>） | 4–23小時 |
| 清除率 | 20–30 mL/kg/min |
| 蛋白結合率 | 97% |
| 持續輸注半時間 | 短（即使長時間輸注） |

Propofol的Context-sensitive half-time在所有靜脈麻醉藥中最短，適合持續輸注維持麻醉。

#### 臨床應用

| 應用場景 | 劑量/方式 |
|---------|---------|
| 麻醉誘導 | 1–2.5 mg/kg IV |
| 麻醉維持 | 100–200 mcg/kg/min（複合N<sub>2</sub>O或Opioid） |
| ICU鎮靜 | 25–75 mcg/kg/min |
| 術後止吐 | 10–20 mg IV 或 10 mcg/kg/min |

#### 器官系統效應

- **CNS**：降低腦血流量、腦代謝率、顱內壓、眼內壓；無鎮痛作用；可出現肌陣攣
- **心血管**：顯著血管擴張；血壓下降（老年人、容積不足患者更明顯）；可能出現心搏過緩
- **呼吸**：強效呼吸抑制；單次誘導劑量常見暫時性呼吸中止
- **其他**：注射疼痛（可用Lidocaine混合或選擇較大靜脈緩解）；術後噁心嘔吐少

<span style="color:#f87171">**Propofol輸注症候群（Propofol Infusion Syndrome）**</span>：長時間高劑量輸注後出現無法解釋的心搏過速、代謝性酸中毒，應立即停藥並給予支持性治療。

### Barbiturates（巴比妥鹽類）

<span style="color:#60a5fa">**Thiopental（硫噴妥鈉）**</span>與<span style="color:#60a5fa">**Methohexital（美索比妥）**</span>已大部分被Propofol取代，但仍具臨床價值。

#### 作用機轉
強化GABA<sub>A</sub>抑制性傳遞，同時可能抑制興奮性氨基酸傳遞。

#### 藥物動力學

| 參數 | Thiopental | Methohexital |
|------|-----------|-------------|
| 誘導劑量 | 3–5 mg/kg IV | 1–1.5 mg/kg IV |
| 起效 | <30秒 | <30秒 |
| 分布半衰期 | 2–4分鐘 | 5–6分鐘 |
| 消除半衰期 | 11小時 | 4小時 |
| 蛋白結合率 | 83% | 73% |

Thiopental主要經肝臟代謝；Methohexital清除率較高，恢復更快速完整。

#### 臨床應用

- 麻醉誘導（已被Propofol大幅取代）
- 顱內壓控制（強效腦血管收縮）
- 癲癇發作控制
- 兒科直腸誘導（Methohexital 20–30 mg/kg）

#### 注意事項

<span style="color:#f87171">**誤注入artery（誤入动脉）可能導致嚴重組織壞死**</span>；過敏反應罕見。

### Midazolam（咪達唑侖）

<span style="color:#60a5fa">**Midazolam（咪達唑侖）**</span>為短效Benzodiazepine類藥物，具有**鎮靜、抗焦慮、順向性遺忘**效果。

#### 藥物動力學

| 參數 | 數值 |
|------|------|
| 誘導劑量 | 0.1–0.3 mg/kg IV |
| 起效 | 15–20秒 |
| 分布半衰期 | 7–15分鐘 |
| 消除半衰期 | 1.7–2.6小時 |
| 蛋白結合率 | 94% |
| 逆轉劑 | Flumazenil（氟馬西尼） |

#### 臨床應用

- 術前給藥（1–2 mg IV）
- 區域麻醉鎮靜
- 門診手術鎮靜
- 癲癇持續狀態
- 兒科口服給藥（0.5 mg/kg，術前30分鐘）

<span style="color:#22d3ee">** Benzodiazepine類藥物的獨特優勢：可用Flumazenil逆轉，安全性較高。**</span>

### Etomidate（依托咪酯）

<span style="color:#60a5fa">**Etomidate（依托咪酯）**</span>的顯著特點為**對心血管系統影響極小**，適合血流動力學不穩定患者。

#### 藥物動力學

| 參數 | 數值 |
|------|------|
| 誘導劑量 | 0.2–0.3 mg/kg IV |
| 起效 | 3–8秒 |
| 分布半衰期 | 2–4分鐘 |
| 消除半衰期 | 2.9–5.3小時 |
| 清除率 | 18–25 mL/kg/min |
| 蛋白結合率 | 77% |

主要經肝臟與血漿膽鹼酯酶水解代謝；不到3%以原型經尿液排出。

#### 臨床特點

| 系統 | 效應 |
|------|------|
| CNS | 強效腦血管收縮（↓顱內壓）；可能激活癲癇灶；>50%患者出現肌陣攣 |
| 心血管 | **輕微**；心肌抑制輕微；血壓變化小 |
| 呼吸 | 呼吸抑制輕微（相對Barbiturates） |
| 內分泌 | **抑制11β-羥化酶**；皮質醇合成減少4–8小時；不建議持續輸注 |

<span style="color:#f87171">**禁忌**：因腎上腺抑制，不建議用於膿毒症或皮質醇缺乏患者。</span>

### Ketamine（氯胺酮）

<span style="color:#60a5fa">**Ketamine（氯胺酮）**</span>為<span style="color:#60a5fa">**NMDA受體拮抗劑**</span>，可產生獨特的**解離性麻醉（Dissociative anesthesia）**狀態，特點為眼睛張開、眼球震顫運動、咽喉反射保留。

#### 作用機轉
主要透過抑制<span style="color:#60a5fa">NMDA受體複合體</span>；S(+)-對映體效力為R(-)-的3倍。

#### 藥物動力學

| 參數 | 數值 |
|------|------|
| 誘導劑量（IV） | 1–2 mg/kg |
| 誘導劑量（IM） | 4–6 mg/kg |
| 起效（IV） | 30–60秒 |
| 作用持續時間 | 5–10分鐘 |
| 蛋白結合率 | 12%（所有靜脈麻醉藥中最低） |
| 消除半衰期 | 2–4小時 |

主要經肝臟CYP450 N-去甲基化代謝，產生活性代謝物Norketamine（效力為母藥的1/3至1/5）。

#### 臨床特點

| 系統 | 效應 |
|------|------|
| CNS | 強效鎮痛；**意識變化/幻覺**（苏醒期反應）；增加腦血流與CMR<sub>2</sub>；傳統上慎用於顱內壓升高患者 |
| 心血管 | **擬交感神經作用**；血壓、心率、心輸出量↑；直接心肌抑制（通常被擬交感作用掩蓋） |
| 呼吸 | 呼吸抑制輕微；支氣管擴張；增加唾液分泌 |
| 特殊 | 可經IV/IM/口服/直腸/硬膜外多途徑給藥 |

<span style="color:#f87171">**苏醒期精神反應（Emergence Reactions）**：夢境、幻覺、感覺扭曲；兒童發生率較低且程度較輕；與Benzodiazepine合用可減少此反應。</span>

#### 臨床應用

- 血流動力學不穩定患者
- 氣管反應性患者（支氣管擴張）
- 短小門診手術
- 區域麻醉輔助鎮痛（小劑量0.2–0.8 mg/kg IV）
- **亞鎮痛劑量輸注**（3–5 mcg/kg/min）減少Opioid耐受與痛覺過敏

### Dexmedetomidine（右美托咪定）

<span style="color:#60a5fa">**Dexmedetomidine（右美托咪定）**</span>為高選擇性<span style="color:#60a5fa">α<sub>2</sub>-腎上腺素受體激動劑</span>，可用α<sub>2</sub>-拮抗劑逆轉。

#### 藥物動力學

| 參數 | 數值 |
|------|------|
| 負荷劑量 | 0.5–1 mcg/kg（10–15分鐘輸注） |
| 維持輸注速率 | 0.2–0.7 mcg/kg/h |
| 分布半衰期 | 2–3分鐘 |
| 消除半衰期 | 2–3小時 |
| 蛋白結合率 | 94% |

主要經肝臟葡萄糖醛酸結合、N-甲基化與羥化代謝。

#### 臨床特點

- **CNS**：鎮靜（模擬生理睡眠）、催眠（作用於藍斑核）、鎮痛（作用於脊髓背角）
- **心血管**：中等程度↓心率與全身血管阻力；單次負荷可短暫↑血壓後↓心率
- **呼吸**：潮氣量輕度↓；對高二氧化碳通氣反應不變；無顯著呼吸抑制
- 可減少其他麻醉藥物劑量需求

#### 臨床應用

- ICU短期鎮靜（主要適應症）
- 清醒纖維光學氣管插管
- 區域麻醉輔助鎮靜
- 術後減少麻醉藥需求

### Opioid Analgesics（鴉片類止痛藥）

鴉片類藥物具有強效<span style="color:#60a5fa">**鎮痛**</span>效果，與麻醉藥物合用可減少後者用量。Fentanyl、Alfentanil、Sufentanil、Remifentanil為常用於麻醉的Opioid。Remifentanil因具有**組織與血漿非特異性酯酶代謝**特性，其半衰期不隨輸注時間延長，適合長時間輸注。

<span style="color:#f87171">**大劑量Opioid配合Benzodiazepine可用於心臟手術患者的靜脈複合麻醉。**</span>

## 第四節　臨床實務與麻醉技術

### 平衡麻醉（Balanced Anesthesia）

現代麻醉實踐結合多種藥物以達到理想麻醉效果並減少不良反應：

| 目的 | 藥物類別 |
|------|---------|
| 意識消失 | 吸入性麻醉劑、Propofol、Barbiturates |
| 遺忘 | Benzodiazepine類藥物（Midazolam） |
| 鎮痛 | Opioid（Fentanyl、Remifentanil）、Ketamine |
| 肌肉鬆弛 | 神經肌肉阻斷劑（Succinylcholine、Atracurium、Rocuronium） |

### 麻醉深度監測

| 技術 | 原理 |
|------|------|
| BIS（Bispectral Index） | 腦電波分析；數值40–60代表合適麻醉深度 |
| Entropy監測 | 監測聽覺誘發電位與EEG；評估意識狀態 |
| MAC引導 | 吸入性麻醉藥濃度達到適當MAC |

### 各類患者麻醉選擇原則

| 患者類型 | 推薦麻醉策略 |
|---------|-----------|
| 老年/心血管疾病 | Etomidate或小劑量Propofol；避免心肌抑制強的藥物 |
| 顱內壓升高 | Propofol或Thiopental（↓顱內壓）；避免高濃度Halothane |
| 氣管反應性（哮喘） | Sevoflurane或Halothane（支氣管擴張）；避免Desflurane |
| 膿毒症/腎上腺功能減退 | Ketamine（擬交感/不抑制皮質醇） |
| 惡性高熱病史 | 避免所有鹵化烷類與Succinylcholine；純靜脈麻醉（TIVA） |

## 第五節　重點摘要

- 全身麻醉的五大核心效果：意識消失、遺忘、鎮痛、自主神經反射抑制、骨骼肌鬆弛
- 吸入性麻醉藥的效力以<span style="color:#60a5fa">**MAC（最小肺泡濃度）**</span>表示，MAC值越低代表效力越強
- 血:氣分配係數決定麻醉藥的誘導與恢復速度；低溶解度藥物（如Desflurane、N<sub>2</sub>O）恢復最快
- <span style="color:#fb923c">Propofol</span>為目前最廣泛使用的靜脈注射麻醉藥，恢復快速且context-sensitive half-time短
- <span style="color:#fb923c">Ketamine</span>的NMDA受體拮抗作用提供強效鎮痛與解離性麻醉，但苏醒期幻覺限制使用
- <span style="color:#fb923c">Etomidate</span>對血流動力學影響最小，適合不穩定患者，但抑制腎上腺皮質醇合成
- <span style="color:#fb923c">Dexmedetomidine</span>的α<sub>2</sub>激動作用提供獨特鎮靜/鎮痛效果，適合ICU鎮靜
- <span style="color:#f87171">惡性高熱為威脅生命的麻醉併發症，治療首選Dantrolene</span>
- 平衡麻醉技術結合多種藥物，取長補短，是現代標準麻醉實踐
