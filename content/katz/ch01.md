## <span style="color:#60a5fa">藥物與受體：藥效學與藥物動力學概論</span>

## 章節導讀

<span style="color:#e2e8f0">藥理學</span>是研究藥物與生物體交互作用的科學，本章建立核心概念框架，包括<span style="color:#60a5fa">藥效學</span>（藥物對身體的作用）與<span style="color:#60a5fa">藥物動力學</span>（身體對藥物的處理）的基本原則，以及遺傳變異對藥物反應的深遠影響。

---

## 藥物與受體

### 受體的基本概念

<span style="color:#fb923c">受體（Receptor）</span>是細胞上的特定蛋白質結構，能與藥物分子結合並引發一系列生化反應，最終導致觀察到的藥理效應。藥物作為<span style="color:#60a5fa">激動劑（Agonist）</span>激活受體，或作為<span style="color:#60a5fa">拮抗劑（Antagonist）</span>阻止受體被激活。

藥物的分子特性決定其與受體的結合能力：

| 藥物特性 | 說明 |
|---------|------|
| 分子大小 | 多數藥物分子量介於 <span style="color:#34d399">100-1000</span> 之間 |
| 形狀與立體化學 | 必須與受體互補，<span style="color:#c084fc">手性（Chirality）</span>決定對映異構物的活性差異 |
| 鍵結方式 | 共價鍵（強、不可逆）> 靜電鍵 > 氫鍵 > 疏水性交互作用 |

<span style="color:#f87171">重要原則：鍵結越弱的藥物通常選擇性越高</span>，因為弱鍵需要藥物與受體精確契合。

### 藥物-受體鍵結類型

- **共價鍵**：強且通常不可逆，例如 <span style="color:#fb923c">Aspirin</span> 與 cyclooxygenase 的鍵結
- **靜電鍵**：從強離子鍵到弱氫鍵、范德華力
- **疏水性鍵**：對脂溶性藥物與細胞膜磷脂的交互作用很重要

## 藥物-身體交互作用

### 藥效學（Pharmacodynamics）

藥物作用於身體的基本模式：

```
藥物 + 受體 → 藥物-受體複合物 → 效應分子 → 生理效應
```

**藥物-受體交互作用類型：**

| 類型 | 說明 |
|------|------|
| <span style="color:#34d399">完全激動劑（Full Agonist）</span> | 佔據受體後產生最大效應 |
| <span style="color:#fb923c">部分激動劑（Partial Agonist）</span> | 佔據全部受體仍無法產生最大效應；同時具有 agonist 與 antagonist 特性 |
| <span style="color:#60a5fa">競爭性拮抗劑</span> | 與 agonist 競爭結合受體，高濃度 agonist 可逆轉 |
| <span style="color:#f87171">不可逆拮抗劑</span> | 以共價鍵結合受體，降低最大效應且不被 agonist 逆轉 |
| <span style="color:#c084fc">反向激動劑（Inverse Agonist）</span> | 穩定受體於非活性構象，減少基礎活性 |

### 藥物動力學（Pharmacokinetics）

身體對藥物的處理過程：

- **吸收（Absorption）**：藥物由給藥部位進入血液
- **分布（Distribution）**：藥物進入體內各組織區室
- **代謝（Metabolism）**：藥物被肝臟等組織轉化
- **排泄（Excretion）**：藥物或其代謝物離開體內

## 藥物穿透細胞膜

藥物穿透細胞膜的主要機制：

| 機制 | 說明 |
|------|------|
| <span style="color:#22d3ee">水相擴散</span> | 分子通過水溶性通道，服從 Fick's law |
| <span style="color:#22d3ee">脂質擴散</span> | 多數藥物的主要穿透方式；取決於藥物的 <span style="color:#34d399">脂溶性/水溶性分配係數</span> |
| <span style="color:#fb923c">特殊載體轉運</span> | ABC 家族轉運蛋白（如 P-glycoprotein/MDR1）、SLC 家族 |
| <span style="color:#c084fc">胞吞/胞泌</span> | 大分子藥物的摄取方式，如維生素 B₁₂ 與鐵的轉運 |

### Henderson-Hasselbalch 方程式

弱酸與弱鹼藥物的離子化程度受 pH 影響：

- **酸性藥物**：pH = pKa + log([A⁻]/[HA]) — <span style="color:#34d399">低 pH 環境中更具脂溶性</span>
- **鹼性藥物**：pH = pKa + log([B]/[BH⁺]) — <span style="color:#34d399">高 pH 環境中更具脂溶性</span>

## 藥物基因體學

### 基因剔除與敲入技術

- **Knockout mice（基因剔除小鼠）**：剔除特定基因，完全或部分抑制該基因功能
- **Knockin mice（基因敲入小鼠）**：過量表現特定蛋白質
- **Knockdown mice**：部分抑制基因表現

這些動物模型幫助研究受體或內源性配體的生理角色。

### 藥物基因體學（Pharmacogenomics）

研究基因變異如何影響個體間的藥物反應差異：

| 基因變異 | 臨床影響 |
|---------|---------|
| <span style="color:#c084fc">CYP2D6</span> 多型性 | 快/慢代謝者，影響 <span style="color:#fb923c">Codeine</span>（需 CYP2D6 轉化為 morphine）、<span style="color:#fb923c">Beta-blockers</span> 療效 |
| <span style="color:#c084fc">CYP2C9</span> 多型性 | <span style="color:#fb923c">Warfarin</span> 劑量需求差異 |
| <span style="color:#c084fc">CYP2C19</span> 多型性 | 影響 <span style="color:#fb923c">Clopidogrel</span> 活化 |

## 藥物命名與法規

### 受體命名

採用 <span style="color:#60a5fa">IUPHAR</span>（國際藥理學聯合會）的命名標準，不同受體類型包括：

- 離子通道型受體（如 nAChR、GABA_A 受體）
- G 蛋白偶聯受體（GPCR）
- 酪氨酸激酶型受體（如胰島素受體）

### 製藥產業

- 真正的新藥發現需要找到新的<span style="color:#60a5fa">藥物標靶（Drug Target）</span>
- 藥物開發過程漫長且昂貴（平均 10-15 年，數十億美元）
- <span style="color:#fb923c">Big Pharma</span> 在藥物優化、開發和商業化中扮演關鍵角色
