## 章節導讀

本章節介紹四環素類（Tetracyclines）、巨環類（Macrolides）、Clindamycin 與 Chloramphenicol 的藥理學，包括抗菌譜、作用機轉與不良反應。這些藥物主要抑制細菌蛋白質合成，多為<span style="color:#60a5fa"> bacteriostatic</span>。

## Tetracyclines, Macrolides, Clindamycin, Chloramphenicol

### 四環素類（Tetracyclines）

**作用機轉：**

四環素類為<span style="color:#60a5fa">廣效 bacteriostatic 抗生素</span>。藥物進入細菌後，與<span style="color:#22d3ee">30S 核糖體</span>可逆性結合，阻止<span style="color:#60a5fa"> aminoacyl-tRNA</span> 與<span style="color:#60a5fa"> mRNA-ribosome complex</span> 的接受位點結合，阻斷蛋白質合成。

**抗菌譜：**

- <span style="color:#c084fc">立克次體</span>（Rickettsia）：斑疹熱、叢林斑疹傷寒
- <span style="color:#c084fc">黴漿菌</span>（Mycoplasma pneumoniae）
- <span style="color:#c084fc">披衣菌</span>（Chlamydia）：砂眼、肺炎
- <span style="color:#c084fc">螺旋體</span>（Borrelia、Leprosy）
- 某些<span style="color:#c084fc">革蘭氏陽性</span>和<span style="color:#c084fc">革蘭氏陰性菌</span>

**常用藥物：**

| 藥物 | 特色 | 臨床應用 |
|------|------|----------|
| <span style="color:#fb923c">tetracycline</span> | 短效（t½ 6-8h） | 立克次體感染 |
| <span style="color:#fb923c">doxycycline</span> | 長效（t½ 16-18h），每日一次 | 萊姆病、洛基山斑疹熱 |
| <span style="color:#fb923c">minocycline</span> | 高組織穿透性 | 腦膜炎帶菌者、痤瘡 |
| <span style="color:#fb923c">tigecycline</span> |  glycolylcycline，廣效 | 複雜性皮膚/腹腔感染 |

**抗藥性機制：**

1. **外排泵（Efflux pump）**：將藥物排出菌體
2. **核糖體保護蛋白**（如 Tet(M)）：干擾四環素與核糖體結合
3. **酶性去活化**

<span style="color:#fb923c">tigecycline</span> 因其龐大的 t-butylglycylamido 取代基，對上述抗藥性機制有防護作用。

**不良反應：**

- <span style="color:#f87171">胃腸道刺激</span>：噁心、嘔吐、腹瀉
- <span style="color:#f87171">牙齒和骨頭沉積</span>：與鈣離子整合，孕婦和 8 歲以下兒童禁用
- <span style="color:#f87171">光敏感</span>：尤其 doxycycline
- <span style="color:#f87171">肝毒性</span>：大劑量靜脈給藥

### 巨環類抗生素（Macrolides）

**作用機轉：**

巨環類與<span style="color:#22d3ee">50S 核糖體</span>結合，抑制<span style="color:#60a5fa">轉肽酶（transpeptidase）</span>反應和<span style="color:#60a5fa">位移（translocation）</span>，阻斷蛋白質合成。為<span style="color:#60a5fa"> bacteriostatic</span>。

**抗菌譜：**

- <span style="color:#c084fc">革蘭氏陽性菌</span>：<span style="color:#c084fc">葡萄球菌</span>、<span style="color:#c084fc">鏈球菌</span>
- <span style="color:#c084fc">螺旋體</span>：梅毒、Leptospirosis
- <span style="color:#c084fc">黴漿菌</span>、<span style="color:#c084fc">退伍軍人菌</span>（Legionella）
- <span style="color:#c084fc">披衣菌</span>、<span style="color:#c084fc">披蟲</span>

**常用藥物：**

| 藥物 | 特色 | 臨床應用 |
|------|------|----------|
| <span style="color:#fb923c">erythromycin</span> | 原型藥，短效 | 螺旋體、肺炎黴漿菌 |
| <span style="color:#fb923c">azithromycin</span> | 半衰期長（40-68h），每日一次 | 社區肺炎、披衣菌 |
| <span style="color:#fb923c">clarithromycin</span> | 對 H. pylori、MAC 較好 | 消化性潰�、MAC |

<span style="color:#fb923c">azithromycin</span> 單次口服 1g 可治療<span style="color:#c084fc">披衣菌</span>性子宮頸炎或<span style="color:#c084fc">淋病</span>。

**不良反應：**

- <span style="color:#f87171">胃腸道刺激</span>：最常見
- <span style="color:#f87171">QT 間隔延長</span>：心律不整風險
- <span style="color:#f87171">肝毒性</span>：膽汁淤積性肝炎

### 林可醯胺類（Clindamycin）

**作用機轉：**

<span style="color:#fb923c">clindamycin</span> 與<span style="color:#22d3ee">50S 核糖體</span>結合，抑制蛋白質合成。對<span style="color:#c084fc">厭氧菌</span>有很強活性，包括<span style="color:#c084fc">Bacteroides</span>、<span style="color:#c084fc">Clostridium</span>。

**臨床應用：**

- 骨盆腔感染（盆腔炎、子宮內膜感染）
- 腹腔感染（與革蘭氏陰性菌覆蓋藥物合用）
- 皮膚/軟組織感染
- <span style="color:#f87171">艱難梭菌（<span style="color:#c084fc">C difficile</span>）結腸炎</span>：口服 vancomycin 或 fidaxomicin 為首選

**不良反應：**

- <span style="color:#f87171">腹瀉</span>：常見
- <span style="color:#f87171">C difficile 相關腸炎</span>：可能嚴重
- <span style="color:#f87171">過敏反應</span>

### 氯黴素（Chloramphenicol）

**作用機轉：**

<span style="color:#fb923c">chloramphenicol</span> 與<span style="color:#22d3ee">50S 核糖體</span>的<span style="color:#60a5fa"> peptidyl transferase</span> 結合，抑制肽鍵形成。為<span style="color:#60a5fa"> bacteriostatic</span>。

**抗菌譜：**

- <span style="color:#c084fc">傷寒沙門氏菌</span>（Salmonella typhi）
- <span style="color:#c084fc">流感嗜血桿菌</span>（H influenzae）
- <span style="color:#c084fc">腦膜炎球菌</span>（N meningitidis）
- <span style="color:#c084fc">肺炎球菌</span>（S pneumoniae）

**臨床應用：**

- 傷寒熱（now 優先用 fluoroquinolones 或 ceftriaxone）
- 细菌性腦膜炎（當其他藥物無效時）
- <span style="color:#f87171">立克次體感染</span>（對四環素過敏之孕婦）

**不良反應：**

- <span style="color:#f87171">骨髓抑制</span>：劑量相關、可逆性
- <span style="color:#f87171">再生不良性貧血</span>：罕見但致命，與劑量無關
- <span style="color:#f87171">灰色嬰兒症候群</span>（Gray baby syndrome）：新生兒肝臟代謝不足所致

### 其他相關藥物

**Oxazolidinones：**
<span style="color:#fb923c">linezolid</span>：對<span style="color:#c084fc">MRSA</span>、<span style="color:#c084fc">VRE</span>有效。抑制 50S 核糖體的 initiation complex 形成。副作用包括血小板減少、周邊神經病變。

**Streptogramins：**
<span style="color:#fb923c">quinupristin/dalfopristin</span>（Synercid）：對<span style="color:#c084fc">VRE</span>有效。靜脈給藥。

## 重點摘要

- 四環素類抑制 30S 核糖體，為广效 bacteriostatic 抗生素
- 四環素類禁用於孕婦和 8 歲以下兒童（牙齒/骨頭沉積）
- 巨環類抑制 50S 核糖體，對呼吸道病原體和性傳染病原有效
- Azithromycin 半衰期長，單次給藥便利
- Clindamycin 對厭氧菌有效，常用於骨盆腔感染
- Chloramphenicol 為後線藥物，有骨髓抑制風險
