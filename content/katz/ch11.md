## <span style="color:#60a5fa">Vasodilators and Treatment of Angina Pectoris</span>

## 章節導讀

<span style="color:#e2e8f0">血管擴張劑</span>與<span style="color:#e2e8f0">心絞痛治療</span>是心血管藥理的核心應用。本章涵蓋<span style="color:#fb923c">硝酸鹽類</span>、<span style="color:#fb923c">鈣離子通道阻斷劑</span>、<span style="color:#fb923c">ACE 抑制劑</span>、<span style="color:#fb923c">ARB</span> 等藥物在高血壓與心絞痛中的臨床應用。

---

## 中樞性交感神經抑制劑

### Clonidine

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#60a5fa">中樞性 α2 激動劑</span>，減少交感神經輸出 |
| 副作用 | 鎮靜、口乾 |
| <span style="color:#f87171">停藥反彈</span> | 高劑量長期使用後突然停藥可致<span style="color:#f87171">高血壓危象</span> |

### Methyldopa

| 特性 | 說明 |
|------|------|
| 機轉 | 中樞性 α2 激動劑（偽神經傳導物質）|
| 臨床特點 | <span style="color:#34d399">懷孕時高血壓的首選藥物之一</span> |
| 副作用 | 鎮靜、肝功能異常、Coombs 試驗陽性 |

---

## 腎上腺素神經阻斷劑

### Guanethidine

| 特性 | 說明 |
|------|------|
| 機轉 | 阻斷 NE 從交感神經末梢釋放（攝取進入囊泡置換 NE）|
| 副作用 | 姿勢性低血壓、腹瀉、性功能障礙 |
| 現況 | 臨床上已少用 |

### Reserpine

| 特性 | 說明 |
|------|------|
| 機轉 | 阻斷囊泡攝取和儲存單胺類神經傳導物質 |
| 副作用 | <span style="color:#f87171">憂鬱、精神病</span>（中樞胺類耗竭）、帕金森氏症症狀、胃腸道不適 |

---

## 直接血管擴張劑

### Hydralazine

| 特性 | 說明 |
|------|------|
| 機轉 | 釋放 NO，擴張小動脈（對靜脈作用小）|
| 臨床用途 | 高血壓；與硝酸鹽合用治療心衰竭 |
| 副作用 | 反射性心搏過速、紅斑性狼瘡樣症候群（劑量 > 400 mg/day）|

### Minoxidil

| 特性 | 說明 |
|------|------|
| 機轉 | 開啟 K⁺ 通道，穩定平滑肌細胞膜 |
| 臨床用途 | 嚴重或腎衰竭相關高血壓 |
| 副作用 | 反射性心搏過速、<span style="color:#f87171">多毛症</span>（女性困擾）|

### Sodium Nitroprusside

| 特性 | 說明 |
|------|------|
| 機轉 | 釋放 NO，激活 guanylyl cyclase → ↑cGMP |
| 作用時間 | <span style="color:#34d399">數分鐘內生效，停藥後效應立即消失</span> |
| 臨床用途 | <span style="color:#f87171">高血壓急症</span> |
| 副作用 | <span style="color:#f87171">氰化物中毒</span>（嚴重）|

### Diazoxide

| 特性 | 說明 |
|------|------|
| 機轉 | 開啟 K⁺ 通道 |
| 臨床用途 | 高血壓急症 |
| 副作用 | 過度低血壓、高血糖 |

### Fenoldopam

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#fb923c">Dopamine D1 受體激動劑</span> |
| 臨床用途 | 高血壓急症、術後高血壓 |

---

## ACE 抑制劑

### 作用機制

<span style="color:#fb923c">ACE 抑制劑</span>抑制血管張力素轉化酶，減少血管張力素 II 生成並增加 bradykinin 作用。

| 效應 | 說明 |
|------|------|
| ↓ Angiotensin II | 血管擴張，減少醛固酮 |
| ↑ Bradykinin | NO、前列腺素釋放增加 |

### 代表藥物

| 藥物 | 特性 |
|------|------|
| <span style="color:#fb923c">Captopril</span> | 短效，硫醇基團 |
| <span style="color:#fb923c">Enalapril</span> | 前驅藥 |
| <span style="color:#fb923c">Lisinopril</span> | 長效 |
| <span style="color:#fb923c">Ramipril</span>、<span style="color:#fb923c">Quinapril</span> | 長效 |

### 副作用

| 副作用 | 說明 |
|-------|------|
| <span style="color:#f87171">乾咳</span> | Bradykinin 累積 |
| <span style="color:#f87171">血管性水腫</span> | 可能致命（喉部水腫）|
| <span style="color:#f87171">高血鉀</span> | 醛固酮減少 |
| <span style="color:#f87171">腎功能惡化</span> | 雙側腎动脉狹窄患者 |
| <span style="color:#f87171">胎兒毒性</span> | 懷孕第二、三期禁用 |

---

## 血管張力素受體阻斷劑（ARBs）

<span style="color:#fb923c">Losartan</span>、<span style="color:#fb923c">Valsartan</span>、<span style="color:#fb923c">Candesartan</span> 等阻斷 AT1 受體。

| 特性 | 說明 |
|------|------|
| 選擇性 | 不影響 bradykinin 代謝 |
| 副作用 | 血管性水腫（較 ACE 抑制劑少）、咳嗽（少）|

---

## 鈣離子通道阻斷劑

### 分類

| 類別 | 代表藥物 | 心臟作用 |
|------|---------|---------|
| <span style="color:#60a5fa">非二氫吡啶類</span> | Verapamil、Diltiazem | 心臟抑制（↓ 傳導、↓ 收縮力）|
| <span style="color:#34d399">二氫吡啶類</span> | Amlodipine、Nifedipine、Felodipine | 主要血管擴張 |

### 二氫吡啶類

| 藥物 | 半衰期 | 特性 |
|------|-------|------|
| <span style="color:#fb923c">Amlodipine</span> | 長 | 每日一次，周邊水腫 |
| <span style="color:#fb923c">Nifedipine</span> | 短 | 反射性心搏過速 |
| <span style="color:#fb923c">Felodipine</span> | 中 | 血管選択性 |

### 適應症

| 藥物 | 高血壓 | 心絞痛 | 心律不整 |
|------|-------|------|---------|
| <span style="color:#fb923c">Verapamil</span> | ✓ | ✓ | ✓ |
| <span style="color:#fb923c">Diltiazem</span> | ✓ | ✓ | ✓ |
| <span style="color:#fb923c">Amlodipine</span> | ✓ | ✓ | — |

## 高血壓治療原則

### 目標血壓

| 患者類型 | 目標血壓 |
|---------|---------|
| 一般患者 | < 140/90 mmHg |
| 糖尿病或慢性腎病患者 | < 130/80 mmHg |

### 第一線藥物選擇

| 臨床情況 | 建議藥物類別 |
|---------|------------|
| 一般高血壓 | Thiazide 利尿劑、ACE 抑制劑/ARB、CCB、β 阻斷劑 |
| 糖尿病/腎病 | ACE 抑制劑/ARB |
| 心絞痛 | β 阻斷劑、CCB |
| 心衰竭 | ACE 抑制劑/ARB、β 阻斷劑 |
| BPH（男性）| α1 阻斷劑 |

### 联合治療

當單一藥物無法控制血壓時，需加入第二種藥物，通常包括利尿劑。

| 藥物 | 機轉 | 臨床用途 | 副作用 |
|------|------|---------|-------|
| <span style="color:#fb923c">Clonidine</span> | 中樞性 α2 激動劑 | 高血壓（懷孕時）| 鎮靜、口乾、<span style="color:#f87171">停藥反彈性高血壓</span> |
| <span style="color:#fb923c">Methyldopa</span> | 中樞性 α2 激動劑 | 懷孕時高血壓 | 鎮靜、肝功能異常、Coombs 陽性 |
| <span style="color:#fb923c">Guanethidine</span> | 阻斷 NE 釋放 | 嚴重高血壓（少用）| 姿勢性低血壓、腹瀉、性功能障礙 |
| <span style="color:#fb923c">Reserpine</span> | 阻斷囊泡攝取單胺類 | 高血壓（少用）| <span style="color:#f87171">憂鬱</span>、帕金森氏症 |
| <span style="color:#fb923c">Hydralazine</span> | 釋放 NO | 高血壓、心衰竭（+硝酸鹽）| 反射性心搏過速、<span style="color:#f87171">SLE 樣症候群</span> |
| <span style="color:#fb923c">Minoxidil</span> | 開啟 K⁺ 通道 | 嚴重高血壓 | 反射性心搏過速、<span style="color:#f87171">多毛症</span> |
| <span style="color:#fb923c">Sodium Nitroprusside</span> | 釋放 NO | <span style="color:#f87171">高血壓急症</span> | <span style="color:#f87171">氰化物中毒</span> |
| <span style="color:#fb923c">Diazoxide</span> | 開啟 K⁺ 通道 | 高血壓急症 | 過度低血壓、高血糖 |
| <span style="color:#fb923c">Fenoldopam</span> | D1 agonist | 高血壓急症 | 反射性心搏過速、頭痛 |
| <span style="color:#fb923c">Captopril</span> | ACE 抑制劑 | 高血壓、心衰竭、糖尿病腎病 | <span style="color:#f87171">乾咳</span>、血管性水腫、高血鉀 |
| <span style="color:#fb923c">Enalapril</span> | ACE 抑制劑（前驅）| 高血壓、心衰竭 | 乾咳、血管性水腫、高血鉀 |
| <span style="color:#fb923c">Lisinopril</span> | ACE 抑制劑 | 高血壓、心衰竭 | 乾咳、血管性水腫、高血鉀 |
| <span style="color:#fb923c">Losartan</span> | AT1 阻斷劑 | 高血壓、心衰竭、糖尿病腎病 | 血管性水腫（少）|
| <span style="color:#fb923c">Valsartan</span> | AT1 阻斷劑 | 高血壓、心衰竭 | 血管性水腫（少）|
| <span style="color:#fb923c">Amlodipine</span> | CCB（二氫吡啶）| 高血壓、心絞痛 | 周邊水腫、頭痛 |
| <span style="color:#fb923c">Verapamil</span> | CCB（非二氫吡啶）| 高血壓、心絞痛、心律不整 | 心搏過緩、便祕、心衰竭 |
| <span style="color:#fb923c">Diltiazem</span> | CCB（非二氫吡啶）| 高血壓、心絞痛、心律不整 | 心搏過緩、頭痛、浮腫 |
