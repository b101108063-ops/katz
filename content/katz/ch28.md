## 章節導讀

憂鬱症是全球最主要的致殘性疾病之一，抗憂鬱藥物的發展經歷了從三環類到選擇性血清素回收抑制劑的重大演進。本章節系統探討單胺類神經傳遞物質與憂鬱症的病理生理學，並深入分析各類抗憂鬱藥物——包括SSRIs、SNRIs、TCAs、MAOIs及新型抗憂鬱藥——的藥理特性、臨床應用與不良反應，以及它們在焦慮症、強迫症創傷後壓力症候群等疾病的應用。

## <span style="color:#60a5fa">Antidepressants</span>

Depression is one of the leading causes of disability worldwide, and the development of antidepressant drugs has undergone significant evolution from tricyclics to selective serotonin reuptake inhibitors. This chapter systematically explores the pathophysiology of monoamine neurotransmitters and depression, and provides an in-depth analysis of various antidepressant drug classes—including SSRIs, SNRIs, TCAs, MAOIs, and novel antidepressants—their pharmacological properties, clinical applications, and adverse effects, as well as their use in anxiety disorders, obsessive-compulsive disorder, and post-traumatic stress disorder.

## 第一節　憂鬱症的病理生理學

### 單胺類假說

<span style="color:#e2e8f0">**單胺類假說（Monoamine Hypothesis）**</span>提出憂鬱症與腦內單胺類神經傳遞物質（<span style="color:#60a5fa">**血清素（5-HT）**</span>、<span style="color:#60a5fa">**正腎上腺素（NE）**</span>、<span style="color:#60a5fa">**多巴胺（DA）**</span>）功能不足有關。

| 神經傳遞物質 | 與憂鬱症的關聯 |
|-------------|--------------|
| **5-HT（血清素）** | 最核心；SSRIs為一線治療；5-HT前驅（色氨酸/5-HTP）可能有效 |
| **NE（正腎上腺素）** | TCA類主要作用；SNRIs（Venlafaxine、Duloxetine）同時作用於5-HT與NE |
| **DA（多巴胺）** | 動機/獎勵系統；Bupropion增加DA；憂鬱症患者DA功能低下 |

### 訊號傳遞與神經可塑性異常

現代研究顯示憂鬱症與以下異常相關：

| 機轉 | 說明 |
|------|------|
| **cAMP-CREB訊號路徑** | 長期抗憂鬱治療上調cAMP路徑，增加BDNF（腦衍生神經滋養因子）表現 |
| **GSK-3（糖原合成酶激酶-3）** | 情緒調節；鋰鹽抑制GSK-3 |
| **血清素轉運體（SERT）** | 基因多形性（5-HTTLPR）與Stress交互影響憂鬱風險 |
| **下丘腦-腦垂腺-腎上腺軸（HPA axis）** | 過度活化；皮質醇升高；影響情緒調節 |

## 第二節　選擇性血清素回收抑制劑（SSRIs）

### 作用機轉

<span style="color:#60a5fa">**SSRIs（Selective Serotonin Reuptake Inhibitors）**</span>選擇性抑制<span style="color:#e2e8f0">**血清素轉運體（SERT）**</span>，使突觸間隙血清素濃度增加。

| 藥物 | 標準劑量 | 半衰期 | 活性代謝物 | 特點 |
|------|---------|--------|----------|------|
| <span style="color:#fb923c">Fluoxetine</span> | 20–80 mg/d | 4–6天 | **Yes（Norfluoxetine，7–15天）** | 抑制CYP2D6；長效 |
| <span style="color:#fb923c">Sertraline</span> | 50–200 mg/d | 26小時 | No | 抑制CYP2D6/1A2；對PYY影響小 |
| <span style="color:#fb923c">Paroxetine</span> | 20–50 mg/d | 21小時 | No | **抗膽鹼作用最強**；抑制CYP2D6 |
| <span style="color:#fb923c">Fluvoxamine</span> | 50–300 mg/d | 15.6小時 | No | **抑制CYP1A2、CYP2C19**；強迫症常用 |
| <span style="color:#fb923c">Citalopram</span> | 20–60 mg/d | 35小時 | No | 抑制CYP2D6（輕度）；QTc延長風險 |
| <span style="color:#fb923c">Escitalopram</span> | 10–20 mg/d | 27–32小時 | No | Citalopram S(+)對映體；選擇性更強 |

### 臨床應用

| 適應症 | 說明 |
|--------|------|
| **重鬱症（MDD）** | 第一線治療 |
| **廣泛性焦慮症（GAD）** | 一線治療之一 |
| **社交焦慮症（SAD）** | 一線治療 |
| **恐慌症（Panic Disorder）** | 有效；可能初期加重需低劑量起始 |
| **強迫症（OCD）** | 高劑量；療效低於憂鬱 |
| **創傷後壓力症候群（PTSD）** | 一線治療之一 |
| **經前不悅症（PMDD）** | 間歇性給藥（月經週期） |

### 不良反應

| 系統 | 表現 | 說明 |
|------|------|------|
| **胃腸道** | 噁心（30%）、腹瀉 | 5-HT<sub>3</sub>刺激；通常2–4週改善 |
| **性功能** | 性慾減退、勃起/潤滑障礙、延遲性高潮 | **最常見的治療中断原因**；5-HT<sub>2</sub>/5-HT<sub>3</sub>作用 |
| **CNS** | 頭痛、焦慮/激越、失眠或嗜睡 | 初期常見；失眠可用鎮靜SSRI早晨給藥 |
| **停藥反應** | 頭暈、「電擊」感（Paresthesias）、流感樣症狀 | **不可骤然停藥**；需漸進減量 |
| **其他** | 體重變化（輕度） | Fluoxetine/Paroxetine可能增加 |

<span style="color:#f87171">**Serotonin症候群（血清素症候群）**：SSRI與MAOIs、SRI、Tramadol、Meperidine、鋰鹽合用可能引起；表現：激越、高熱、反射亢進、肌陣政、出汗、顫抖。需立即停藥/支持性治療。</span>

## 第三節　血清素-正腎上腺素回收抑制劑（SNRIs）

<span style="color:#60a5fa">**SNRIs（Serotonin-Norepinephrine Reuptake Inhibitors）**</span>同時抑制SERT與<span style="color:#e2e8f0">**正腎上腺素轉運體（NET）**</span>。

| 藥物 | 劑量 | 半衰期 | 受體作用 | 特點 |
|------|------|--------|---------|------|
| <span style="color:#fb923c">Venlafaxine</span> | 37.5–225 mg/d（分次/緩釋） | 5小時 | **無其他受體作用** | 對NE作用隨劑量增加而增加；對GAD有效 |
| <span style="color:#fb923c">Desvenlafaxine</span> | 50–100 mg/d | 11小時 | 無 | Venlafaxine活性代謝物；無明顯CYP交互 |
| <span style="color:#fb923c">Duloxetine</span> | 30–120 mg/d | 12小時 | **輕度抑制DOPamine回收** | **對糖尿病神經痛有效**；對肌肉骨骼疼痛也有用 |
| <span style="color:#fb923c">Milnacipran</span> | 50–100 mg/d（分次） | 6–8小時 | **NE/5-HT比例約1:1** | 歐洲Fibromyalgia一線；美國用於Fibromyalgia |

### SNRIs不良反應

| 表現 | 說明 |
|------|------|
| 血壓升高 | Venlafaxine（劑量相關）；需監測血壓 |
| 噁心、便秘、口乾 | NE作用增加；比SSRIs更明顯 |
| 性功能障礙 | 類似SSRIs（但可能低於SSRIs） |
| 停藥反應 | 不可骤然停藥 |

## 第四節　三環類抗憂鬱藥物（TCAs）

<span style="color:#60a5fa">**TCAs（Tricyclic Antidepressants）**</span>為抗憂鬱藥物的經典類別，同時抑制5-HT與NE回收，也具有抗膽鹼、抗組織胺與α<sub>1</sub>阻斷作用。

| 藥物 | 5-HT/NE選擇性 | 抗膽鹼 | 鎮靜 | 說明 |
|------|--------------|--------|------|------|
| <span style="color:#fb923c">Clomipramine</span> | 5-HT>NE | 強 | 強 | **對OCD最有效** |
| <span style="color:#fb923c">Imipramine</span> | 5-HT=NE | 中等 | 中等 | 第一個TCA；原型 |
| <span style="color:#fb923c">Amitriptyline</span> | 5-HT>NE | 強 | 最強 | 對失眠/焦慮型憂鬱有效 |
| <span style="color:#fb923c">Nortriptyline</span> | NE>5-HT | 輕 | 輕 | 常用於老年人；治療藥物監測（TDM）有用 |
| <span style="color:#fb923c">Desipramine</span> | NE>5-HT | 最輕 | 最輕 | 主要NE抑制；對憂鬱/疼痛有效 |
| <span style="color:#fb923c">Doxepin</span> | 混合 | 強 | 強 | 也用於失眠/皮膚瘙癢（H1阻斷） |

### 不良反應

| 類別 | 表現 | 機轉 |
|------|------|------|
| **抗膽鹼** | 口乾、視力模糊（散瞳）、便祕、尿滯留、心搏過速、認知障礙（老年人） | Muscarinic受體阻斷 |
| **抗組織胺** | 嗜睡、體重增加 | H1受體阻斷 |
| **α<sub>1</sub>阻斷** | 姿態性低血壓（老年人跌倒風險） | α<sub>1</sub>-AR阻斷 |
| **心臟** | QTc延長、室性心律不整、傳導延遲 | 心肌離子通道作用 |
| **過量** | **致命**（心律不整/癲癇）；TCA過量死亡率高 | CNS/心臟毒性 |

<span style="color:#f87171">**TCA過量**：心搏過速、低血壓、意識改變、癲癇、心律不整（寬QRS）。處理：活性炭/鹽水灌腸；NaHCO<sub>3</sub>鹼化血漿（穩定心臟離子通道）；抗癲癇藥。</span>

## 第五節　單胺氧化酶抑制劑（MAOIs）

<span style="color:#60a5fa">**MAOIs（Monoamine Oxidase Inhibitors）**</span>抑制單胺氧化酶，減少兒茶酚胺/血清素降解，使單胺累積。

| 藥物 | MAO選擇性 | 可逆性 | 說明 |
|------|----------|--------|------|
| <span style="color:#fb923c">Phenelzine</span> | MAO-A=MAO-B | 不可逆 | 高血壓危機風險 |
| <span style="color:#fb923c">Tranylcypromine</span> | MAO-A=MAO-B | 不可逆 | 可能中樞刺激更強 |
| <span style="color:#fb923c">Isocarboxazid</span> | MAO-A=MAO-B | 不可逆 | 療效類似；但肝毒性 |
| <span style="color:#fb923c">Selegiline（口服，低劑量）</span> | MAO-B>MAO-A（低劑量） | 不可逆 | **帕金森氏症/憂鬱（低劑量5 mg）**；高劑量（10 mg+）抑制MAO-A |
| <span style="color:#fb923c">Moclobemide</span> | MAO-A（選擇性） | **可逆** | 歐洲/加拿大可用；對MAO-B作用弱；食物限制較少 |

### 高血壓危機（Hypertensive Crisis）

<span style="color:#f87171">**機轉**：MAOIs抑制腸道MAO-A，使食物中的Tyramine進入體循環，作為間接交感神經作用劑使血壓急劇升高。</span>

<span style="color:#f87171">**富含Tyramine食物（需避免）**：陳年起司、發酵肉/魚、醬油、紅酒、蠶豆、含咖啡因飲料。</span>

**表現**：嚴重高血壓（>200/120 mmHg）、顱內出血（可能致命）。

**處理**：Phentolamine（α阻斷劑）2–5 mg IV；或Nicardipine/拉貝他樂爾。

## 第六節　新型抗憂鬱藥物

### A. Bupropion

<span style="color:#60a5fa">**Bupropion（安非他酮）**</span>抑制<span style="color:#e2e8f0">**多巴胺（DA）**</span>與<span style="color:#e2e8f0">**NE**</span>回收；**無5-HT作用**。

| 特點 | 說明 |
|------|------|
| 優點 | **無性功能障礙**；體重中性；可用於戒菸（Wellbutrin/Zyban） |
| 缺點 | **降低癲癇閾值**；失眠；頭痛 |
| 禁用 | 癲癇病史、貪食/暴食症（增加癲癇風險）、使用MAOIs |

### B. Mirtazapine（米氮平）

| 特點 | 說明 |
|------|------|
| 機轉 | **α<sub>2</sub>-自體受體拮抗**（增加NE/5-HT釋放）；5-HT<sub>2</sub>/5-HT<sub>3</sub>阻斷；強效H1阻斷 |
| 優點 | **性功能障礙少**；對失眠/焦慮有效；快速起效（1–2週） |
| 缺點 | **顯著嗜睡**；體重增加（H1作用）；口乾（α<sub>2</sub>作用） |

### C. Trazodone（曲唑酮）

| 特點 | 說明 |
|------|------|
| 機轉 | **5-HT<sub>2A</sub>受體拮抗**；SERT抑制（弱） |
| 優點 | **對失眠有效**（低劑量50–100 mg）；無性功能障礙 |
| 缺點 | **姿態性低血壓**；嗜睡；長期使用可能陰莖異常勃起（Priapism） |

### D. Vilazodone（維拉唑酮）

| 特點 | 說明 |
|------|------|
| 機轉 | **SERT抑制 + 5-HT<sub>1A</sub>部分激動** |
| 優點 | 起效可能較快；性功能障礙比SSRIs少 |
| 缺點 | 胃腸道副作用；腹瀉 |

### E. Vortioxetine（沃替西汀）

| 特點 | 說明 |
|------|------|
| 機轉 | **SERT抑制 + 5-HT<sub>1A</sub>/5-HT<sub>1B</sub>激動 + 5-HT<sub>3</sub>/5-HT<sub>7</sub>/5-HT<sub>1D</sub>拮抗** |
| 優點 | 對認知功能可能有正面影響；性功能障礙適中 |
| 缺點 | 噁心（最常見） |

## 第七節　抗憂鬱藥物的臨床應用

### 憂鬱症的治療原則

| 原則 | 說明 |
|------|------|
| **單一療法優先** | 單一SSRI/SNRI/TCA起始；避免多重藥物同時起始 |
| **劑量漸增** | 降低初期副作用；減少停藥率 |
| **足療程** | 急性治療6–12週；緩解後維持6–12個月；復發者終身維持 |
| **療效顯現** | SSRIs/SNRIs：2–4週可能開始改善；完全療效需4–8週 |
| **反應不佳** | 換藥或加強（Augmentation：Bupropion、Aripiprazole、Quetiapine、Lithium） |

### 各類抗憂鬱藥的臨床選擇

| 患者特點 | 建議選擇 |
|---------|---------|
| 老年患者 | Escitalopram、Sertraline（Citalopram注意QTc） |
| 心血管疾病/QTc延長 | Sertraline、Escitalopram（心臟安全性較好） |
| 性功能障礙高風險 | **Bupropion**、Mirtazapine（作為SSRI輔助或替代） |
| 失眠患者 | Mirtazapine睡前、Trazodone |
| 慢性疼痛/纖維肌痛 | Duloxetine、Milnacipran |
| 強迫症（OCD） | **Clomipramine**、SSRIs（高劑量） |
| 恐慌症 | SSRIs（一線）、TCAs |
| 創傷後壓力症候群 | SSRIs（一線：Sertraline、Paroxetine）、Venlafaxine |
| 貪食/暴食症 | Fluoxetine（對暴食症有效） |
| 帕金森氏症憂鬱 | **SSRI需謹慎**（可能加重運動症狀）；Bupropion可能較安全 |

## 第八節　重點摘要

- 憂鬱症的主要病理生理涉及<span style="color:#60a5fa">**血清素（5-HT）**</span>、<span style="color:#60a5fa">**正腎上腺素（NE）**</span>與<span style="color:#60a5fa">**多巴胺（DA）**</span>系統的功能異常
- <span style="color:#fb923c">SSRIs</span>（Fluoxetine、Sertraline、Paroxetine、Citalopram、Escitalopram）為憂鬱症第一線治療
- <span style="color:#fb923c">SNRIs</span>（Venlafaxine、Duloxetine）同時作用於5-HT與NE，對慢性疼痛/纖維肌痛有效
- <span style="color:#fb923c">TCAs</span>（Amitriptyline、Nortriptyline）療效強但副作用多，過量可致命
- <span style="color:#fb923c">MAOIs</span>（Phenelzine、Tranylcypromine）對難治性憂鬱有效，但有高血壓危機風險，需飲食限制
- <span style="color:#fb923c">Bupropion</span>抑制DA/NE回收，無性功能障礙；但有癲癇風險
- <span style="color:#fb923c">Mirtazapine</span>的α<sub>2</sub>/5-HT<sub>2</sub>/5-HT<sub>3</sub>阻斷特點：嗜睡/體重增加，但性功能障礙少
- <span style="color:#f87171">所有抗憂鬱藥均需注意Serotonin症候群的風險</span>
- <span style="color:#f87171">TCA過量致死率高（心律不整），需緊急處理</span>
- 抗憂鬱藥治療需6–12週才能達到完全療效；緩解後應維持治療6–12個月
