## 章節導讀

造血過程需要鐵、維生素B12、葉酸等營養素以及造血生長因子的調控。本章節系統探討缺鐵性貧血、巨芽細胞性貧血（維生素B12/葉酸缺乏）與腎性貧血（紅血球生成素缺乏）的藥物治療，同時涵蓋鐮刀型貧血的藥物管理以及紅血球生成刺激劑的臨床應用。

---

## 第一節　鐵缺乏與缺鐵性貧血

### 鐵的生理學

<span style="color:#22d3ee">**鐵（Iron）**</span>是血紅蛋白（Hemoglobin）、肌紅蛋白（Myoglobin）與多種酶的必需成分。

| 鐵的分佈 | 男性（mg） | 女性（mg） |
|---------|---------|---------|
| 血紅蛋白 | 3050 | 1700 |
| 肌紅蛋白 | 430 | 300 |
| 儲存（鐵蛋白/含鐵血黃素） | 750 | 300 |
| 運輸（運鐵蛋白） | 8 | 6 |

<span style="color:#e2e8f0">**Hepcidin（鐵調素）**</span>為肝細胞分泌的激素，是鐵穩態的核心調節因子，負向調控腸道鐵吸收與巨噬細胞鐵釋放。

### 鐵吸收

| 因素 | 對吸收的影響 |
|------|------------|
| **鐵狀態** | 缺鐵時吸收↑；鐵過量時吸收↓ |
| **吸收形式** | 血紅素鐵（吸收率約25%）> 非血紅素鐵（2–5%） |
| **維生素C** | 將Fe<sup>3+</sup>還原為Fe<sup>2+</sup>→吸收↑ |
| **草酸/單寧酸/植酸** | 結合非血紅素鐵→吸收↓ |
| **胃酸** | 促進非血紅素鐵溶解→吸收↑ |
| **Hepcidin** | ↑Hepcidin→↓吸收 |

### 口服鐵劑

| 藥物 | 元素鐵含量 | 說明 |
|------|-----------|------|
| <span style="color:#fb923c">硫酸亞鐵（Ferrous Sulfate）</span> | 65 mg/325 mg | 最常用；性價比高 |
| <span style="color:#fb923c">葡萄糖酸亞鐵（Ferrous Gluconate）</span> | 36 mg/325 mg | 胃腸刺激較少 |
| <span style="color:#fb923c">富馬酸亞鐵（Ferrous Fumarate）</span> | 106 mg/325 mg | 元素鐵含量最高 |

<span style="color:#34d399">**標準劑量**：元素鐵150–200 mg/d，分1–3次空腹服用。</span>

| 不良反應 | 說明 |
|---------|------|
| 胃腸道 | 噁心、腹痛、便祕（常見）、腹瀉 |
| 糞便變色 | 黑色糞便（正常，應與胃腸道出血鑑別） |
| 鐵過載 | 長期大劑量可能導致（遺傳性血色素沉著症患者需注意） |

### 腸胃外鐵劑

| 適應症 | 說明 |
|--------|------|
| 口服鐵劑不耐 | 嚴重胃腸副作用 |
| 吸收不良 | 腹腔疾病、發炎性腸道疾病（Crohn's） |
| 慢性腎病 | EPO治療輔助 |
| 需求快速補充 | 嚴重貧血 |

| 藥物 | 給藥方式 | 說明 |
|------|---------|------|
| <span style="color:#fb923c">蔗糖鐵（Iron Sucrose）</span> | 靜脈 | 安全；常用於CKD |
| <span style="color:#fb923c">葡萄糖酸亞鐵（Ferric Gluconate）</span> | 靜脈 | 低游離鐵風險 |
| <span style="color:#fb923c">Ferric Carboxymaltose</span> | 靜脈 | 大劑量快速輸注（15分鐘） |
| <span style="color:#fb923c">低分子量右旋糖酐鐵（Iron Dextran）</span> | 靜脈/肌肉 | 過敏反應風險較高；需試驗劑量 |

## 第二節　維生素B12與葉酸

### 維生素B12（Cobalamin）

<span style="color:#60a5fa">**維生素B12**</span>為DNA合成、紅血球成熟與神經功能所必需。

| 缺乏原因 | 說明 |
|---------|------|
| **惡性貧血** | 胃壁細胞破壞→內在因子（Intrinsic Factor）缺乏→回腸吸收障礙 |
| 胃切除術 | 內在因子↓ |
| 迴腸疾病/切除 | 吸收障礙 |
| 嚴格素食 | 飲食缺乏（植物中無活性B12） |

#### 製劑

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">氰鈷胺（Cyanocobalamin）</span> | 口服/肌肉注射；常用 |
| <span style="color:#fb923c">氫鈷胺素（Hydroxocobalamin）</span> | 肌肉注射；停留時間較長 |
| <span style="color:#fb923c">甲基鈷胺素（Methylcobalamin）</span> | 口服（可能被吸收）；可能較好 |

<span style="color:#34d399">**劑量參考**：起始：1000 mcg IM 每週一次×3–4週；然後每月一次；或1000–2000 mcg/d口服。</span>

| 不良反應 | 說明 |
|---------|------|
| 過敏反應 | 罕見（對鈷過敏） |
| 低血鉀 | 治療初期可能（紅血球生成對鉀需求↑） |
| 尿酸↑ | 治療初期（核酸分解↑） |

### 葉酸（Folic Acid）

<span style="color:#60a5fa">**葉酸**</span>為一碳單位載體，參與DNA/RNA合成。

| 適應症 | 說明 |
|--------|------|
| **巨芽細胞性貧血** | 與B12缺乏相似；主要見於營養不良、妊娠、酒精濫用 |
| **妊娠** | 預防胎兒神經管缺陷（建議劑量400–800 mcg/d） |
| **藥物引起** | 甲氨蝶呤（Methotrexate）輔助 |

<span style="color:#34d399">**劑量參考**：1–5 mg/d口服；妊娠預防400–800 mcg/d。</span>

<span style="color:#f87171">**注意**：單獨補充葉酸會使B12缺乏的神經學症狀惡化（因為紅血球生成改善會增加B12消耗），因此需確認不是B12缺乏。</span>

## 第三節　紅血球生成素（Erythropoietin, EPO）

<span style="color:#60a5fa">**紅血球生成素（Erythropoietin, EPO）**</span>為腎臟分泌的造血生長因子，刺激紅血球前驅細胞分化。

### 適應症

| 適應症 | 說明 |
|--------|------|
| **慢性腎病（CKD）貧血** | 腎臟EPO分泌減少；最主要適應症 |
| **化療引起的貧血** | 癌症化療導致骨髓抑制 |
| **愛滋病（AZT引起）** | 較少見 |
| **大手術前（自體捐血）** | 刺激紅血球生成 |

### 製劑

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Epoetin Alfa（EPO-α）</span> | 靜脈/皮下；Epogen/Procrit |
| <span style="color:#fb923c">Darbepoetin Alfa（達貝泊汀）</span> | N-糖基化增加→半衰期更長；給藥頻率更低 |

<span style="color:#34d399">**目標血紅蛋白**：CKD患者通常維持10–12 g/dL；避免>13 g/dL（心血管風險）。</span>

### 不良反應

| 副作用 | 說明 |
|--------|------|
| **高血壓** | 常見；與血比容增加相關 |
| **血栓風險** | 動靜脈血栓；CKD透析通路血栓 |
| **血紅蛋白過高** | 增加心血管事件（中風、心肌梗塞） |
| **純紅血球發育不全（PRCA）** | 罕見；抗EPO抗體形成；主要與皮下給藥相關 |

## 第四節　鐮刀型貧血（Sickle Cell Disease）

<span style="color:#e2e8f0">**鐮刀型貧血（Sickle Cell Disease）**</span>為β-血紅蛋白基因突變（HbS）引起的遺傳性疾病。

### 病理生理

| 變化 | 說明 |
|------|------|
| **HbS聚合** | 去氧HbS形成聚合物→紅血球變形（鐮刀狀） |
| **血管阻塞** | 異常紅血球堵塞微血管→組織缺血 |
| **溶血** | 紅血球破坏→慢性溶血性貧血 |

| 併發症 | 說明 |
|--------|------|
| **疼痛危機** | 骨骼/關節血管阻塞→劇烈疼痛 |
| **急性胸腔症候群** | 肺部血管阻塞；發燒、呼吸困難 |
| **腦中風** | 腦血管阻塞 |
| **脾臟隔離** | 兒童急性脾臟增大/低血溶性危機 |

### 藥物治療

| 藥物 | 機轉/說明 |
|------|---------|
| <span style="color:#fb923c">Hydroxyurea（羥基尿素）</span> | **增加胎兒血紅蛋白（HbF）**→干擾HbS聚合；減少疼痛危機；第一個獲FDA核准 |
| <span style="color:#fb923c">L-Glutamine（ 左旋麩醯胺酸）</span> | 抗氧化；減少氧化壓力 |
| <span style="color:#fb923c">Voxelotor</span> | HbS聚合抑制劑；減少溶血 |
| <span style="color:#fb923c">Crizanlizumab</span> | 抗P-選擇素單株抗體；減少疼痛危機頻率 |

## 第五節　重點摘要

- <span style="color:#fb923c">硫酸亞鐵</span>為治療缺鐵性貧血的口服首選，150–200 mg/d元素鐵
- <span style="color:#fb923c">Hepcidin（鐵調素）</span>為鐵穩態的核心調節因子，慢性發炎狀態下hepcidin↑→鐵吸收↓（功能性鐵缺乏）
- <span style="color:#fb923c">維生素B12</span>缺乏最常見原因為<span style="color:#e2e8f0">**惡性貧血（內在因子缺乏）**</span>，需注射補充
- 單獨補充<span style="color:#fb923c">葉酸</span>可能使B12缺乏的神經學症狀惡化
- <span style="color:#fb923c">Epoetin Alfa</span>與<span style="color:#fb923c">Darbepoetin</span>用於慢性腎病與化療引起的貧血
- EPO治療目標血紅蛋白10–12 g/dL，過高增加心血管風險
- <span style="color:#fb923c">Hydroxyurea</span>為第一個獲FDA核准治療鐮刀型貧血的藥物，透過增加HbF減少血管阻塞事件
- <span style="color:#fb923c">Voxelotor</span>與<span style="color:#fb923c">Crizanlizumab</span>為新型鐮刀型貧血藥物
