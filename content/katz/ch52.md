# CH52 癌症化學治療

## 章節導讀

癌症化學治療（化療）是惡性腫瘤治療的重要支柱之一。本章節系統介紹細胞週期動力學基礎、藥物作用機轉分類（細胞週期特異性與非特異性藥物）、藥物合併治療原則、抗藥性機轉，以及各類化療藥物的藥理學特性。化療的成功有賴於正確的藥物選擇、劑量強度管理及對不良反應的及時處理。

---

## 細胞週期動力學基礎

### 細胞週期各時期

| 時期 | 主要事件 | 化療藥物作用點 |
|------|---------|---------------|
| <span style="color:#22d3ee">G₀期（靜止期）</span> | 細胞處於休眠狀態，不進行分裂 | CCNS藥物可作用 |
| <span style="color:#22d3ee">G₁期（DNA合成前期）</span> | 細胞準備DNA合成 | 主要由CCNS藥物殺滅 |
| <span style="color:#22d3ee">S期（DNA合成期）</span> | DNA複製；放射菌素D、6-MP等 | <span style="color:#60a5fa">**CCS藥物主要作用點**</span> |
| <span style="color:#22d3ee">G₂期（DNA合成後期）</span> | 準備有絲分裂 | 博萊黴素、紫杉醇等 |
| <span style="color:#22d3ee">M期（有絲分裂期）</span> | 細胞分裂 | 長春花生物鹼、紫杉醇 |

### 對數殺滅假說（Log-Kill Hypothesis）

<span style="color:#60a5fa">**核心概念**：化療藥物在治療劑量範圍內，按固定比例殺滅腫瘤細胞，而非固定數量。</span>

例如：某藥物可將腫瘤細胞數從10¹⁰降至10⁷（3 log殺滅），同樣劑量可將10⁵降至10²。這意味著<span style="color:#f87171">**腫瘤越小，達到治愈所需的化療週期越少**</span>。

---

## 化療藥物分類

### 細胞週期特異性藥物（CCS）

| 類別 | 代表藥物 | 作用時期 |
|------|---------|---------|
| <span style="color:#fb923c">抗代謝藥物</span> | 5-FU、MTX、6-MP、gemcitabine、capecitabine | S期 |
| <span style="color:#fb923c">長春花生物鹼</span> | Vinblastine、Vincristine、Vinorelbine | M期 |
| <span style="color:#fb923c">紫杉醇類</span> | Paclitaxel、Docetaxel | M期 |
| <span style="color:#fb923c">喜樹鹼類</span> | Irinotecan、Topotecan | S期（topoisomerase I抑制）|

### 細胞週期非特異性藥物（CCNS）

| 類別 | 代表藥物 |
|------|---------|
| <span style="color:#fb923c">烷化劑</span> | Cyclophosphamide、melphalan、chlorambucil、nitrosoureas |
| <span style="color:#fb923c">鉑類製劑</span> | Cisplatin、carboplatin、oxaliplatin |
| <span style="color:#fb923c">抗腫瘤抗生素</span> | Doxorubicin、daunorubicin、bleomycin |
| <span style="color:#fb923c">Epipodophyllotoxins</span> | Etoposide（topoisomerase II抑制）|

---

## 藥物合併治療原則

有效的化療組合需滿足以下原則：

| 原則 | 說明 |
|------|------|
| <span style="color:#60a5fa">**有效性**</span> | 只選擇對特定腫瘤單獨使用時有效的藥物 |
| <span style="color:#60a5fa">**毒性互補**</span> | 各藥物的劑量限制毒性不重疊（如A骨髓抑制、B腎毒性）|
| <span style="color:#60a5fa">**最佳時程**</span> | 藥物應按其最佳給藥時程給予 |
| <span style="color:#60a5fa">**作用機轉互補**</span> | 不同生化機轉的藥物合併可減少抗藥性產生 |

---

## 劑量強度與治療失敗

<span style="color:#f87171">**劑量強度（dose intensity）**是化療成功的關鍵限制因素之一。</span>

- 動物實驗顯示：劑量-反應曲線在線性階段非常陡峭
- 降低劑量20%即可導致治療失敗
- 增加給藥間隔會減少劑量強度，降低療效

---

## 抗藥性機轉

| 抗藥性類型 | 機轉 |
|-----------|------|
| <span style="color:#f87171">**內因性抗藥**</span> | 腫瘤從未對藥物有過反應（如黑色素瘤、腎細胞癌、腦癌）|
| <span style="color:#f87171">**獲得性抗藥**</span> | 暴露於藥物後產生；可分為： |
| — 單一藥物特異性 | 由特定基因改變引起 |
| — 多重抗藥性（MDR）| MDR1基因增幅；P-glycoprotein增加導致藥物外流；對結構無關的藥物（anthracyclines、vinca alkaloids、taxanes等）均具抗藥性 |

---

## 烷化劑（Alkylating Agents）

<span style="color:#60a5fa">**作用機轉**：將烷基轉移至DNA的鳥糞嘌呤N7位置，造成DNA鏈間或鏈內交聯，阻止DNA複製與轉錄。</span>

### 臨床常用製劑

| 藥物 | 主要適應症 | 劑量限制毒性 |
|------|-----------|-------------|
| <span style="color:#fb923c">Cyclophosphamide</span> | 淋巴瘤、乳癌、卵巢癌 | <span style="color:#f87171">**出血性膀胱炎**</span>、骨髓抑制 |
| <span style="color:#fb923c">Ifosfamide</span> | 軟組織肉瘤、睪丸癌 | <span style="color:#f87171">**出血性膀胱炎**</span>（需同時給予mesna）|
| <span style="color:#fb923c">Melphalan</span> | 多發性骨髓瘤 | 骨髓抑制 |
| <span style="color:#fb923c">Cisplatin</span> | 睪丸癌、卵巢癌、肺癌 | <span style="color:#f87171">**腎毒性**</span>、周邊神經病變、聽力損失 |
| <span style="color:#fb923c">Carboplatin</span> | 卵巢癌、肺癌 | 骨髓抑制（血小板減少為主）|
| <span style="color:#fb923c">Oxaliplatin</span> | 大腸直腸癌 | <span style="color:#f87171">**週邊感覺神經病變**</span>（累積性）|

### 常見不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**骨髓**</span> | 劑量限制性骨髓抑制（嗜中性球、血小板減少）|
| <span style="color:#f87171">**胃腸道**</span> | 噁心、嘔吐（可用5-HT₃拮抗劑+dexamethasone預防）|
| <span style="color:#f87171">**生殖**</span> | 不孕症（卵巢/睪丸功能抑制）|
| <span style="color:#f87171">**致突變/致癌**</span> | 治療後可能發生二次白血病 |

---

## 抗代謝藥物（Antimetabolites）

<span style="color:#60a5fa">**作用機轉**：結構類似正常代謝物，干擾核酸合成或蛋白質修飾。</span>

### 常用藥物

| 藥物 | 作用機轉 | 主要適應症 |
|------|---------|-----------|
| <span style="color:#fb923c">Methotrexate (MTX)</span> | 抑制二氫葉酸還原酶（DHFR）| 絨毛膜癌、白血病、淋巴瘤、乳癌 | 
| <span style="color:#fb923c">5-Fluorouracil (5-FU)</span> | 抑制胸苷酸合成酶（TS）| 大腸直腸癌、乳癌 | 
| <span style="color:#fb923c">Capecitabine</span> | 口服前藥，轉化為5-FU | 大腸直腸癌、乳癌 |
| <span style="color:#fb923c">Gemcitabine</span> | 抑制DNA合成酶 | 胰臟癌、肺癌、膀胱癌 |
| <span style="color:#fb923c">6-Mercaptopurine (6-MP)</span> | 抑制嘌呤合成 | 急性淋巴性白血病 |

### Methotrexate 毒性與解毒

<span style="color:#f87171">**大劑量MTX治療**需同時給予leucovorin（folinic acid）救援，以保護正常細胞。</span>

| 毒性 | 說明 |
|------|------|
| <span style="color:#f87171">**骨髓抑制**</span> | 劑量限制性 |
| <span style="color:#f87171">**腎毒性**</span> | MTX結晶沉積於腎小管 |
| <span style="color:#f87171">**肝毒性**</span> | 長期使用導致肝纖維化 |
| <span style="color:#f87171">**肺毒性**</span> | 過敏性肺炎 |

---

## 抗腫瘤抗生素（Antitumor Antibiotics）

| 藥物 | 作用機轉 | 主要適應症 | 特殊毒性 |
|------|---------|-----------|---------|
| <span style="color:#fb923c">Doxorubicin</span> | 嵌入DNA；topoisomerase II抑制 | 乳癌、淋巴瘤、肉瘤 | <span style="color:#f87171">**心臟毒性**</span>（累積性心肌病變）；最大累積劑量550 mg/m² |
| <span style="color:#fb923c">Daunorubicin</span> | 同上 | 急性骨髓性白血病 | 心臟毒性 |
| <span style="color:#fb923c">Bleomycin</span> | 產生自由基，斷裂DNA | 淋巴瘤、睪丸癌 | <span style="color:#f87171">**肺纖維化**</span>（劑量限制性）；發燒過敏 |
| <span style="color:#fb923c">Mitomycin C</span> | 烷化作用 | 胃腸道癌症、膀胱癌 | 骨髓抑制（延遲性）|

---

## 植物生物鹼（Plant Alkaloids）

### 長春花生物鹼（Vinca Alkaloids）

<span style="color:#60a5fa">**作用機轉**：與β-tubulin結合，抑制微小管組裝，阻止有絲分裂紡錘體形成。</span>

| 藥物 | 主要適應症 | 主要毒性 |
|------|-----------|---------|
| <span style="color:#fb923c">Vincristine</span> | 急性淋巴性白血病、淋巴瘤 | <span style="color:#f87171">**神經毒性**</span>（週邊感覺異常、便秘）|
| <span style="color:#fb923c">Vinblastine</span> | 睪丸癌、淋巴瘤 | 骨髓抑制 |
| <span style="color:#fb923c">Vinorelbine</span> | 肺癌、乳癌 | 骨髓抑制 |

### 紫杉醇類（Taxanes）

<span style="color:#60a5fa">**作用機轉**：促進微小管聚合並抑制其解聚，阻止紡錘體功能，將細胞阻斷於G₂/M期。</span>

| 藥物 | 主要適應症 | 主要毒性 |
|------|-----------|---------|
| <span style="color:#fb923c">Paclitaxel</span> | 卵巢癌、乳癌、肺癌 | <span style="color:#f87171">**過敏反應**</span>（需預防性給予類固醇+抗組織胺）；骨髓抑制 |
| <span style="color:#fb923c">Docetaxel</span> | 乳癌、肺癌、前列腺癌 | 液體滯留症候群；指甲病變 |

---

## 喜樹鹼類（Camptothecins）

<span style="color:#60a5fa">**作用機轉**：抑制topoisomerase I，阻止DNA複製過程中的超螺旋修復。</span>

| 藥物 | 主要適應症 | 主要毒性 |
|------|-----------|---------|
| <span style="color:#fb923c">Irinotecan</span> | 大腸直腸癌（與5-FU+leucovorin合併）| <span style="color:#f87171">**延遲性腹瀉**</span>；骨髓抑制 |
| <span style="color:#fb923c">Topotecan</span> | 卵巢癌、小細胞肺癌 | 骨髓抑制 |

---

## 激素製劑（Hormonal Agents）

<span style="color:#60a5fa">**特點**：對荷爾蒙依賴性腫瘤有效；作用機轉為抑制激素合成或阻斷激素受體。</span>

| 藥物 | 機轉 | 主要適應症 | 主要不良反應 |
|------|------|-----------|------------|
| <span style="color:#fb923c">Tamoxifen</span> | 選擇性雌激素受體調節劑（SERM）| 乳癌 | 子宮內膜癌風險；熱潮紅 |
| <span style="color:#fb923c">Anastrozole/Letrozole</span> | 芳香酶抑制劑 | 停經後乳癌 | 骨質疏鬆 |
| <span style="color:#fb923c">Flutamide/Bicalutamide</span> | 雄性素受體拮抗劑 | 前列腺癌 | 肝毒性 |
| <span style="color:#fb923c">Dexamethasone</span> | 糖皮質素 | 淋巴瘤、白血病（腦部浸潤）| 免疫抑制 |

## 化療輔助治療

### 止嘔藥物（CNE prophylaxis）

| 層級 | 藥物組合 | 適用情境 |
|------|---------|---------|
| 高致嘔風險 | <span style="color:#60a5fa">5-HT₃拮抗劑</span> + <span style="color:#60a5fa">Dexamethasone</span> + <span style="color:#60a5fa">NK₁受體拮抗劑</span>（aprepitant）| Cisplatin ≥70 mg/m² |
| 中致嘔風險 | <span style="color:#60a5fa">5-HT₃拮抗劑</span> + <span style="color:#60a5fa">Dexamethasone</span> | Carboplatin、anthracycline+cyclophosphamide |
| 低致嘔風險 | <span style="color:#60a5fa">Dexamethasone</span> alone | 5-FU、MTX |

### 造血生長因子

| 製劑 | 適應症 |
|------|--------|
| <span style="color:#fb923c">Filgrastim (G-CSF)</span> | 預防嗜中性球減少性發燒 |
| <span style="color:#fb923c">Epoetin alfa (EPO)</span> | 化療相關貧血 |

## 化療藥物不良反應快速參考

| 系統 | 常見元兇藥物 | 處理要點 |
|------|-------------|---------|
| <span style="color:#f87171">**骨髓抑制**</span> | 大多數化療藥物 | 監測血球計數；必要時输血、G-CSF支持 |
| <span style="color:#f87171">**噁心/嘔吐**</span> | Cisplatin、anthracyclines | 5-HT₃拮抗劑+類固醇為主 |
| <span style="color:#f87171">**心臟毒性**</span> | Doxorubicin | 累積劑量限制；心臟超聲監測 |
| <span style="color:#f87171">**肺毒性**</span> | Bleomycin | 最大累積劑量400單位；監測肺功能 |
| <span style="color:#f87171">**腎毒性**</span> | Cisplatin、MTX | 充分水化；必要時鹼化尿液 |
| <span style="color:#f87171">**神經毒性**</span> | Vincristine、Oxaliplatin | 無特殊解藥；劑量調整 |
| <span style="color:#f87171">**出血性膀胱炎**</span> | Cyclophosphamide、Ifosfamide | Mesna預防；充分水化 |
| <span style="color:#f87171">**脫髮**</span> | Anthracyclines、taxanes | 衛教；考慮降低頭部溫度（cold cap）|
