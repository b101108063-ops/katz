## 章節導讀

本章介紹<span style="color:#60a5fa">酒精類</span>的藥理學，包括<span style="color:#fb923c">乙醇（Ethanol）</span>的藥物動力學、急性與慢性效應、依賴性與戒斷症狀，並說明<span style="color:#fb923c">甲醇（Methanol）</span>與<span style="color:#fb923c">乙二醇（Ethylene Glycol）</span>中毒的機轉與治療。

---

## 乙醇（Ethanol）

### 藥物動力學

| 特性 | 說明 |
|------|------|
| 吸收 | 胃腸道快速吸收，空腹30分鐘達峰值 |
| 分布 | 分布迅速，分布體積≈全身水量（0.5-0.7 L/kg） |
| 代謝 | >90%在肝臟氧化 |
| 排除 | 10%經肺與尿液排出 |
| 動力學 | <span style="color:#e2e8f0">零級動力學</span>（恆定速率） |
| 代謝速率 | 約7-10 g/小時（相當於1標準杯） |

### 乙醇代謝途徑

| 途徑 | 酶 | 產物 |
|------|---|------|
| <span style="color:#60a5fa">主要途徑</span> | 乙醇脫氫酶（ADH） | 乙醛 |
| MEOS途徑 | CYP2E1 | 乙醛 |
| 乙醛氧化 | 乙醛脫氫酶（ALDH） | 醋酸鹽 |

<span style="color:#f87171">警告：乙醛脫氫酶抑制時（如Disulfiram），乙醛累積引起臉部潮紅、噁心、嘔吐</span>

---

## 乙醇急性效應

### 血酒精濃度與臨床效應

| BAC（mg/dL） | 臨床效應 |
|-------------|---------|
| 50-100 | 鎮靜、主觀「high」、反應變慢 |
| 100-200 | 運動功能受損、構音困難、共濟失調 |
| 200-300 | 嘔吐、木僵 |
| 300-400 | 昏迷 |
| >400 | 呼吸抑制、<span style="color:#f87171">死亡</span> |

### CNS效應

乙醇為<span style="color:#e2e8f0">CNS抑制劑</span>：
- <span style="color:#60a5fa">低劑量</span>：緩解焦慮、欣快感
- <span style="color:#60a5fa">中劑量</span>：鎮靜、運動失調、判斷力受損
- <span style="color:#60a5fa">高劑量</span>：木僵、昏迷、呼吸抑制

### 對神經傳遞物質的影響

| 系統 | 效應 |
|------|------|
| GABA_A | <span style="color:#60a5fa">增強GABA作用</span>→抑制 |
| NMDA | <span style="color:#f87171">抑制NMDA受體</span>→影響記憶 |
| 多巴胺 | 增加釋放→獎勵效應 |

<span style="color:#f87171">重要：「blackout」（記憶缺失）可能與NMDA受體抑制有關</span>

### 心血管效應

| 效應 | 說明 |
|------|------|
| 心肌收縮抑制 | 中等劑量（>100 mg/dL） |
| 血管擴張 | 導致低體溫 |
| 高血壓 | 大量飲用（>3杯/日） |

## 乙醇慢性效應

### 肝臟疾病

| 疾病階段 | 說明 |
|---------|------|
| 酒精性脂肪肝 | 可逆性 |
| 酒精性肝炎 | 可能進展 |
| 肝硬化 | 不可逆，肝移植常見適應症 |

<span style="color:#f87171">警告：女性對酒精性肝毒的敏感性高於男性</span>

### 神經系統毒性

| 疾病 | 說明 |
|------|------|
| 周邊神經病變 | 對稱性感覺運動障礙 |
| Wernicke-Korsakoff | <span style="color:#f87171">硫胺素缺乏</span>→眼肌麻痺、共濟失調、記憶障礙 |
| 癡呆 | 慢性大量飲用 |

<span style="color:#f87171">所有疑似Wernicke-Korsakoff患者應給予硫胺素</span>

### 心血管效應

| 效應 | 說明 |
|------|------|
| 酒精性心肌病變 | 長期大量→擴張型心肌病 |
| 心律不整 | 特別是「binge」飲用後 |
| 高血壓 | 估計約5%的高血壓由此引起 |

### 胎兒酒精症候群（FAS）

| 異常類型 | 說明 |
|---------|------|
| 生長遲緩 | 子宮內發育不良 |
| 頭小畸型 | 腦發育障礙 |
| 顏面異常 | 人中平滑、上唇薄 |
| 心臟缺陷 | 先天性心臟病 |
| 神經發育異常 | 智力障礙 |

## 酒精依賴與戒斷

### 戒斷症狀進展

| 時間 | 症狀 |
|------|------|
| 6-8小時 | 焦慮、失眠、顫抖、心悸 |
| 12-24小時 | 酒精性幻覺 |
| 24-48小時 | 戒斷痙攣 |
| 48-96小時 | <span style="color:#f87171">譫妄妄動（Delirium Tremens）</span> |

### Delirium Tremens特徵

<span style="color:#f87171">譫妄、激動、自律神經不穩定（心搏過速、高血壓、發燒）、顫抖、出汗</span>

## 酒精相關藥物治療

| 藥物 | 用途 | 機轉 |
|------|------|------|
| <span style="color:#fb923c">Disulfiram</span> | 戒酒輔助 | <span style="color:#f87171">抑制ALDH</span>→乙醛累積 |
| <span style="color:#fb923c">Naltrexone</span> | 減少渴望 | 鴉片受體拮抗 |
| <span style="color:#fb923c">Acamprosate</span> | 維持戒酒 | 調節麩胺酸系統 |

<span style="color:#f87171">警告：服用Disulfiram時飲酒會引起嚴重不良反應（臉潮紅、嘔吐、低血壓）</span>

## 甲醇（Methanol）

### 中毒機轉

<span style="color:#fb923c">Methanol</span>→ADH→<span style="color:#f87171">甲醛</span>→ALDH→<span style="color:#f87171">甲酸</span>（劇毒）

### 臨床特徵

| 系統 | 症狀 |
|------|------|
| CNS | 頭痛、眩暈、昏迷 |
| 視覺 | <span style="color:#f87171">視力模糊、失明</span>（甲醛毒性） |
| 代謝 | 嚴重代謝性酸中毒 |

### 治療

| 治療方式 | 說明 |
|---------|------|
| Fomepizole | <span style="color:#60a5fa">ADH抑制劑</span> |
| Ethanol | 競爭ADH（較高親和力） |
| 血液透析 | 加速排除 |

---

## 乙二醇（Ethylene Glycol）

### 中毒機轉

<span style="color:#fb923c">Ethylene Glycol</span>→ADH→<span style="color:#f87171">乙醇醛</span>→...→<span style="color:#f87171">草酸</span>（腎毒性）

### 臨床特徵

| 系統 | 症狀 |
|------|------|
| CNS | 初期：醉酒樣症狀 |
| 心肺 | 心搏過速、肺水腫 |
| 腎臟 | <span style="color:#f87171">急性腎衰竭</span>（草酸鈣沉積） |

### 治療

| 治療方式 | 說明 |
|---------|------|
| Fomepizole | <span style="color:#60a5fa">ADH抑制劑</span> |
| Thiamine、Pyridoxine | 促進無毒代謝物形成 |
| 血液透析 | 嚴重病例 |

---

## 藥物-酒精交互作用

| 交互作用類型 | 代表藥物 | 效應 |
|-------------|---------|------|
| CNS抑制相加 | 鎮靜催眠藥、鴉片類 | <span style="color:#f87171">嚴重呼吸抑制</span> |
| 肝臟酶誘導 | Barbiturates | 增加藥物代謝 |
| 肝臟酶抑制 | 急性飲用 | 減少藥物代謝 |
| Acetaminophen | 慢性大量飲用 | <span style="color:#f87171">肝毒性風險增加</span> |

| 藥物名稱 | 類別 | 用途 | 機轉/作用 |
