# CH57 圍產期與兒童藥理學

## 章節導讀

圍產期與兒童藥理學是研究藥物對胎兒、新生兒及兒童作用的專門學問。本章節介紹胎盤藥物轉運的影響因素、妊娠期用藥原則、藥物對胎兒的致畸性，以及嬰兒與兒童的藥動學與藥效學特點。兒童並非「小型成人」，其藥物劑量與給藥時程需根據年齡、體重與腎功能進行調整。哺乳期的藥物傳遞與安全性亦一併討論。

---

## 胎盤藥物轉運

### 影響胎盤藥物轉運的因素

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**脂溶性**</span> | 脂溶性藥物易通過胎盤；高度離子化藥物通過較慢 |
| <span style="color:#60a5fa">**分子量**</span> | < 500 Da較易通過；> 1000 Da（如heparin）几乎不通過 |
| <span style="color:#60a5fa">**蛋白質結合**</span> | 游離藥物才能通過；胎兒側蛋白質結合較低時，游離藥物可蓄積 |
| <span style="color:#60a5fa">**離子 trapping**</span> | 胎兒血pH (7.3)較母親（7.4）低；鹼性藥物在胎兒側離子化→蓄積 |
| <span style="color:#60a5fa">**P-glycoprotein**</span> | 藥物轉運蛋白，可將某些藥物泵回母體循環 |

## 致畸性與藥物分級

### FDA妊娠藥物分級

| 等級 | 說明 |
|------|------|
| <span style="color:#34d399">**A**</span> | 對照研究顯示無胎兒風險 |
| <span style="color:#34d399">**B**</span> | 動物研究無胎兒風險但無人體對照研究 |
| <span style="color:#fb923c">**C**</span> | 動物研究顯示不良作用，但無人體研究；僅在潛在效益大於風險時使用 |
| <span style="color:#fb923c">**D**</span> | 有胎兒風險的證據，但效益可能大於風險（如生命威脅疾病）|
| <span style="color:#f87171">**X**</span> | 動物或人體研究顯示胎兒異常；風險明顯大於效益；<span style="color:#f87171">**禁用於孕婦**</span> |

## 常見致畸藥物

### 有明確致畸風險的藥物

| 藥物 | 風險胎兒異常 | 孕期影響 |
|------|-------------|---------|
| <span style="color:#f87171">**ACE抑制劑**</span> | 腎功能衰竭、畸胎 | 所有孕期，特別第二、三期 |
| <span style="color:#f87171">**酒精**</span> | 胎兒酒精症候群（FAS）：生長遲緩、面容異常、CNS功能障礙 | 所有孕期 |
| <span style="color:#f87171">**Isotretinoin**</span> | CNS、顔面、耳畸形 | <span style="color:#f87171">**極高度風險**</span>；妊娠首三個月禁用 |
| <span style="color:#f87171">**Warfarin**</span> | 鼻發育不全、軟骨發育不全；CNS異常 | 第一期禁用；第三期致胎兒出血 |
| <span style="color:#f87171">**Lithium**</span> | Ebstein anomaly（心臟畸形）| 第一、三期 |
| <span style="color:#f87171">**Phenytoin**</span> | 胎兒苯妥英症候群：指甲發育不全、面容異常 | 所有孕期 |
| <span style="color:#f87171">**Valproic acid**</span> | 神經管缺陷（無腦兒、脊柱裂）| <span style="color:#f87171">**第一期風險最高**</span> |
| <span style="color:#f87171">**Carbamazepine**</span> | 神經管缺陷 | 第一期 |
| <span style="color:#fb923c">**Tetracycline**</span> | 牙齒變色、骨骼生長遲緩 | 所有孕期（牙齒發育期）|
| <span style="color:#fb923c">**SSRIs**</span> | 新生兒停藥症候羣、持續性肺高壓 | 第三期 |

### 妊娠期用藥安全性要點

<span style="color:#60a5fa">**基本原則**：任何藥物用於孕婦時，應先確認其必要性；優先選擇有長期安全數據的藥物。</span>

| 情況 | 建議藥物 |
|------|---------|
| <span style="color:#60a5fa">**止痛/退燒**</span> | Acetaminophen（首選）；避免aspirin（尤其晚期妊娠）|
| <span style="color:#60a5fa">**感染**</span> | Penicillins、Cephalosporins（安全）；避免tetracyclines、fluoroquinolones |
| <span style="color:#60a5fa">**氣喘**</span> | Inhaled β₂-agonists、corticosteroids（安全）；避免systemic steroids（短期可）|
| <span style="color:#60a5fa">**憂鬱**</span> | SSRIs（如fluoxetine）；需衡量停藥與治療風險 |

## 胎兒治療（Fetal Therapy）

| 藥物 | 適應症 | 說明 |
|------|--------|------|
| <span style="color:#fb923c">**Corticosteroids**</span> | 促進胎兒肺成熟（早產風險）| 目前唯一確認有效的胎兒治療 |
| <span style="color:#fb923c">**Digoxin**</span> | 胎兒心律不整 | 母親口服，經胎盤傳遞至胎兒 |
| <span style="color:#fb923c">**Zidovudine**</span> | 預防HIV母胎傳播 | 可降低2/3傳播風險；合併抗逆轉錄病毒效果更佳 |

## 新生兒與兒童藥動學

### 吸收

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**肌注吸收**</span> | 取決於肌肉血流；休克或心衰竭時吸收不規則 |
| <span name="color:#60a5fa">**口服吸收**</span> | 胃酸分泌在出生後數小時內建立；早產兒胃酸分泌較慢 |
| <span style="color:#60a5fa">**胃排空**</span> | 出生後頭1-2天延遲；影响口服藥物吸收時程 |
| <span style="color:#60a5fa">**胆汁**</span> | 膽汁酸和脂肪酶活性在4個月前較低；影響脂溶性藥物吸收 |

### 分佈

| 特點 | 說明 |
|------|------|
| <span style="color:#60a5fa">**體水分比例較高**</span> | 新生兒：70-75%（成人：50-60%）；早產兒可達85% |
| <span style="color:#60a5fa">**細胞外水分比例較高**</span> | 新生兒40%（成人20%）；水溶性藥物分佈體積較大 |
| <span style="color:#60a5fa">**脂肪比例較低**</span> | 早產兒脂肪僅1%（足月兒15%）；影響脂溶性藥物分佈 |
| <span style="color:#60a5fa">**蛋白質結合較低**</span> | 白蛋白較低；游離藥物比例較高 |

<span style="color:#f87171">**重要**：蛋白質結合率低的藥物（如diazepam）在新生兒即使血中總濃度與成人相同，游離藥物濃度可能高出數倍。</span>

### 代謝

| 特點 | 說明 |
|------|------|
| <span style="color:#60a5fa">**CYP450酶活性**</span> | 僅50-70%成人值 |
| <span style="color:#60a5fa">**葡萄糖酸化**</span> | 3-4歲才達成人值（每公斤體重）|
| <span style="color:#60a5fa">**半衰期延長**</span> | 大多數藥物半衰期在新生兒明顯延長 |

### 排除

| 特點 | 說明 |
|------|------|
| <span style="color:#60a5fa">**腎絲球濾過率（GFR）**</span> | 出生時僅30-40%成人值（按體表面積）；34週前早產兒更低 |
| <span style="color:#60a5fa">**腎功能成熟**</span> | 第1週末增加50%；第3週末達50-60%成人值；6-12個月達成人值 |
| <span style="color:#60a5fa">**藥物影響**</span> | Penicillins、aminoglycosides、digoxin等腎排泄藥物清除率大幅降低 |

## 新生兒特殊藥效學考量

| 情況 | 說明 |
|------|------|
| <span style="color:#60a5fa">**嗎啡敏感性**</span> | 對中樞抑制作用較敏感；需更低劑量 |

## 兒童劑量計算

### 按體重計算

<span style="color:#60a5fa">**Young's Rule**：劑量 = 成人劑量 × 年齡 / (年齡 + 12)</span>

### 按體表面積計算（更準確）

| 體重(kg) | 年齡 | 體表面積(m²) | 成人劑量% |
|---------|------|------------|----------|
| 3 | 新生兒 | 0.2 | 12% |
| 6 | 3個月 | 0.3 | 18% |
| 10 | 1歲 | 0.45 | 28% |
| 20 | 5.5歲 | 0.8 | 48% |
| 30 | 9歲 | 1.0 | 60% |
| 40 | 12歲 | 1.3 | 78% |
| 成人 | — | 1.7 | 100% |

<span style="color:#f87171">**注意**：兒童劑量永遠不應超過成人劑量。</span>

## 哺乳期用藥

### 藥物進入乳汁的影響因素

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**藥物分子量**</span> | 分子量越小越容易進入 |
| <span style="color:#60a5fa">**脂溶性**</span> | 脂溶性藥物更易進入乳汁 |
| <span style="color:#60a5fa">**蛋白質結合**</span> | 游離藥物才能進入；低蛋白質結合藥物更易分泌 |
| <span style="color:#60a5fa">**酸鹼度**</span> | 鹼性藥物在酸性乳汁中離子化→濃縮 |

### 哺乳期相對安全的藥物

| 藥物 | 安全性 | 說明 |
|------|--------|------|
| <span style="color:#34d399">Penicillins</span> | 安全 | 乳汁濃度低 |
| <span style="color:#34d399">Cephalosporins</span> | 安全 | 類似penicillins |
| <span style="color:#34d399">Acetaminophen</span> | 安全 | 微量分泌 |
| <span style="color:#34d399">Ibuprofen</span> | 安全 | 低乳汁濃度 |
| <span style="color:#fb923c">**Codeine**</span> | 注意 | 超快速代謝者（ CYP2D6）可能致嬰兒呼吸抑制 |
| <span style="color:#fb923c">**Diazepam**</span> | 謹慎 | 半衰期長；嬰兒蓄積 |
| <span style="color:#f87171">**放射性藥物**</span> | 禁用 | 如radioiodine；需暫停哺乳數天至數週 |
| <span style="color:#f87171">**抗癌化療**</span> | 禁用 | 免疫抑制、細胞毒性 |
| <span style="color:#f87171">**Lithium**</span> | 謹慎 | 乳汁濃度等於母體血清濃度 |

<span style="color:#60a5fa">**哺乳時間建議**：服藥後30-60分鐘再哺乳；或避開血中濃度高峰期</span>

## 新生兒停藥症候羣（Neonatal Abstinence Syndrome）

| 原因藥物 | 說明 |
|---------|------|
| <span style="color:#fb923c">Opioids（海洛因、美沙冬）</span> | 母親長期使用，胎兒/新生兒依賴 |
| <span name="color:#fb923c">Benzodiazepines</span> | 長期使用後停藥 |
| <span style="color:#fb923c">Barbiturates</span> | 長期使用後停藥 |

| 處理 | 說明 |
|------|------|
| 支持性治療 | 包裹、餵養困難處理 |
| <span style="color:#fb923c">Methadone</span> | 劑量遞減 |
| <span style="color:#fb923c">Morphine</span> | 控制戒斷症狀 |
