## 章節導讀

本章節說明 β-內醯胺抗生素（Penicillins、Cephalosporins、Carbapenems）與其他細胞壁活性抗生素（Vancomycin、Daptomycin）的作用機轉、抗菌譜與臨床應用。

## Beta-Lactam & Cell Wall-Active Antibiotics

### 作用機轉

<span style="color:#60a5fa">β-內醯胺抗生素</span>藉由抑制<span style="color:#22d3ee">細菌細胞壁</span>的<span style="color:#60a5fa">轉肽酶（transpeptidase）</span>反應來阻止<span style="color:#22d3ee">肽聚糖（peptidoglycan）</span>合成。當細胞壁無法形成時，細菌因滲透壓差而溶解死亡。

<span style="color:#60a5fa">β-lactamases</span>（β-內醯胺酶）可水解 β-lactam 環，使抗生素失效。這是細菌產生<span style="color:#f87171">抗藥性</span>的主要機制之一。

### 青黴素類（Penicillins）

**分類：**

1. **標準青黴素**（如 <span style="color:#fb923c">penicillin G</span>）：對<span style="color:#c084fc">革蘭氏陽性菌</span>、<span style="color:#c084fc">革蘭氏陰性球菌</span>有效，但易被 β-lactamases 水解
2. **抗葡萄球菌青黴素**（如 <span style="color:#fb923c">nafcillin</span>、<span style="color:#fb923c">oxacillin</span>、<span style="color:#fb923c">dicloxacillin</span>）：對 <span style="color:#c084fc">MRSA</span> 有效
3. **廣效青黴素**（如 <span style="color:#fb923c">amoxicillin</span>、<span style="color:#fb923c">ampicillin</span>、<span style="color:#fb923c">piperacillin</span>）：對<span style="color:#c084fc">革蘭氏陰性桿菌</span>有較好活性

**常見藥物：**

- <span style="color:#fb923c">penicillin G</span>：注射製劑，用於<span style="color:#c084fc">梅毒</span>、<span style="color:#c084fc">肺炎球菌腦膜炎</span>
- <span style="color:#fb923c">amoxicillin</span>：口服製劑，用於呼吸道、泌尿道感染
- <span style="color:#fb923c">piperacillin</span>：廣效，對<span style="color:#c084fc">綠膿桿菌</span>（<span style="color:#c084fc">P aeruginosa</span>）有效

### 頭孢菌素類（Cephalosporins）

頭孢菌素依抗菌譜分為五代：

| 世代 | 藥物 | 特色 |
|------|------|------|
| 第一代 | <span style="color:#fb923c">cephalexin</span>、<span style="color:#fb923c">cefazolin</span> | 革蘭氏陽性为主 |
| 第二代 | <span style="color:#fb923c">cefuroxime</span> | 對 <span style="color:#c084fc">H influenzae</span>、<span style="color:#c084fc">M catarrhalis</span> 有效 |
| 第三代 | <span style="color:#fb923c">ceftriaxone</span>、<span style="color:#fb923c">cefotaxime</span> | 腦膜炎、肺炎、淋病 |
| 第四代 | <span style="color:#fb923c">cefepime</span> | 對 <span style="color:#c084fc">綠膿桿菌</span>有效 |
| 第五代 | <span style="color:#fb923c">ceftaroline</span> | 對 MRSA 有效 |

### 碳青黴烯類（Carbapenems）

<span style="color:#fb923c">imipenem</span>、<span style="color:#fb923c">meropenem</span>、<span style="color:#fb923c">ertapenem</span> 為超廣效抗生素，對<span style="color:#c084fc">革蘭氏陽性菌</span>、<span style="color:#c084fc">革蘭氏陰性菌</span>、<span style="color:#c084fc">厭氧菌</span>均有效。對大多數 β-lactamases 穩定。

### 單環類（Monobactams）

<span style="color:#fb923c">aztreonam</span> 僅對<span style="color:#c084fc">革蘭氏陰性菌</span>（尤其是<span style="color:#c084fc">綠膿桿菌</span>）有效，對<span style="color:#c084fc">革蘭氏陽性菌</span>和<span style="color:#c084fc">厭氧菌</span>無效。適用於對青黴素過敏的患者。

### 糖肽類（Glycopeptides）

<span style="color:#fb923c">vancomycin</span>：對<span style="color:#c084fc">MRSA</span>、<span style="color:#c084fc">表皮葡萄球菌</span>、<span style="color:#c084fc">腸球菌</span>有效。為<span style="color:#f87171">最後一線藥物</span>（last resort drug）。主要副作用為<span style="color:#f87171">腎毒性</span>和<span style="color:#f87171">耳毒性</span>。

<span style="color:#fb923c">teicoplanin</span>：類似 vancomycin，但半衰期較長，可靜脈或肌肉注射。

### 酯類（Daptomycin）

<span style="color:#fb923c">daptomycin</span> 為<span style="color:#60a5fa"> lipopeptide 抗生素</span>，作用於<span style="color:#22d3ee">細菌細胞膜</span>，使細胞膜去極化。對<span style="color:#c084fc">MRSA</span>、<span style="color:#c084fc">vancomycin-resistant Enterococcus</span>（VRE）有效。不用於肺炎（會被肺表面活性劑抑制）。

### 抗藥性機制

1. **β-lactamases 水解**：最常見的抗藥性機制
2. **PBP 改變**：如 MRSA 的 mecA 基因產生低親和性 PBP
3. **藥物滲透障礙**：革蘭氏陰性菌外膜 porin 通道改變
4. **外排泵（Efflux pump）**：將藥物排出菌體

### 臨床應用要點

- <span style="color:#f87171">Penicillin 過敏者</span>若僅有皮疹，可考慮使用 cephalosporins（交叉過敏反應 < 1-2%）
- <span style="color:#f87171">Penicillin 過敏者</span>若有全身性過敏反應（anaphylaxis），應避免所有 β-lactams
- <span style="color:#fb923c">ceftriaxone</span> 可用於細菌性腦膜炎的初始治療
- <span style="color:#fb923c">vancomycin</span> 需監測血中濃度（trough level 10-15 mcg/mL 用於 MRSA 肺炎）

## 重點摘要

- β-內醯胺抗生素抑制細胞壁合成，具<span style="color:#60a5fa"> bactericidal</span>作用
- 青黴素類分為三群：標準、抗葡萄球菌、广效
- 頭孢菌素類分為五代，各有抗菌譜特點
- Vancomycin 為對抗 MRSA、Enterococcus 的最後一線藥物
- β-lactamase 抑制劑（如 <span style="color:#fb923c">clavulanate</span>、<span style="color:#fb923c">tazobactam</span>）可保護 β-lactam 抗生素不被水解
