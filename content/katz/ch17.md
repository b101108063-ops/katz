## 章節導讀

本章介紹<span style="color:#60a5fa">類二十烷酸</span>的生物合成途徑，包括<span style="color:#60a5fa">環氧酶（COX）</span>、<span style="color:#60a5fa">脂肪氧酶（LOX）</span>與<span style="color:#60a5fa">細胞色素P450</span>途徑，並涵蓋<span style="color:#60a5fa">前列腺素</span>、<span style="color:#60a5fa">血栓烷</span>、<span style="color:#c084fc">白三烯</span>的生理作用與臨床藥理學。

---

## 類二十烷酸概述

類二十烷酸是<span style="color:#e2e8f0">多元不飽和脂肪酸（主要是花生四烯酸AA）</span>的氧化產物。

### 生物合成途徑

| 途徑 | 產物 |
|------|------|
| <span style="color:#60a5fa">COX（環氧酶）</span> | 前列腺素、血栓烷、前列腺環素 |
| <span style="color:#60a5fa">LOX（脂肪氧酶）</span> | 白三烯、脂氧素 |
| <span style="color:#60a5fa">P450環氧酶</span> | EETs（環氧二十碳三烯酸） |

### COX同功酶

| COX類型 | 特性 | 功能 |
|---------|------|------|
| <span style="color:#60a5fa">COX-1</span> | 結構型，「housekeeping」 | 胃黏膜保護、血小板功能 |
| <span style="color:#60a5fa">COX-2</span> | 誘導型 | 發炎、疼痛、發燒 |

## 前列腺素（Prostaglandins）

### 前列腺素受體

| 受體 | 對應配體 |
|------|---------|
| EP1-4 | PGE₂ |
| FP | PGF₂α |
| DP | PGD₂ |
| IP | PGI₂（前列腺環素） |
| TP | TXA₂ |

### 各類前列腺素效應

**PGE₂效應**：
- 發炎（血管擴張、水腫）
- 發燒（經EP₃）
- 疼痛敏感化
- 胃黏膜保護（小劑量時）
- 腎血流量與鈉排泄

**PGF₂α效應**：
- 子宮收縮
- 支氣管收縮
- 血管平滑肌收縮

**PGI₂（前列腺環素）效應**：
- 血管擴張
- <span style="color:#60a5fa">抑制血小板聚集</span>

**TXA₂效應**：
- 血管收縮
- <span style="color:#f87171">血小板聚集</span>

## 白三烯（Leukotrienes）

### 生物合成

<span style="color:#e2e8f0">花生四烯酸（AA）</span>→經<span style="color:#e2e8f0">5-LOX</span>→<span style="color:#e2e8f0">LTA₄</span>→LTA₄→LTB₄或LTC₄、LTD₄、LTE₄

### 半胱氨酰白三烯效應（LTC₄、LTD₄、LTE₄）

| 效應 | 說明 |
|------|------|
| 支氣管收縮 | <span style="color:#c084fc">效力是組織胺的1000倍</span> |
| 血管通透性增加 | 導致水腫 |
| 黏液分泌 | 過多黏液產生 |

### 白三烯受體

| 受體 | 配體 | 功能 |
|------|------|------|
| BLT1、BLT2 | LTB₄ | 白血球趨化性 |
| CysLT1、CysLT2 | 半胱氨酰白三烯 | 支氣管收縮 |

## 脂氧素（Lipoxins）

- 抗發炎介質
- 對抗白三烯作用
- 促進發炎緩解

---

## NSAIDs（非類固醇抗發炎藥物）

### 作用機轉

<span style="color:#60a5fa">NSAIDs抑制COX-1和/或COX-2</span>，減少前列腺素與血栓烷合成

| NSAID類型 | 選擇性 | 代表藥物 |
|-----------|--------|---------|
| 非選擇性COX抑制 | COX-1>COX-2 | <span style="color:#fb923c">Aspirin</span>、Ibuprofen、Naproxen |
| COX-2選擇性抑制 | COX-2 | <span style="color:#fb923c">Celecoxib</span> |

### Aspirin（阿斯匹靈）特點

| 特性 | 說明 |
|------|------|
| 作用特點 | <span style="color:#f87171">不可逆COX抑制</span> |
| 臨床用途 | 止痛、退燒、抗發炎、<span style="color:#60a5fa">心血管保護</span> |
| 重要副作用 | 胃腸道出血、<span style="color:#f87171">抑制血小板功能</span> |

<span style="color:#f87171">警告：血小板COX-1被Aspirin不可逆抑制後，需約7-10天才能恢復血小板功能</span>
