## 章節導讀

鴉片類止痛藥是臨床疼痛管理最重要的藥物類別，透過作用於中樞與周邊神經系統的μ、δ、κ等鴉片受體而產生強效鎮痛效果。本章節系統探討鴉片受體的分布與訊號傳遞、各類鴉片類藥物的藥理特性、臨床應用、不良反應與耐受/依賴的機轉，以及鴉片類拮抗劑與部分激動劑的臨床應用。

## <span style="color:#60a5fa">Opioid Analgesics</span> & <span style="color:#60a5fa">Antagonists</span>

Opioid analgesics are the most important drug class in clinical pain management, producing potent analgesic effects by acting on μ, δ, κ and other opioid receptors in the central and peripheral nervous systems. This chapter systematically explores the distribution and signal transduction of opioid receptors, the pharmacological properties of various opioid drugs, their clinical applications, adverse effects and tolerance/dependence mechanisms, as well as the clinical use of opioid antagonists and partial agonists.

## 第一節　鴉片受體系統

### 受體分類

<span style="color:#e2e8f0">**內源性鴉片系統（Endogenous Opioid System）**</span>包括內啡肽（Endorphins）、腦啡肽（Enkephalins）與強啡肽（Dynorphins）。

| 受體 | 內源性配體 | 主要效應 |
|------|----------|---------|
| **μ（Mu/MOP）** | β-Endorphin | **最強鎮痛**；欣快感；呼吸抑制；瞳孔縮小；胃腸抑制（便秘）；依賴性 |
| **δ（Delta/DOP）** | Enkephalins | 鎮痛；情緒調節；可能減少μ相關副作用 |
| **κ（Kappa/KOP）** | Dynorphins | 鎮痛；鎮靜；幻覺；瞳孔縮小；利尿 |
| **ORL-1（NOP）** | Nociceptin/Orphanin FQ | 抗鎮痛（Allodynia）；焦慮；食慾 |

### 訊號傳遞

<span style="color:#60a5fa">**μ受體**</span>為G<sub>i/o</sub>蛋白偶聯受體：

| 效應 | 說明 |
|------|------|
| **抑制Adenylyl cyclase** | 減少cAMP |
| **開放K<sup>+</sup>通道** | 細胞膜超極化 |
| **關閉電壓依賴性Ca<sup>2+</sup>通道** | 減少神經傳遞物質釋放 |

## 第二節　鴉片類藥物的分類

### A. 天然與半合成鴉片類藥物

| 藥物 | 來源 | 特點 |
|------|------|------|
| <span style="color:#fb923c">Morphine（嗎啡）</span> | 鴉片（罌粟） | 經典μ完全激動劑；原型藥物 |
| <span style="color:#fb923c">Codeine（可待因）</span> | 鴉片（低含量） | **前驅藥**；經CYP2D6轉化為Morphine |
| <span style="color:#fb923c">Heroin（二醋嗎啡）</span> | 半合成 | Diacetylmorphine；高脂溶性→快速通過BBB |
| <span style="color:#fb923c">Hydromorphone（氫嗎啡酮）</span> | 半合成 | 嗎啡衍生物；效價約5–7倍 |
| <span style="color:#fb923c">Oxycodone（羥考酮）</span> | 半合成 | 中效；μ激動劑 |
| <span style="color:#fb923c">Oxymorphone（氫氧嗎啡酮）</span> | 半合成 | 強效；口服/注射 |
| <span style="color:#fb923c">Hydrocodone（氫可酮）</span> | 半合成 | 中效；常與Acetaminophen/ibuprofen合用 |

### B. 合成鴉片類藥物

| 藥物 | 效價（vs嗎啡） | 特點 |
|------|--------------|------|
| <span style="color:#fb923c">Fentanyl（芬太尼）</span> | 100倍 | 超強效；μ激動劑；可用於癌症疼痛貼片 |
| <span style="color:#fb923c">Methadone（美沙酮）</span> | 2–3倍 | NMDA受體拮抗；鴉片維持治療；長半衰期 |
| <span style="color:#fb923c">Meperidine（哌替啶）</span> | 1/10 | 短效；**不宜長期使用**（Normeperidine累積→CNS毒性） |
| <span style="color:#fb923c">Tramadol（曲馬多）</span> | 1/5 | **弱μ激動劑 + NE/5-HT回收抑制**；癲癇閾值降低 |
| <span style="color:#fb923c">Tapentadol（他噴他多）</span> | 1/3–1/5 | **μ激動劑 + NE回收抑制**；神經病理痛 |
| <span style="color:#fb923c">Alfentanil</span> | 20–30倍 | 超短效；手術止痛 |
| <span style="color:#fb923c">Sufentanil</span> | 500–1000倍 | 極強效；硬膜外/靜脈麻醉 |
| <span style="color:#fb923c">Remifentanil</span> | 100倍 | **短效（酯酶代謝）**；麻醉維持 |

### C. 鴉片部分激動劑/混合作用藥物

| 藥物 | 受體作用 | 特點 |
|------|---------|------|
| <span style="color:#fb923c">Buprenorphine（丁丙諾啡）</span> | **μ部分激動劑（K>μ）** | 高親和力； ceiling呼吸抑制；常用於鴉片維持 |
| <span style="color:#fb923c">Pentazocine</span> | κ激動/μ部分激動 | 輕度鎮痛；不宜與其他μ激動劑合用 |
| <span style="color:#fb923c">Butorphanol</span> | κ激動/μ部分激動 | 鼻噴劑可用於偏頭痛 |
| <span style="color:#fb923c">Nalbuphine</span> | κ激動/μ部分激動 | 術後止痛；對μ相關副作用有天花板效應 |

## 第三節　藥物動力學

| 特性 | 說明 |
|------|------|
| **吸收** | 口服吸收良好（首過效應明顯）；經皮貼片（Fentanyl）；舌下/口腔（ buprenorphine） |
| **分布** | 高度親脂性；廣泛分布於組織；可通過胎盤；進入母乳 |
| **代謝** | 肝臟CYP450（主要CYP3A4、CYP2D6）；嗎啡經UDP-葡萄糖醛酸轉移酶（UGT） |
| **排泄** | 腎臟（原型與代謝物）；糞便（膽汁排泄） |
| **半衰期** | 各異（Remifentanil數分鐘；Methadone數十小時） |

### 特殊族群

| 族群 | 劑量調整 |
|------|---------|
| **老年人** | 敏感性↑；腎功能減退（尤其嗎啡-6-葡萄糖醛酸苷蓄積） |
| **腎功能減退** | 避免嗎啡（M6G蓄積）；Fentanyl/ methadone較安全 |
| **肝功能減退** | 所有鴉片類代謝減少；劑量需減少 |
| **肥胖** | 以實際體重計算；Fentanyl貼片劑量需個別化 |

## 第四節　臨床應用

### 疼痛類型與藥物選擇

| 疼痛類型 | 建議藥物 |
|---------|---------|
| **急性疼痛（術後/外傷）** | 嗎啡、氫嗎啡酮、Fentanyl（靜脈PCA）；嗎啡/氫考酮（口服） |
| **慢性非癌症疼痛** | 需審慎評估；儘可能使用非鴉片藥物；如需使用則以低劑量/短效為原則 |
| **癌症疼痛** | 強效鴉片類（嗎啡、氫嗎啡酮、Fentanyl）；按時+必要時（PRN）給藥 |
| **神經病理痛** | **Tapentadol**、Tramadol；可加用抗癲癇藥/抗憂鬱藥 |
| **產科止痛** | **Fentanyl（硬膜外）**；避免長時間Meperidine（Normeperidine蓄積） |

### 給藥途徑

| 途徑 | 說明 |
|------|------|
| **口服** | 首選（嗎啡、氫嗎啡酮、氧可酮、美沙酮） |
| **靜脈/肌肉/皮下** | 急性疼痛；PCA（患者自控止痛） |
| **硬膜外/脊椎** | 手術麻醉/術後止痛；嗎啡/Fentanyl/Sufentanil |
| **經皮貼片** | Fentanyl貼片（慢性疼痛）；Buprenorphine貼片 |
| **舌下/口腔** | Buprenorphine（鴉片依賴） |

### 嗎啡劑量參考

| 情況 | 初始劑量 |
|------|---------|
| 成人急性疼痛（口服） | 嗎啡IR 10–30 mg q3-4h 或 15–30 mg ER q12h |
| 成人急性疼痛（靜脈） | 2–5 mg IV q3-4h 或 PCA |
| 老年人/體弱者 | 起始劑量減少50% |

## 第五節　不良反應

| 不良反應 | 說明 | 處理 |
|---------|------|------|
| **呼吸抑制** | **最嚴重**；μ受體作用；危及生命 | **Naloxone（納洛酮）**靜脈注射；重複給藥 |
| **便秘** | **最常見**；無耐受；需預防性使用刺激性瀉劑 | 軟便劑/刺激性瀉劑；甲基納曲酮（Lmethylnaltrexone）/Naloxegol |
| **噁心/嘔吐** | 初期常見；化學觸發區（CTZ）刺激 | Ondansetron、Prochlorperazine |
| **鎮靜/嗜睡** | 初期常見；通常數天耐受 | 避免駕駛； Caffeine可能有幫助 |
| **認知障礙** | 老年人明顯；急性譫妄 | 減少劑量；考慮更換藥物 |
| **瘙癢** | 嗎啡明顯；組織胺釋放；CTZ作用 | Antihistamines；Naloxone少量 |
| **尿滯留** | 老年人/男性；抗利尿作用 | 導尿；Naloxone |
| **瞳孔縮小（Miosis）** | 所有μ激動劑；診斷價值 | 通常為預期副作用 |

<span style="color:#f87171">**呼吸抑制為危及生命的不良反應**，處理為靜脈注射<span style="color:#fb923c">**Naloxone（納洛酮）**</span>。</span>

## 第六節　耐受與依賴

### 耐受（Tolerance）

| 類型 | 說明 |
|------|------|
| **藥效（Analgesia）** | 需增加劑量維持相同效果 |
| **呼吸抑制** | 發展相對慢 |
| **嘔吐/鎮靜** | 快速耐受 |
| **便秘** | **幾乎無耐受**；需持續預防 |
| **瞳孔縮小** | 輕度耐受 |

**交叉耐受**：對一種μ激動劑耐受對其他μ激動劑也有交叉耐受。

### 依賴（Dependence）

| 類型 | 說明 |
|------|------|
| **生理依賴** | 突然停藥引起戒斷症狀；生理適應 |
| **心理依賴/成癮** | 強迫性藥物尋求行為；非醫療使用 |

<span style="color:#e2e8f0">**戒斷症狀（Withdrawal）**：焦慮、激越、流汗、嘔吐、腹瀉、肌肉痙攣、瞳孔散大、雞皮疙瘩（"Cold turkey"）。</span>

### 長期使用原則

| 原則 | 說明 |
|------|------|
| **審慎評估** | 風險/效益分析；疼痛程度量化 |
| **知情同意** | 告知患者副作用與成癮風險 |
| **低劑量起始** | 逐步滴定 |
| **定期監測** |疼痛評估/功能改善；異常用藥行為 |
| **逐漸減量** | 避免骤然停藥引起戒斷 |

## 第七節　鴉片類拮抗劑與部分激動劑

### 拮抗劑（Antagonists）

| 藥物 | 機轉 | 臨床應用 |
|------|------|---------|
| <span style="color:#fb923c">Naloxone（納洛酮）</span> | **μ/δ/κ完全拮抗** | **鴉片過量急救**（0.4–2 mg IV，5分鐘重複）；術後逆轉；診斷疑似鴉片過量 |
| <span style="color:#fb923c">Naltrexone（納曲酮）</span> | **μ/δ/κ完全拮抗（口服）** | **鴉片依賴復發預防**；酒精依賴輔助治療；長效肌肉注射（Vivitrol） |

### 部分激動劑（Partial Agonists）

| 藥物 | 機轉 | 臨床應用 |
|------|------|---------|
| <span style="color:#fb923c">Buprenorphine（丁丙諾啡）</span> | **μ部分激動（高親和力）**；κ拮抗 | **鴉片依賴維持治療**（美沙酮替代）；術後止痛；慢性疼痛 |

<span style="color:#f87171">**Naloxone可逆轉所有鴉片類藥物的鎮痛/呼吸抑制作用，但對Methadone與Buprenorphine的作用逆轉可能不完全（因高親和力）。</span>

## 第八節　重點摘要

- <span style="color:#fb923c">Morphine</span>為μ受體完全激動劑的原型藥物，用於急性與慢性疼痛
- <span style="color:#fb923c">Fentanyl</span>效價為嗎啡的100倍，有靜脈制劑與經皮貼片
- <span style="color:#fb923c">Remifentanil</span>為短效酯酶代謝的μ激動劑，用於麻醉
- <span style="color:#fb923c">Methadone</span>同時為NMDA受體拮抗劑，可用於神經病理痛與鴉片維持治療
- <span style="color:#fb923c">Tramadol</span>與<span style="color:#fb923c">Tapentadol</span>結合μ激動與NE/5-HT回收抑制
- <span style="color:#fb923c">Buprenorphine</span>為μ部分激動劑，用於鴉片依賴維持治療
- <span style="color:#fb923c">Naloxone</span>為完全拮抗劑，用於<span style="color:#f87171">**鴉片過量急救**</span>
- <span style="color:#f87171">**便秘是最常見且無耐受的副作用，需預防性用藥**</span>
- <span style="color:#f87171">**呼吸抑制是最危險的急性不良反應**，可用Naloxone逆轉
- 長期使用鴉片類藥物會產生生理依賴，突然停藥會引起戒斷症狀
