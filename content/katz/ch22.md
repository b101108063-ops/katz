## 章節導讀

本章介紹<span style="color:#60a5fa">抗癲癇藥物</span>的藥理學，包括傳統藥物（如<span style="color:#fb923c">Phenytoin</span>、<span style="color:#fb923c">Carbamazepine</span>、<span style="color:#fb923c">Valproate</span>）與新型藥物（如<span style="color:#fb923c">Lamotrigine</span>、<span style="color:#fb923c">Levetiracetam</span>、<span style="color:#fb923c">Gabapentin</span>）的作用機轉、臨床應用與不良反應。

---

## 癲癇分類與治療原則

### 主要癲癇類型

| 發作類型 | 特徵 |
|---------|------|
| 全身強直陣攣（大發作） | 意識喪失、全身痙攣 |
| 失神（小發作） | 短暫意識喪失，無痙攣 |
| 局部發作 | 局部肌肉抽搐或感覺異常 |
| 複雜部分發作 | 意識障礙，自動行為 |
| 癲癇重積狀態 | 連續發作，意識未恢復 |

---

## 抗癲癇藥物分類

### 依作用機轉

| 機轉 | 代表藥物 |
|------|---------|
| <span style="color:#60a5fa">鈉通道阻斷</span> | Phenytoin、Carbamazepine、Lamotrigine |
| <span style="color:#60a5fa">鈣通道阻斷（T型）</span> | Ethosuximide |
| <span style="color:#60a5fa">GABA增強</span> | Phenobarbital、Benzodiazepines、Vigabatrin |
| <span style="color:#60a5fa">谷氨酸/NMDA抑制</span> | Felbamate、Topiramate |
| <span style="color:#60a5fa">多重機轉</span> | Valproate、Levetiracetam |

---

## 鈉通道阻斷劑

### Phenytoin（苯妥英）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">選擇性阻斷已去極化細胞的電壓依賴性鈉通道</span> |
| 臨床用途 | <span style="color:#60a5fa">局部發作、全身強直陣攣發作</span> |
| 治療血漿濃度 | <span style="color:#34d399">10-20 mg/L</span> |
| 非線性藥物動力學 | 是（半衰期隨劑量改變） |

**劑量與血漿濃度關係**：
- 低劑量：線性（一級動力學）
- 高劑量：非線性（零級動力學）

**主要副作用**：

| 系統 | 副作用 |
|------|--------|
| 齒齦增生 | 約50%患者 |
| 周邊神經病變 | 長期用藥 |
| 眼球震顫 | 濃度過高 |
| 畸胎 | <span style="color:#f87171">胎兒乙內醯胺症</span>（唇顎裂、心臟缺陷） |
| 血液系統 | 粒性白血球減少、再障性貧血 |
| 皮膚 | Stevens-Johnson症候群（罕見） |

<span style="color:#f87171">注意：Phenytoin為窄治療窗口藥物，需監測血漿濃度</span>

---

### Carbamazepine（卡馬西平）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">鈉通道阻斷</span> |
| 臨床用途 | <span style="color:#60a5fa">局部發作、複雜部分發作、全身強直陣攣</span> |
| 誘導自身代謝 | 是 |

**主要副作用**：

| 系統 | 副作用 |
|------|--------|
| CNS | 眩暈、共濟失調、視力模糊 |
| 血液系統 | <span style="color:#f87171">顆粒性白血球缺乏症</span>、再生不良性貧血 |
| 皮膚 | <span style="color:#f87171">Stevens-Johnson症候群</span>、毒性表皮溶解 |
| 肝臟 | 肝毒性 |
| 其他 | 低鈉血症、抗利尿激素分泌不當 |

<span style="color:#f87171">警告：建議定期監測血液象，特別是前3個月</span>

---

### Oxcarbazepine（奧卡西平）

| 特性 | 說明 |
|------|------|
| 為Carbamazepine的酮類衍生物 | 較少血液系統與肝臟毒性 |
| 臨床用途 | 局部發作、部分繼發全身發作 |
| 優點 | 低鈉血症發生率較高 |

---

### Lamotrigine（拉莫三嗪）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">鈉通道阻斷＋抑制谷氨酸釋放</span> |
| 臨床用途 | <span style="color:#60a5fa">局部發作、失神、Lennox-Gastaut症候群</span> |
| 優點 | 較少認知副作用 |

**主要副作用**：
- <span style="color:#f87171">皮疹（包括Stevens-Johnson）</span>：需緩慢滴定

<span style="color:#f87171">注意：需非常緩慢增加劑量，以降低皮疹風險</span>

---

## 鈣通道阻斷劑（T型）

### Ethosuximide（乙琥胺）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">阻斷T型鈣通道</span>（視丘神經元） |
| 臨床用途 | <span style="color:#60a5fa">失神發作（小發作）</span> |
| 專一性 | 對其他發作類型無效 |

**主要副作用**：

| 系統 | 副作用 |
|------|--------|
| 胃腸道 | 噁心、嘔吐 |
| CNS | 眩暈、嗜睡、頭痛 |
| 血液系統 | 顆粒性白血球缺乏（罕見） |

---

## GABA增強劑

### Phenobarbital（苯巴比妥）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">GABA_A受體增強</span> |
| 臨床用途 | <span style="color:#60a5fa">新生兒痙攣、熱性痙攣、全身強直陣攣</span> |
| 優點 | 價格低廉、長效 |
| 缺點 | 鎮靜、認知影響 |

**主要副作用**：

| 系統 | 副作用 |
|------|--------|
| CNS | 鎮靜、嗜睡、認知受損 |
| 依賴性 | <span style="color:#f87171">長期使用具依賴性</span> |
| 運動 | 行為問題、活動過度（兒童） |

---

### Benzodiazepines（用於癲癇）

| 藥物 | 臨床用途 |
|------|---------|
| <span style="color:#fb923c">Diazepam</span> | <span style="color:#60a5fa">癲癇重積（靜脈）</span> |
| <span style="color:#fb923c">Lorazepam</span> | <span style="color:#60a5fa">癲癇重積（靜脈）</span> |
| <span style="color:#fb923c">Clonazepam</span> | 失神、肌陣攣 |
| <span style="color:#fb923c">Clorazepate</span> | 輔助治療 |

---

### Vigabatrin（氨己烯酸）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">GABA轉胺酶抑制</span> |
| 臨床用途 | <span style="color:#60a5fa">嬰兒痙攣</span>、局部發作 |
| 副作用 | <span style="color:#f87171">周邊視野缺損（不可逆）</span> |

<span style="color:#f87171">警告：用藥前需進行視野檢查，並定期追蹤</span>

---

## 多重機轉抗癲癇藥物

### Valproate（丙戊酸）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">多重機轉：鈉通道阻斷＋GABA增加＋T型鈣通道阻斷</span> |
| 臨床用途 | <span style="color:#60a5fa">全身強直陣攣、失神、肌陣攣、局部發作</span> |
| 光譜 | 抗癲癇光譜最廣 |

**主要副作用**：

| 系統 | 副作用 |
|------|--------|
| 肝臟 | <span style="color:#f87171">肝毒性（特別是兒童）</span> |
| 胰臟 | <span style="color:#f87171">胰臟炎</span> |
| 血液系統 | 血小板減少 |
| 畸胎 | <span style="color:#f87171">神經管缺陷（spina bifida）</span> |
| 體重 | 體重增加、肥胖 |
| 毛髮 | 多毛症、禿頭 |

<span style="color:#f87171">警告：禁用於孕婦及有肝臟疾病者</span>

---

### Levetiracetam（左乙拉西坦）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">與SV2A蛋白結合</span>，抑制突觸傳遞 |
| 臨床用途 | <span style="color:#60a5fa">局部發作、全身強直陣攣</span> |
| 優點 | 較少藥物交互作用 |

**副作用**：
- CNS：眩暈、嗜睡、行為改變（兒童）
- 體重改變（通常減少）

---

### Topiramate（托吡酯）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">多重：鈉通道阻斷＋GABA增強＋AMPA/紅藻氨酸鹽受體抑制</span> |
| 臨床用途 | <span style="color:#60a5fa">局部發作、減重（可考慮用於肥胖患者）</span> |
| 副作用 | 感覺異常、認知障礙、<span style="color:#f87171">腎結石</span>、體重減輕 |

---

### Gabapentin/Pregabalin

| 特性 | Gabapentin | Pregabalin |
|------|-----------|-----------|
| 機轉 | <span style="color:#e2e8f0">與α2δ亞單位結合</span> | 類似 |
| 臨床用途 | <span style="color:#60a5fa">局部發作</span>、神經痛 | 局部發作、神經痛、焦慮 |
| 副作用 | 眩暈、嗜睡 | 眩暈、嗜睡 |
| 特點 | 不與血漿蛋白結合，無藥物交互作用 | 較高效力 |

## 癲癇重積狀態治療

| 藥物 | 給藥途徑 | 劑量 |
|------|---------|------|
| <span style="color:#fb923c">Lorazepam</span> | 靜脈 | 0.1 mg/kg |
| <span style="color:#fb923c">Diazepam</span> | 靜脈/直腸 | 10-20 mg |
| <span style="color:#fb923c">Fosphenytoin</span> | 靜脈 | 15-20 mg PE/kg |
| <span style="color:#fb923c">Valproate</span> | 靜脈 | 20-30 mg/kg |

## 抗癲癇藥物與妊娠

| 藥物 | 畸胎風險 |
|------|---------|
| Valproate | <span style="color:#f87171">最高（神經管缺陷1-2%）</span> |
| Phenytoin | 胎兒乙內醯胺症 |
| Carbamazepine | 輕度風險 |
| Lamotrigine | 較低（建議補充葉酸） |
| Levetiracetam | 動物數據，人類資料有限 |

<span style="color:#f87171">建議：計劃懷孕者應與醫師討論，補充高劑量葉酸（4-5 mg/日）</span>
