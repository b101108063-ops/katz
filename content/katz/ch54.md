# CH54 毒理學概論

## 章節導讀

毒理學是研究藥物及其他外源性物質對生物體不良作用的科學。本章節介紹毒理學的基本概念，包括毒性分類、劑量-反應關係、毒性作用的時間與劑量因素，以及中毒的臨床評估與處理原則。這些知識對於理解藥物不良反應、藥物過量及環境毒物暴露至關重要。

---

## 毒性分類

### 依作用時間分類

| 類型 | 定義 | 範例 |
|------|------|------|
| <span style="color:#60a5fa">**急性毒性**</span> | 單次或24小時內多次暴露所致 | 農藥中毒、藥物過量 |
| <span style="color:#60a5fa">**慢性毒性**</span> | 長期反覆暴露（數月或數年）| 重金屬累積中毒、職業病 |
| <span style="color:#60a5fa">**亞急性毒性**</span> | 短中期暴露（數天至數週）| 藥物蓄積中毒 |

### 依毒性作用部位分類

| 類型 | 說明 |
|------|------|
| <span style="color:#60a5fa">**直接毒性**</span> | 藥物或其代謝物直接傷害組織 |
| <span style="color:#60a5fa">**特異體質反應**</span> | 遺傳性代謝異常導致（例：G6PD缺乏導致溶血）|
| <span style="color:#60a5fa">**過敏反應**</span> | 免疫媒介（例：Penicillin過敏）|
| <span style="color:#60a5fa">**Idiosyncrasy**</span> | 异常的、不可預測的反應 |

---

## 劑量-反應關係

### 治療指數與安全範圍

<span style="color:#60a5fa">**治療指數（Therapeutic Index, TI）** = LD₅₀ / ED₅₀</span>

| 數值 | 臨床意義 |
|------|---------|
| TI大 | 安全範圍廣 |
| TI小 | 安全範圍窄；需精確劑量控制 |

<span style="color:#f87171">**重要**：兩個藥物可能有相同的TI，但安全劑量範圍可能不同（取決於劑量-反應曲線的斜率）。</span>

### 量化風險與劑量反應

| 概念 | 說明 |
|------|------|
| <span style="color:#60a5fa">**劑量-反應曲線**</span> | 多數藥物為S形曲線（sigmoID）；有些為線性（如殺蟲劑）|
| <span style="color:#60a5fa">**個體差異**</span> | 即使是「安全」藥物，在高敏感個體可能產生意外毒性 |
| <span style="color:#60a5fa">**數量化風險評估**</span> | 常用於環境毒物（如no-observed-adverse-effect level, NOAEL）|

---

## 毒性作用的時間因素

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**接觸時間**</span> | 暴露持續時間決定總劑量 |
| <span style="color:#60a5fa">**蓄積**</span> | 吸收超過排除，組織濃度增加 |
| <span style="color:#60a5fa">**生物轉化**</span> | 有些化合物需經代謝活化才具毒性（例：methanol→formaldehyde）|
| <span style="color:#60a5fa">**延遲毒性**</span> | 症狀出現落後於暴露（如：砷中毒）|

## 中毒病患處理原則

### ABCD搶救步驟

| 步驟 | 內容 |
|------|------|
| <span style="color:#60a5fa">**A (Airway)**</span> | 維持呼吸道通暢；必要時插管 |
| <span style="color:#60a5fa">**B (Breathing)**</span> | 評估呼吸；若有呼吸抑制，機械輔助換氣 |
| <span name="color:#60a5fa">**C (Circulation)**</span> | 監測脈搏、血壓、尿量；建立靜脈通路 |
| <span style="color:#60a5fa">**D (Drugs/Decontamination)**</span> | 血糖檢測；必要時給予解毒劑；清除污染 |

### 初始處置

| 處置 | 說明 |
|------|------|
| <span style="color:#60a5fa">**靜脈給予高張葡萄糖**</span> | 成人25 g（50 mL of 50% dextrose）；兒童0.5 g/kg |
| <span style="color:#60a5fa">**Naloxone**</span> | 0.4-2 mg IV；逆轉鴉片類藥物呼吸抑制 |
| <span style="color:#60a5fa">**Thiamine**</span> | 100 mg IM或加於靜脈輸液中；預防Wernicke腦病 |
| <span style="color:#60a5fa">**Flumazenil**</span> | 0.2 mg IV（必要時重複，最大3 mg）；逆轉benzodiazepine；<span style="color:#f87171">**禁用於TCA過量或癲癇患者**</span> |

## 中毒評估要點

### 生命徵象與理學檢查

| 徵象 | 可能的中毒類型 |
|------|-------------|
| <span style="color:#60a5fa">**高血壓、心搏過速**</span> | Amphetamines、Cocaine、抗膽鹼制劑 |
| <span style="color:#60a5fa">**低血壓、心搏過緩**</span> | β-blockers、Calcium channel blockers、Clonidine、鎮靜劑 |
| <span style="color:#60a5fa">**瞳孔放大（Mydriasis）**</span> | Amphetamines、Cocaine、LSD、Atropine |
| <span style="color:#60a5fa">**瞳孔縮小（Miosis）**</span> | 鴉片類、Clonidine、有機磷中毒 |
| <span style="color:#60a5fa">**體溫過高**</span> | 抗膽鹼制劑、sympathomimetics、salicylates |
| <span style="color:#60a5fa">**體溫過低**</span> | CNS抑制藥物（特別是combined with cold exposure）|

### 實驗室評估

| 檢驗 | 目的 |
|------|------|
| <span style="color:#60a5fa">**血清滲透壓差**</span> | 檢測醇類中毒（ethanol、methanol、ethylene glycol、isopropanol）|
| <span style="color:#60a5fa">**陰離子間隙**</span> | 升高：常見於salicylates、methanol、ethylene glycol、iron、isoniazid |
| <span style="color:#60a5fa">**心電圖**</span> | QRS延長：TCA過量；QT延長：quinidine、erythromycin |
| <span style="color:#60a5fa">**X光**</span> | 某些藥物可顯影（鐵製劑、鉀製劑）|

## 清除技術（Enhanced Elimination）

### 血液透析適應症

| 透析可移除的藥物 | 透析無效的藥物 |
|----------------|--------------|
| <span style="color:#fb923c">Ethylene glycol</span> | Amphetamines |
| <span style="color:#fb923c">Methanol</span> | 抗憂鬱劑 |
| <span style="color:#fb923c">Lithium</span> | 抗精神病藥物 |
| <span style="color:#fb923c">Salicylates</span>（嚴重時）| Benzodiazepines |
| <span style="color:#fb923c">Theophylline</span> | Opioids |
| <span style="color:#fb923c">Valproic acid</span> | Beta blockers |

### 尿液鹼化

<span style="color:#60a5fa">**適應症**：Salicylate中毒（目標尿液pH > 7.5）</span>

原理：鹼性環境使salicylate離子化，減少腎小管再吸收，增加排泄。

## 常見中毒症候群

### 抗膽鹼制劑中毒

<span style="color:#60a5fa">**口號**：「像甜菜一样红」（皮膚潮红），「像野兔一样烫」（體溫過高），「像骨头一样干」（黏膜乾燥、無汗），「像蝙蝠一样盲」（視力模糊），「像帽匠一样疯」（意識混亂、譫妄）</span>

| 處置 | 說明 |
|------|------|
| 支持性治療 | 維持呼吸道、靜脈輸液 |
| <span style="color:#fb923c">Physostigmine</span> | <span style="color:#f87171">**特異解毒劑**</span>：0.5-1 mg IV（緩慢）；<span style="color:#f87171">**禁用於TCA過量**</span> |

### Tricyclic Antidepressants（TCA）中毒

<span style="color:#60a5fa">**毒性機轉**：抗膽鹼作用+quinidine樣心臟毒性（Na通道阻斷）+α受體阻斷</span>

| 表現 | 說明 |
|------|------|
| <span style="color:#60a5fa">**心臟**</span> | QRS延長（> 100 ms）；心室心律不整 |
| <span style="color:#60a5fa">**抗膽鹼**</span> | 瞳孔放大、心搏過速、尿瀦留 |
| <span style="color:#60a5fa">**CNS**</span> | 意識障礙、痙攣 |

| 處置 | 說明 |
|------|------|
| <span style="color:#fb923c">Sodium bicarbonate</span> | <span style="color:#34d399">**首選解毒**</span>：1-2 mEq/kg IV bolus；增強細胞外鈉濃度對抗Na通道阻斷 |
| 避免 | Physostigmine（可能加重心臟傳導抑制）|

### Acetaminophen中毒

<span style="color:#60a5fa">**毒性機轉**：N-acetyl-p-benzoquinone imine (NAPQI)堆積，耗竭肝臟glutathione</span>

| 劑量 | 風險 |
|------|------|
| > 150-200 mg/kg（兒童）或 > 7 g（成人）| 可能具毒性 |
| > 250 mg/kg | 肝細胞壞死高風險 |

| 處置 | 說明 |
|------|------|
| <span style="color:#fb923c">Acetylcysteine (N-acetylcysteine, NAC)</span> | <span style="color:#34d399">**特異解毒劑**</span>；8-10小時內給予效果最佳；作為glutathione替代物結合NAPQI |
| <span style="color:#60a5fa">**Liver transplant**</span> | 暴發性肝衰竭時考虑 |
