## 章節導讀

本章介紹抗心律不整藥物的分類與藥理學，涵蓋<span style="color:#60a5fa">Vaughan-Williams 分類系統</span>（Class I-IV），包括鈉通道阻斷劑、β阻斷劑、動作電位延長劑及鈣通道阻斷劑的作用機轉與臨床應用，並說明致心律不整風險與臨床用藥原則。

---

## Vaughan-Williams 抗心律不整藥物分類

抗心律不整藥物可減少異位節律點的自動性，效果較SA結更明顯。這些藥物也能降低傳導與興奮性，並在已去極化組織中延長有效不反應期。

主要藥理機轉包括：
1. **鈉通道阻斷**
2. **阻斷心臟交感神經效應**
3. **延長有效不反應期**
4. **鈣通道阻斷**

---

## Class 1：鈉通道阻斷劑

### Subgroup 1A — 中間動力學，延長APD

**Quinidine（奎尼丁）**
- **機轉**：鈉通道阻斷，同時具有<span style="color:#e2e8f0">抗膽鹼作用</span>與<span style="color:#e2e8f0">α阻斷作用</span>
- **臨床用途**：心房與心室心律不整
- **副作用**：腹瀉、耳鳴（cinchonism）、QT延長、<span style="color:#f87171">torsades de pointes</span>

**Procainamide（普魯卡因胺）**
- **機轉**：阻斷鈉通道，減慢動作電位上升速度，延長QRS與APD
- **臨床用途**：心室心律不整
- **副作用**：<span style="color:#f87171">紅斑性狼瘡樣症候群（LE症狀）</span>、粒性白血球減少

### Subgroup 1B — 快速動力學，縮短APD

**Lidocaine（利多卡因）**
- **機轉**：優先阻斷已去極化細胞中的鈉通道，對正常心臟傳導影響小
- **臨床用途**：心室心律不整，特別是<span style="color:#e2e8f0">缺血組織</span>與心梗後
- **副作用**：中樞神經效應（眩暈、癲癇）

**Mexiletine（美西律）**
- **機轉**：類似利多卡因，但可口服
- **臨床用途**：慢性心室心律不整
- **副作用**：噁心、震顫、肝功能異常

### Subgroup 1C — 慢動力學，對APD影響小

**Propafenone（普羅帕酮）**
- **機轉**：強效鈉通道阻斷，同時具有<span style="color:#60a5fa">β阻斷活性</span>
- **臨床用途**：上心室與心室心律不整
- **副作用**：心臟抑制、<span style="color:#f87171">致心律不整風險</span>

---

## Class 2：β阻斷劑（交感神經抑制）

**Propranolol（普萘洛爾）**
- 透過β受體阻斷與直接膜效應發揮抗心律不整作用

**Esmolol（艾司洛爾）**
- <span style="color:#e2e8f0">短效β₁選擇性阻斷劑</span>，主要用於術中及急性心律不整

**Sotalol（索他洛爾）**
- 非選擇性β阻斷劑，同時具有<span style="color:#60a5fa">Class 3延長動作電位</span>作用，<span style="color:#f87171">有torsades de pointes風險</span>

---

## Class 3：延長動作電位藥物

### Amiodarone（胺碘酮）

**心臟效應**：顯著延長APD（QT間期），透過阻斷IKr同時阻斷已去極化鈉通道。另有弱交感神經與鈣通道阻斷作用。

**心外效應（重要）**：
| 系統 | 副作用 |
|------|--------|
| 肺部 | <span style="color:#f87171">肺纖維化（最重要的不良反應）</span> |
| 甲狀腺 | 甲狀腺機能亢進或低下（因含碘） |
| 肝臟 | 肝毒性 |
| 皮膚 | 灰藍色變色、光過敏 |
| 眼睛 | 角膜顯微沉積 |

**藥物動力學**：半衰期極長（數週），脂溶性高，在組織中蓄積。<span style="color:#f87171">需注意torsades風險較低</span>。

### Dronedarone（決奈達隆）

- Amiodarone的結構類似物，但無碘原子
- 多通道阻斷作用相似，但半衰期較短（24小時）
- <span style="color:#f87171">無甲狀腺功能異常或肺毒性報告</span>
- <span style="color:#f87171">禁忌於急性失代償性或晚期（第IV級）心衰竭</span>

### Dofetilide（多非利特）
- 選擇性IKr阻斷劑
- 用於心房顫動/撲動
- <span style="color:#f87171">需住院起始治療，因torsades風險</span>

### Ibutilide（伊布利特）
- 僅供靜脈注射
- 用於急性終止心房顫動/撲動
- <span style="color:#f87171">有torsades de pointes風險</span>

---

## Class 4：鈣通道阻斷劑

**Verapamil（維拉帕米）**
- **心臟效應**：減慢SA與AV結傳導，負性肌力作用
- **臨床用途**：上心室心搏過速、心房顫動時的心率控制、心絞痛
- **副作用**：心傳導阻斷、便祕、心衰竭惡化

**Diltiazem（地爾硫卓）**
- 類似Verapamil但負性肌力作用較輕
- **臨床用途**：上心室心律不整、心絞痛、高血壓

---

## 其他抗心律不整藥物

### Adenosine（腺苷）

| 特性 | 說明 |
|------|------|
| 機轉 | 活化A₁受體，產生短暫AV結阻斷 |
| 臨床用途 | 終止陣發性上心室心搏過速（PSVT）、寬複雜心搏過速的鑑別診斷 |
| 特點 | 半衰期極短（約秒） |
| 副作用 | 潮紅、胸悶、呼吸困難（短暫） |

### Magnesium（鎂）

- **機轉**：尚未完全明瞭
- **臨床用途**：Torsades de pointes、某些頑固性心律不整

---

## 致心律不整風險

<span style="color:#f87171">警告：</span>許多抗心律不整藥物可能誘發新的或更嚴重的心律不整，特別是：
- **Class 1A**（Quinidine、Procainamide）：QT延長引起Torsades
- **Class 3**（Amiodarone、Sotalol、Dofetilide、Ibutilide）：QT延長

治療心律不整時需權衡藥物效益與致心律不整風險。
