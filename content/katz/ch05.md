## <span style="color:#60a5fa">Development and Regulation of Drugs</span>

## 章節導讀

<span style="color:#e2e8f0">藥物開發與法規</span>涵蓋從新藥發現到上市審批的完整歷程，包括<span style="color:#60a5fa">藥物篩選</span>、<span style="color:#60a5fa">臨床試驗階段</span>、<span style="color:#60a5fa">FDA 審批程序</span>，以及<span style="color:#fb923c">孤兒藥</span>與<span style="color:#fb923c">加速審批</span>等特殊機制。

---

## 新藥發現流程

### 藥物標靶的發現

真正的新藥需要發現新的<span style="color:#60a5fa">藥物標靶（Drug Target）</span>——即疾病的病理生理過程或受質。多數新標靶發現起源於學術界與政府研究機構。

### 藥物開發的兩大階段

| 階段 | 說明 |
|------|------|
| 發現階段 | 在實驗室中對化合物進行篩選與優化 |
| 開發階段 | 耗時且昂貴的化學、藥理、毒理研究 |

---

## 臨床試驗

### 臨床試驗階段

| 階段 | 目的 | 受試人數 |
|------|------|---------|
| <span style="color:#60a5fa">Phase I</span> | 安全性、耐受性、藥物動力學 | 20-100 健康志願者 |
| <span style="color:#60a5fa">Phase II</span> | 初步療效、劑量範圍 | 100-500 患者 |
| <span style="color:#60a5fa">Phase III</span> | 大規模療效與安全性確認 | 1000-5000 患者 |
| <span style="color:#60a5fa">Phase IV</span> | 上市後監視 | 廣大使用者群 |

### IND 申請

<span style="color:#fb923c">IND（Investigational New Drug）</span>申請：製藥公司向 FDA 申請進行人體臨床試驗。

### NDA 申請

<span style="color:#fb923c">NDA（New Drug Application）</span>申請：完成 Phase III 後，向 FDA 提交的上市許可申請。

---

## 特殊藥物類型

### 孤兒藥（Orphan Drugs）

| 特性 | 說明 |
|------|------|
| 定義 | 用於治療罕見疾病（美國定義：患者 < 20 萬人）的藥物 |
| 激勵措施 | 市場独占期 7 年、稅收優惠、補助資助 |

### 加速審批（Accelerated Approval）

允許根據<span style="color:#60a5fa">替代終點（Surrogate Endpoint）</span>提前批准用於治療重大疾病的藥物。

---

## 藥物專利與市場独占

| 類型 | 說明 |
|------|------|
| 專利保護 | 申請後 20 年独占期 |
| 市場独占 | NDA 批准後一定期間的市場独占（取決於藥物類型）|
| 學名藥 | 品牌藥專利過期後的仿製藥 |

---

## 生物製劑與疫苗

### 生物製劑

| 特性 | 說明 |
|------|------|
| 定義 | 由生物來源（如蛋白質、抗體）製成的藥物 |
| 審批途徑 | BLA（Biologics License Application）|
| 例子 | <span style="color:#fb923c">Insulin</span>、<span style="color:#fb923c">Monoclonal antibodies</span>、<span style="color:#fb923c">Erythropoietin</span> |

### 疫苗

疫苗開發需經過特殊的臨床試驗設計，包括<span style="color:#60a5fa">免疫原性</span>與<span style="color:#60a5fa">保護效力</span>評估。

---

## 藥物命名

| 類型 | 例子 | 說明 |
|------|------|------|
| 化學名 | N-acetyl-para-aminophenol | 藥物的化學結構名稱 |
| 非專利名（INN） | Acetaminophen | 全球通用的官方名稱 |
| 商品名 | Tylenol | 製藥公司的品牌名稱 |

---

## 上市後監視

### 藥物警戒（Pharmacovigilance）

| 機制 | 說明 |
|------|------|
| 不良反應通報系統 | 醫療專業人員與製藥公司向 FDA 通報不良反應 |
| <span style="color:#f87171">藥物安全警告</span> | FDA 發布 black box warning 或修改仿單 |
| 上市後研究 | Phase IV 研究補充安全性數據 |

<span style="color:#f87171">重要：</span>臨床試驗樣本數有限，罕見不良反應（發生率 < 1/1000）可能在上市後才被發現。

## 特殊人群的藥物使用

### 孕婦用藥

| 分級 | 說明 |
|------|------|
| A | 在對照研究中未顯示風險 |
| B | 動物研究無風險，但人類研究不足 |
| C | 動物研究顯示風險，人類研究不足 |
| D | 有證據顯示風險，但利益大於風險 |
| X | 禁忌於孕婦 |

### 兒童用藥

兒童並非小型成人——藥物動力學與藥效學與成人有顯著差異。

---

## 藥物價格與可近性

| 問題 | 說明 |
|------|------|
| 藥物開發成本 | 新藥開發平均耗時 10-15 年，成本可達數十億美元 |
| 價格爭議 | 品牌藥與學名藥價格差異、國際價格差異 |
| 學名藥的好處 | 增加藥物可近性，降低醫療成本 |

<span style="color:#60a5fa">學名藥（Generic Drugs）</span>在品牌藥專利過期後上市，需證明與品牌藥的<span style="color:#60a5fa">生體相等性（Bioequivalence）</span>。
