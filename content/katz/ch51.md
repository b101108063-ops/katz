# CH51 驅蟲藥物

## 章節導讀

寄生蟲感染是全球重要的公共衛生問題，尤其在熱帶與亞熱帶地區。本章節介紹臨床常用的驅蟲藥物，涵蓋線蟲（如鉤蟲、蟯蟲、糞線蟲）、吸蟲（如血吸蟲）及絛蟲的治療藥物。這些藥物的作用機轉各異，選擇時需考慮寄生蟲種類、感染部位及患者族群等因素。

---

## 驅蟲藥物總覽

| 藥物 | 主要適應症 | 作用機轉 |
|------|-----------|----------|
| <span style="color:#fb923c">Albendazole</span> | 線蟲感染、包蟲囊病 | 抑制β-微管蛋白聚合 |
| <span style="color:#fb923c">Mebendazole</span> | 鞭蟲、鉤蟲、蟯蟲、圓蟲 | 抑制β-微管蛋白聚合 |
| <span style="color:#fb923c">Pyrantel pamoate</span> | 蟯蟲、鉤蟲 | 神經肌肉阻斷（菸鹼型受體激動）|
| <span style="color:#fb923c">Praziquantel</span> | 血吸蟲病、絛蟲病 | 增加細胞膜對鈣離子通透性 |
| <span style="color:#fb923c">Ivermectin</span> | 糞線蟲病、蟯蟲病、絲蟲病 | 谷氨酸閘控氯離子通道活化 |
| <span style="color:#fb923c">Diethylcarbamazine</span> | 絲蟲病（象皮病）| 抑制前列腺素合成、影響蟲體肌肉 |
| <span style="color:#fb923c">Niclosamide</span> | 絛蟲病 | 抑制氧化磷酸化 |

---

##  benzimidazoles 類（苯並咪唑類）

###  albendazole（阿苯達唑）

<span style="color:#60a5fa">**作用機轉**：選擇性抑制寄生蟲腸細胞的β-微管蛋白聚合，阻斷寄生蟲攝取葡萄糖，導致ATP耗竭及蟲體死亡。</span>

| 適應症 | 劑量 | 療程 |
|--------|------|------|
| 鉤蟲感染（Ancylostoma, Necator）| 400 mg口服單次 | 單次 |
| 蟯蟲病（Enterobius vermicularis）| 400 mg口服，2週後再給一劑 | 單次，2週後重複 |
| 鞭蟲病（Trichuris trichiura）| 400 mg口服每日一次 | 3天 |
| 圓蟲幼蟲移行症（Visceral larva migrans）| 400 mg口服每日二次 | 3–5天 |
| <span style="color:#22d3ee">**包蟲囊病（Hydatid disease）**</span> | 400 mg口服每日二次 | 28天×3療程（間隔14天）|
| 類圓蟲病（Strongyloidiasis）| 400 mg口服每日二次 | 7天 |
| 皮下幼蟲移行症（Cuta larva migrans）| 400 mg口服每日一次 | 3天 |

###  mebendazole（甲苯達唑）

<span style="color:#60a5fa">**特點**：與albendazole相似，但腸道吸收較差，主要在腸道局部作用。</span>

| 適應症 | 劑量 |
|--------|------|
| 鞭蟲病 | 100 mg口服每日二次 或 500 mg單次 |
| 鉤蟲、圓蟲、蟯蟲混合感染 | 100 mg口服每日二次×3天 |

###  不良反應（benzimidazoles類）

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 腹痛、腹瀉（蟲體死亡釋出抗原）|
| <span style="color:#f87171">**肝臟**</span> | 肝功能異常（包蟲囊病大劑量長期療程時）|
| <span style="color:#f87171">**血液**</span> | 骨髓抑制、白血球減少（長期大劑量時）|
| <span style="color:#f87171">**致畸性**</span> | <span style="color:#f87171">**孕婦禁用**</span>；可能抑制胎兒發育 |

<span style="color:#34d399">**包蟲囊病療程監測**：建議每週監測AST/ALT及全血球計數</span>

---

##  pyrantel pamoate（噻嘧啶）

<span style="color:#60a5fa">**作用機轉**：作為菸鹼型膽鹼酯酶抑制劑，刺激蟲體肌肉去極化，導致強直性癱瘓，蟲體隨糞便排出。</span>

| 適應症 | 劑量 |
|--------|------|
| 蟯蟲病 | 11 mg/kg（最大1 g）口服單次，2週後再給一劑 |
| 鉤蟲病 | 11 mg/kg（最大1 g）口服，每日一次×3天 |

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 腹痛、噁心、嘔吐、腹瀉 |
| <span style="color:#fb923c">**神經**</span> | 頭暈、頭痛 |
| <span style="color:#fb923c">**皮膚**</span> | 皮疹 |

<span style="color:#34d399">**優點**：不在腸道吸收；對幼兒及孕婦相對安全</span>

---

##  praziquantel（吡喹酮）

<span style="color:#60a5fa">**作用機轉**：增加蟲體細胞膜對Ca²⁺的通透性，導致蟲體肌肉強直收縮及表皮損傷，最終脫離宿主組織並死亡。</span>

| 適應症 | 劑量 | 備註 |
|--------|------|------|
| <span style="color:#22d3ee">**血吸蟲病（Schistosomiasis）**</span> | 20 mg/kg口服，4–6小時後追加一次 | 或20 mg/kg q4-6h×1天 |
| 埃及血吸蟲（*S. haematobium*）| 20 mg/kg q4-6h×1天 | |
| 曼氏血吸蟲（*S. mansoni*）| 20 mg/kg q4-6h×1天 | |
| 日本血吸蟲（*S. japonicum*）| 30 mg/kg q4-6h×1天 | |
| <span style="color:#22d3ee">**絛蟲病（Cestodiasis）**</span> | 5–10 mg/kg口服單次 | 魚類、豬肉絛蟲 |
| <span style="color:#c084fc">*Clonorchis sinensis*</span>（肝吸蟲）| 25 mg/kg口服3次（間隔4-6小時）| |

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**中樞神經**</span> | 頭暈、嗜睡（蟲體死亡釋出抗原）|
| <span style="color:#fb923c">**胃腸道**</span> | 腹痛、噁心（最常見）|
| <span style="color:#fb923c">**過敏**</span> | 蕁麻疹（蟲體蛋白質引起）|
| <span style="color:#f87171">**心臟**</span> | 室性早搏（罕見）|

<span style="color:#34d399">**注意**：血吸蟲病治療後可能出現Herxheimer様反應（急性發燒、發冷），給予皮質類固醇可緩解</span>

---

##  ivermectin（伊維菌素）

<span style="color:#60a5fa">**作用機轉**：活化寄生蟲神經肌肉接點的谷氨酸閘控氯離子通道，導致蟲體弛緩性麻痺及死亡。對人類神經元影響極微（血腦障壁通透性低）。</span>

| 適應症 | 劑量 |
|--------|------|
| <span style="color:#22d3ee">**糞線蟲病（Strongyloidiasis）**</span> | 200 μg/kg口服每日一次×1–2天 |
| 蟯蟲病（Scabies）| 200 μg/kg口服，1–2週後再給一劑 |
| 旋毛蟲病（Trichinosis）| 200 μg/kg口服×2天 |
| 淋巴絲蟲病（Microfilaria）| 150 μg/kg口服（與DEC或albendazole合用）|

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**中樞神經**</span> | 頭暈、嗜睡（微絲蚴死亡釋出抗原）|
| <span style="color:#fb923c">**發燒**</span> | 微絲蚴消滅熱（Mazzotti反應）|
| <span style="color:#fb923c">**皮膚**</span> | 瘙癢、皮疹 |
| <span style="color:#fb923c">**眼**</span> | 眼窩疼痛、視覺模糊（眼部絲蟲感染治療時）|
| <span style="color:#f87171">**腦炎**</span> | 極少數<span style="color:#c084fc">*Loa loa*</span>高度感染者可能發生 |

<span style="color:#34d399">**優點**：單次給藥效果好；耐受性佳；孕婦可用（治療益處大於風險時）</span>

---

##  diethylcarbamazine（乙胺嗪，DEC）

<span style="color:#60a5fa">**作用機轉**：抑制寄生蟲前列腺素合成，改變微絲蚴的表皮結構，使其易被宿主免疫系統清除。對成蟲亦有一定作用。</span>

| 適應症 | 劑量 | 備註 |
|--------|------|------|
| <span style="color:#22d3ee">**淋巴絲蟲病（Lymphatic filariasis）**</span> | 6 mg/kg/d口服，分3次×12天 | 與albendazole 400mg合用（每年一次）|
| 羅阿絲蟲病（Loiasis）| 8–10 mg/kg/d口服×21天 | |
| 熱帶肺嗜曙紅血球增多症（TPE）| 同淋巴絲蟲病療程 | |

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**過敏/發燒**</span> | 發燒、頭痛、關節痛（Mazzotti反應）|
| <span style="color:#fb923c">**視覺**</span> | 眼部絲蟲感染時惡化 |
| <span style="color:#fb923c">**腎臟**</span> | 腎絲球腎炎（長期使用時）|

<span style="color:#f87171">**注意**：<span style="color:#c084fc">*Loa loa*</span>感染者使用DEC可能引發嚴重腦炎（微絲蚴大量死亡）</span>

---

##  niclosamide（氯硝柳胺）

<span style="color:#60a5fa">**作用機轉**：抑制絛蟲頭節及體節的氧化磷酸化，導致絛蟲頭節從腸道壁脫落，蟲體隨糞便排出（不被人體腸道吸收）。</span>

| 適應症 | 劑量 |
|--------|------|
| 魚肉絛蟲病（Diphyllobothriasis）| 2 g口服單次（空腹嚼碎服用）|
| 豬肉絛蟲病（Taeniasis）| 2 g口服單次 |
| 矮小絛蟲病（Hymenolepiasis）| 2 g口服，7天後再給1 g |

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 腹痛、噁心、腹瀉 |
| <span style="color:#fb923c">**全身**</span> | 頭暈、倦怠 |

<span style="color:#34d399">**優點**：不被腸道吸收；全身性不良反應少；孕婦可用</span>

---

##  驅蟲藥物臨床選擇指南

###  蟯蟲病（Enterobiasis）

| 藥物 | 劑量 | 備註 |
|------|------|------|
| <span style="color:#fb923c">Albendazole</span> | 400 mg單次，2週後重複 | 首選 |
| <span style="color:#fb923c">Mebendazole</span> | 100 mg單次，2週後重複 | 首選 |
| <span style="color:#fb923c">Pyrantel pamoate</span> | 11 mg/kg（最大1g）單次，2週後重複 | 孕婦可用 |

<span style="color:#60a5fa">**建議**：家庭接觸者均需治療；內衣褲、床單需煮沸消毒</span>

###  血吸蟲病（Schistosomiasis）

| 藥物 | 劑量 | 適用蟲種 |
|------|------|-----------|
| <span style="color:#fb923c">Praziquantel</span> | 20–30 mg/kg（劑量依蟲種調整）| 所有血吸蟲 |

<span style="color:#f87171">**注意**：Praziquantel對移行期童蟲效果較差；需多劑療程或搭配其他藥物</span>

###  絛蟲病（Cestodiasis）

| 藥物 | 劑量 | 備註 |
|------|------|------|
| <span style="color:#fb923c">Praziquantel</span> | 5–10 mg/kg單次 | 首選 |
| <span style="color:#fb923c">Niclosamide</span> | 2 g單次（嚼碎）| 孕婦首選 |

---

##  不良反應與特殊考量總整理

| 藥物 | 重要不良反應 | 禁忌/注意 |
|------|-------------|-----------|
| <span style="color:#fb923c">Albendazole</span> | 肝毒性、骨髓抑制 | <span style="color:#f87171">**孕婦禁用**</span>；包蟲囊病需監測肝功能 |
| <span style="color:#fb923c">Mebendazole</span> | 胃腸道不適 | <span style="color:#f87171">**孕婦禁用**</span> |
| <span style="color:#fb923c">Pyrantel</span> | 胃腸道不適、頭暈 | 肝功能不良者慎用；可與piperazine互斥（作用拮抗）|
| <span style="color:#fb923c">Praziquantel</span> | 頭暈、腹痛 | 寄生蟲性囊腫患者需住院觀察（炎症反應）|
| <span style="color:#fb923c">Ivermectin</span> | Mazzotti反應、暫時性眼部症狀 | <span style="color:#c084fc">*Loa loa*</span>高度感染者可能腦炎 |
| <span style="color:#fb923c">DEC</span> | 發燒、過敏反應、腎絲球腎炎 | <span style="color:#c084fc">*Loa loa*</span>感染者禁用 |

##  寄生蟲感染預防原則

1. <span style="color:#60a5fa">**個人衛生**</span>：飯前便後洗手；正確處理糞便；避免赤腳行走（鉤蟲幼蟲）
2. <span style="color:#60a5fa">**食品安全**</span>：徹底煮熟肉類及魚類；避免生食淡水魚（肝吸蟲、絛蟲）
3. <span style="color:#60a5fa">**水源管理**</span>：避免接觸疫水（血吸蟲）；淨化飲用水
4. <span style="color:#60a5fa">**群體治療**</span>：在高流行區進行大規模藥物投藥（如albendazole + ivermectin）
5. <span style="color:#60a5fa">**疾病監控**</span>：寄生蟲感染史；糞便及血液檢查確診
