## 章節導讀

藥物濫用是全球公共衛生重大議題，涉及中樞神經系統抑制劑（酒精、巴比妥鹽類、Benzodiazepine類）、刺激劑（安非他命、古柯鹼、尼古丁）與鴉片類等各類物質。本章節探討藥物濫用的神經生物學基礎——特別是中腦邊緣獎勵系統與多巴胺路徑——以及各類濫用藥物的藥理特性、依賴機轉、戒斷症狀與治療策略。

---

## 第一節　藥物濫用的神經生物學

### 中腦邊緣獎勵系統

<span style="color:#22d3ee">**中腦邊緣多巴胺系統（Mesolimbic Dopamine System）**</span>是藥物獎勵與成癮神經生物學的核心。

| 路徑/結構 | 說明 |
|----------|------|
| **腹側被蓋區（VTA）** | 含有多巴胺神經元本體；為獎勵系統的起點 |
| **伏隔核（NAc）** | VTA投射至此；多巴胺釋放產生「欣快感」 |
| **前額葉皮質** | 執行功能；抑制控制；成癮時功能減退 |
| **杏仁核** | 情緒處理；與藥物相關記憶形成 |
| **海馬** | 情境學習；藥物相關線索的記憶編碼 |

### 多巴胺獎勵假說

多數成癮性藥物透過↑VTA-NAc多巴胺傳遞產生獎勵效應：

| 藥物類別 | 對多巴胺的作用 |
|---------|--------------|
| **古柯鹼/Amphetamines** | 阻斷/逆轉DAT → ↑細胞外DA |
| **酒精、Benzodiazepines、Opioids** | 強化GABA<sub>A</sub>抑制VTA GABA中間神經元 → 間接↑DA |
| **Nicotine** | 激活VTA膽鹼受體 → ↑DA |
| **Cannabis** | Anandamide（內源性大麻素）→ 間接增加DA（動物研究） |

### 長期變化與依賴

| 變化 | 說明 |
|------|------|
| **獎勵系統鈍化** | 長期用藥→細胞外DA減少→對正常獎勵刺激快感減退 |
| **應激系統活化** | CRF/ Cortisol系統過度活化→負向情緒狀態→藥物復發驅力 |
| **習慣化/自動化** | 從目標導向（Goal-directed）轉為習慣化（Habit）用藥 |
| **抑制控制減退** | 前額葉功能減退→衝動控制障礙 |
| **記憶系統過度敏感** | 與藥物相關的環境線索觸發復發 |

## 第二節　中樞神經抑制劑濫用

### A. 酒精（Alcohol）

<span style="color:#60a5fa">**酒精（Ethanol）**</span>為全球最廣泛使用的成癮性抑制劑。

#### 作用機轉

| 機轉 | 說明 |
|------|------|
| **GABA<sub>A</sub>增強** | 酒精為正別構調節劑；增加氯離子內流 |
| **NMDA受體拮抗** | 高濃度時；減少興奮性傳遞 |
| **電壓門控離子通道** | 作用於多種離子通道 |

#### 急性效應

| 血酒精濃度（BAC）| 效應 |
|----------------|------|
| 0.02–0.05% | 欣快、社交性↑、判斷↓ |
| 0.06–0.10% | 運動失調、反射↓、視力模糊 |
| 0.11–0.20% | 明顯失調、嘔吐、定向障礙 |
| 0.21–0.30% | 意識混亂、嘔吐、無法行走 |
| 0.31–0.40% | 木僵、昏迷、呼吸抑制 |
| >0.40% | 呼吸心跳停止、死亡 |

#### 慢性效應

| 系統 | 表現 |
|------|------|
| **肝臟** | 脂肪肝→酒精性肝炎→肝硬化 |
| **心臟** | 心肌病變（擴張型） |
| **胃腸** | 胃炎、胰炎、食道靜脈曲張 |
| **CNS** | 魏尼克腦病（Wernicke's encephalopathy）、酒精性失智、Korsakoff症候群 |
| **血液** | 巨紅球性貧血、粒性白細胞減少 |
| **周邊神經** | 酒精性神經病變 |

#### 戒斷症狀

| 時間 | 症狀 |
|------|------|
| 6–24小時 | 顫抖、焦慮、失眠、噁心、心搏過速、出汗 |
| 24–48小時 | 幻覺（視/聽/觸） |
| 24–72小時 | **酒精性癲癇發作（戒斷性癲癇）** |
| 3–5天 | **酒精性譫妄（Delirium Tremens）**：意識障礙、高熱、心律不整、幻覺 |

<span style="color:#f87171">**酒精戒斷可能危及生命（癲癇、譫妄）**：首選<span style="color:#fb923c">**Benzodiazepine**</span>（長效制劑如Diazepam或Chlordiazepoxide），必要時使用抗癲癇藥。</span>

#### 治療

| 藥物 | 作用 |
|------|------|
| <span style="color:#fb923c">Disulfiram（戒酒硫）</span> | 抑制ALDH→飲酒後乙醛累積→臉紅、噁心、心悸（預防復發） |
| <span style="color:#fb923c">Naltrexone（納曲酮）</span> | μ受體拮抗；減少渴求；對減少 heavy drinking有效 |
| <span style="color:#fb923c">Acamprosate（阿坎酸）</span> | NMDA受體調節；維持戒酒；對維持戒酒有效 |

### B. Benzodiazepines

<span style="color:#60a5fa">**Benzodiazepines**</span>主要用於焦慮、失眠、肌肉痙攣、癲癇，但有依賴性。

| 特性 | 說明 |
|------|------|
| 作用 | GABA<sub>A</sub>正別構調節 |
| 長期使用 | 身體依賴發展（數週至數月） |
| 戒斷 | 焦慮反彈、失眠、顫抖、癲癇 |
| 過量 | 嗜睡、失調、呼吸抑制（但致死率低於Barbiturates） |

<span style="color:#f87171">**禁用於**：孕婦（致畸）、哺乳、重症肌無力、嚴重COPD。</span>

### C. Barbiturates

| 特性 | 說明 |
|------|------|
| 作用 | GABA<sub>A</sub>直接開啟（不同於BDZ） |
| 濫用 | 目前少見（已被BDZ取代） |
| 過量 | 呼吸抑制、昏迷；致死劑量窄；無特定拮抗劑 |
| 戒斷 | 類似酒精戒斷；可能致命 |

## 第三節　中樞神經刺激劑濫用

### A. 古柯鹼（Cocaine）

<span style="color:#60a5fa">**古柯鹼（Cocaine）**</span>為強效局部麻醉藥與Monoamine回收抑制劑。

| 作用 | 說明 |
|------|------|
| **DAT抑制** | 阻斷多巴胺轉運體→細胞外DA↑→欣快 |
| **NET抑制** | 去甲腎上腺素↑→心搏過速、高血壓、血管收縮 |
| **SERT抑制** | 血清素↑→作用較弱 |

#### 急性效應

| 系統 | 效應 |
|------|------|
| **心血管** | 冠狀動脈痙攣、心肌缺血、心律不整、高血壓 |
| **CNS** | 欣快、警覺↑、偏執/幻覺 |
| **瞳孔** | 散瞳 |
| **體溫** | 過熱 |

<span style="color:#f87171">**急性心肌梗塞/心律不整可能發生**；有心血管疾病者風險更高。</span>

#### 長期效應

| 表現 | 說明 |
|------|------|
| **鼻中隔穿孔** | 鼻吸古柯鹼的局部毒性 |
| **缺血性腸道疾病** | 血管痙攣 |
| **神經精神** | 偏執性精神障礙、古柯鹼幻覺觸覺（"Cocaine bugs"/"Formication") |
| **依賴** | 強烈渴求、耐受 |

#### 戒斷

| 時期 | 症狀 |
|------|------|
| **崩解期（Crahs）** | 抑鬱、嗜睡、渴求 |
| **戒斷** | 情緒惡劣、疲勞、失眠/過度睡眠 |

#### 治療

目前無藥物核准用於古柯鹼依賴治療；研究中的藥物：Bupropion、Naltrexone。

### B. 安非他命（Amphetamines）

| 作用 | 說明 |
|------|------|
| **DA/NE釋放↑** | 逆轉轉運體；欣快/警覺↑ |
| **DAT抑制** | 細胞外DA↑ |

| 效應 | 說明 |
|------|------|
| 急性 | 欣快、精力↑、食慾↓、心搏過速、高血壓、過熱 |
| 長期 | 牙齒損耗（"Meth mouth"）、體重減輕、精神病性症狀 |
| 戒斷 | 抑鬱、疲勞、睡眠過多 |

## 第四節　鴉片類藥物濫用

### 依賴的治療

| 治療方式 | 說明 |
|---------|------|
| **替代/維持治療（Agonist Maintenance）** | 以長效μ激動劑替代街頭藥物 |
| <span style="color:#fb923c">美沙酮（Methadone）</span> | 長效μ激動劑；口服；需在許可門診分發 |
| <span style="color:#fb923c">Buprenorphine（丁丙諾啡）</span> | μ部分激動劑；門診處方；較安全；可與Naloxone合用（Suboxone） |
| **拮抗劑治療（Antagonist Treatment）** | Naltrexone；需先解毒後使用 |
| **戒毒（Detoxification）** | 逐步減量；Clonidine/LOFAP症狀緩解 |

<span style="color:#fb923c">**Suboxone（丁丙諾啡/納洛酮）**</span>：口腔含服時Buprenorphine發揮作用；如注射，Naloxone阻斷Buprenorphine作用，減少靜脈濫用。

## 第五節　大麻（ cannabis）與其他物質

### A. 大麻（Cannabis）

| 成份 | 說明 |
|------|------|
| **THC（Δ9-Tetrahydrocannabinol）** | 主要活性成分；CB1受體激動劑 |
| **CBD（Cannabidiol）** | 非精神活性；抗焦慮/抗精神病潛力 |

| 作用 | 說明 |
|------|------|
| **急性** | 欣快、放鬆、食慾↑、時間知覺改變、記憶障礙 |
| **長期** | 依賴（10%使用者）；呼吸道刺激 |
| **戒斷** | 煩躁、焦慮、失眠、食慾↓ |

### B. 吸入劑（Inhalants）

| 類別 | 代表物 |
|------|------|
| **溶劑** | 膠水、汽油、油漆稀釋劑 |
| **氣體** | 笑氣（N<sub>2</sub>O）、氟烷 |
| **硝酸鹽** | 「Poppers」 |

<span style="color:#f87171">**急性毒性**：心律不整（Sudden Sniffing Death Syndrome，SSD）；CNS抑制；窒息。</span>

## 第六節　藥物濫用的治療原則

| 原則 | 說明 |
|------|------|
| **動機增強治療（Motivational Enhancement）** | 認知層面；處理矛盾心理 |
| **認知行為治療（CBT）** | 辨識/改變破壞性思考模式 |
| **12步驟計劃（12-Step Programs）** | 匿名戒酒會（AA）等 |
| **藥物輔助治療（MAT）** | 酒精：Naltrexone、Acamprosate、Disulfiram；鴉片類：Methadone、Buprenorphine、Naltrexone |
| **行為契約與監控** | 門診藥物篩檢 |

## 第七節　重點摘要

- 藥物濫用的神經生物學核心為<span style="color:#22d3ee">**中腦邊緣多巴胺獎勵系統（VTA-NAc路徑）**</span>
- <span style="color:#fb923c">酒精</span>急性作用為GABA<sub>A</sub>增強；長期使用導致肝硬化、胰炎、CNS退化
- <span style="color:#fb923c">酒精戒斷</span>可能致命（癲癇、譫妄）；首選Diazepam治療
- <span style="color:#fb923c">古柯鹼</span>阻斷DAT引起細胞外DA↑，可致心肌缺血、心律不整
- <span style="color:#fb923c">美沙酮</span>與<span style="color:#fb923c">Buprenorphine</span>為鴉片依賴的主要替代維持治療藥物
- <span style="color:#fb923c">Suboxone</span>結合Buprenorphine與Naloxone，減少靜脈濫用
- <span style="color:#fb923c">Naltrexone</span>為μ受體拮抗劑，用於酒精依賴與鴉片依賴復發預防
- <span style="color:#f87171">藥物輔助治療（MAT）結合藥物與心理治療為藥物濫用最有效治療模式</span>
