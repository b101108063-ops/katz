# CH53 免疫藥理學

## 章節導讀

免疫藥理學涵蓋免疫系統的藥理學調節，包括免疫抑制劑、免疫增強劑及抗發炎藥物。本章節介紹免疫系統的基本組成（先天性與適應性免疫）、免疫抑制劑（環孢素、他克莫司、黴酚酸酯、皮質類固醇等）的藥理學特性與臨床應用，以及超敏反應與自體免疫疾病的治療原則。

---

## 免疫系統概述

### 先天性免疫（Innate Immunity）

| 組成 | 功能 |
|------|------|
| <span style="color:#22d3ee">補體系統（C1-C9）</span> | 細菌裂解（膜攻擊複合體MAC）；調理作用；化學趨化作用 |
| <span style="color:#22d3ee">吞噬細胞</span> | 嗜中性球、巨噬細胞；吞噬並消化病原體 |
| <span style="color:#22d3ee">自然殺手細胞（NK cells）</span> | 殺死病毒感染細胞及腫瘤細胞 |
| <span style="color:#22d3ee">樹突細胞</span> | 抗原呈遞；連結先天性與適應性免疫 |

### 適應性免疫（Adaptive Immunity）

| 組成 | 功能 |
|------|------|
| <span style="color:#22d3ee">T淋巴細胞</span> | 細胞媒介免疫；CD4⁺ helper T cells（TH1/TH2/TH17）；CD8⁺ cytotoxic T cells |
| <span style="color:#22d3ee">B淋巴細胞</span> | 體液免疫；抗體產生；漿細胞與記憶B細胞 |
| <span style="color:#22d3ee">抗體（IgG, IgM, IgA, IgE, IgD）</span> | 中和毒素；調理作用；補體活化 |

### T細胞活化所需的兩個信號

| 信號 | 描述 |
|------|------|
| <span style="color:#60a5fa">**信號1**</span> | TCR與MHC-胜肽複合體結合 |
| <span style="color:#60a5fa">**信號2（共同刺激）**</span> | 抗原呈遞細胞的CD80/CD86與T細胞的CD28結合 |
| <span style="color:#60a5fa">**負向調控**</span> | CTLA-4與CD80/CD86親和力更高，抑制T細胞活化 |

## 超敏反應分類

### 第一型（立即型）— IgE媒介

<span style="color:#60a5fa">**機轉**：過敏原與肥大細胞/嗜鹼性球表面的IgE結合，導致去顆粒，釋出組織胺、白三烯等介質。</span>

| 臨床表現 | 說明 |
|---------|------|
| 全身性過敏反應 | 威脅生命的氣道水腫、血壓下降 |
| 氣喘 | 支氣管收縮、黏液分泌 |
| 過敏性鼻炎 | 打噴嚏、鼻塞 |
| 蕁麻疹 | 皮膚風疹塊、瘙癢 |

### 第二型（細胞毒型）— IgG/IgM抗體

<span style="color:#60a5fa">**機轉**：抗體與細胞表面或細胞外基質抗原結合，透過補體活化或ADCC導致細胞損傷。</span>

| 臨床範例 | 說明 |
|---------|------|
| 輸血反應 | 血型不合導致溶血 |
| Rh不相容 | 母體抗Rh抗體攻擊胎兒紅血球 |
| 藥物誘導性溶血 | Penicillin等藥物結合紅血球形成新抗原 |

### 第三型（免疫複合體型）

<span style="color:#60a5fa">**機轉**：抗原-抗體複合體沉積於血管壁或腎絲球，補體活化導致組織損傷。</span>

| 臨床範例 | 說明 |
|---------|------|
| 血清病 | 藥物或異源蛋白引起；發燒、關節炎、腎炎 |
| 局部Arthus反應 | 注射部位壞死 |
| 腎絲球腎炎 | 免疫複合體沉積 |

### 第四型（遲發型）— 細胞媒介

<span style="color:#60a5fa">**機轉**：TH1細胞釋放IFN-γ等細胞激素，招募並活化巨噬細胞，導致組織損傷。</span>

| 臨床範例 | 說明 |
|---------|------|
| 結核菌素反應 | 結核菌素皮膚試驗 |
| 接觸性過敏 | 毒葛過敏（pentadecacatechol）|
| 移植排斥反應 | 急性細胞媒介排斥 |

## 免疫抑制劑

### 鈣神經磷酸酶抑制劑（Calcineurin Inhibitors）

####  cyclosporine（環孢素）

<span style="color:#60a5fa">**作用機轉**：與cyclophilin結合形成複合體，抑制calcineurin，阻斷IL-2基因轉錄，抑制T細胞活化。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | 器官移植（肝、腎、心）；自體免疫疾病 |
| 給藥途徑 | 口服或靜脈（微乳劑型Neoral）|
| 半衰期 | 約24小時（變異性大）|
| 治療藥物監測 | <span style="color:#34d399">**目標谷底濃度**：移植後100-250 ng/mL（各中心略有不同）</span> |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**腎臟**</span> | 急性腎毒性（可逆性）；慢性腎間質纖維化 |
| <span style="color:#f87171">**高血壓**</span> | 常見（calcineurin抑制導致血管收縮）|
| <span style="color:#f87171">**神經**</span> | 顫抖、頭痛、感覺異常 |
| <span style="color:#f87171">**齒齦增生**</span> | 齒齦肥大（常見）|
| <span style="color:#f87171">**多毛症**</span> | 臉部及全身毛髮增加 |
| <span style="color:#fb923c">**感染**</span> | 機會性感染（CMV、BK病毒、JC病毒）|

---

####  tacrolimus（他克莫司，FK506）

<span style="color:#60a5fa">**作用機轉**：與FK506 binding protein (FKBP-12) 結合，抑制calcineurin，與cyclosporine相似但效力更強。</span>

| 特性 | 說明 |
|------|------|
| 效力 | 約100倍於cyclosporine |
| 適應症 | 肝、腎移植；類風濕關節炎、乾癬 |
| 給藥途徑 | 口服（緩釋膠囊）或靜脈 |
| 治療藥物監測 | <span style="color:#34d399">**目標谷底濃度**：10-15 ng/mL（早期）；5-10 ng/mL（維持期）</span> |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**腎臟**</span> | 急性腎毒性（與cyclosporine相似）|
| <span style="color:#f87171">**神經**</span> | <span style="color:#f87171">**手部顫抖**</span>（比cyclosporine常見）；頭痛、失眠 |
| <span style="color:#f87171">**代謝**</span> | <span style="color:#f87171">**糖尿病**</span>（新發生糖尿病風險較cyclosporine高）|
| <span style="color:#fb923c">**感染**</span> | 與cyclosporine相似 |

---

### 抗增殖藥物（Antiproliferative Agents）

####  mycophenolate mofetil（黴酚酸酯，MMF）

<span style="color:#60a5fa">**作用機轉**：抑制inosine monophosphate dehydrogenase (IMPDH)，阻斷GMP合成，選擇性抑制T和B淋巴細胞增殖。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | 腎、心、肝移植；自體免疫疾病 |
| 給藥 | 口服或靜脈；每日2次 |
| 活性代謝物 | Mycophenolic acid（MPA）|

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 腹瀉（最常見）；噁心、嘔吐 |
| <span style="color:#fb923c">**骨髓**</span> | 白血球減少、血小板減少 |
| <span style="color:#fb923c">**感染**</span> | 機會性感染（特別是CMV）|

---

####  azathioprine（硫唑嘌呤）

<span style="color:#60a5fa">**作用機轉**：在體內轉化為6-mercaptopurine (6-MP)，干擾嘌呤合成，抑制淋巴細胞增殖。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | 腎移植；自體免疫疾病（類風濕關節炎、紅斑狼瘡）|
| 給藥 | 口服或靜脈 |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**骨髓**</span> | <span style="color:#f87171">**劑量限制性骨髓抑制**</span>（特別是白血球減少）|
| <span style="color:#fb923c">**肝臟**</span> | 肝功能異常 |
| <span style="color:#fb923c">**胃腸道**</span> | 噁心、嘔吐 |

<span style="color:#f87171">**注意**：TPMT缺乏症患者禁用（會導致嚴重骨髓毒性）</span>

---

### mTOR抑制劑

####  sirolimus（ rapamycin，西羅莫司）

<span style="color:#60a5fa">**作用機轉**：與FKBP-12結合，但不同於tacrolimus，此複合體抑制mTOR，阻斷細胞週期G₁至S期的進程，抑制T細胞增殖及血管平滑肌細胞增殖。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | 腎移植（與cyclosporine或tacrolimus合用）；心血管支架預防再狹窄 |
| 半衰期 | 長（約60-70小時）|

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**高脂血症**</span> | 高膽固醇、高三酸甘油酯（常見）|
| <span style="color:#f87171">**傷口癒合延遲**</span> | 移植術後傷口併發症 |
| <span style="color:#fb923c">**口腔潰瘍**</span> | 口腔炎 |
| <span style="color:#fb923c">**肺部**</span> | 間質性肺炎（少見但嚴重）|

---

### 皮質類固醇（ Corticosteroids）

<span style="color:#60a5fa">**作用機轉**：作為glucocorticoid receptor配體，進入細胞核調節基因轉錄；抑制NF-κB等轉錄因子，減少多種細胞激素（IL-1, IL-2, IL-6, TNF-α等）產生。</span>

| 代表藥物 | 效能比較 |
|---------|---------|
| <span style="color:#fb923c">Prednisone</span> | 中效；常用於維持治療 |
| <span style="color:#fb923c">Methylprednisolone</span> | 強效；常用於靜脈脈衝治療 |

### 臨床應用

| 情境 | 說明 |
|------|------|
| 急性排斥反應 | Methylprednisolone靜脈脈衝（500-1000 mg/d）×3天 |
| 移植維持免疫抑制 | 低劑量prednisone合併其他製劑 |
| 自體免疫疾病 | SLE、血管炎、類風濕關節炎等 |

### 不良反應（長期使用）

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**代謝**</span> | 高血糖、體重增加、脂肪分布異常（Cushing様）|
| <span style="color:#f87171">**骨骼**</span> | 骨質疏鬆（預防：維生素D+鈣質補充）|
| <span style="color:#f87171">**免疫**</span> | 感染風險增加 |
| <span style="color:#fb923c">**眼科**</span> | 白內障、青光眼 |
| <span style="color:#fb923c">**心血管**</span> | 高血壓、高血脂 |

## 抗發炎藥物

### 免疫抑制單株抗體

| 藥物 | 標的 | 適應症 | 說明 |
|------|------|--------|------|
| <span style="color:#fb923c">Basiliximab</span> | IL-2Rα (CD25) | 腎移植 | 嵌合抗體；預防急性排斥 |
| <span style="color:#fb923c">Daclizumab</span> | IL-2Rα | 腎移植 | （已停產）|
| <span style="color:#fb923c">Alemtuzumab</span> | CD52 | CLL、移植 | 去除T、B細胞；嚴重免疫抑制 |
| <span style="color:#fb923c">Antithymocyte globulin (ATG)</span> | 多種T細胞抗原 | 急性排斥治療 | 動物（兔/馬）來源的抗淋巴細胞球蛋白 |
| <span style="color:#fb923c">Rituximab</span> | CD20 | B細胞淋巴瘤、移植 | 去除B細胞 |

## 免疫增強劑（Immunomodulators）

### 干擾素（Interferons）

| 類型 | 來源 | 主要作用 |
|------|------|---------|
| <span style="color:#fb923c">IFN-α</span> | 白血球 | 抗病毒；抗腫瘤（毛狀細胞白血病、B型肝炎、C型肝炎）|
| <span style="color:#fb923c">IFN-β</span> | 成纖維細胞 | 抗病毒；多發性硬化症治療 |
| <span style="color:#fb923c">IFN-γ</span> | T細胞、NK細胞 | 免疫調節；巨噬細胞活化 |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**流感様症狀**</span> | 發燒、寒顫、肌肉酸痛（干擾素最常見）|
| <span style="color:#fb923c">**神經**</span> | 憂鬱（干擾素-α）；認知功能改變 |
| <span style="color:#fb923c">**骨髓**</span> | 白血球減少、血小板減少 |
| <span style="color:#fb923c">**自體免疫**</span> | 甲狀腺機能異常；自體抗體產生 |

|------|---------|-----------|
| <span style="color:#fb923c">Hydroxychloroquine</span> | 免疫調節 | 輕度類風濕、SLE |

| <span style="color:#fb923c">Cyclosporine/Tacrolimus</span> | Calcineurin抑制 | 類風濕關節炎、乾癬 |

## 免疫抑制療法的臨床應用

### 器官移植免疫抑制方案

<span style="color:#60a5fa">**標準三合一療法（Triple Therapy）**</span>：

| 藥物 | 角色 |
|------|------|
| <span style="color:#fb923c">Calcineurin抑制劑</span>（cyclosporine或tacrolimus）| 基礎免疫抑制 |
| <span style="color:#fb923c">抗增殖藥物</span>（MMF或azathioprine）| 抑制淋巴細胞增殖 |
| <span style="color:#fb923c">皮質類固醇</span>（prednisone）| 快速抗發炎/免疫抑制 |

### 急性排斥反應治療

| 等級 | 治療方式 |
|------|---------|
| 細胞媒介（急性）| 類固醇脈衝治療（Methylprednisolone 500-1000 mg/d×3天）或ATG |
| 抗體媒介（急性）| Rituximab或血漿置換 |

---

## 免疫抑制劑藥物交互作用

| 藥物組合 | 影響 |
|---------|------|
| Cyclosporine + Ketoconazole | Ketoconazole抑制CYP3A4，增加cyclosporine濃度 |
| Tacrolimus + Erythromycin | 同上，增加tacrolimus濃度 |
| Sirolimus + Cyclosporine | 兩者協同腎毒性；需監測腎功能 |
| MMF + Antacids | 減少MMF吸收 |

---

## 免疫製劑過敏反應處理

<span style="color:#f87171">**⚠️ 單株抗體靜脈注射可能引起輸注反應（infusion reactions）**</span>

| 反應程度 | 處理方式 |
|---------|---------|
| 輕度（瘙癢、皮疹）| 減慢輸注速度；給予抗組織胺 |
| 中度（氣管痙攣）| 停止輸注；皮質類固醇；腎上腺素 |
| 重度（過敏性休克）| <span style="color:#f87171">**立即腎上腺素注射**</span>；類固醇、抗組織胺 |

---

## 各類免疫抑制劑比較

| 藥物 | 主要作用點 | 腎毒性 | 神經毒性 | 代謝副作用 |
|------|---------|--------|---------|-----------|
| <span style="color:#fb923c">Cyclosporine</span> | T細胞（IL-2）| <span style="color:#f87171">**高**</span> | 低 | 高血壓、高血鉀 |
| <span style="color:#fb923c">Tacrolimus</span> | T細胞（IL-2）| <span style="color:#f87171">**高**</span> | <span style="color:#f87171">**高**</span>（顫抖）| 新發生糖尿病 |
| <span style="color:#fb923c">MMF</span> | T/B細胞增殖 | 無 | 無 | 腹瀉 |
| <span style="color:#fb923c">Azathioprine</span> | T/B細胞增殖 | 無 | 無 | 骨髓抑制 |
| <span style="color:#fb923c">Sirolimus</span> | mTOR | 無 | 低 | 高血脂、傷口癒合延遲 |
| <span style="color:#fb923c">Corticosteroids</span> | 廣泛抗發炎 | 高血壓、高血糖、骨質疏鬆 |
