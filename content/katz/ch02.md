## 章節導讀

<span style="color:#e2e8f0">藥效學</span>研究藥物如何通過與受體結合產生作用，本章深入探討<span style="color:#60a5fa">受體-效應器耦合</span>、<span style="color:#60a5fa">備用受體</span>、<span style="color:#60a5fa">競爭性與非競爭性拮抗</span>等核心概念，並介紹<span style="color:#fb923c">部分激動劑</span>與<span style="color:#fb923c">反向激動劑</span>等特殊藥物類型。

---

## 受體的分子本質

### 受體的分類

<span style="color:#fb923c">藥物受體（Receptor）</span>大多是蛋白質分子，根據結構與訊號傳導機制分為：

| 受體類型 | 例子 | 訊號機制 |
|---------|------|---------|
| <span style="color:#60a5fa">調節型受體</span> | GPCR（G 蛋白偶聯受體） | 透過 G 蛋白激活下游效應酶 |
| <span style="color:#c084fc">離子通道型受體</span> | nAChR、GABA_A 受體 | 直接控制離子流動 |
| <span style="color:#22d3ee">酪氨酸激酶受體</span> | 胰島素受體、EGF 受體 | 激活細胞內酪氨酸激酶活性 |
| <span style="color:#fb923c">核內受體</span> | 類固醇、甲狀腺素受體 | 調節基因轉錄 |

## 藥物濃度-效應關係

### 濃度-效應曲線

在理想化系統中，藥物濃度與效應呈<span style="color:#60a5fa">雙曲線關係</span>：

```
E = E_max × C / (EC_50 + C)
```

- **E**：在濃度 C 時觀察到的效應
- **E_max**：藥物可產生的最大效應
- **EC_50**：產生 50% 最大效應的藥物濃度

### 效應與劑量對數曲線

將效應對濃度對數作圖，雙曲線轉化為<span style="color:#34d399">S 形曲線</span>，擴展低濃度端的刻度而壓縮高濃度端。

### 受體結合

藥物與受體的結合關係：

```
B = B_max × C / (K_d + C)
```

- **B_max**：受體總濃度
- **K_d**：解離常數 — K_d 越低，代表受體對藥物的<span style="color:#60a5fa">親和力越高</span>
- **EC_50 與 K_d**：兩者可以相同或不同，取決於受體-效應器耦合效率

## 受體-效應器耦合與備用受體

### 耦合機制

藥物佔據受體後需要經過<span style="color:#60a5fa">耦合（Coupling）</span>過程才能產生藥理效應。耦合效率決定相同受體佔據程度下的效應強度差異。

### 備用受體（Spare Receptors）

<span style="color:#34d399">備用受體</span>現象說明：即使 agonist 濃度不足以佔據全部受體，仍可達到最大生物效應。

<span style="color:#f87171">臨床意義：</span>改變受體數量可改變細胞對 agonist 的敏感度。例如使用不可逆拮抗劑移除部分受體後，需要更高濃度的 agonist 才能達到原有最大效應。

---

## 競爭性拮抗劑與不可逆拮抗劑

### 競爭性拮抗劑

<span style="color:#60a5fa">競爭性拮抗劑</span>與 agonist 競爭結合同一受體位置：

| 特性 | 說明 |
|------|------|
| 效應可逆性 | 高濃度 agonist 可逆轉其效應 |
| 曲線特徵 | S 形曲線向右平行移動，最大效應不變 |
| Schild 方程式 | C'/C = 1 + [I]/K_i |

<span style="color:#fb923c">Propranolol</span> 是經典的競爭性 β 受體拮抗劑。

### 不可逆拮抗劑

<span style="color:#f87171">不可逆拮抗劑</span>以共價鍵與受體形成穩定鍵結：

- 佔據部分受體後，即使高濃度 agonist 也無法達到原有最大效應
- 若有備用受體存在，可維持最大效應但需要更高 agonist 濃度
- <span style="color:#fb923c">Phenoxybenzamine</span> 是 α 受體不可逆拮抗劑的代表藥物

---

## 部分激動劑（Partial Agonists）

<span style="color:#fb923c">部分激動劑</span>佔據全部受體時仍無法產生最大效應：

| 特性 | 說明 |
|------|------|
| 內在活性低 | 只能 stabilizes 部分受體於活化構象 |
| 雙重行為 | 無完全 agonist 存在時表現 agonist 活性；有完全 agonist 存在時表現拮抗作用 |
| 臨床應用 | <span style="color:#fb923c">Buprenorphine</span>（μ-opioid 受體部分 agonist）比 <span style="color:#fb923c">Morphine</span> 更安全，過量時呼吸抑制較輕 |

## 其他拮抗機制

### 化學性拮抗

<span style="color:#f87171">Protamine</span> 帶正電，臨床上用於中和帶負電的 <span style="color:#fb923c">Heparin</span>。

### 生理性拮抗

不同受體系統間的對抗，例如 <span style="color:#fb923c">Insulin</span> 對抗 <span style="color:#fb923c">Glucocorticoid hormones</span> 的升血糖作用。

## 藥物動力學與藥效學的整合

### 時間歷程

| 過程 | 說明 |
|------|------|
| 分布相（α相） | 藥物由血液分布到組織 |
| 消除相（β相） | 藥物濃度在血液與組織間達平衡後的下降 |
| 終末半衰期 | 反映藥物從最深部組織清除的速率 |

### 臨床應用原則

- 藥物效應持續時間取決於：受體佔據時間、耦合分子的存在時間、受體脫敏機制
- 藥物從身體消除後，效應可能仍持續（因預存訊號分子的持續作用）
