## 章節導讀

<span style="color:#e2e8f0">膽鹼受體阻斷劑</span>涵蓋 muscarinic 受體拮抗劑、神經節阻斷劑和神經肌肉阻斷劑三大類。本章重點介紹<span style="color:#fb923c">Atropine</span> 與 <span style="color:#fb923c">Scopolamine</span> 的藥理作用與臨床應用，以及<span style="color:#f87171">Succinylcholine</span> 等神經肌肉阻斷劑的特性。

---

## Muscarinic 受體拮抗劑

### Atropine 及其相關藥物

<span style="color:#fb923c">Atropine</span> 是競爭性 muscarinic 拮抗劑，阻斷所有 M 受體亞型（M1-M5）。

| 藥物類型 | 代表藥物 | CNS 穿透性 |
|---------|---------|----------|
| 叔胺化合物 | Atropine、Scopolamine | 高穿透 BBB |
| 季銨化合物 | Ipratropium、Glycopyrrolate | 不穿透 BBB |

### Atropine 的組織效應

| 系統 | 效應 | 說明 |
|------|------|------|
| <span style="color:#22d3ee">眼睛</span> | 散瞳（Mydriasis）、睫狀肌麻痺（Cycloplegia）| M3 受體阻斷；<span style="color:#f87171">可能誘發急性閉角型青光眼</span> |
| <span style="color:#22d3ee">唾液腺</span> | 分泌顯著減少 | 口乾；<span style="color:#34d399">最敏感的組織之一</span> |
| <span style="color:#22d3ee">心臟</span> | 劑量依賴性：低劑量（0.4-0.6 mg）可能引起<span style="color:#f87171">心搏過緩</span>（阻斷突觸前 M2 自體受體）；中等至高劑量引起心搏過速 |
| <span style="color:#22d3ee">支氣管</span> | 支氣管擴張、分泌減少 | 對 COPD 患者顯著 |
| <span style="color:#22d3ee">GI 道</span> | 蠕動與分泌減少 | 抗痙攣作用 |
| <span style="color:#22d3ee">泌尿道</span> | 逼尿肌收縮減少 | 尿滯留 |
| <span style="color:#22d3ee">CNS</span> | 高劑量：興奮、譫妄、幻覺 | M1 受體阻斷 |

### Scopolamine

| 特性 | 說明 |
|------|------|
| 與 Atropine 的差異 | CNS 作用更強（鎮靜、遺忘作用）|
| 臨床用途 | <span style="color:#fb923c">動暈症</span>（經皮貼片）、術前鎮靜 |

## 合成 Muscarinic 拮抗劑

| 藥物 | 特性 | 臨床用途 |
|------|------|---------|
| <span style="color:#fb923c">Ipratropium</span> | 季銨化合物，不穿透 BBB | COPD、氣喘（吸入）|
| <span style="color:#fb923c">Tiotropium</span> | 長效 muscarinic 拮抗劑（LAMA）| COPD（每日一次）|
| <span style="color:#fb923c">Glycopyrrolate</span> | 季銨化合物 | 術前給藥（止涎）、COPD |
| <span style="color:#fb923c">Tropicamide</span> | 短效散瞳劑 | 眼科散瞳/睫狀肌麻痺 |
| <span style="color:#fb923c">Oxybutynin</span> | M3 選擇性 | 膀胱過動症、尿失禁 |
| <span style="color:#fb923c">Tolterodine</span> | M3 選擇性 | 膀胱過動症 |
| <span style="color:#fb923c">Darifenacin</span>、<span style="color:#fb923c">Solifenacin</span> | M3 選擇性，長效 | 膀胱過動症，每日一次 |

## 神經肌肉阻斷劑

作用於骨骼肌神經肌肉接合處的 <span style="color:#c084fc">Nicotinic（N_N2）</span> 受體。

### 非去極化型（競爭性拮抗劑）

| 藥物 | 作用時間 | 特性 |
|------|---------|------|
| <span style="color:#fb923c">Rocuronium</span> | 中效 | 快速 onset，適合快速誘導插管 |
| <span style="color:#fb923c">Vecuronium</span> | 中效 | 心臟副作用少，肝臟代謝 |
| <span style="color:#fb923c">Cisatracurium</span> | 中效 | 主要經 Hofmann 降解（非酶性），<span style="color:#34d399">適合肝腎功能不良患者</span> |
| <span style="color:#fb923c">Pancuronium</span> | 長效 | 可能引起心搏過速（抗迷走神經作用）|

### 去極化型

| 藥物 | 機轉 | 臨床說明 |
|------|------|---------|
| <span style="color:#f87171">Succinylcholine</span> | 持續激活 N_N2 受體，導致持續去極化 | 快速 onset，短時間（數分鐘）；<span style="color:#f87171">禁忌：惡性高熱病史、高血鉀、燒傷/神經損傷</span> |

### 逆轉方法

| 方法 | 說明 |
|------|------|
| <span style="color:#fb923c">Neostigmine</span> | AChE 抑制劑，增加 NMJ 的 ACh 濃度 |
| <span style="color:#fb923c">Sugammadex</span> | 選擇性結合劑，包裹 Rocuronium/Vecuronium |

## Atropine 中毒處理

<span style="color:#f87171">兒童對 Atropine 極度敏感，2 mg 即可能致命</span>

### 中毒症狀

<span style="color:#f87171">口乾、瞳孔散大、心搏過速、皮膚發熱發紅、興奮、譫妄</span>

口訣：<span style="color:#f87171">「乾如枯骨、盲如蝙蝠、紅如甜菜、瘋如帽商」</span>

### 治療

| 方法 | 說明 |
|------|------|
| 支持性療法 | 降溫毯、癲癇控制（Diazepam）|
| <span style="color:#fb923c">Physostigmine</span> | AChE 抑制劑（穿透 BBB），小劑量緩慢 IV（成人 1-4 mg）|

---

| 禁忌情況 | 說明 |
|---------|------|
| <span style="color:#f87171">閉角型青光眼</span> | Atropine 可能誘發急性發作 |
| <span style="color:#f87171">攝護腺肥大</span> | 可能誘發尿滯留 |
| <span style="color:#f87171">GI 阻塞</span> | 腸阻塞 |
| <span style="color:#f87171">麻痹性腸阻塞</span> | — |
| <span style="color:#f87171">尿滯留</span> | — |
| <span style="color:#f87171">心搏過速性心律不整</span> | — |

## 藥物總整理

| 藥物 | 機轉 | 臨床用途 | 副作用 |
|------|------|---------|-------|
| <span style="color:#fb923c">Atropine</span> | Muscarinic 拮抗劑（M1-M5）| 術前給藥、心搏過緩、眼科散瞳、GI 痙攣 | 口乾、視覺模糊、心搏過速、尿滯留、CNS 興奮 |
| <span style="color:#fb923c">Scopolamine</span> | Muscarinic 拮抗劑 | 動暈症（貼片）、術前鎮靜 | 嗜睡、視覺模糊、口乾 |
| <span style="color:#fb923c">Ipratropium</span> | Muscarinic 拮抗劑（吸入）| COPD、氣喘 | 局部刺激、極少全身作用 |
| <span style="color:#fb923c">Tiotropium</span> | 長效 muscarinic 拮抗劑（LAMA）| COPD（每日一次）| 口乾、便祕 |
| <span style="color:#fb923c">Glycopyrrolate</span> | 季銨 muscarinic 拮抗劑 | 術前給藥（止涎）、COPD | 口乾 |
| <span style="color:#fb923c">Tropicamide</span> | 短效 muscarinic 拮抗劑 | 眼科散瞳/睫狀肌麻痺 | 視覺模糊 |
| <span style="color:#fb923c">Rocuronium</span> | 非去極化 NMJ 阻斷劑 | 麻醉誘導、維持肌肉鬆弛 | 注射部位疼痛 |
| <span style="color:#fb923c">Vecuronium</span> | 非去極化 NMJ 阻斷劑 | 麻醉維持 | 肝功能影響 |
| <span style="color:#fb923c">Cisatracurium</span> | 非去極化 NMJ 阻斷劑 | 麻醉（肝腎功能不良患者）| 注射部位反應 |
| <span style="color:#f87171">Succinylcholine</span> | 去極化 NMJ 阻斷劑 | 快速誘導插管、短手術 | 肌肉疼痛、高血鉀、心律不整、<span style="color:#f87171">惡性高熱</span> |
