## 章節導讀

血脂異常是心血管疾病的主要危險因子，本章節系統探討臨床上用於治療高膽固醇血症與高三酸甘油酯血症的各類藥物，包括Statins（他汀類）、膽汁酸結合劑、膽固醇吸收抑制劑、菸鹼酸、Fibrates與PCSK9抑制劑，並深入分析它們的作用機轉、臨床應用與不良反應，以及血脂控制的治療目標與指南建議。

## <span style="color:#60a5fa">Dyslipidemias</span> & <span style="color:#60a5fa">Lipid-Lowering Agents</span>

Dyslipidemia is a major risk factor for cardiovascular disease. This chapter systematically explores the various drugs used clinically to treat hypercholesterolemia and hypertriglyceridemia, including Statins, bile acid sequestrants, cholesterol absorption inhibitors, niacin, fibrates, and PCSK9 inhibitors, and provides an in-depth analysis of their mechanisms of action, clinical applications, and adverse effects, as well as treatment goals and guideline recommendations for lipid control.

## 第一節　血脂與脂蛋白

### 脂蛋白分類

<span style="color:#22d3ee">**脂蛋白（Lipoproteins）**</span>是膽固醇與三酸甘油酯在血漿中的轉運形式：

| 脂蛋白 | 主要成分 | 功能 |
|--------|---------|------|
| **Chylomicrons** | 三酸甘油酯（85%) | 飲食脂肪轉運（腸道→周邊） |
| **VLDL（極低密度脂蛋白）** | 三酸甘油酯 | 肝臟轉運內源性脂肪至周邊 |
| **IDL（中間密度脂蛋白）** | 膽固醇/三酸甘油酯 | VLDL代謝產物 |
| **LDL（低密度脂蛋白）** | 膽固醇（50%） | **主要致粥狀硬化膽固醇** |
| **HDL（高密度脂蛋白）** | 膽固醇/磷脂 | **逆向膽固醇轉運**；抗粥狀硬化 |

### 致粥狀硬化血脂模式

| 特徵 | 說明 |
|------|------|
| **高三酸甘油酯** | VLDL殘粒↑→小型緻密LDL↑→HDL↓ |
| **低HDL-C** | 男<40 mg/dL；女<50 mg/dL |
| **LDL-C升高** | **心血管疾病主要危險因子** |

## 第二節　Statins（他汀類）

<span style="color:#60a5fa">**Statins（HMG-CoA Reductase抑制劑）**</span>是治療高膽固醇血症的一線藥物。

### 作用機轉

| 作用 | 說明 |
|------|------|
| **HMG-CoA reductase抑制** | 抑制肝臟膽固醇合成→細胞內膽固醇↓ |
| **LDL受體上調** | 肝細胞增加LDL受體表現→血漿LDL-C↓ |
| **多重效應** | 抗炎、抗氧化、穩定斑塊（斑塊消退作用） |

### 各藥物特性

| 藥物 | 強度 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Rosuvastatin（瑞舒伐他汀）</span> | **最高** | 5–40 mg；肝/腎排泄 |
| <span style="color:#fb923c">Atorvastatin（阿托伐他汀）</span> | **高** | 10–80 mg；肝臟代謝 |
| <span style="color:#fb923c">Simvastatin（斯伐他汀）</span> | 中-高 | 5–80 mg；與CYP3A4交互 |
| <span style="color:#fb923c">Pravastatin（普伐他汀）</span> | 中 | 10–80 mg；水溶性；較少交互作用 |
| <span style="color:#fb923c">Pitavastatin（匹伐他汀）</span> | 中-高 | 1–4 mg；CYP2C9代謝 |
| <span style="color:#fb923c">Lovastatin（洛伐他汀）</span> | 中 | 10–80 mg；CYP3A4；前驅藥 |

### LDL-C降低幅度

| 強度 | LDL-C↓幅度 | 代表藥物劑量 |
|------|-----------|------------|
| **低** | <30% | Pravastatin 10–20 mg |
| **中** | 30–49% | Simvastatin 10 mg、Pravastatin 40 mg |
| **高** | 50–59% | Atorvastatin 10–20 mg、Rosuvastatin 5–10 mg |
| **極高** | >60% | Atorvastatin 40–80 mg、Rosuvastatin 20–40 mg |

### 不良反應

| 不良反應 | 說明 |
|---------|------|
| **肌肉相關** | 肌痛（常見，5–10%）、肌炎（<1%）、**横紋肌溶解症**（罕見，<0.1%） |
| **肝臟** | 肝功能異常（ALT↑）；嚴重肝毒性罕見 |
| **新增糖尿病** | 空腹血糖/HbA1c↑；主要見於高風險/老年人 |

<span style="color:#f87171">**横紋肌溶解症（Rhabdomyolysis）**：嚴重肌肉破壞；肌球蛋白尿→急性腎損傷；主要見於Statin+其他藥物（Fibrates、CYP3A4抑制劑）的交互作用。</span>

<span style="color:#34d399">**CK（肌酸激酶）升高>10倍正常上限**：需停藥。</span>

## 第三節　膽汁酸結合劑（Bile Acid Sequestrants）

| 藥物 | 機轉 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Cholestyramine（考來烯胺）</span> | 結合膽汁酸→糞便排泄↑→肝臟膽固醇轉化為膽汁酸↑ | LDL-C↓15–30%；便祕/腹脹 |
| <span style="color:#fb923c">Colestipol（考來替泊）</span> | 同上 | 胃腸道副作用較少 |
| <span style="color:#fb923c">Colesevelam（考來維侖）</span> | 同上 | 對血糖可能有額外效益（糖尿病患者） |

| 特點 | 說明 |
|------|------|
| 作用部位 | 腸道；不吸收 |
| LDL-C↓ | 15–30% |
| 缺點 | 腹脹、便祕；三酸甘油酯↑；減少脂溶性維生素吸收 |

<span style="color:#e2e8f0">**Statin加強治療**：可與Statin合用增加降LDL效果。</span>

## 第四節　膽固醇吸收抑制劑

### Ezetimibe（依折麥布）

<span style="color:#60a5fa">**Ezetimibe（依折麥布）**</span>抑制小腸刷狀緣<span style="color:#e2e8f0">**NPC1L1轉運蛋白**</span>，減少飲食與膽汁中的膽固醇吸收。

| 特點 | 說明 |
|------|------|
| LDL-C↓ | 15–20% |
| 特點 | 不影響三酸甘油酯或脂溶性維生素吸收 |
| 臨床試驗 | IMPROVE-IT：Ezetimibe+Simvastatin vs Simvastatin→心血管事件↓（中度） |
| 製劑 | 單方或與Statin複方（Vytorin） |

<span style="color:#e2e8f0">**他汀+依折麥布**：對需要進一步降低LDL-C的患者。</span>

## 第五節　菸鹼酸（Niacin）

<span style="color:#60a5fa">**菸鹼酸（Niacin/Vitamin B3）**</span>對所有血脂參數均有改善：

| 血脂參數 | 效應 |
|---------|------|
| **LDL-C** | ↓ 5–25% |
| **TG** | ↓ 20–50% |
| **HDL-C** | **↑ 15–35%**（唯一顯著升高HDL的藥物） |

| 特點 | 說明 |
|------|------|
| 機轉 | 抑制VLDL產生；減少HDL分解 |
| 副作用 | 臉部潮紅（ prostaglandin介導→Aspirin預處理）、搔癢、肝功能異常、血糖↑ |
| 臨床試驗 | AIM-HIGH、HPS2-THRIVE：**未能證實額外心血管效益** |

<span style="color:#f87171">**AIM-HIGH/HPS2-THRIVE**顯示：Statin治療上加用菸鹼酸未能減少心血管事件，但不良反應增加。</span>

## 第六節　Fibrates（貝特類）

<span style="color:#60a5fa">**Fibrates（PPARα激動劑）**</span>主要用於降低三酸甘油酯。

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Gemfibrozil（吉非貝齊）</span> | 第一代；TG↓30–50%；HDL↑10–15%；膽結石↑ |
| <span style="color:#fb923c">Fenofibrate（非諾貝特）</span> | 第二代；TG↓30–50%；HDL↑10–20%；腎功能影響較大 |
| <span style="color:#fb923c">Fenofibric Acid（非諾貝特酸）</span> | 膽鹼鹽；腎功能不全可用 |

| 對血脂的影響 | 說明 |
|-------------|------|
| **TG** | ↓ 30–50% |
| **HDL** | ↑ 10–20% |
| **LDL** | 可變（高TG時LDL可能↑） |

| 不良反應 | 說明 |
|---------|------|
| 肌肉 | **與Statin合用顯著增加横紋肌溶解症風險**；Gemfibrozil干擾Statin葡萄醣醛酸化 |
| 肝功能 | ALT↑ |
| 膽結石 | 增加膽結石風險 |

<span style="color:#f87171">**Statin+Fibrate合用**：選擇Fenofibrate（非Gemfibrozil）以減少肌肉毒性。</span>

## 第七節　PCSK9抑制劑

<span style="color:#60a5fa">**PCSK9（Proprotein Convertase Subtilisin/Kexin Type 9）抑制劑**</span>是新型降膽固醇藥物。

### 作用機轉

<span style="color:#e2e8f0">**PCSK9**</span>蛋白結合<span style="color:#e2e8f0">**LDL受體**</span>使其降解→肝細胞表面LDL受體↓→LDL-C↑。PCSK9抑制劑阻止此結合，使更多LDL受體回收→LDL-C↓↓。

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Evolocumab（evolocumab）</span> | 完全人源化單株抗體；皮下注射每2–4週一次 |
| <span style="color:#fb923c">Alirocumab</span> | 完全人源化單株抗體；皮下注射每2–4週一次 |

| 特點 | 說明 |
|------|------|
| LDL-C↓ | **60–70%**（聯合Statin時） |
| Lp(a)↓ | 約30% |
| 優勢 | 每2–4週一次；耐受性好；無顯著肌肉/肝毒性 |
| 適應症 | 家族性高膽固醇血症（HeFH）、 ASCVD需要進一步降低 |

| 藥物 | 機轉 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Lomitapide</span> | MTP抑制劑 | 減少VLDL合成；用於HoFH；腹瀉/肝毒性 |
| <span style="color:#fb923c">Mipomersen</span> | ApoB-100反義寡核苷酸 | 減少ApoB產生；用於HoFH；肝毒性 |
| <span style="color:#fb923c">Omega-3 Fatty Acids</span> | 多不飽和脂肪酸 | **高劑量（4 g/d）降低TG**；可能含EPA/DHA |

## 第九節　治療目標與臨床應用

### 各類患者LDL-C治療目標

| 風險分層 | LDL-C目標 |
|---------|---------|
| ASCVD（二級預防） | **<70 mg/dL**（部分<55 mg/dL） |
| 糖尿病（40–75歲，ASCVD risk≥7.5%） | <70 mg/dL |
| 糖尿病（40–75歲，ASCVD risk<7.5%） | <100 mg/dL |
| 無ASCVD/糖尿病，10年ASCVD risk≥7.5% | <100 mg/dL |

### 藥物選擇原則

| 情況 | 首選藥物 |
|------|---------|
| 高LDL-C | Statin（一線）；需加強時+依折麥布或PCSK9抑制劑 |
| 高TG（>500 mg/dL） | Fibrate（Fenofibrate）→預防胰臟炎 |
| 混合型血脂異常 | Statin（降LDL為主）；加強時加Fibrate或Ezetimibe |
| 低HDL-C | 菸鹼酸（已少用）；Statin（些微↑）；無特效藥 |

## 第十節　重點摘要

- <span style="color:#fb923c">Statins</span>（HMG-CoA reductase抑制劑）是治療高膽固醇血症的一線藥物，透過上調LDL受體降低LDL-C
- Statins按強度分為低/中/高/極高強度；高強度Statin（Atorvastatin 40–80 mg、Rosuvastatin 20–40 mg）可使LDL-C降低>50%
- <span style="color:#f87171">Statins的主要不良反應為肌肉毒性（肌痛→横紋肌溶解症）</span>；與Fibrates合用增加肌肉毒性
- <span style="color:#fb923c">Ezetimibe</span>抑制膽固醇吸收，與Statin合用可額外降低LDL-C 15–20%
- <span style="color:#fb923c">PCSK9抑制劑</span>（Evolocumab、Alirocumab）可使LDL-C降低60–70%，用於家族性高膽固醇血症與ASCVD患者
- <span style="color:#fb923c">Fibrates</span>主要降低TG（30–50%）並輕度升高HDL，但肌肉毒性是與Statin合用的主要顧慮
- <span style="color:#fb923c">菸鹼酸</span>可升高HDL但臨床試驗未能證實額外心血管效益
- ASCVD二級預防的LDL-C目標為<70 mg/dL（部分極高風險患者<55 mg/dL）
