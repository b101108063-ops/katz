# CH56 中毒病患處理

## 章節導讀

中毒是急診常見的緊急狀況，快速、系統性的處理是搶救成功的關鍵。本章節介紹中毒病患的緊急處理原則，包括ABC維持、毒物清除技術、特異解毒劑的使用，以及常見中毒症候群（<span style="color:#c084fc">**acetaminophen**</span>、<span style="color:#c084fc">**鎮靜劑**</span>、<span style="color:#c084fc">**三環抗憂鬱劑**</span>等）的識別與處理。

---

## 中毒病患死亡機轉

| 機轉 | 說明 |
|------|------|
| <span style="color:#f87171">**中樞神經抑制**</span> | 呼吸抑制、意識障礙 → 吸入性肺炎、呼吸衰竭 |
| <span style="color:#f87171">**心臟血管衰竭**</span> | β-blockers、Ca channel blockers、digoxin過量 |
| <span style="color:#f87171">**癲癇**</span> | 抗憂鬱劑、cocaine、isoniazid過量 → 吸入性肺炎、缺氧 |
| <span style="color:#f87171">**體溫過高**</span> | 抗膽鹼制劑、sympathomimetics → 肌肉過度活動 → 橫紋肌溶解 |
| <span style="color:#f87171">**延遲器官損傷**</span> | Acetaminophen → 肝衰竭；Paraquat → 肺纖維化 |

## 初始處理：ABCD原則

| 步驟 | 內容 |
|------|------|
| <span style="color:#60a5fa">**A - Airway（呼吸道）**</span> | 清除嘔吐物；必要時插管或置入口呼吸道 |
| <span style="color:#60a5fa">**B - Breathing（呼吸）**</span> | 評估呼吸；脈搏血氧儀；必要時機械換氣 |
| <span style="color:#60a5fa">**C - Circulation（循環）**</span> | 建立靜脈通路；持續監測脈搏、血壓、尿量 |
| <span style="color:#60a5fa">**D - Drugs（藥物/去污染）**</span> | 血糖檢測；解毒劑；清除污染 |

### 初始藥物處置

| 藥物 | 劑量 | 適應症 |
|------|------|--------|
| <span style="color:#fb923c">50% Dextrose</span> | 成人25 g（50 mL）；兒童0.5 g/kg | 血糖過低或未確定 |
| <span style="color:#fb923c">Naloxone</span> | 0.4-2 mg IV | 鴉片類藥物過量 |
| <span style="color:#fb923c">Thiamine</span> | 100 mg IM/IV | 預防Wernicke腦病（酗酒/營養不良患者）|
| <span style="color:#fb923c">Flumazenil</span> | 0.2 mg IV（最大3 mg）| <span style="color:#f87171">**Benzodiazepine過量**</span>；<span style="color:#f87171">**禁用於TCA過量或癲癇患者**</span> |

## 病史與理學檢查

### 重點理學檢查

| 項目 | 重要發現 | 可能的中毒類別 |
|------|---------|--------------|
| <span style="color:#60a5fa">**生命徵象**</span> | 高血壓、心搏過速 | Amphetamines、Cocaine、抗膽鹼制劑 |
| | 低血壓、心搏過緩 | β-blockers、Ca channel blockers、clonidine |
| <span style="color:#60a5fa">**瞳孔**</span> | 放大（Mydriasis）| Amphetamines、Cocaine、LSD、atropine |
| | 縮小（Miosis）| 鴉片類、clonidine、有機磷 |
| <span style="color:#60a5fa">**皮膚**</span> | 潮紅乾燥 | 抗膽鹼制劑 |
| | 盜汗 | 有機磷、nicotine、sympathomimetics |
| <span style="color:#60a5fa">**腹部**</span> | 腸音消失 | 抗膽鹼、opioid、鎮靜劑 |
| | 腸音亢進 | 有機磷、iron、theophylline |

## 實驗室評估

### 陰離子間隙（Anion Gap）

<span style="color:#60a5fa">**公式**：AG = (Na⁺ + K⁺) − (HCO₃⁻ + Cl⁻)；正常：12-16 mEq/L</span>

| 導致AG升高藥物 | 說明 |
|---------------|------|
| <span style="color:#fb923c">Salicylates</span> | 混合性呼吸鹼中毒+代謝性酸中毒 |
| <span style="color:#fb923c">Methanol</span> | 甲酸累積 |
| <span style="color:#fb923c">Ethylene glycol</span> | 草酸、乙醇酸累積 |
| <span style="color:#fb923c">Isoniazid</span> | 癲癇相關乳酸酸中毒 |
| <span style="color:#fb923c">Iron</span> | 直接細胞毒性 |

### 血清滲透壓差（Osmol Gap）

<span style="color:#60a5fa">**公式**：滲透壓差 = 測得滲透壓 − 計算滲透壓 = 2×Na⁺ + Glucose/18 + BUN/2.8</span>

| 物質 | 血清濃度 | 預期滲透壓差 |
|------|---------|-------------|
| Ethanol | 350 mg/dL | 75 mOsm/kg |
| Methanol | 80 mg/dL | 25 mOsm/kg |
| Ethylene glycol | 200 mg/dL | 35 mOsm/kg |
| Isopropanol | 350 mg/dL | 60 mOsm/kg |

### 心電圖評估

| 發現 | 可能的毒素 |
|------|----------|
| <span style="color:#f87171">**QRS延長**</span>（> 100 ms）| TCA、quinidine |
| <span style="color:#f87171">**QT延長**</span>（> 440 ms）| Quinidine、erythromycin、抗憂鬱劑、lithium |
| <span style="color:#f87171">**心室心律不整**</span> | Digoxin、TCA、quinidine |

## 去污染技術

### 皮膚去污染

| 步驟 | 說明 |
|------|------|
| 移除衣物 | 雙層包裝以防二次暴露 |
| 清水冲洗 | 清水+肥皂徹底冲洗 |

### 腸胃道去污染

| 方法 | 適應症 | 說明 |
|------|--------|------|
| <span style="color:#fb923c">**活性炭**</span> | 大多數口服毒物 | 首選；劑量：1 g/kg（或至少10:1 活性炭：毒物比）；<span style="color:#f87171">**不改變離子、鋰、鉀、醇類**</span> |
| <span style="color:#fb923c">**催吐（Ipecac）**</span> | <span style="color:#f87171">**不再建議**</span> | 風險大於效益；禁用於腐蝕劑、碳氫化合物、rapid-acting convulsants |
| <span style="color:#fb923c">**胃灌洗**</span> | 早期（< 1小時）大量攝入 | 大口徑管；生理食鹽水冲洗；<span style="color:#f87171">**腐蝕劑禁用**</span> |
| <span style="color:#fb923c">**全腸道灌洗**</span> | 鐵片、長效製劑、毒品包 | PEG-ELS 1-2 L/h（兒童500 mL/h）直到直腸排出清液 |

## 特異解毒劑

| 解毒劑 | 適應症 | 劑量與用法 |
|--------|--------|-----------|
| <span style="color:#fb923c">Acetylcysteine</span> | Acetaminophen | 口服首選；首日140 mg/kg，之後70 mg/kg q4h×17劑 |
| <span style="color:#fb923c">Atropine</span> | 有機磷、氨基甲酸酯 | 1-2 mg IV；每10-15分鐘加倍直到肺部分泌物減少 |
| <span style="color:#fb923c">Calcium gluconate</span> | Ca channel blockers、氟化物 | 15-30 mg/kg IV（急性）；大劑量 |
| <span style="color:#fb923c">Digoxin-specific antibodies</span> | Digoxin過量 | 每瓶結合0.5 mg digoxin |
| <span style="color:#fb923c">Flumazenil</span> | Benzodiazepine | 0.2 mg IV（最大3 mg）；<span style="color:#f87171">**禁用於TCA或癲癇患者**</span> |
| <span style="color:#fb923c">Fomepizole</span> | Methanol、ethylene glycol | 15 mg/kg loading dose；之後10 mg/kg q12h |
| <span style="color:#fb923c">Glucagon</span> | β-blockers | 5-10 mg IV bolus |
| <span style="color:#fb923c">Hydroxocobalamin</span> | 氰化物 | 5 g IV over 15 min（成人）|
| <span style="color:#fb923c">Naloxone</span> | 鴉片類 | 0.4-2 mg IV（可重複）|
| <span style="color:#fb923c">Pralidoxime (2-PAM)</span> | 有機磷 | 1 g IV（可重複或 continuous infusion 250-400 mg/h）|
| <span style="color:#fb923c">Sodium bicarbonate</span> | TCA | 1-2 mEq/kg IV bolus（QRS延長時）|
| <span style="color:#fb923c">Deferoxamine</span> | 鐵 | 15 mg/kg/h IV（嚴重時）|

## 常見中毒症候群

### Acetaminophen中毒

<span style="color:#60a5fa">**毒性機轉**：NAPQI堆積 → 耗竭glutathione → 肝細胞壞死</span>

| 劑量 | 風險 |
|------|------|
| > 150-200 mg/kg（兒童）或 > 7 g（成人）| 潛在毒性 |
| > 250 mg/kg | 嚴重肝細胞壞死 |

| 治療時間窗 | 說明 |
|-----------|------|
| <span style="color:#34d399">**8小時內**</span> | NAC效果最佳 |
| > 24小時 | 肝細胞壞死已發生；NAC可能仍有價值（邊緣效益）|

### 鴉片類中毒

<span style="color:#60a5fa">**經典型三聯徵**：針尖瞳孔 + 呼吸抑制 + 意識障礙</span>

| 治療 | 說明 |
|------|------|
| <span style="color:#fb923c">Naloxone</span> | 首選；大劑量可能需要（propoxyphene、codeine）|

### Benzodiazepine中毒

| 治療 | 說明 |
|------|------|
| 支持性治療為主 | 呼吸抑制時插管換氣 |
| <span style="color:#fb923c">Flumazenil</span> | 特異解毒；<span style="color:#f87171">**禁用於TCA過量、癲癇或benzodiazepine依賴患者**</span> |

### Tricyclic Antidepressants中毒

<span style="color:#60a5fa">**QRS延長是心臟毒性的早期指標**</span>

| 處置 | 說明 |
|------|------|
| <span style="color:#fb923c">Sodium bicarbonate</span> | <span style="color:#34d399">**首選**</span>：1-2 mEq/kg IV bolus；增加細胞外Na對抗Na通道阻斷 |
| 避免 | Physostigmine（可能加重心臟傳導抑制）|

### Salicylate（Aspirin）中毒

<span style="color:#60a5fa">**混合性酸鹼失衡**：早期呼吸鹼中毒 → 晚期代謝性酸中毒</span>

| 嚴重度 | 血中濃度 |
|--------|---------|
| 輕度 | < 150 mg/L |
| 中度 | 150-300 mg/L |
| 重度 | > 300 mg/L；透析指徵 |

| 治療 | 說明 |
|------|------|
| 靜脈輸液 | 補充脫水 |
| <span style="color:#fb923c">Sodium bicarbonate</span> | 尿液鹼化（目標尿液pH > 7.5）|
| 血液透析 | 重度中毒（血清 > 100 mg/dL、昏迷、腎衰竭）|

## 中毒預防與衛教

| 策略 | 說明 |
|------|------|
| 安全的藥物儲存 | 兒童無法觸及；原包裝存放 |
| 清楚的標籤 | 大字體；說明用途 |
| 緊急聯絡資訊 | 毒物中心電話 |
| 藥物複查 | 「棕色袋子分析」— 請患者帶所有藥物就診 |
