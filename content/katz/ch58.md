# CH58 老年藥理學

## 章節導讀

老年人的藥理學特性與年輕成人有顯著差異，主要源於年齡相關的生理功能下降，包括腎功能減退、肝臟代謝能力改變、身體組成分變化及藥效學敏感度改變。本章節介紹老年人藥動學與藥效學的變化，以及主要藥物類別（心血管藥物、中樞神經藥物、抗感染藥物等）在老年人中的使用原則與不良反應風險。

---

## 老年人生理變化與藥動學

### 腎功能減退

<span style="color:#60a5fa">**腎絲球濾過率（GFR）随年齡下降**，約2/3老年人有此現象。</span>

| 問題 | 說明 |
|------|------|
| <span style="color:#f87171">**血清肌酸酐的誤導性**</span> | 老年人的肌肉量減少，肌酸酐產生減少；即使腎功能已下降，血清肌酸酐可能仍在正常範圍 |
| <span style="color:#60a5fa">**Cockcroft-Gault公式**</span> | 適用於40-80歲：CrCl = [(140-年齡)×體重(kg)] / [72×血清肌酸酐(mg/dL)]；女性×0.85 |

<span style="color:#34d399">**臨床意義**：主要經腎臟排除的藥物（如aminoglycosides、digoxin、lithium、部分penicillins）需根據腎功能調整劑量。</span>

### 肝臟代謝能力變化

| 變化 | 說明 |
|------|------|
| <span style="color:#60a5fa">**肝臟血流減少**</span> | 60-80歲約為年輕人的55-60% |
| <span style="color:#60a5fa">**CYP450酶活性**</span> | Phase I反應（氧化）下降；Phase II反應（接合）變化較小 |
| <span style="color:#60a5fa">**肝臟恢復能力**</span> | 肝炎或肝毒性物質損傷後恢復能力下降 |

| 肝臟清除減少的藥物 | 肝臟清除不變的藥物 |
|-------------------|------------------|
| Diazepam、Alprazolam | Lorazepam、Oxazepam |
| Meperidine、Nortriptyline | Lidocaine、Prazosin |
| Propranolol、Theophylline | Warfarin、Isoniazid |

### 身體組成分變化

| 變化 | 說明 |
|------|------|
| <span style="color:#60a5fa">**體水分減少**</span> | 61%（年輕成人）→ 53%（老年人）；水溶性藥物分佈體積減少 |
| <span style="color:#60a5fa">**體脂肪增加**</span> | 脂溶性藥物（如benzodiazepines、anesthetics）分佈體積增加，半衰期延長 |
| <span name="color:#60a5fa">**肌肉量減少**</span> | 影響digoxin等藥物的分佈 |
| <span style="color:#60a5fa">**白蛋白減少**</span> | 游離藥物比例增加；影響高度蛋白質結合藥物 |

## 老年人的藥效學變化

### 中樞神經系統藥物敏感性增加

<span style="color:#60a5fa">**老年人對多種中樞神經藥物更敏感**，包括：</span>

| 藥物類別 | 敏感性增加的表現 |
|---------|----------------|
| <span style="color:#fb923c">Benzodiazepines</span> | 嗜睡、共濟失調；跌倒風險增加 |
| <span style="color:#fb923c">Opioids</span> | 呼吸抑制作用增強 |
| <span style="color:#fb923c">Antipsychotics</span> | 錐體外症狀增加 |
| <span name="color:#fb923c">Antidepressants</span> | 抗膽鹼作用更明顯 |

### 心血管系統的代償機制減退

| 變化 | 說明 |
|------|------|
| <span style="color:#60a5fa">**心輸出量對運動的反應減退**</span> | 心搏過速減少，依賴增加每搏輸出量 |
| <span name="color:#60a5fa">**姿勢性低血壓**</span> | 姿勢改變時血壓調節能力下降；跌倒風險 |
| <span style="color:#60a5fa">**體溫調節受損**</span> | 對體溫過高或過低更敏感 |

## 主要藥物類別在老年人中的使用

### 心血管藥物

#### 抗高血壓藥物

| 藥物類別 | 老年人使用要點 |
|---------|--------------|
| <span style="color:#fb923c">**Thiazide利尿劑**</span> | 首選之一；但低劑量使用（避免低血鉀、高血糖、高尿酸）|
| <span style="color:#fb923c">**Ca channel blockers**</span> | 有效；注意便秘（diltiazem/verapamil）和水腫（dihydropyridines）|
| <span style="color:#fb923c">**β-blockers**</span> | 對老年人較β-blockers效果差（老年人β受體反應下降）；阻塞性肺疾病者禁用 |
| <span name="color:#fb923c">**ACE抑制劑/ARB**</span> | 對心衰竭、糖尿病者有腎臟保護作用；但老年人起始劑量要低 |

<span style="color:#f87171">**注意**：老年人使用任何抗高血壓藥物都應定期監測姿勢性低血壓。</span>

#### 毛地黃（Digoxin）

| 特性 | 說明 |
|------|------|
| <span style="color:#60a5fa">**腎排泄**</span> | 半衰期延長（> 50%老年人）|
| <span style="color:#60a5fa">**毒性風險增加**</span> | 心律不整、噁心、精神障礙 |
| <span style="color:#60a5fa">**劑量建議**</span> | 維持劑量通常需降低；監測血清濃度 |

<span style="color:#f87171">**老年人使用毛地黃的常見毒性**：心律不整（最常見）、意識障礙、胃腸道症狀、視覺障礙（黃視）</span>

#### 抗心律不整藥物

| 藥物 | 老年人考量 |
|------|-----------|
| <span style="color:#fb923c">Quinidine/Procainamide</span> | 半衰期延長；procainamide可能引起紅斑性狼瘡 |
| <span style="color:#fb923c">Disopyramide</span> | <span style="color:#f87171">**避免使用**</span>：強抗膽鹼作用（尿瀦留）；負性肌力作用（心衰竭）|
| <span style="color:#fb923c">Lidocaine</span> | 分布體積可能改變；起始負荷劑量降低 |

---

### 中樞神經系統藥物

#### 鎮靜催眠藥

| 藥物 | 老年人考量 |
|------|-----------|
| <span style="color:#fb923c">Long-acting benzodiazepines</span> | <span style="color:#f87171">**避免**</span>（diazepam、flurazepam）；半衰期過長，蓄積 |
| <span style="color:#fb923c">Lorazepam、Oxazepam</span> | 較安全（不通過CYP450，無活性代謝物）|
| <span style="color:#fb923c">Zolpidem</span> | 可能導致意識模糊、夜間跌倒 |

<span style="color:#60a5fa">**老年人使用鎮靜劑的原則**：從最低有效劑量開始；避免長期使用；注意翌日鎮靜。</span>

#### 抗精神病藥物

| 藥物 | 老年人考量 |
|------|-----------|
| <span style="color:#fb923c">典型抗精神病（phenothiazines）</span> | 錐體外症狀、抗膽鹼作用、姿勢性低血壓 |
| <span name="color:#fb923c">Haloperidol</span> | 錐體外症狀較少；但已有帕金森氏症者禁用 |
| <span style="color:#fb923c">非典型抗精神病（clozapine、olanzapine）| 較少錐體外症狀；但有代謝症候群風險 |

<span style="color:#f87171">**警告**：抗精神病藥物用於失智症患者可能輕微增加死亡率。</span>

#### 抗憂鬱藥物

| 藥物類別 | 老年人考量 |
|---------|-----------|
| <span style="color:#fb923c">Tricyclic antidepressants</span> | <span style="color:#f87171">**高風險**</span>：抗膽鹼作用（尿瀦留、意識障礙）、心律不整、姿勢性低血壓 |
| <span style="color:#fb923c">SSRIs</span> | 首選之一；但需注意低血鈉（SIADH）、腸道出血 |
| <span name="color:#fb923c">SNRIs</span> | Venlafaxine需監測血壓；duloxetine注意肝功能 |

<span style="color:#60a5fa">**老年人憂鬱症狀可能被低估或誤認為失智**：仔細區分很重要。</span>

### 阿茲海默症治療藥物

#### 膽鹼酯酶抑制劑

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Donepezil</span> | 每日一次；5 mg起始，4-6週後增至10 mg |
| <span style="color:#fb923c">Rivastigmine</span> | 膠囊或貼片；起始低劑量慢慢增加 |
| <span style="color:#fb923c">Galantamine</span> | 錠劑或緩釋膠囊 |

| 不良反應 | 說明 |
|---------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 噁心、嘔吐、腹瀑（膽鹼酯酶抑制的膽鹼能作用）|
| <span style="color:#fb923c">**心臟**</span> | 心搏過緩（有心臟傳導障礙者慎用）|

#### NMDA受體拮抗劑

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Memantine</span> | 中-重度阿茲海默症；可單獨使用或與膽鹼酯酶抑制劑合用 |

---

### 抗感染藥物

| 考量 | 說明 |
|------|------|
| <span style="color:#60a5fa">**腎功能**</span> | 大多數β-lactams、aminoglycosides、fluoroquinolones經腎排泄；需根據GFR調整 |
| <span style="color:#60a5fa">**β-lactams**</span> | 相對安全；但高劑量可能誘發癲癇 |
| <span style="color:#fb923c">**Aminoglycosides**</span> | <span style="color:#f87171">**高風險**</span>：腎毒性+耳毒性；老年人GFR下降，半衰期明顯延長；必要時使用並監測谷底濃度 |
| <span style="color:#fb923c">**Fluoroquinolones**</span> | 注意中樞神經副作用（意識障礙、癲癇）； tendon破裂風險 |

---

### 抗發炎藥物

#### NSAIDs

<span style="color:#f87171">**⚠️ 老年人使用NSAIDs有顯著風險**</span>

| 風險 | 說明 |
|------|------|
| <span style="color:#f87171">**腎功能惡化**</span> | 可能造成急性腎損傷；已有腎功能減退者禁用 |
| <span name="color:#f87171">**上消化道出血**</span> | 老年人風險增加；必要時加上質子泵抑制劑 |
| <span style="color:#f87171">**心衰竭惡化**</span> | 水納瀦留；已有心衰竭者慎用 |
| <span style="color:#fb923c">**高血壓**</span> | 鈉瀦留可能降低降壓藥效果 |

| 替代方案 | 說明 |
|---------|------|
| <span style="color:#fb923c">Acetaminophen</span> | 首選替代；每日不超過3 g；注意肝毒性 |
| <span style="color:#fb923c">COX-2抑制劑</span> | 消化道安全性較好；但心血管風險；必要時使用 |

#### 皮質類固醇

| 風險 | 說明 |
|------|------|
| <span style="color:#f87171">**骨質疏鬆**</span> | 劑量相關；老年人骨折風險高；同時補充鈣質和維生素D |
| <span style="color:#fb923c">**糖尿病惡化**</span> | 類固醇誘發高血糖 |
| <span style="color:#fb923c">**感染風險**</span> | 免疫抑制 |

## 老年人不良藥物反應

### 發生率

<span style="color:#60a5fa">**不良藥物反應（ADR）在老年人的發生率是年輕人的2倍以上**。</span>

| 因素 | 說明 |
|------|------|
| <span name="color:#60a5fa">**多重用藥**</span> | 處方數量與ADR發生率直接相關；5種藥物約10%風險；10種藥物接近100% |
| <span style="color:#60a5fa">**不適當處方**</span> | 劑量過高；藥物交互作用；不適當藥物選擇 |
| <span name="color:#60a5fa">**患者遵藥性**</span> | 忘記服藥；誤解指示；藥物費用 |

### 常見的可避免問題

| 問題 | 預防措施 |
|------|---------|
| 跌倒與骨折 | 避免長效鎮靜劑；監測血壓 |
| 認知功能障礙 | 避免抗膽鹼作用強的藥物（TCA、antihistamines）|
| 腎功能衰竭 | 避免NSAIDs；監測腎功能 |
| 消化道出血 | NSAIDs時預防性使用PPI |

## 老年人用藥安全原則

1. <span style="color:#60a5fa">**從最低劑量開始**</span>：老年人對藥物更敏感；「start low, go slow」
2. <span style="color:#60a5fa">**簡化用藥方案**</span>：優先選擇長效製劑；減少每日服藥次數
3. <span name="color:#60a5fa">**定期藥物複查**</span>：「棕色袋子分析」—請患者帶所有藥物就診
4. <span style="color:#60a5fa">**監測腎功能**</span>：GFR計算比血清肌酸酐更準確
5. <span style="color:#60a5fa">**注意藥物交互作用**</span>：Cimetidine、ketoconazole等CYP抑制劑顯著改變藥物濃度
6. <span style="color:#60a5fa">**衛教患者與家屬**</span>：清楚說明用藥目的與注意事項
