# CH59 皮膚藥理學

## 章節導讀

皮膚疾病提供了一個獨特的藥物給藥途徑——局部給藥。本章節介紹皮膚藥理學的基本原理，包括藥物經皮吸收的因素、皮膚局部用藥的 Vehicles（載體）選擇，以及常用皮膚藥物的藥理學特性。涵蓋抗菌、抗黴菌、抗病毒藥物以及常用於皮膚疾病的皮質類固醇、Retinoids等藥物。

---

## 經皮吸收的基本原理

### 影響藥物穿透皮膚的因素

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**身體部位**</span> | 陰囊、面部、腋下、头皮渗透性最高；前臂最低 |
| <span style="color:#60a5fa">**濃度梯度**</span> | 濃度越高，單位時間穿透量越大 |
| <span name="color:#60a5fa">**給藥頻次**</span> | 皮膚作為儲庫；很多藥物可每日一次 |
| <span style="color:#60a5fa">**Vehicles**</span> | 不同載體影響蒸發速率及藥物釋放 |
| <span style="color:#60a5fa">**皮膚完整性**</span> | 受损皮膚吸收顯著增加 |

### Vehicles（載體）選擇原則

| 急性炎症（有滲出）| 慢性炎症（乾燥、鱗屑）|
|----------------|-----------------|
| 酊劑、濕敷、懸浮劑 | 乳霜、軟膏 |

| 載體類型 | 特性 |
|---------|------|
| 軟膏（Ointment） | 最保濕；油脂性；適於乾燥、鱗屑病變 |
| 乳霜（Cream） | 保濕但較不油膩；適於一般用途 |
| 懸浮劑（Lotion） | 蒸發後留薄層藥物；適於毛髮區域 |
| 凝胶（Gel） | 水性基底；較不油膩 |
| 泡沫（Foam） | 毛髮區域方便使用 |

## 局部抗菌藥物

### Bacitracin與Gramicidin

| 特性 | 說明 |
|------|------|
| <span style="color:#60a5fa">**抗菌譜**</span> | 格蘭氏陽性菌（葡萄球菌、鏈球菌、肺炎球菌）|
| <span style="color:#60a5fa">**常用製劑**</span> | 與neomycin、polymyxin B合併（三抗菌軟膏）|
| <span style="color:#60a5fa">**不良反應**</span> | 過敏性接觸性皮膚炎；系統吸收極微 |

---

### Mupirocin（莫匹羅星）

<span style="color:#60a5fa">**作用機轉**：結構獨特的抗生素，抑制細菌蛋白質合成。</span>

| 特性 | 說明 |
|------|------|
| <span style="color:#60a5fa">**抗菌譜**</span> | 格蘭氏陽性菌，包括<span style="color:#c084fc">*MSSA、MRSA*</span>、A群β溶血性鏈球菌 |
| <span style="color:#60a5fa">**適應症**</span> | 膿痂疹（<span style="color:#c084fc">*S. aureus*</span>、A群鏈球菌）；微創傷繼發感染 |
| <span style="color:#60a5fa">**給藥**</span> | 局部軟膏；每日2-3次 |

---

### Retapamulin

<span style="color:#60a5fa">**作用機轉**：Pleromutilin衍生物，抑制細菌蛋白質合成。</span>

| 特性 | 說明 |
|------|------|
| <span name="color:#60a5fa">**抗菌譜**</span> | A群β溶血性鏈球菌、<span style="color:#c084fc">*S. aureus*</span>（不含MRSA）|
| <span style="color:#60a5fa">**適應症**</span> | 非複雜性膿痂疹；9個月以上兒童及成人 |
| <span style="color:#60a5fa">**療程**</span> | 每日2次×5天 |

---

### Polymyxin B

<span style="color:#60a5fa">**抗菌譜**：格蘭氏陰性菌（<span style="color:#c084fc">*Pseudomonas aeruginosa*</span>、<span style="color:#c084fc">*E. coli*</span>、<span style="color:#c084fc">*Klebsiella*</span>）</span>

<span style="color:#f87171">**注意**：總劑量不超過200 mg/日（開放性傷口或燒傷面積大時系統吸收增加）</span>

---

### Neomycin與Gentamicin

| 藥物 | 抗菌譜 |
|------|--------|
| <span style="color:#fb923c">Neomycin</span> | 格蘭氏陰性菌（<span style="color:#c084fc">*E. coli*</span>、<span style="color:#c084fc">*Proteus*</span>、<span style="color:#c084fc">*Klebsiella*</span>）；對<span style="color:#c084fc">*Pseudomonas*</span>效果差 |
| <span style="color:#fb923c">Gentamicin</span> | 對<span style="color:#c084fc">*Pseudomonas*</span>效果較neomycin佳；對格蘭氏陽性菌也有活性 |

<span style="color:#f87171">**不良反應**：過敏性接觸性皮膚炎常見；大面積使用可能導致腎毒性/耳毒性</span>

---

## 青春痘（Acne）的局部抗生素治療

### Clindamycin

<span style="color:#60a5fa">**作用機轉**：抑制<span style="color:#c084fc">*Propionibacterium acnes*</span>；體外抗菌活性</span>

| 製劑 | 說明 |
|------|------|
| 1%凝膠、乳液、溶液 | 每日1-2次 |
| 固定複方製劑 | clindamycin + benzoyl peroxide（Acanya, Duac）|

### Erythromycin

<span style="color:#60a5fa">**特點**：游離鹼基而非鹽類製劑；渗透性較佳</span>

<span style="color:#f87171">**不良反應**：用於治療青春痘時可能出現刺激性；過敏性接觸性皮膚炎少見</span>

---

### 其他青春痘局部用藥

| 藥物 | 作用/適應症 | 不良反應 |
|------|-----------|---------|
| <span style="color:#fb923c">Azelaic acid</span> | 抗菌、抗發炎；輕-中度青春痘 | 輕微刺激 |
| <span style="color:#fb923c">Dapsone 5% gel</span> | 抗發炎；青春痘 | 輕微乾燥、紅斑 |
| <span style="color:#fb923c">Benzoyl peroxide</span> | 抗菌；與clindamycin合用效果佳 | 乾燥、脫皮 |

## 局部抗黴菌藥物

### 黴菌感染分類

| 病原 | 感染的皮膚病變 |
|------|-------------|
| <span style="color:#c084fc">*Epidermophyton*</span>、<span style="color:#c084fc">*Microsporum*</span>、<span style="color:#c084fc">*Trichophyton*</span> | 皮癬菌感染（足癬、股癬、體癬）|
| <span style="color:#c084fc">*Candida albicans*</span> | 念珠菌感染（間擦疹、口腔鵝口瘡）|
| <span style="color:#c084fc">*Malassezia furfur*</span> | 花斑癬（tinea versicolor）|

---

### Imidazoles類（局部抗黴菌）

| 藥物 | 適應症 |
|------|--------|
| <span style="color:#fb923c">Clotrimazole</span> | 皮癬菌、念珠菌； OTC |
| <span style="color:#fb923c">Miconazole</span> | 皮癬菌、念珠菌；也有靜脈製劑用於全身黴菌病 |
| <span style="color:#fb923c">Ketoconazole</span> | 皮癬菌、念珠菌；也有口服製劑 |
| <span name="color:#fb923c">Econazole、Sulconazole</span> | 皮癬菌、念珠菌 |

<span style="color:#60a5fa">**作用機轉**：抑制黴菌細胞膜的ergosterol合成（阻斷lanosterol 14α-demethylase）</span>

---

### Allylamines類

| 藥物 | 特點 |
|------|------|
| <span style="color:#fb923c">Terbinafine</span> | 對皮癬菌高效；也有口服製劑（用於甲癬）|
| <span style="color:#fb923c">Naftifine</span> | 局部高效抗黴菌 |

<span style="color:#60a5fa">**作用機轉**：抑制squalene epoxidase → 黴菌細胞膜ergosterol耗竭</span>

<span style="color:#34d399">**劑量**：2%乳膏；每日2次</span>

## 口服抗黴菌藥物

### Terbinafine（口服）

| 適應症 | 劑量 |
|--------|------|
| 甲癬（onychomycosis）| 250 mg/d×6週（指甲）；12週（腳趾甲）|

### Ketoconazole（口服）

<span style="color:#f87171">**⚠️ 肝毒性顯著**：需監測肝功能；建議用於嚴重黴菌感染</span>

| 適應症 | 說明 |
|--------|------|
| 慢性黏膜皮膚念珠菌病 | 200 mg/d；可能需長期維持 |
| 花斑癬 | 200 mg/d×5天 |

### Griseofulvin（口服）

<span style="color:#60a5fa">**作用機轉**：干擾黴菌細胞骨架形成；抑制有絲分裂</span>

| 適應症 | 說明 |
|--------|------|
| 皮癬菌感染 | 對头皮癬、股癬效果好；指甲/腳趾甲需長期治療（6-18個月）|

<span style="color:#f87171">**不良反應**：頭痛、噁心、光敏感；可能引起血紅素下降；禁用於porphyria患者</span>

## 皮質類固醇（局部）

### 效能分級

| 等級 | 藥物 | 說明 |
|------|------|------|
| <span style="color:#f87171">**最強（Class I）**</span> | Clobetasol propionate、Betamethasone dipropionate | 極強效；只用於嚴重、頑固性病變；<span style="color:#f87171">**禁長期大面積使用**</span> |
| <span style="color:#fb923c">**強效（Class II-III）**</span> | Fluocinonide、Mometasone furoate | 中-強效；通常不超過2週 |
| <span style="color:#34d399">**弱效（Class IV-V）**</span> | Hydrocortisone、Desonide | 輕-中效；兒童及臉部首選 |

### 常見不良反應（長期使用）

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**皮膚萎縮**</span> | 皮膚變薄、皮紋、脆弱 |
| <span style="color:#f87171">**紫斑**</span> | 血管脆弱 |
| <span name="color:#f87171">**類固醇痤瘡**</span> | 毛囊炎 |
| <span style="color:#f87171">**毛細血管擴張**</span> | 泛血絲 |
| <span style="color:#f87171">**接觸過敏**</span> | 對製劑中其他成分過敏 |

## Retinoids（維生素A衍生物）

### 局部Tretinoin（維A酸）

<span style="color:#60a5fa">**作用機轉**：穩定溶酶體；增加RNA polymerase活性；促進表皮細胞更新；減少毛孔阻塞</span>

| 適應症 | 說明 |
|--------|------|
| 青春痘 | 輕-中度；首選之一 |
| 光老化 | 長期使用促進膠原蛋白新生；減少皺紋 |

### 口服Isotretinoin

<span style="color:#f87171">**⚠️ 嚴重青春痘（囊腫型）的首選治療**</span>

| 特性 | 說明 |
|------|------|
| <span style="color:#60a5fa">**作用機轉**</span> | 抑制皮脂分泌；減少<span style="color:#c084fc">*P. acnes*</span>；抗發炎 |
| <span style="color:#60a5fa">**療程**</span> | 0.5-1 mg/kg/d×4-6個月；通常總劑量120-150 mg/kg |
| <span style="color:#fb923c">**不良反應**</span> | 口唇乾燥脫皮；血脂肪升高；肝功能異常；<span style="color:#f87171">**致畸性**</span> |

<span style="color:#f87171">**⚠️ 致畸性極強**：生育年齡女性必需使用兩種避孕方法；iPLEDGE計畫强制登記</span>

## 驅蟲藥物（局部用於疥瘡）

### Permethrin（氯菊酯）

| 特性 | 說明 |
|------|------|
| <span style="color:#60a5fa">**適應症**</span> | 疥瘡；頭蝨 |
| <span style="color:#60a5fa">**5%乳膏**</span> | 頭蝨：塗抹全頭並保留10分鐘後沖洗；疥瘡：頸部以下塗抹，保留8-14小時 |
| <span style="color:#60a5fa">**不良反應**</span> | 短暫燒灼感、刺痛 |

### Lindane（林丹）

<span style="color:#f87171">**⚠️ 神經毒性風險**：可能抑制中樞神經系統；早產兒、癲癇患者禁用；加州禁用</span>

## 皮膚美白劑

### Hydroquinone（氫醌）

<span style="color:#60a5fa">**作用機轉**：抑制tyrosinase → 減少黑色素合成</span>

| 特性 | 說明 |
|------|------|
| 濃度 | 2-4%乳膏 |
| 適應症 | 黑斑、雀斑 |
| 不良反應 | 刺激；過敏性接觸性皮膚炎；外源性褐黃病（過度使用時）|

## 防曬劑（Sunscreens）

### 防曬係數（SPF）

<span style="color:#60a5fa">**SPF** = 有防曬劑時的最小紅斑劑量 / 無防曬劑時的最小紅斑劑量</span>

| SPF值 | 防護效果 |
|------|---------|
| SPF 15 | 阻擋約93% UVB |
| SPF 30 | 阻擋約97% UVB |
| SPF 50+ | 阻擋約98% UVB |

<span style="color:#60a5fa">**寬頻防護（Broad Spectrum）**：同時防護UVA與UVB</span>

### 常用防曬成分

| 類別 | 代表藥物 | 防護範圍 |
|------|---------|---------|
| PABA酯 | Padimate O | UVB |
| 苯甲酮 | Oxybenzone | UVB/部分UVA |
| 二苯甲酮 | Avobenzone (Parsol 1789) | UVA |
| 二氧化鈦 | Titanium dioxide | 物理性遮蔽；广譜 |
