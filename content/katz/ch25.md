## 章節導讀

骨骼肌鬆弛劑為麻醉實踐中不可或缺的輔助用藥，透過作用於神經肌肉接合處（NMJ）而產生肌肉麻痺效果，使外科醫師能在手術中獲得理想的肌肉鬆弛條件。本章節系統探討末梢性（神經肌肉阻斷劑）與中樞性骨骼肌鬆弛劑的藥理學，包括其作用機轉、藥物動力學特性、臨床應用與不良反應的逆轉策略。

## <span style="color:#60a5fa">Skeletal Muscle Relaxants</span>

Skeletal muscle relaxants are indispensable adjuncts in anesthetic practice, producing muscle paralysis by acting at the neuromuscular junction (NMJ), allowing surgeons to achieve optimal conditions during procedures. This chapter systematically explores the pharmacology of peripheral (neuromuscular blocking agents) and central skeletal muscle relaxants, including their mechanisms of action, pharmacokinetic properties, clinical applications, and reversal strategies.

## 第一節　神經肌肉阻斷藥物

### 基本結構

所有可用之神經肌肉阻斷藥物在結構上與神經傳導物質<span style="color:#e2e8f0">**乙醯膽鹼（Acetylcholine, ACh）**</span>有高度結構相似性。

- <span style="color:#fb923c">Succinylcholine（琥珀膽鹼）</span>為兩個ACh分子頭尾相連的結構
- 非去極化型藥物（如<span style="color:#fb923c">Pancuronium</span>）為具有一個或兩個四級氮的剛性環狀結構

<span style="color:#22d3ee">**神經肌肉接合處（NMJ）的解剖**</span>：運動神經末梢釋放ACh，結合後使肌肉纖維去極化引發收縮。神經肌肉阻斷藥競爭性或非競爭性阻斷此過程。

### 分類

#### A. 非去極化型（Nondepolarizing Agents）

競爭性阻斷<span style="color:#60a5fa">**菸鹼型乙醯膽鹼受體（nAChR）**</span>，可被<span style="color:#fb923c">**Acetylcholinesterase抑制劑（如Neostigmine、Edrophonium）**</span>逆轉。

| 藥物 | 作用時間 | 代謝途徑 | 臨床特點 |
|------|---------|---------|---------|
| <span style="color:#fb923c">Pancuronium</span> | 長效（>60分） | 腎臟排泄；肝臟代謝（部分） | 心率↑；血壓↑；迷走神經阻斷 |
| <span style="color:#fb923c">Vecuronium</span> | 中效（30–60分） | 肝臟代謝；膽汁排泄 | 血流動力學穩定；輕度維庫溴胺活性代謝物累積（腎衰竭） |
| <span style="color:#fb923c">Rocuronium</span> | 中效（30–60分） | 肝膽排泄 | 起效快（可用於快速誘導）；中等程度維庫溴胺樣作用 |
| <span style="color:#fb923c">Atracurium</span> | 中效（30–60分） | Hofmann消除（非酶性）；血漿酯酶水解 | 代謝產物Laudanosine（可能促癲癇）；血流動力學最穩定 |
| <span style="color:#fb923c">Cisatracurium</span> | 中效 | Hofmann消除（優於Atracurium） | Laudanosine產生更少；臨床上首選 |
| <span style="color:#fb923c">Mivacurium</span> | 短效（15–30分） | 血漿膽鹼酯酶水解 | 恢復快速；但起效較慢；可用於腎衰竭患者 |
| <span style="color:#fb923c">Tubocurarine</span> | 長效 | 腎臟排泄 | 組胺釋放（低血壓）；已少用 |

#### B. 去極化型（Depolarizing Agents）

<span style="color:#fb923c">**Succinylcholine（琥珀膽鹼）**</span>為目前唯一臨床使用的去極化型神經肌肉阻斷藥。

**作用機轉**：Succinylcholine結合nAChR，使終板持續去極化，產生初始肌肉收縮（肌纖維成束收縮）後，因受體去敏感化而使肌肉麻痺。

| 特點 | 說明 |
|------|------|
| 起效 | 極快（60–90秒） |
| 作用持續 | 短（5–10分鐘，因血漿膽鹼酯酶快速水解） |
| 代謝 | 血漿膽鹼酯酶水解 → Succinylmonocholine → 琥珀酸 + 膽鹼 |
| 逆轉 | **無法被Acetylcholinesterase抑制劑逆轉**；反而會加重 |

<span style="color:#f87171">**Succinylcholine使用禁忌**：

- 惡性高熱病史
- <span style="color:#f87171">**家族性或特發性高血鉀症**</span>（燒傷、創傷、嚴重感染後2天至6個月、SCI、腦中風後）
- 活動性肌肉病變（如肌營養不良）
- 琥珀膽鹼過敏

<span style="color:#f87171">**琥珀膽鹼引起高血鉀**：正常情況下血鉀升高輕微（約0.5 mEq/L），但上述高風險族群可能發生危及生命的高血鉀（可達8–10 mEq/L）。</span>

## 第二節　藥物動力學

### 非去極化型藥物的動力學

| 特點 | 說明 |
|------|------|
| 高度離子化 | 不易進入CNS；分佈體積約80–140 mL/kg（略大於血容量） |
| 蛋白結合 | 結合程度各異（Pancuronium約80%） |
| 半衰期與持續時間 | 與消除半衰期高度相關 |
| 肝腎功能影響 | 腎衰竭：Pancuronium（長效）、Tubocurarine累積；肝功能異常：Rocuronium清除下降 |

### 影響個體間差異的因素

| 因素 | 影響 |
|------|------|
| **年齡** | 新生兒對非去極化藥物敏感性↓（需要較高劑量）；老年人敏感性↑ |
| **腎功能** | 腎衰竭延長多數藥物作用（除Atracurium、Cisatracurium外） |
| **肝功能** | 肝硬化減少白蛋白 → 游離藥物↑；肝衰竭影響Rocuronium/Vecuronium清除 |
| **電解質/酸鹼** | 低血鉀/低血鎂：增強阻斷效果；呼吸性酸中毒延緩恢復 |
| **體溫** | 體溫過低延長作用時間 |
| **吸入性麻醉劑** | 增強非去極化阻斷（Isoflurane > Sevoflurane > Desflurane） |
| **抗生素** | Aminoglycosides、Polymyxin、Clindamycin、Lincosamides：加強神經肌肉阻斷 |
| **神經肌肉疾病** | 重症肌無力：對非去極化藥物極度敏感；肌營養不良/脊髓側索硬化：對Succinylcholine敏感 |

## 第三節　逆轉策略

### Acetylcholinesterase抑制劑

<span style="color:#fb923c">**Neostigmine（溴化新斯的明）**</span>與<span style="color:#fb923c">**Edrophonium（依酚氯銨）**</span>是最常用的逆轉劑。

**作用機轉**：抑制Acetylcholinesterase，使神經末梢ACh累積，競爭性置換非去極化阻斷藥。

| 藥物 | 劑量 | 起效 | 持續 |
|------|------|------|------|
| <span style="color:#fb923c">Neostigmine</span> | 0.04–0.07 mg/kg IV | 3–5分鐘 | 60–90分鐘 |
| <span style="color:#fb923c">Edrophonium</span> | 0.5–1 mg/kg IV | 1–2分鐘 | 30–60分鐘 |

<span style="color:#f87171">**注意**：逆轉Succinylcholine引起的阻斷**無效甚至有害**，因其延長去極化狀態。</span>

**抗膽鹼副作用**：心搏過緩、唾液分泌增加、支氣管痙攣 → 常與<span style="color:#fb923c">**Glycopyrrolate（胃長寧）**</span>或<span style="color:#fb923c">**Atropine（阿托品）**</span>合用。

### Sugammadex（舒更葡萄糖）

<span style="color:#60a5fa">**Sugammadex（舒更葡萄糖）**</span>為新型逆轉劑，專門用於逆轉<span style="color:#fb923c">**Rocuronium**</span>與<span style="color:#fb923c">**Vecuronium**</span>引起的深度神經肌肉阻斷。

| 特點 | 說明 |
|------|------|
| 機轉 | 形成Encapsulation複合物（cyclodextrin）；直接結合Rocuronium/Vecuronium，將其隔離在血漿中 |
| 逆轉深度 | 可逆轉深度阻斷（PTC < 5）；也可快速逆轉（Ro現用Ro 1.2 mg/kg 3分鐘內逆轉） |
| 副作用 | 罕見；可能味覺障礙；對其他藥物可能有藥物交互作用 |

## 第四節　中樞性骨骼肌鬆弛劑

不同於作用於NMJ的末梢性藥物，中樞性骨骼肌鬆弛劑作用於<span style="color:#22d3ee">**脊髓與腦幹**</span>，臨床上主要用於緩解肌肉痙攣與疼痛。

| 藥物 | 作用機轉 | 適應症 | 副作用 |
|------|---------|--------|--------|
| <span style="color:#fb923c">Cyclobenzaprine</span> | 抑制脊髓多突觸反射；類似TCA結構 | 急性肌肉痙攣（>72小時） | 嗜睡、口乾；避免與MAOIs合用 |
| <span style="color:#fb923c">Methocarbamol</span> | 中樞抑制 | 肌肉痙攣 | 嗜睡、眩暈；靜脈制劑可致低血壓 |
| <span style="color:#fb923c">Baclofen（巴氯芬）</span> | GABA<sub>B</sub>受體激動劑；抑制脊髓單/多突觸反射 | 嚴重慢性痙攣（SCI、MS、腦性麻痺） | 嗜睡、眩暈；突然停藥可致癲癇/精神病 |
| <span style="color:#fb923c">Tizanidine</span> | α<sub>2</sub>-腎上腺素受體激動劑；抑制脊髓中間神經元 | 痙攣（口乾明顯） | 口乾、嗜睡、低血壓；肝毒性（需監測） |
| <span style="color:#fb923c">Dantrolene（丹曲林）</span> | 直接抑制骨骼肌Ryanodine受體；減少肌質網鈣離子釋放 | 惡性高熱治療/預防；慢性嚴重痙攣 | 肌肉無力、眩暈、肝毒性；可能致肋膜積液 |

## 第五節　重點摘要

- 神經肌肉阻斷藥分為**非去極化型（競爭性nAChR拮抗）**與**去極化型（持續去極化）**兩大類
- <span style="color:#fb923c">Succinylcholine</span>為去極化型唯一臨床用藥，起效最快（60–90秒），但有高血鉀、惡性高熱、組胺釋放等風險
- <span style="color:#fb923c">Cisatracurium</span>為目前最推薦的中效非去極化藥物，Hofmann消除使其不依賴肝腎功能
- <span style="color:#fb923c">Rocuronium</span>起效快，可替代Succinylcholine用於快速誘導
- 非去極化阻斷可用<span style="color:#fb923c">Neostigmine</span>或<span style="color:#fb923c">Edrophonium</span>（+抗膽鹼藥）逆轉；<span style="color:#fb923c">Sugammadex</span>可特異性逆轉Rocuronium/Vecuronium
- <span style="color:#f87171">Succinylcholine禁用於高血鉀風險族群（燒傷、創傷、SCI等）</span>
- 中樞性骨骼肌鬆弛劑（如Baclofen、Tizanidine）主要用於慢性痙攣的內科治療
- <span style="color:#fb923c">Dantrolene</span>為**惡性高熱**的治療首選
