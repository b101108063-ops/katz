## 章節導讀

止血是維持血液流動性、修補血管損傷並防止出血同時避免血栓形成之間的動態平衡過程。本章節系統探討抗血小板藥物、抗凝血藥物與血栓溶解藥物的藥理學，包括它們的作用機轉、臨床應用與不良反應的重點整理。

## <span style="color:#60a5fa">Drugs Affecting Hemostasis</span> & <span style="color:#60a5fa">Thrombosis</span>

Hemostasis is a dynamic balancing process of maintaining blood fluidity, repairing vessel damage, and preventing bleeding while avoiding thrombosis. This chapter systematically explores the pharmacology of antiplatelet agents, anticoagulants, and thrombolytic drugs, including their mechanisms of action, clinical applications, and adverse effects.

## 第一節　止血與凝血機轉

### 血小板與原發性止血

<span style="color:#22d3ee">**血小板（Platelets）**</span>在止血中扮演核心角色：

| 階段 | 說明 |
|------|------|
| **黏附** | 受損血管內皮暴露膠原蛋白；von Willebrand因子（vWF）結合血小板GPIb受體 |
| **活化** | 血小板內部信號級聯；GPIb/IIIa受體活化；TXA<sub>2</sub>、ADP、Serotonin釋放 |
| **聚集** | 活化GPIb/IIIa結合纖維蛋白原；血小板聚集形成血小板栓 |

### 凝血級聯

<span style="color:#22d3ee">**凝血級聯（Cascade）**</span>分為內因性與外因性路徑：

| 路徑 | 啟動因子 | 共同路徑 |
|------|---------|---------|
| **外因性路徑** | 組織因子（TF）+ Factor VIIa | **Factor X → Thrombin（Factor IIa）→ Fibrin** |
| **內因性路徑** | 膠原蛋白/內皮受損 |  |

<span style="color:#e2e8f0">**天然抗凝血系統**</span>：
- **Antithrombin III（AT-III）**：抑制Thrombin（IIa）、IXa、Xa、XIa、XIIa
- **Protein C/Protein S**：抑制Factor Va、VIIIa
- **TFPI（Tissue Factor Pathway Inhibitor）**：抑制TF-VIIa複合體

## 第二節　抗血小板藥物

### A. 阿斯匹靈（Aspirin）

<span style="color:#60a5fa">**Aspirin（阿斯匹靈）**</span>不可逆抑制<span style="color:#e2e8f0">**環氧酶-1（COX-1）**</span>，減少<span style="color:#e2e8f0">**血栓素A2（TXA<sub>2</sub>）**</span>生成。

| 特點 | 說明 |
|------|------|
| 作用 | 抑制血小板COX-1→TXA<sub>2</sub>↓；抗血小板聚集 |
| 劑量 | 心血管二級預防：75–100 mg/d；齒科單次：300–600 mg |
| 作用持續 | 血小板生命週期（約7–10天）；需停藥7–10天才能恢復 |
| 說明 | <span style="color:#34d399">**最廣泛使用的抗血小板藥物**</span> |

### B. P2Y<sub>12</sub>受體抑制劑

| 藥物 | 機轉 | 臨床應用 |
|------|------|---------|
| <span style="color:#fb923c">Clopidogrel（氯吡格雷）</span> | **前驅藥**；經CYP450（尤其是CYP2C19）代謝活化；抑制P2Y<sub>12</sub> ADP受體 | 冠心病、支架術後（PCI）、缺血性中風 |
| <span style="color:#fb923c">Prasugrel</span> | 前驅藥；經CYP代謝；**更快、更強、更一致** | 糖尿病PCI患者；出血風險較高 |
| <span style="color:#fb923c">Ticagrelor</span> | **直接作用**；不需要代謝；可逆性P2Y<sub>12</sub>抑制 | 急性冠心症（ACS）；與Aspirin合用（雙重抗血小板治療，DAPT） |

<span style="color:#34d399">**DAPT（雙重抗血小板治療）療程**：藥物支架術後通常12個月。</span>

### C. GP IIb/IIIa抑制劑

| 藥物 | 特性 |
|------|------|
| <span style="color:#fb923c">Abciximab</span> | 單株抗體；不可逆；術中使用 |
| <span style="color:#fb923c">Eptifibatide</span> | 胜肽；可逆；急性冠心症 |
| <span style="color:#fb923c">Tirofiban</span> | 非胜肽；可逆 |

## 第三節　抗凝血藥物

### A. Heparin（肝素）

<span style="color:#60a5fa">**Heparin**</span>結合並增強<span style="color:#e2e8f0">**Antithrombin III（AT-III）**</span>活性。

| 類別 | 說明 |
|------|------|
| **普通肝素（UFH）** | 分子量約15000 Da；同時抑制IIa（Thrombin）與Xa；需監測aPTT |
| **低分子量肝素（LMWH）** | Enoxaparin、Dalteparin；主要抑制Xa（抗Xa:抗IIa比約3:1）；通常不需監測 |

<span style="color:#34d399">**劑量參考（Enoxaparin）**：DVT預防：40 mg SC qd；DVT治療：1 mg/kg SC q12h。</span>

| 不良反應 | 說明 |
|---------|------|
| **出血** | 最主要 |
| **Heparin誘發血小板減少症（HIT）** | **II型HIT（免疫介導）**：抗PF4-肝素抗體形成→血小板減少→血栓形成（White clot syndrome）<br>4T評分診斷；立即停用所有肝素 |
| 骨質疏鬆 | 長期使用（>1個月） |

<span style="color:#f87171">**HIT治療**：立即停用肝素；改用直接凝血酶抑制劑（Argatroban）或Fondaparinux；不使用Warfarin（初期可能加劇皮膚壞死/血栓）。</span>

### B. Warfarin（ warfarin）

<span style="color:#60a5fa">**Warfarin（ warfarin）**</span>抑制<span style="color:#e2e8f0">**維生素K環氧化物還原酶（VKOR）**</span>，減少凝血因子II、VII、IX、X與Protein C/S的γ-羧化。

| 特點 | 說明 |
|------|------|
| 起效 | 延遲（需現有凝血因子消耗）；通常需2–3天達到療效 |
| 監測 | **PT/INR**；目標INR：AF：2.0–3.0；機械瓣膜：2.5–3.5 |
| 逆轉 | **維生素K**（需數小時）；新鮮冰凍血漿（FFP）或凝血酶原複合濃縮物（PCC）用於急性逆轉 |

<span style="color:#f87171">**Warfarin壞死（Warfarin-induced Skin Necrosis）**：常見於Protein C缺乏患者；維生素K輔因子耗竭→皮膚微血栓→壞死。常在治療前5天出現。</span>

### C. 直接凝血酶抑制劑（Direct Thrombin Inhibitors）

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Dabigatran（達比加群）</span> | **直接抑制游離與結合型Thrombin**；口服；腎臟排泄；**不需要監測INR**；用於NVAF中風預防 |
| <span style="color:#fb923c">Argatroban</span> | 靜脈；肝臟代謝；用於HIT或肾功能不全患者 |

### D. 直接Xa因子抑制劑（Direct Factor Xa Inhibitors）

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Rivaroxaban（利伐沙班）</span> | 口服；單一靶點抑制Xa；不需要監測 |
| <span style="color:#fb923c">Apixaban（阿哌沙班）</span> | 口服；生物利用率高；NVAF中風預防；DVT/PE治療 |
| <span style="color:#fb923c">Edoxaban</span> | 口服；NVAF；DVT/PE治療 |
| <span style="color:#fb923c">Fondaparinux</span> | **選擇性Xa抑制**（pentasaccharide序列）；皮下；预防血栓 |

### DOACs比較

| 特點 | Dabigatran | Rivaroxaban | Apixaban | Edoxaban |
|------|-----------|------------|---------|---------|
| 靶點 | Thrombin (IIa) | Xa | Xa | Xa |
| 給藥 | 口服 bid | 口服 qd | 口服 bid | 口服 qd |
| 腎排泄 | 80% | 33% | 27% | 50% |
| 逆轉劑 | **Idarucizumab** | **Andexanet alfa** | Andexanet alfa | Andexanet alfa |

## 第四節　血栓溶解藥物（Thrombolytics）

<span style="color:#60a5fa">**血栓溶解藥物**</span>激活<span style="color:#e2e8f0">**纖溶酶原（Plasminogen）**</span>轉化為<span style="color:#e2e8f0">**纖溶酶（Plasmin）**</span>，分解纖維蛋白。

| 藥物 | 機轉 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Alteplase（tPA）</span> | 組織型纖溶酶原活化劑；重組 | **急性心肌梗塞（AMI）；缺血性中風；肺栓塞** |
| <span style="color:#fb923c">Tenecteplase（TNK-tPA）</span> | 長效tPA突變體 | **單次靜脈推注**；AMI；較少過敏反應 |
| <span style="color:#fb923c">Reteplase</span> | 重組tPA | AMI；雙次靜脈推注 |
| <span style="color:#fb923c">Streptokinase</span> | 與Plasminogen形成複合體激活Plasminogen | AMI；DVT/PE；**過敏反應**；低血壓 |
| <span style="color:#fb923c">Urokinase</span> | 直接激活Plasminogen | PE；DVT；急性外週血栓 |

<span style="color:#f87171">**禁忌**：活動性出血、近期（<2–3月）顱內出血、已知顱內腫瘤/血管畸形、已知出血體質。</span>

## 第五節　抗纖維蛋白溶解藥物

| 藥物 | 機轉 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Aminocaproic Acid（氨甲環酸）</span> | 抑制Plasmin | 預防大手術出血；口腔出血 |
| <span style="color:#fb923c">Tranexamic Acid（氨甲環酸TXA）</span> | 抑制Plasmin（比Aminocaproic更強） | **外傷出血**；經血過多；心臟手術；CRASH-2試驗證實降低創傷出血死亡 |

## 第六節　抗凝血藥物逆轉

| 藥物 | 逆轉策略 |
|------|---------|
| **Heparin（UFH）** | <span style="color:#fb923c">**Protamine Sulfate**</span>（1 mg中和100 IU UFH）；LMWH：0.6–1 mg/100 anti-Xa IU |
| **Warfarin** | 維生素K（急性逆轉：10 mg IV）；PCC（急性大出血）；FFP（次選） |
| **Dabigatran** | <span style="color:#fb923c">**Idarucizumab（Praxbind）**</span>（5 g IV）；血液透析（可移除部分） |
| **Rivaroxaban/Apixaban/Edoxaban** | <span style="color:#fb923c">**Andexanet Alfa（Ondexxya）**</span>（逆轉Xa抑制劑） |
| **HIT** | Argatroban（靜脈直接Thrombin抑制）；Fondaparinux |

## 第七節　重點摘要

- <span style="color:#fb923c">Aspirin</span>不可逆抑制COX-1，是最基本的抗血小板藥物
- <span style="color:#fb923c">Clopidogrel</span>為前驅藥，需CYP2C19代謝活化；攜帶者可考慮Prasugrel或Ticagrelor
- <span style="color:#fb923c">Heparin</span>增強AT-III抑制Thrombin與Xa；UFH需監測aPTT；LMWH通常不需監測
- <span style="color:#f87171">**Heparin誘發血小板減少症（HIT）**</span>為免疫介導的嚴重併發症，需立即停用肝素
- <span style="color:#fb923c">Warfarin</span>抑制VKOR，起效慢需數天，INR監測，藥物/食物交互作用多
- <span style="color:#fb923c">DOACs</span>（Dabigatran、Rivaroxaban、Apixaban）口服直接抑制Thrombin或Xa，不需要例行監測
- DOACs各有專屬逆轉劑（Idarucizumab、Andexanet alfa）
- <span style="color:#fb923c">Alteplase/Tenecteplase</span>為急性心肌梗塞與缺血性中風的血栓溶解治療
- <span style="color:#fb923c">Tranexamic Acid</span>用於外傷出血，CRASH-2試驗顯示可降低創傷死亡
