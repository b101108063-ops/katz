# CH55 重金屬中毒與螯合劑

## 章節導讀

重金屬中毒是臨床上常見的環境與職業病。本章節系統介紹<span style="color:#c084fc">**鉛**</span>、<span style="color:#c084fc">**砷**</span>、<span style="color:#c084fc">**汞**</span>等重金屬的毒性機轉、臨床表現、診斷及治療。螯合劑（chelating agents）是重金屬中毒的特異性解毒劑，包括<span style="color:#fb923c">**Succimer (DMSA)**</span>、<span style="color:#fb923c">**EDTA**</span>、<span style="color:#fb923c">**Unithiol (DMPS)**</span>、<span style="color:#fb923c">**Dimercaprol (BAL)**</span>等。及時診斷與正確使用螯合劑是治療成敗的關鍵。

---

## 鉛中毒（Lead Intoxication）

### 鉛的體內分佈

| 部位 | 說明 |
|------|------|
| <span style="color:#22d3ee">**血液**</span> | 佔總體負荷5-10%；與紅血球結合 |
| <span style="color:#22d3ee">**軟組織**</span> | 肝、腎、腦（置換Ca²⁺）|
| <span style="color:#22d3ee">**骨骼**</span> | 佔總體負荷90%以上；慢性暴露主要儲存庫 |

<span style="color:#60a5fa">**血中鉛濃度參考值**</span>：
- 正常：< 10 mcg/dL
- 需進一步評估：10-45 mcg/dL
- 需螯合治療：> 45 mcg/dL（兒童）；> 30 mcg/dL（症狀患者）

---

### 鉛的毒性機轉

<span style="color:#60a5fa">**主要毒性作用**：</span>

1. 干擾δ-胺基左旋酸脫水酶（ALA dehydratase）→ 抑制血紅素合成
2. 抑制ferrochelatase → 減少亞鐵摻入原紫質 IX
3. 增加紅血球膜脆性 → 溶血
4. 置換中樞神經系統的Ca²⁺ → 神經毒性

---

### 臨床表現

#### 中樞神經系統

| 族群 | 表現 |
|------|------|
| <span style="color:#60a5fa">**兒童**</span> | 智商下降（血鉛1-10 mcg/dL即可造成6.2 IQ點下降）；發育遲緩；行為問題 |
| <span style="color:#60a5fa">**成人**</span> | 頭痛、記憶障礙、易怒、失眠；嚴重時：腦病變（> 100 mcg/dL）→ 共濟失調、昏迷、痙攣 |
| <span style="color:#60a5fa">**老年人**</span> | 可能加速年齡相關認知功能衰退 |

#### 血液系統

| 表現 | 說明 |
|------|------|
| <span style="color:#60a5fa">**貧血**</span> | 正常血球性或小球性、低色素性 |
| <span style="color:#60a5fa">**嗜鹼性點彩**</span> | 紅血球中可見（非特異性）|
| <span style="color:#60a5fa">**，游離紅血球原紫質↑**</span> | 暴露4-8週後出現 |

#### 腎臟

| 表現 | 說明 |
|------|------|
| <span style="color:#60a5fa">**腎間質纖維化**</span> | 慢性高劑量暴露 |
| <span style="color:#60a5fa">**腎病變**</span> | 腎絲球功能受損 |
| <span style="color:#60a5fa">**痛風（saturnine gout）**</span> | 尿酸排泄異常 |

#### 胃腸道

| 表現 | 說明 |
|------|------|
| <span style="color:#60a5fa">**腹痛（铅绞痛）**</span> | 嚴重絞痛；腸道平滑肌痙攣 |
| <span style="color:#60a5fa">**便祕**</span> | 常見 |

<span style="color:#f87171">**齒齦藍線（gingival lead lines）**：鉛與口腔微生物產生的硫離子結合形成硫化鉛沉積；現已少見</span>

---

### 診斷

| 檢驗 | 說明 |
|------|------|
| <span style="color:#60a5fa">**血中鉛濃度**</span> | 最可靠指標；反映近期暴露 |
| <span style="color:#60a5fa">**血中原紫質/鋅原紫質**</span> | 落後於血鉛變化；反映數週暴露 |
| <span style="color:#60a5fa">**尿中螯合挑戰試驗**</span> | 注射CaNa₂-EDTA後收集24小時尿液；反映總體負荷 |
| <span style="color:#60a5fa">**骨骼X光螢光檢測**</span> | K X-ray fluorescence；反映長期累積暴露 |

---

### 治療

#### 螯合治療

| 血鉛濃度 | 建議 |
|---------|------|
| <span style="color:#34d399">10-45 mcg/dL（兒童）</span> | 環境評估與源頭控制；營養介入（鈣、鐵補充）|
| <span style="color:#fb923c">> 45 mcg/dL（兒童）</span> | 需積極螯合治療 |
| <span style="color:#fb923c">> 30 mcg/dL（有症狀）</span> | 需積極螯合治療 |

| 藥物 | 適應症 | 說明 |
|------|--------|------|
| <span style="color:#fb923c">Succimer (DMSA)</span> | 輕-中度中毒，口服 | 口服首選；不良反應：胃腸道、皮疹 |
| <span style="color:#fb923c">CaNa₂-EDTA</span> | 中-重度中毒，注射 | 僅靜脈給藥；腎毒性 |
| <span style="color:#fb923c">Dimercaprol (BAL)</span> | 嚴重/急性，注射 | 與EDTA合用（腦病變時）|

---

## 砷中毒（Arsenic Intoxication）

### 砷的來源與暴露

| 來源 | 說明 |
|------|------|
| <span style="color:#c084fc">**地下水**</span> | 某些地區（印度、孟加拉Ganges三角洲）|
| <span style="color:#c084fc">**農業殺蟲劑**</span> | 含砷化合物 |
| <span style="color:#c084fc">**半導體產業**</span> | 砷化鎵製程 |
| <span style="color:#c084fc">**砷化氫（Arsine）**</span> | 強溶血性氣體 |

<span style="color:#e2e8f0">**歷史**：Fowler's solution（含1%亞砷酸鉀）曾广泛用作藥物；Salvarsan（arsphenamine）為第一個現代化學治療藥物</span>

---

### 毒性機轉

<span style="color:#60a5fa">**三價砷（As³⁺）**比五價砷（As⁵⁺）毒性強2-10倍。</span>

| 機轉 | 說明 |
|------|------|
| <span style="color:#60a5fa">**硫氫基團結合**</span> | 三價砷與蛋白質的-SH基團高親和力結合 → 抑制多種酶 |
| <span style="color:#60a5fa">**氧化壓力**</span> | 誘導自由基產生 |
| <span style="color:#60a5fa">**基因表現改變**</span> | 影響DNA甲基化 |

---

### 臨床表現

#### 急性無機砷中毒

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**胃腸道**</span> | 嘔吐、腹瀉（米湯樣便）、腹痛；數小時內出現 |
| <span style="color:#f87171">**心血管**</span> | 低血壓、休克、毛細血管滲漏 |
| <span style="color:#f87171">**血液**</span> | 全血球減少；溶血 |
| <span style="color:#f87171">**神經**</span> | 意識障礙、腦病變；周邊感覺運動神經病變（2-6週後出現）|
| <span style="color:#f87171">**指甲**</span> | Mees lines（白色橫紋）|

<span style="color:#f87171">**⚠️ 砷化氫（Arsine）中毒**：強效溶血毒素，暴露後2-24小時出現醬油色尿（血紅素尿）、黃疸、腎衰竭。</span>

#### 慢性無機砷中毒

| 系統 | 表現 |
|------|------|
| <span style="color:#22d3ee">**皮膚**</span> | 「雨滴狀」色素沉著；掌蹠角化過度 |
| <span style="color:#22d3ee">**周邊神經**</span> | 感覺運動神經病變（手套-襪子分布）|
| <span style="color:#22d3ee">**癌症風險**</span> | 肺癌、皮膚癌、膀胱癌 |

---

### 診斷

| 檢驗 | 說明 |
|------|------|
| <span style="color:#60a5fa">**尿中總砷**</span> | 急性：數千mcg/L；正常：< 20 mcg/L |
| <span style="color:#60a5fa">**頭髮/指甲砷含量**</span> | 反映過去暴露；正常 < 1 ppm |
| <span style="color:#60a5fa">**血砷**</span> | 急性後迅速自血液消失，不建議作為診斷用途 |

<span style="color:#60a5fa">**注意**：海鮮中含有大量無毒的有機砷（arsenobetaine）；採檢前需禁食海鮮3天。</span>

---

### 治療

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Unithiol (DMPS)</span> | 水溶性；IV 3-5 mg/kg q4-6h；首選急性中毒 |
| <span style="color:#fb923c">Dimercaprol (BAL)</span> | IM 3-5 mg/kg q4-6h；油性製劑 |
| <span style="color:#fb923c">Succimer (DMSA)</span> | 口服；慢性中毒或維持治療 |

<span style="color:#f87171">**⚠️ 砷化氫中毒**：目前可用螯合劑效果有限；支持性治療（輸液、輸血、必要時透析）是主要治療。</span>

---

## 汞中毒（Mercury Intoxication）

### 汞的形態與來源

| 形態 | 來源 | 主要毒性 |
|------|------|---------|
| <span style="color:#c084fc">**元素汞（液態）**</span> | 溫度計、牙科用銀粉 | 吸入蒸氣 → 神經/腎毒性 |
| <span style="color:#c084fc">**無機汞鹽**</span> | 防腐劑、某些傳統藥物 | 胃腸道腐蝕、腎毒性 |
| <span style="color:#c084fc">**烷基汞（methylmercury）**</span> | 工業廢水汙染魚類 | <span style="color:#f87171">**強神經毒性**</span>；胎兒特別敏感 |

---

### 毒性機轉

<span style="color:#60a5fa">**所有形態的汞都與硫氫基團（-SH）高度結合**，抑制多種酶的活性。</span>

| 形態 | 特殊機轉 |
|------|---------|
| <span style="color:#60a5fa">**元素汞蒸氣**</span> | 吸入後在紅血球中氧化為Hg²⁺；易通過血腦障壁 |
| <span style="color:#60a5fa">**甲基汞**</span> | 抑制丙酮酸脫氫酶；干擾粒線體功能 |

---

### 臨床表現

#### 急性元素汞蒸氣吸入

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**呼吸道**</span> | 化學性肺炎、非心因性肺水腫 |
| <span style="color:#f87171">**神經**</span> | 意識障礙、腦病變 |

#### 慢性元素汞蒸氣暴露（常見於牙醫）

<span style="color:#60a5fa">**經典型三聯徵**</span>：
1. <span style="color:#60a5fa">**顫抖**</span>（意向性顫抖）
2. <span style="color:#60a5fa">**精神神經障礙**</span>（憂鬱、焦慮、記憶減退）
3. <span style="color:#60a5fa">**齒齦口腔炎**</span>（齒齦炎、牙齒鬆動）

#### 甲基汞中毒

| 族群 | 表現 |
|------|------|
| <span style="color:#f87171">**成人**</span> | 感覺異常（共濟失調）；視野縮小；聽力障礙；語言障礙 |
| <span style="color:#f87171">**胎兒/新生兒**</span> | <span style="color:#f87171">**腦性麻痺様症候群**</span>；心智遲緩；聽力/視力損失 |

<span style="color:#f87171">**歷史事件**：日本水俁病（Minamata disease）— 工廠廢水排放含汞化合物，魚類體內累積，居民食用後爆發大規模中毒。</span>

---

### 診斷

| 檢驗 | 說明 |
|------|------|
| <span style="color:#60a5fa">**尿汞**</span> | 正常：< 5 mcg/L；職業暴露：< 35 mcg/g creatinine |
| <span name="color:#60a5fa">**血汞**</span> | 正常：< 5 mcg/L；工作週結束：< 15 mcg/L |
| <span style="color:#60a5fa">**血全汞**</span> | 甲基汞暴露時較準確 |

---

### 治療

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Unithiol (DMPS)</span> | 首選；水溶性，可口服或IV |
| <span style="color:#fb923c">Dimercaprol (BAL)</span> | 急性無機汞鹽攝入時（胃腸道去污染後）|
| <span style="color:#fb923c">Succimer (DMSA)</span> | 口服；慢性暴露維持治療 |

---

## 螯合劑總整理

| 藥物 | 適應症 | 給藥途徑 | 主要不良反應 |
|------|--------|---------|------------|
| <span style="color:#fb923c">Succimer (DMSA)</span> | 鉛、砷、汞 | <span style="color:#34d399">**口服**</span> | 胃腸道不適、皮疹、肝功能異常 |
| <span style="color:#fb923c">CaNa₂-EDTA</span> | 鉛 | IV/IM | <span style="color:#f87171">**腎毒性**</span> |
| <span style="color:#fb923c">Unithiol (DMPS)</span> | 汞、砷、鉍 | 口服/IV | 過敏反應、胃腸道不適 |
| <span style="color:#fb923c">Dimercaprol (BAL)</span> | 砷、汞、鉛 | IM | 注射部位疼痛、高血壓 |
| <span style="color:#fb923c">Deferoxamine</span> | 鐵 | IV | 腎毒性、低血壓、過敏 |

---

## 重金屬中毒預防原則

1. <span style="color:#60a5fa">**源頭控制**</span>：確認並移除暴露源
2. <span style="color:#60a5fa">**環境評估**</span>：居住/工作環境檢測
3. <span style="color:#60a5fa">**營養介入**</span>：確保足夠鈣、鐵攝取（減少鉛吸收）
4. <span style="color:#60a5fa">**風險溝通**</span>：患者及家屬衛教
