# CH50 抗原蟲藥物

## 章節導讀

原蟲感染是全球重要的公共衛生問題，特別是在熱帶及開發中國家。本章介紹臨床上常用的抗原蟲藥物，包括對抗**阿米巴**、**瘧疾**、**錐蟲**、**利什曼原蟲**及**肺孢子蟲**等病原的藥物。这些药物的作用機轉各異，臨床應用時需根據病原種類、感染部位及患者族群選擇適當制劑。

---

##  nitroimidazoles（硝基咪唑類）

###  metronidazole（甲硝唑）

<span style="color:#60a5fa">**作用機轉**：穿透原蟲及厭氧菌細胞，通過鐵氧還原蛋白（flavodoxin）依賴途徑還原其硝基基團，產生細胞毒性自由基，導致DNA鍵斷裂及螺旋結構破壞。</span>

| 特性 | 說明 |
|------|------|
| 抗菌/抗蟲譜 | <span style="color:#c084fc">*Giardia lamblia*</span>、<span style="color:#c084fc">*Entamoeba histolytica*</span>、<span style="color:#c084fc">*Trichomonas vaginalis*</span>、厭氧菌 |
| 給藥途徑 | 口服、直腸（栓劑）、靜脈注射 |
| 半衰期 | 約8小時 |
| 代谢 | 肝臟代谢（氫氧化及側鏈氧化）|

### 臨床適應症

| 適應症 | 劑量 |
|--------|------|
| <span style="color:#c084fc">*Trichomonas vaginalis*</span> 陰道炎 | 口服2 g單次，或500 mg每日2次×7天 |
| 梨形蟲病（Giardiasis）| 250 mg每日3次×5–7天 |
| 阿米巴痢疾（Amebiasis）| 500–750 mg每日3次×5–10天 |
| <span style="color:#f87171">**厭氧菌感染**</span> | IV 500 mg q8h 或口服400–500 mg q8h |
| <span style="color:#c084fc">*C. difficile*</span> 結腸炎 | 口服125–500 mg q6h×10–14天 |

### 不良反應

- <span style="color:#fb923c">**胃腸道**</span>：金屬味、噁心、腹瀉
- <span style="color:#fb923c">**神經系統**</span>：周邊神經病變（劑量相關）、頭暈、共濟失調
- <span style="color:#f87171">**雙硫侖樣反應**：與酒精併用引起臉潮紅、心搏過速、嘔吐</span>
- <span style="color:#fb923c">**過敏**</span>：皮疹、蕁麻疹
- 靜脈注射可能引起血栓性靜脈炎

### 藥物交互作用

- <span style="color:#f87171">**酒精**：雙硫侖樣反應（應避免同時使用）</span>
- <span style="color:#60a5fa">**CYP450抑制**：增強 warfarin、phenytoin、carbamazepine、lithium之作用</span>

---

###  tinidazole（替硝唑）

<span style="color:#60a5fa">**特性**</span>：與metronidazole相似的硝基咪唑類，但半衰期更長（12–14小時），可每日一次給藥。

| 適應症 | 劑量 |
|--------|------|
| <span style="color:#c084fc">*T. vaginalis*</span> | 2 g單次口服 |
| <span style="color:#c084fc">*G. lamblia*</span> | 2 g單次口服 |
| 阿米巴痢疾 | 2 g口服×3–5天 |

<span style="color:#34d399">**優點**：療程短（可單次給藥）；耐受性通常較metronidazole佳</span>

---

##  benzimidazoles（苯並咪唑類）

###  albendazole（阿苯達唑）

<span style="color:#60a5fa">**作用機轉**：選擇性抑制蟲體腸細胞的β-微管蛋白聚合，阻斷葡萄糖攝取及胞器功能，導致蟲體能量耗竭死亡。</span>

| 適應症 | 劑量 | 備註 |
|--------|------|------|
| 鉤蟲、蟯蟲感染 | 400 mg單次 | 糞便檢查確診後給藥 |
| 蟯蟲病（Enterobiasis）| 400 mg單次，2週後再給一劑 | 家庭接觸者亦建議治療 |
| 圓蟲幼蟲移行症 | 400 mg每日2次×3天 | |
| <span style="color:#22d3ee">**包蟲囊病（Hydatid disease）**</span> | 400 mg每日2次×28天×3療程（療程間隔14天）| 手術前輔助治療 |
| 類圓蟲病（Strongyloidiasis）| 400 mg每日2次×7天 | |

###  mebendazole（甲苯達唑）

<span style="color:#60a5fa">**適應症**</span>：鞭蟲、鉤蟲、蟯蟲、圓蟲混合感染；劑量為100 mg每日2次×3天（或500 mg單次）。

###  不良反應（albendazole/mebendazole）

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 腹痛、腹瀉（蟲體死亡釋出抗原） |
| <span style="color:#f87171">**肝臟**</span> | 肝功能異常（膿胸囊病大劑量療程時）|
| <span style="color:#f87171">**血液**</span> | 骨髓抑制（長期大劑量時）|
| <span style="color:#fb923c">**致畸**</span> | <span style="color:#f87171">**孕婦禁用**</span> |

<span style="color:#34d399">**肝功能監測**：膿胸囊病治療期間應每週監測AST/ALT及白血球計數</span>

---

##  pentamidine（噴他咪）

<span style="color:#60a5fa">**作用機轉**：干擾原蟲DNA複製及RNA合成，亦可能抑制氧化磷酸化。</span>

### 適應症與用法

| 適應症 | 途徑 | 劑量 |
|--------|------|------|
| <span style="color:#c084fc">*Pneumocystis jiroveci*</span> 肺炎（PCP）| 靜脈注射 | 4 mg/kg/d×14–21天 |
| 非洲錐蟲病（早期）| 肌肉注射 | 4 mg/kg/d×7–10天 |
| 皮膚型利什曼原蟲症 | 病灶內注射 | 局部使用 |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**腎臟**</span> | 腎功能不全（常見，可能嚴重）|
| <span style="color:#f87171">**心臟**</span> | 心律不整（QT延長）、低血壓 |
| <span style="color:#fb923c">**代謝**</span> | 低血糖（胰島β細胞毒性）|
| <span style="color:#fb923c">**胃腸道**</span> | 噁心、嘔吐 |
| 注射局部 | 硬結、疼痛 |

<span style="color:#f87171">**警告**：靜脈注射可能引起致命性低血壓；應讓患者平躺並緩慢輸注</span>

---

##  suramin（蘇拉明）

<span style="color:#60a5fa">**作用機轉**：干擾錐蟲的糖酵解及氧化磷酸化；與宿主血漿蛋白高度結合。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | <span style="color:#c084fc">*Trypanosoma brucei*</span> 錐蟲病（早期）|
| 給藥 | 靜脈注射（稀釋後緩慢給予）|
| 半衰期 | 非常長（40–60天）|
| 毒性 | <span style="color:#f87171">**腎毒性**</span>、發燒、過敏反應 |

---

##  melarsoprol（美拉胂醇）

<span style="color:#60a5fa">**作用機轉**：含三價砷的有機胂製劑，透過抑制丙酮酸激酶及多種酶系統殺滅錐蟲。</span>

<span style="color:#f87171">**適應症**：晚期非洲錐蟲病（昏睡病，錐蟲已侵犯中樞神經系統）</span>

| 療程 | 劑量 |
|--------|------|
| 建議療程 | 2.2 mg/kg/day IV×10天（總劑量不超過18–25 mL）|

###  不良反應

<span style="color:#f87171">**⚠️ 嚴重不良反應**</span>

- <span style="color:#f87171">**砷中毒性腦病變**（最嚴重）：表現為意識障礙、昏迷，死亡率達10–50%
- 發燒反應（Herxheimer-like reaction）
- 腎功能衰竭
- 肝炎

<span style="color:#34d399">**注意**：需由有經驗的醫師在加護環境下給藥；建議在第一次注射前先用suramin清除血中錐蟲</span>

---

##  eflornithine（依氟鳥氨酸）

<span style="color:#60a5fa">**作用機轉**：不可逆抑制 ornithine decarboxylase（鳥氨酸脫羧酶），阻斷多胺合成，從而抑制錐蟲細胞分裂。</span>

| 特性 | 說明 |
|------|------|
| 適應症 | 晚期非洲錐蟲病（<span style="color:#c084fc">*T. brucei gambiense*</span>感染）|
| 給藥 | 靜脈注射 |
| 療程 | 400 mg/kg/day，分4次×14天 |

###  不良反應

- <span style="color:#fb923c">**血液**</span>：骨髓抑制（貧血、白血球減少、血小板減少）
- <span style="color:#fb923c">**胃腸道**</span>：腹瀉、腹痛
- <span style="color:#fb923c">**脫髮**</span>

---

##  抗瘧疾藥物

###  chloroquine（氯奎寧）

<span style="color:#60a5fa">**作用機轉**：在瘧原蟲的酸性食物泡（food vacuole）中聚集，與血紅素結合形成毒性複合物，抑制瘧原蟲的蛋白質合成。</span>

| 適應症 | 劑量 |
|--------|------|
| 間日瘧及卵形瘧（<span style="color:#22d3ee">**對chloroquine敏感**</span>）| 口服600 mg（鹽基），6小時後300 mg，之後每日300 mg×2天 |
| 預防（特定地區）| 300 mg（鹽基）/週 |

###  不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**胃腸道**</span> | 噁心、嘔吐（飯後服用可減輕）|
| <span style="color:#fb923c">**皮膚**</span> | 瘙癢（非洲人口常見）|
| <span style="color:#f87171">**眼睛**</span> | <span style="color:#f87171">**視網膜病變**（長期大劑量使用時，為劑量限制性毒性）</span> |
| <span style="color:#fb923c">**心臟**</span> | QT延長（過量時）|

---

###  mefloquine（美爾奎寧）

<span style="color:#60a5fa">**適應症**</span>：對chloroquine具抗藥性之<span style="color:#c084fc">*P. falciparum*</span>瘧疾的治療及預防。

| 用途 | 劑量 |
|--------|------|
| 預防 | 228 mg（鹽基250 mg）/週，出發前1–2週開始，返國後繼續4週 |
| 治療 | 1250 mg（25 mg/kg）分次口服 |

###  不良反應

- <span style="color:#fb923c">**神經精神**</span>：眩暈、焦慮、夢魘、精神病（<span style="color:#f87171">**有精神病史者禁用**</span>）
- <span style="color:#fb923c">**心臟**</span>：心律不整、QT延長
- <span style="color:#fb923c">**胃腸道**</span>：噁心、嘔吐

---

###  atovaquone-proguanil（阿托夸酮-氯胍）

<span style="color:#60a5fa">**作用機轉**：Atovaquone抑制瘧原蟲粒線體電子傳遞鏈；Proguanil（在體內轉化為cycloguanil）抑制二氫葉酸還原酶。兩者具協同作用。</span>

| 用途 | 劑量 |
|--------|------|
| 預防（高抗藥地區）| 每日1片（250/100 mg），出發前1–2天開始，返國後續服7天 |
| 治療（無併發症之<span style="color:#c084fc">*P. falciparum*</span>）| 每日4片×3天 |

<span style="color:#34d399">**優點**：對多種抗藥性<span style="color:#c084fc">*P. falciparum*</span>有效；耐受性佳</span>

---

###  artemisinin derivatives（青蒿素衍生物）

<span style="color:#60a5fa">**代表藥物**：Artemether、Dihydroartemisinin、Artesunate</span>

<span style="color:#60a5fa">**作用機轉**：含有過氧化物橋的倍半萜內酯，經鐵催化的裂解反應產生自由基，對瘧原蟲所有生命周期階段均有殺滅作用（尤其是早期血液型蟲體）。</span>

| 特點 | 說明 |
|------|------|
| 優勢 | 快速降低瘧原蟲血症（48小時內可达90%以上清除）|
| 療程 | 與長效藥物合併使用（ACT：Artemisinin-based Combination Therapy）|
| 半衰期 | 短（約1小時）|
| 適應症 | 所有類型瘧疾，特別是重症及腦瘧 |

<span style="color:#f87171">**⚠️ WHO建議**：不可作為單一藥物使用（易產生抗藥性）；需與其他長效抗瘧藥合併製成複方製劑（ACT）。</span>

##  抗原蟲藥物比較表

| 藥物 | 作用機轉 | 主要適應症 | 給藥途徑 | 重要不良反應 |
|------|----------|------------|----------|--------------|
| <span style="color:#fb923c">Metronidazole</span> | 硝基還原 | <span style="color:#c084fc">*T. vaginalis*</span>、<span style="color:#c084fc">*E. histolytica*</span>、<span style="color:#c084fc">*G. lamblia*</span>、厭氧菌 | 口服/IV/直腸 | 金屬味、神經病變、雙硫侖樣反應 |
| <span style="color:#fb923c">Tinidazole</span> | 同上 | 同上（單次給藥優勢）| 口服 | 類似metronidazole但耐受性較佳 |
| <span style="color:#fb923c">Albendazole</span> | β-微管蛋白抑制 | 線蟲感染、包蟲囊病 | 口服 | 肝毒性、骨髓抑制 |
| <span style="color:#fb923c">Pentamidine</span> | DNA/RNA抑制 | PCP、錐蟲病、利什曼症 | IV/IM | 腎毒性、低血糖、心律不整 |
| <span style="color:#fb923c">Suramin</span> | 干擾糖酵解 | 早期錐蟲病 | IV | 腎毒性、過敏反應 |
| <span style="color:#fb923c">Melarsoprol</span> | 砷毒性酶抑制 | 晚期錐蟲病（昏睡病）| IV | <span style="color:#f87171">**砷性腦病變**、發燒、腎衰竭 |
| <span style="color:#fb923c">Eflornithine</span> | ornithine decarboxylase抑制 | 晚期錐蟲病 | IV | 骨髓抑制、脫髮 |
| <span style="color:#fb923c">Chloroquine</span> | 血紅素聚集毒性 | 對氯奎寧敏感瘧疾 | 口服 | <span style="color:#f87171">**視網膜病變**</span>、心律不整 |
| <span style="color:#fb923c">Mefloquine</span> | 不明 | 抗藥性<span style="color:#c084fc">*P. falciparum*</span> | 口服 | <span style="color:#f87171">**神經精神症狀**</span>、心律不整 |
| <span style="color:#fb923c">Atovaquone-proguanil</span> | 粒線體電子傳遞+二氫葉酸抑制 | 抗藥性<span style="color:#c084fc">*P. falciparum*</span> | 口服 | 輕微胃腸不適 |
| <span style="color:#fb923c">Artemether</span> | 自由基產生 | 所有瘧疾（重症優先）| IM/口服 | 過敏、網狀血球減少 |

##  特殊族群用藥注意

###  孕婦

<span style="color:#f87171">**⚠️ 孕婦瘧疾為產科急症**：不治療或延誤治療可導致流產、死產、母親死亡。</span>

| 藥物 | 孕期安全性 |
|------|-----------|
| <span style="color:#34d399">Chloroquine</span> | 相對安全（必要時使用）|
| <span style="color:#34d399">Proguanil</span> | 安全（建議合併葉酸）|
| <span style="color:#f87171">Mefloquine</span> | 避免使用（除非獲益大於風險）|
| <span style="color:#f87171">Artemisinin衍生物</span> | 妊娠首三個月禁用（除非重症威脅生命）|
| <span style="color:#f87171">Tetracycline</span> | 禁用 |

###  預防用藥原則

<span style="color:#60a5fa">**預防失敗常見原因**：未按建議時程服藥；低估了感染的風險；藥物吸收不佳（如嘔吐、腹瀉）</span>

瘧疾流行區旅行者的預防策略：
1. 個人防蚊措施（驅蟲劑、長袖衣物、蚊帳）
2. 化學預防（視地區抗藥性選擇適當藥物）
3. 發燒時立即就醫（48小時內）
