## 章節導讀

巴金森氏症是一種漸進性神經退化性疾病，主要病理特徵為<span style="color:#22d3ee">**黑質緻密部（Substantia Nigra Pars Compacta）多巴胺神經元退化</span>，導致紋狀體（Striatum）多巴胺含量下降。本章節系統探討巴金森氏症的病理生理學，以及左旋多巴、多巴胺受體激動劑、COMT抑制劑、MAO-B抑制劑、抗膽鹼藥物與金剛烷胺等藥物的臨床應用，同時涵蓋舞蹈症、妥瑞氏症與肌張力不全等運動障礙疾病的藥物治療策略。

---

## 第一節　巴金森氏症的病理生理學

### 基底核神經路徑

<span style="color:#22d3ee">**基底核（Circuitry）**</span>的神經傳遞涉及三條主要路徑：

| 路徑 | 作用 | 巴金森氏症時的變化 |
|------|------|----------------|
| **直接路徑（Direct Pathway）** | 促進運動（抑制GPi/SNr → 減少丘腦抑制） | 多巴胺↓ → 活動減少 |
| **間接路徑（Indirect Pathway）** | 抑制運動（激活GPe → 抑制STN → 抑制GPi/SNr → 減少丘腦促進） | 多巴胺↓ → 過度抑制運動 |
| **多巴胺系統** | D1受體激活直接路徑；D2受體抑制間接路徑 | 退化 → 運動障礙 |

### 病理學

- <span style="color:#e2e8f0">**路易氏體（Lewy Bodies）**</span>：α-突觸核蛋白（α-Synuclein）組成的細胞內包涵體，是<span style="color:#e2e8f0">**突觸核蛋白病（Synucleinopathy）**</span>的特徵
- Braak分期：病理變化從嗅球/低位腦幹開始，逐步進展至黑質，最終瀰漫至整個新皮質

### 非運動症狀

| 類別 | 表現 |
|------|------|
| 自主神經 | 姿態性低血壓、便祕、尿失禁、性功能障礙 |
| 睡眠 | REM行為障礙（REM sleep behavior disorder）、失眠 |
| 精神 | 憂鬱、焦慮、冷漠、幻覺（晚期） |
| 認知 | 輕度認知障礙至失智症（晚期） |

## 第二節　左旋多巴與脫羧酶抑制劑

### Levodopa（左旋多巴）

<span style="color:#60a5fa">**Levodopa（左旋多巴）**</span>是<span style="color:#60a5fa">**多巴胺的前驅藥物**</span>，可穿過血腦屏障後經<span style="color:#e2e8f0">**芳香族L-胺基酸脫羧酶（DOPA decarboxylase, DDC）**</span>轉化為多巴胺。

| 特點 | 說明 |
|------|------|
| 給藥 | 口服；吸收依賴腸道轉運蛋白；蛋白質競爭吸收 |
| 血腦屏障 | **只有Levodopa可通過；多巴胺本身無法通過** |
| 單獨給藥 | 僅約1%進入CNS；其餘在外周轉化為多巴胺 → 副作用 |

**為什麼要與脫羧酶抑制劑合併使用？**

- 單獨使用Levodopa：>95%在外周被DDC轉化為多巴胺 → **噁心、嘔吐、心律不整、低血壓**
- 與<span style="color:#fb923c">**Carbidopa（左旋多巴/卡比多巴）**</span>或<span style="color:#fb923c">**Benserazide（芐絲肼）**</span>合併：抑制外周DDC → 更多Levodopa進入CNS → 療效增強、副作用減少

### Carbidopa/Levodopa製劑

| 製劑 | 說明 |
|------|------|
| <span style="color:#fb923c">Carbidopa/Levodopa（速效型）</span> | 10/100, 25/100, 25/250 mg；每日3–4次 |
| <span style="color:#fb923c">Carbidopa/Levodopa CR（持續釋放型）</span> | 25/100, 50/200 mg；減少"Off"時間；但吸收較不穩定 |
| <span style="color:#fb923c">Rytary（左旋多巴緩釋膠囊）</span> | 含有速效與緩釋珠；吸收更平穩 |
| <span style="color:#fb923c">Duodopa（腸膠）</span> | 持續性十二指腸/空腸輸注；用於晚期患者運動併發症 |

### 運動併發症

| 併發症 | 機轉 | 處理策略 |
|--------|------|---------|
| **運動困難（Motor Complications）** | 中樞多巴胺血漿濃度波動 | 减少單次劑量、增加給藥頻率 |
| **"Off"現象（關期）** | 藥效消退；血漿Levodopa濃度低 | 加用COMT抑制劑或MAO-B抑制劑延長作用 |
| **"On/Off"波動** | 藥代動力學不穩定 | 使用持續釋放製劑或腸道輸注 |
| **異動症（Dyskinesia）** | 多巴胺受體過度刺激 | 減少Levodopa劑量；加用AMANTADINE；DBS手術 |

<span style="color:#f87171">**「蜜月期」**：Levodopa治療初期療效顯著，但通常在2–5年內出現運動併發症。</span>

## 第三節　多巴胺受體激動劑

<span style="color:#60a5fa">**多巴胺受體激動劑（DA Agonists）**</span>直接激活紋狀體D2/D3受體，不依賴內源性多巴胺合成。

###麥角類（Ergot Derivatives）

| 藥物 | 劑量 | 特點 |
|------|------|------|
| <span style="color:#fb923c">Bromocriptine</span> | 2.5–15 mg/d（分2–3次） | D2受體激動；可能誘發纖維化（腹膜後/肺） |
| <span style="color:#fb923c">Pergolide</span> | 0.5–3 mg/d | D1/D2激動；**已因心臟纖維化退市** |

### 非麥角類（Non-Ergot Derivatives）

| 藥物 | 受體選擇性 | 劑量 | 特點 |
|------|-----------|------|------|
| <span style="color:#fb923c">Pramipexole</span> | D3 > D2 | 0.5–4.5 mg/d（分3次） | 對憂鬱有效（情感動機區域D3） |
| <span style="color:#fb923c">Ropinirole</span> | D2 = D3 | 3–24 mg/d（分3次） | 用途廣；也有長效緩釋型 |
| <span style="color:#fb923c">Rotigotine</span> | D1=D2=D3 | 經皮貼片2–8 mg/24h | 每日一次；減少波動 |

### 臨床應用

| 策略 | 說明 |
|------|------|
| **早期單一治療** | 年輕患者；延緩Levodopa使用 |
| **輔助Levodopa** | 晚期減少Levodopa劑量需求 |
| **非運動症狀** | Pramipexole對憂鬱可能有額外效益 |

### 副作用

| 副作用類別 | 表現 |
|-----------|------|
| **胃腸道** | 噁心、嘔吐（比Levodopa常見） |
| **心血管** | 姿態性低血壓（尤其是Pramipexole） |
| **神經精神** | 衝動控制障礙（病態賭博、購物、性慾亢進）；幻覺（晚期） |
| **白天嗜睡** | 突然入睡（尤其Pramipexole）；開車時需注意 |

<span style="color:#f87171">**警告**：DA激動劑可能引起衝動控制障礙（病態賭博/購物/性行為），需事先告知患者及家屬。</span>

## 第四節　COMT抑制劑

<span style="color:#60a5fa">**COMT（Catechol-O-Methyltransferase）抑制劑**</span>抑制外周Levodopa的甲基化降解，使更多Levodopa進入CNS。

| 藥物 | 劑量 | 特性 |
|------|------|------|
| <span style="color:#fb923c">Entacapone</span> | 200 mg（與每次Levodopa同步） | 短效；糞便變橙色 |
| <span style="color:#fb923c">Tolcapone</span> | 100–200 mg tid | 長效；但有**肝毒性**（需監測肝功能）；已被建議作為二線用藥 |
| <span style="color:#fb923c">Opicapone</span> | 25–50 mg qd | 長效；每日一次；肝毒性風險低 |

<span style="color:#fb923c">**Stalevo（思利寧）**</span>：Carbidopa + Levodopa + Entacapone三合一製劑，簡化服藥。

---

## 第五節　MAO-B抑制劑

<span style="color:#60a5fa">**MAO-B（Catecholamine-B型單胺氧化酶）抑制劑**</span>抑制腦內多巴胺的降解，延長其作用。

| 藥物 | 劑量 | 特性 |
|------|------|------|
| <span style="color:#fb923c">Selegiline（司來吉蘭）</span> | 5 mg bid（早餐/午餐） | 不可逆抑制；可能的神經保護（爭議）；代謝產物為安非他命 |
| <span style="color:#fb923c">Rasagiline（雷沙吉蘭）</span> | 0.5–1 mg qd | 不可逆抑制；無安非他命樣代謝；可能有疾病修飾作用（ADAGIO試驗） |
| <span style="color:#fb923c">Safinamide（沙芬酰胺）</span> | 50–100 mg qd | 可逆抑制；也有多巴胺/谷氨酸調節作用 |

<span style="color:#f87171">**Serotonin症候群風險**：MAO-B抑制劑與SSRIs/SNRIs/Meperidine/Tramadol/MAOIs合用可能引起Serotonin症候群，應避免。</span>

---

## 第六節　抗膽鹼藥物

<span style="color:#60a5fa">**抗膽鹼藥物（Antimuscarinics）**</span>為治療巴金森氏症最古老的藥物類別，透過阻斷紋狀體膽鹼毒蕈鹼受體，恢復多巴胺-膽鹼平衡。

| 藥物 | 劑量 | 臨床特點 |
|------|------|---------|
| <span style="color:#fb923c">Trihexyphenidyl</span> | 1–2 mg/d（分次）；可達6–15 mg/d | 對顫抖效果好；副作用較多 |
| <span style="color:#fb923c">Benztropine</span> | 0.5–6 mg/d | 可同時用於藥物誘發帕金森氏症 |

<span style="color:#f87171">**禁用/慎用**：老年患者、尿滯留、窄角性青光眼。</span>

**主要副作用**：口乾、視力模糊、尿滯留、便祕、認知障礙（老年人易出現精神症狀）。

---

## 第七節　金剛烷胺（Amantadine）

<span style="color:#60a5fa">**Amantadine（金剛烷胺）**</span>原為抗病毒藥物，後發現有輕微抗巴金森作用。

| 特點 | 說明 |
|------|------|
| 機轉 | NMDA受體抑制（減少興奮性毒性）；可能促進多巴胺釋放 |
| 療效 | 輕度至中度；對顫抖、僵直、運動遲緩均有效 |
| 特殊應用 | **減少Levodopa誘發的異動症** |
| 副作用 | 腿部水腫、網狀青斑（Livedo reticularis）、認知障礙、失眠 |

## 第八節　其他運動障礙疾病

### 舞蹈症（Huntington's Disease）

<span style="color:#e2e8f0">**舞蹈症（Huntington's Disease）**</span>為顯性遺傳的退化性疾病，由Huntingtin基因CAG三核苷酸重複突變引起。

| 藥物 | 機轉 | 說明 |
|------|------|------|
| <span style="color:#fb923c">Tetrabenazine</span> | VMAT2抑制劑；耗竭多巴胺 | **主要治療**；可能加重憂鬱 |
| <span style="color:#fb923c">Deutetrabenazine</span> | VMAT2抑制劑（新一代） | 副作用較少 |
| <span style="color:#fb923c">Haloperidol</span> | D2受體拮抗 | 常用於控制運動症狀 |
| <span style="color:#fb923c">Olanzapine/Quetiapine</span> | 非典型抗精神病藥物 | 對精神症狀/運動症狀均有效 |

### 妥瑞氏症（Tourette Syndrome）

| 藥物 | 說明 |
|------|------|
| <span style="color:#fb923c">Alpha-2 agonists（Clonidine、Guanfacine）</span> | 首選（輕中度）；抑制tic |
| <span style="color:#fb923c">Antipsychotics（Dopamine antagonists）** | 重度tic；Haloperidol、Pimozide、Risperidone、Aripiprazole |
| <span style="color:#fb923c">Botulinum toxin</span> | 局部注射；對局部tic（如眨眼）有效 |

### 肌張力不全（Dystonia）

| 類別 | 治療 |
|------|------|
| **局部/任務特異性** | Botulinum toxin（局部肌肉注射）；口服藥物效果有限 |
| **全身性** | 口服抗膽鹼藥（高劑量Trihexyphenidyl）；Baklofen；Dopamine抑制劑 |
| **急性/陣發性** | Clonazepam |

## 第九節　重點摘要

- 巴金森氏症的病理核心為<span style="color:#22d3ee">**黑質緻密部多巴胺神經元退化**</span>，導致紋狀體多巴胺缺乏
- <span style="color:#fb923c">Levodopa + Carbidopa</span>是治療巴金森氏症最有效的藥物，Carbidopa抑制外周脫羧酶使更多Levodopa進入CNS
- Levodopa治療後2–5年常出現運動併發症（異動症、"Off"現象）
- <span style="color:#fb923c">Pramipexole</span>與<span style="color:#fb923c">Ropinirole</span>等DA受體激動劑可單獨用於早期或輔助Levodopa
- <span style="color:#fb923c">COMT抑制劑（Entacapone）</span>延長Levodopa作用時間，減少「Off」時間
- <span style="color:#fb923c">MAO-B抑制劑（Rasagiline、Selegiline）</span>抑制腦內多巴胺降解
- <span style="color:#fb923c">Amantadine</span>可減輕Levodopa誘發的異動症
- <span style="color:#fb923c">Tetrabenazine</span>為舞蹈症的主要治療藥物
- <span style="color:#f87171">DA受體激動劑可能引起衝動控制障礙（病態賭博、購物、性慾亢進）</span>
