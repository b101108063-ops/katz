## <span style="color:#60a5fa">藥物動力學與藥效學</span>

## 章節導讀

<span style="color:#e2e8f0">藥物動力學</span>與<span style="color:#e2e8f0">藥效學</span>的整合是精準給藥的基礎，本章介紹<span style="color:#60a5fa">分布體積</span>、<span style="color:#60a5fa">清除率</span>、<span style="color:#60a5fa">半衰期</span>等核心 PK 參數，以及<span style="color:#34d399">一級動力學</span>與<span style="color:#34d399">容量限制動力學</span>的臨床意義。

---

## 基本藥物動力學參數

### 分布體積（Volume of Distribution, V_d）

分布體積連結體內藥物量與血液或血漿中的藥物濃度：

```
體內藥物量 = V_d × C（血漿濃度）
```

| 特性 | 說明 |
|------|------|
| 表觀體積 | V_d 可超過實際身體容積（藥物在組織中蓄積） |
| 臨床意義 | <span style="color:#34d399">Digoxin V_d ≈ 500 L/70kg</span>（實際體積約 70L）|

### 清除率（Clearance, CL）

<span style="color:#60a5fa">清除率</span>是衡量身體消除藥物能力的參數：

```
清除率 = 消除速率 / C（藥物濃度）
```

<span style="color:#34d399">總清除率 = 腎清除率 + 肝清除率 + 其他器官清除率</span>

### 半衰期（Half-life, t_1/2）

<span style="color:#34d399">t_1/2 = 0.693 × V_d / CL</span>

半衰期是劑量調整的關鍵參數，受 V_d 與 CL 兩者影響。

---

## 藥物消除動力學

### 一級動力學（First-order Elimination）

| 特性 | 說明 |
|------|------|
| 消除比例 | 單位時間內消除固定比例的藥物 |
| 半衰期 | 恆定不變 |
| AUC | 與劑量成正比 |
| 臨床意義 | 絕大多數藥物在此動力學範圍內 |

### 容量限制動力學（Capacity-limited/Saturable Kinetics）

<span style="color:#f87171">重要：</span>少數藥物在高濃度時呈現容量限制動力學：

| 藥物例子 | 臨床意義 |
|---------|---------|
| <span style="color:#fb923c">Phenytoin</span> | 飽和代謝，小幅增加劑量可能導致濃度大幅上升 |
| <span style="color:#fb923c">Ethanol</span> | 高濃度時呈零級動力學 |

Michaelis-Menten 方程式：`Rate = V_max × C / (K_m + C)`

## 穩定態與給藥設計

### 穩定態（Steady State）

重複給藥時，給藥速率等於消除速率時達到<span style="color:#60a5fa">穩定態</span>：

```
給藥速率 = CL × C_ss
```

| 參數 | 臨床意義 |
|------|---------|
| 達到穩定態時間 | 約 <span style="color:#34d399">4-5 個半衰期</span>（與劑量無關） |
| 穩定態濃度 | 與給藥速率成正比，與清除率成反比 |

### 維持劑量與負荷劑量

| 公式 | 應用 |
|------|------|
| <span style="color:#34d399">維持劑量速率 = CL × C_ss / F</span> | 持續維持目標濃度 |
| <span style="color:#34d399">負荷劑量 = V_d × C_target</span> | 快速達到目標濃度 |

---

## 生物可用率（Bioavailability, F）

| 給藥途徑 | F 值 | 說明 |
|---------|------|------|
| 靜脈注射 | <span style="color:#34d399">100%</span> | 完全進入體循環 |
| 口服 | 變動 | 受吸收不全與首渡肝臟代謝影響 |
| 其他 | 各異 | 取決於給藥途徑的吸收特性 |

<span style="color:#fb923c">首渡效應（First-pass Effect）</span>：口服藥物經肝臟首次通過時的部分代謝，導致 F < 100%。

## 腎功能與肝功能衰竭時的劑量調整

### 腎功能衰竭

Cockcroft-Gault 方程式估算肌酸酐清除率：

<span style="color:#34d399">CrCl = [(140 - 年齡) × 體重(kg)] / [72 × 血清肌酸酐(mg/dL)]</span>（女性 × 0.85）

| 藥物 | 腎衰竭時調整 |
|------|------------|
| <span style="color:#fb923c">Digoxin</span> | 腎功能不良患者需減少劑量 |
| <span style="color:#fb923c">Aminoglycosides</span> | 顯著依賴腎清除，需监测血藥濃度 |

### 血漿蛋白結合置換

| 臨床意義 | 說明 |
|---------|------|
| 游離藥物濃度 | <span style="color:#60a5fa">不改變</span> |
| 總藥物濃度 | 可能下降 |
| 臨床影響 | 有限（消除率不變）|
