## 章節導讀

抗精神病藥物與鋰鹽主要用於治療精神分裂症與雙相情感障礙等嚴重精神疾病。本章節探討抗精神病藥物的神經生物學基礎（特別是多巴胺假說），以及典型（第一代）與非典型（第二代）抗精神病藥物的藥理學特性、臨床應用與不良反應，並深入分析鋰鹽在雙相情感障礙中的角色、作用機轉與治療藥物監測。

## <span style="color:#60a5fa">Antipsychotics</span> & <span style="color:#60a5fa">Lithium</span>

Antipsychotic drugs and lithium are primarily used in the treatment of severe psychiatric disorders such as schizophrenia and bipolar disorder. This chapter explores the neurobiological basis of antipsychotic drugs (particularly the dopamine hypothesis), the pharmacological properties of typical (first-generation) and atypical (second-generation) antipsychotics, their clinical applications and adverse effects, and provides an in-depth analysis of lithium's role in bipolar disorder, its mechanism of action, and therapeutic drug monitoring.

## 第一節　精神分裂症的神經生物學基礎

### 多巴胺假說

精神分裂症的<span style="color:#e2e8f0">**多巴胺假說（ Dopamine Hypothesis）**</span>：

| 路徑 | 多巴胺活動 | 臨床表現 |
|------|----------|---------|
| **中腦-邊緣路徑（Mesolimbic）** | **↑**多巴胺活性 | 正性症狀（幻覺、妄想、思考障礙） |
| **中腦-皮質路徑（Mesocortical）** | **↓**多巴胺活性 | 負性症狀（情感平板、社交退縮、認知障礙） |
| **黑質-紋狀體路徑（Nigrostriatal）** | **↓**多巴胺活性（被拮抗） | 錐體外路徑副作用（EPS） |
| **結節漏斗路徑（Tuberoinfundibular）** | **↓**多巴胺（被拮抗） | 高泌乳素血症 |

### 5-羥色胺（5-HT）假說

非典型抗精神病藥物的療效部分與<span style="color:#60a5fa">**5-HT<sub>2A</sub>受體阻斷**</span>有關，5-HT<sub>2A</sub>受體抑制使中腦-皮質多巴胺路徑去抑制，可能改善負性症狀與認知功能。

## 第二節　抗精神病藥物的分類

### 第一代（典型）抗精神病藥物

又稱<span style="color:#e2e8f0">**傳統/典型抗精神病藥物**</span>，主要阻斷D2受體，對正性症狀效果顯著。

| 藥物 | 效價 | 臨床特點 |
|------|------|---------|
| <span style="color:#fb923c">Haloperidol</span> | 高 | 注射制劑常用；錐體外副作用明顯 |
| <span style="color:#fb923c">Chlorpromazine</span> | 低-中 | 鎮靜明顯；姿態性低血壓；黃疸/皮疹 |
| <span style="color:#fb923c">Fluphenazine</span> | 高 | 長效酯化物（Decanoate）可用；EPS明顯 |
| <span style="color:#fb923c">Perphenazine</span> | 中-高 | 口服/注射；EPS劑量相關 |
| <span style="color:#fb923c">Thiothixene</span> | 高 | 結構似Thioxanthene |

### 第二代（非典型）抗精神病藥物

又稱<span style="color:#e2e8f0">**非典型抗精神病藥物**</span>，特點為<span style="color:#60a5fa">**5-HT<sub>2A</sub>阻斷 > D2阻斷**</span>。

| 藥物 | 受體作用 | 臨床特點 |
|------|---------|---------|
| <span style="color:#fb923c">Clozapine</span> | D4 > D2；5-HT<sub>2</sub>；α<sub>1</sub>；H<sub>1</sub> | **對難治性精神分裂症唯一有效**；需監測**粒性白血球減少症**（0.8%）；無EPS；镇吐；體重增加 |
| <span style="color:#fb923c">Risperidone</span> | D2；5-HT<sub>2</sub>；α<sub>1</sub>/α<sub>2</sub> | 中等效價；對陽/陰性症狀均有效；劑量相關EPS |
| <span style="color:#fb923c">Olanzapine</span> | D1>D2>D4；5-HT<sub>2</sub>；M1；H<sub>1</sub> | 對陽/陰性症狀有效；**顯著體重增加/糖尿病風險** |
| <span style="color:#fb923c">Quetiapine</span> | D1/D2；5-HT<sub>2</sub>；H<sub>1</sub>；α<sub>1</sub>/α<sub>2</sub> | 較低D2阻斷；**鎮靜**；對失眠/焦慮有效；對Mood stabilizers輔助 |
| <span style="color:#fb923c">Aripiprazole</span> | D2；D3；5-HT<sub>1A</sub>（部分激動）；5-HT<sub>2A</sub> | ** Dopamine-serotonin系統穩定劑（DSSA）**；較少體重增加；可能引起激越 |
| <span style="color:#fb923c">Ziprasidone</span> | D2；5-HT<sub>2</sub>；5-HT<sub>1D</sub>；α<sub>1</sub> | **體重增加最少**；可能延長QTc |
| <span style="color:#fb923c">Paliperidone</span> | D2；5-HT<sub>2</sub> | Risperidone活性代謝物；長效注射剂 |
| <span style="color:#fb923c">Lurasidone</span> | D2；5-HT<sub>2A</sub>；5-HT<sub>7</sub>（阻斷） | 中性代謝；對負性症狀/認知可能有效 |
| <span style="color:#fb923c">Asenapine</span> | D2；D3；5-HT<sub>2</sub>；α<sub>1</sub>/α<sub>2</sub> | 舌下含片 |
| <span style="color:#fb923c">Iloperidone</span> | D2；5-HT<sub>2</sub>；α<sub>1</sub> | 每日两次口服 |
| <span style="color:#fb923c">Cariprazine</span> | D3>D2（優先）；5-HT<sub>2B</sub> | 對負性症狀/認知可能較好 |

## 第三節　藥物動力學

| 特性 | 說明 |
|------|------|
| 吸收 | 口服吸收良好；不受食物影響（除Aripiprazole需空腹） |
| 分佈 | 高度親脂性；廣泛分佈於組織；易通過血腦屏障 |
| 蛋白結合 | 高（>90%） |
| 代謝 | 肝臟CYP450酶系；主要CYP1A2、CYP2D6、CYP3A4 |
| 半衰期 | 各異；Aripiprazole最長（約75小時活性代謝物） |
| 排泄 | 尿液/糞便 |

## 第四節　不良反應

### A. 錐體外路徑副作用（EPS）

| 副作用 | 表現 | 發生時間 | 處理 |
|--------|------|---------|------|
| **急性肌張力障礙** | 頸部/眼肌痙攣 | 數小時–1天 | Anticholinergic（Trihexyphenidyl、Benztropine） |
| **靜坐不能** | 主觀不安、無法靜坐 | 數天–數週 | Beta blockers（Propranolol）；Benzodiazepines |
| **帕金森氏症樣症狀** | 僵直、顫抖、運動遲緩 | 數週–數月 | 減少劑量；更換藥物；Anticholinergic |
| **遲發性運動障礙（TD）** | 嘴/舌不自主運動；刻板動作 | 數月–數年（長期用藥） | **不可逆**；早期發現/停藥關鍵；VMAT2抑制劑（Valbenazine、Deutetrabenazine） |

<span style="color:#f87171">**TD警告**：老年患者、長期用藥、高劑量風險最高；一旦出現應考慮更換為Clozapine。</span>

### B. 抗精神病藥物惡性症候群（NMS）

<span style="color:#f87171">**抗精神病藥物惡性症候群（Neuroleptic Malignant Syndrome, NMS）**</span>為罕見但危及生命的緊急情況。

| 診斷標準 | 說明 |
|---------|------|
| 發燒 | 通常>38°C |
| 肌肉強直 | 「鉛管」樣強直 |
| 意識改變 | 激越→木僵→昏迷 |
| 自主神經不穩 | 心搏過速、血壓波動、出汗 |
| 實驗室 | CK↑、WBC↑、電解質失衡 |

**處理**：立即停用抗精神病藥；支持性治療（積極輸液、降溫）；<span style="color:#fb923c">**Dantrolene**</span>（肌肉鬆弛）或<span style="color:#fb923c">**Bromocriptine**</span>（DA激動劑）；ICU監測。

### C. 代谢副作用

| 副作用 | 表現 | 高風險藥物 |
|--------|------|---------|
| **體重增加** | 明顯 | <span style="color:#fb923c">Olanzapine</span>、<span style="color:#fb923c">Clozapine</span>、<span style="color:#fb923c">Quetiapine</span> |
| **血糖/糖尿病** | 血糖升高、DKA | Olanzapine、Clozapine |
| **血脂異常** | LDL↑、TG↑、HDL↓ | Olanzapine |
| **心律不整** | QTc延長 | Ziprasidone（最高）、Thioridazine |

<span style="color:#f87171">**Olanzapine與Clozapine的糖尿病風險已獲FDA黑框警告**。</span>

### D. 其他不良反應

| 系統 | 表現 | 藥物/說明 |
|------|------|---------|
| **內分泌** | **高泌乳素血症**（月經失調、陽痿、女性男乳） | Risperidone（最高）、典型藥物 |
| **心血管** | 姿態性低血壓、QTc延長 | 低效價典型藥物；Ziprasidone |
| **肝臟** | 膽汁淤積、肝炎 | 低效價典型藥物 |
| **血液** | **粒性白血球減少/顆粒性白血症** | <span style="color:#f87171">**Clozapine**（需每週/月CBC監測） |
| **視覺** | 角膜/水晶體沉積 | Thioridazine（>800 mg/d） |
| **神經** | 癲癇閾值降低 | Clozapine（高劑量） |
| **抗膽鹼** | 口乾、視力模糊、尿滯留、便祕 | 低效價典型藥物、Clozapine |

## 第五節　鋰鹽（Lithium）

<span style="color:#60a5fa">**鋰鹽（Lithium Carbonate）**</span>是治療<span style="color:#e2e8f0">**雙相情感障礙（Bipolar Disorder）**</span>的經典情緒穩定劑。

### 作用機轉

鋰鹽的作用機轉尚未完全闡明，目前的研究顯示：

| 機轉 | 說明 |
|------|------|
| **磷酸肌醇路徑抑制** | 抑制Inositol monophosphatase → 減少PIP<sub>2</sub> → 減少IP<sub>3</sub>與DAG第二信使系統 |
| **抑制GSK-3（糖原合成酶激酶-3）** | 可能與情緒穩定及神經保護相關 |
| **抑制蛋白激酶C（PKC）** | 影響基因表現與長期神經可塑性 |
| **抑制去甲腎上腺素敏感Adenylyl cyclase** | 可能與抗憂鬱/抗躁作用相關 |
| **受體-G蛋白去耦合** | 抗利尿激素與TSH受體去耦合 → 多尿、甲狀腺功能減退 |

### 藥物動力學

| 特性 | 數值 |
|------|------|
| 吸收 | 口服吸收快速；生物利用率60–100% |
| 分佈 | 不與血漿蛋白結合；分佈於全身水分 |
| 半衰期 | 18–36小時（腎功能正常） |
| 腎臟排泄 | >95%以原型經腎臟排泄；鈉鹽狀態影響排泄 |
| 治療血漿濃度 | 急性躁期：0.8–1.2 mEq/L；維持：0.6–1.0 mEq/L |

<span style="color:#e2e8f0">**治療藥物監測（TDM）至關重要**：取血時間為末次服藥後10–12小時。</span>

### 臨床應用

| 適應症 | 說明 |
|--------|------|
| **雙相情感障礙** | 躁期/鬱期均有效；維持治療可預防復發 |
| **單極性憂鬱輔助** | 對抗憂鬱藥反應不佳的增效治療 |
| **分裂情感障礙** | 單獨或與抗精神病藥合用 |
| **其他** | 叢發性頭痛（部分有效） |

### 不良反應

#### A. 神經/精神副作用

| 表現 | 說明 |
|------|------|
| **細微顫抖** | 常見（治療劑量）；Beta blockers（Propranolol）可緩解 |
| **嚴重顫抖/舞蹈樣動作** | 鋰鹽中毒早期徵兆 |
| **嗜睡/共濟失調** | 治療血漿濃度上限；需鑑別中毒 |
| **認知減退** | 主觀感受；客觀影響輕微 |

#### B. 甲狀腺功能減退

<span style="color:#f87171">**鋰鹽抑制甲狀腺激素釋放**</span>，約20%患者出現甲狀腺功能減退（TSH↑、T4↓）。需監測甲狀腺功能。

#### C. 腎臟副作用

| 副作用 | 說明 |
|--------|------|
| **腎原性尿崩症（NDI）** | 鋰鹽使集合管對ADH抵抗 → 多尿、煩渴；約40%患者 |
| **慢性腎病** | 長期使用可能導致腎絲球/間質纖維化；需定期監測腎功能 |

#### D. 鋰鹽中毒

<span style="color:#f87171">**中毒血漿濃度：>1.5 mEq/L；嚴重中毒：>2.0 mEq/L**</span>

| 階段 | 血漿濃度 | 症狀 |
|------|---------|------|
| 輕度 | 1.5–2.0 mEq/L | 嘔吐、腹瀉、嗜睡、顫抖、共濟失調 |
| 中度 | 2.0–2.5 mEq/L | 意識混淆、構音障礙、陳施呼吸（Cheyne-Stokes） |
| 重度 | >2.5 mEq/L | 昏迷、癲癇、心律不整、心跳停止 |

**處理**：立即停藥；生理食鹽水輸注（增加腎臟排泄）；嚴重時血液透析。

### 藥物交互作用

| 藥物 | 交互作用 |
|------|---------|
| **Thiazide利尿劑** | 減少鋰排泄 → **升高血鋰濃度** |
| **NSAIDs** | 減少腎臟排泄 → 升高血鋰 |
| **ACE抑制劑/ARB** | 輕度增加血鋰 |
| **Fluoride** | 增加鋰排泄 |
| **Carbamazepine** | 協同CNS毒性 |
| **SSRI/TCA** | 增加血清素症候群風險 |

## 第六節　重點摘要

- 精神分裂症的多巴胺假說：<span style="color:#22d3ee">**中腦-邊緣路徑多巴胺活性過高**</span>導致正性症狀；<span style="color:#22d3ee">**中腦-皮質路徑多巴胺活性不足**</span>導致負性症狀
- 典型抗精神病藥物主要阻斷D2受體；非典型藥物額外阻斷5-HT<sub>2A</sub>受體
- <span style="color:#fb923c">Clozapine</span>是唯一對難治性精神分裂症有效的抗精神病藥物，但有粒性白血球減少症風險
- <span style="color:#fb923c">Risperidone</span>、<span style="color:#fb923c">Olanzapine</span>、<span style="color:#fb923c">Quetiapine</span>、<span style="color:#fb923c">Aripiprazole</span>為常用非典型抗精神病藥物
- <span style="color:#f87171">錐體外副作用（EPS）為典型藥物主要限制；遲發性運動障礙（TD）可能不可逆</span>
- <span style="color:#f87171">抗精神病藥物惡性症候群（NMS）為危及生命的緊急情況，需立即停藥並積極治療</span>
- <span style="color:#fb923c">Olanzapine</span>與<span style="color:#fb923c">Clozapine</span>有顯著體重增加與糖尿病風險
- <span style="color:#fb923c">Lithium</span>是雙相情感障礙的一線情緒穩定劑，可預防躁期與鬱期復發
- 鋰鹽的治療血漿濃度窄（0.6–1.2 mEq/L），需定期監測；中毒（>1.5 mEq/L）可能危及生命
- <span style="color:#f87171">鋰鹽、甲狀腺、腎臟功能均需定期監測</span>
