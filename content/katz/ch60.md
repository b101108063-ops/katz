# CH60 眼科用藥

## 章節導讀

眼科用藥是臨床藥理學的重要分支，涉及局部（眼藥水、軟膏）與全身性藥物在眼部的應用。本章節介紹常用眼科藥物的藥理學特性，包括<span style="color:#fb923c">**青光眼治療藥物**</span>（β-blockers、 prostaglandin analogues、碳酸酐酶抑制劑）、<span style="color:#fb923c">**散瞳藥物**</span>、<span style="color:#fb923c">**局部麻醉劑**</span>以及影響視力的全身性藥物（如amiodarone、ethambutol等）。眼科用藥需特別注意眼藥水的全身性吸收帶來的不良反應。

---

## 眼科用藥的基本原理

### 局部用藥的考量

| 因素 | 說明 |
|------|------|
| <span style="color:#60a5fa">**全身性吸收**</span> | 眼藥水可通過鼻淚管全身吸收；必要時壓迫內眼角（淚囊）以減少吸收 |
| <span style="color:#60a5fa">**防腐劑**</span> | 長期使用含benzalkonium chloride的眼藥水可能引起接觸性過敏 |
| <span style="color:#60a5fa">** viscosity**</span> | 增加黏稠度可延長眼藥水在結膜囊的停留時間 |

---

## 青光眼藥物

### 青光眼治療概述

<span style="color:#60a5fa">**青光眼**是由視神經退化導致的視野缺損疾病；眼內壓（IOP）升高是其主要危險因子。</span>

### 青光眼藥物分類

| 藥物類別 | 代表藥物 | 作用機轉 |
|---------|---------|---------|
| <span style="color:#fb923c">**β-blockers**</span> | Timolol、Betaxolol、Carteolol | 減少房水生成 |
| <span style="color:#fb923c">**Prostaglandin analogues**</span> | Latanoprost、Bimatoprost、 Travoprost | 增加葡萄膜鞏膜外流 |
| <span style="color:#fb923c">**α₂-agonists**</span> | Brimonidine、Apraclonidine | 減少房水生成；增加外流 |
| <span style="color:#fb923c">**碳酸酐酶抑制劑**</span> | Dorzolamide、Brinzolamide（局部）| 減少碳酸氫鹽分泌→減少房水 |
| <span style="color:#fb923c">**膽鹼激動劑**</span> | Pilocarpine | 收縮瞳孔→拉緊小梁網→增加外流 |
| <span style="color:#fb923c">** Rho激酶抑制劑**</span> | Netarsudil | 增加小梁網外流 |

---

## β-腎上腺素阻斷劑（局部）

### Timolol（馬來酸噻嗎洛爾）

<span style="color:#60a5fa">**作用機轉**：非選擇性β-blocker；局部使用減少睫狀上皮細胞的房水生成。</span>

| 特性 | 說明 |
|------|------|
| 濃度 | 0.25%, 0.5% |
| 給藥 | 每日1-2次 |
| 療效 | 降低IOP約20-30% |

### 不良反應（全身性吸收）

<span style="color:#f87171">**⚠️ 老年患者、心臟疾病患者、氣喘/COPD患者需特別注意**</span>

| 系統 | 表現 |
|------|------|
| <span style="color:#f87171">**心臟**</span> | 心搏過緩、心衰竭惡化、房室傳導阻斷 |
| <span name="color:#f87171">**呼吸**</span> | 氣喘/ COPD惡化 |
| <span name="color:#f87171">**中樞神經**</span> | 憂鬱、意識混淆、陽痿 |
| <span style="color:#fb923c">**局部**</span> | 點狀角膜炎、眼睛刺激、視力模糊 |

### β1-選擇性製劑

| 藥物 | 優點 |
|------|------|
| <span style="color:#fb923c">Betaxolol</span> | 對心臟选择性較高；氣喘患者相对安全 |

---

## Prostaglandin Analogues

### Latanoprost（拉坦前列素）

<span style="color:#60a5fa">**作用機轉**：Prostaglandin F₂α衍生物；增加葡萄膜鞏膜外流通道的房水排出。</span>

| 特性 | 說明 |
|------|------|
| 降低IOP幅度 | 約25-35% |
| 給藥 | 每晚一次 |
| 優點 | 全身不良反應少；每日一次方便 |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**眼睛**</span> | 眼睛發紅（結膜充血）、虹膜色素沉著增加（棕色眼睛變深）、睫毛增長變粗、眼皮色素沉著 |
| <span style="color:#fb923c">**全身**</span> | 肌肉/關節疼痛；皮疹 |

<span style="color:#34d399">**注意**：可能使睫毛、外眼周的毛髮變黑、變粗、變長</span>

---

## α₂-腎上腺素激動劑

### Brimonidine（溴莫尼定）

<span style="color:#60a5fa">**作用機轉**：α₂受體激動；減少房水生成並增加葡萄膜鞏膜外流。</span>

| 特性 | 說明 |
|------|------|
| 降低IOP幅度 | 約20-25% |
| 給藥 | 每日2-3次 |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span style="color:#fb923c">**局部**</span> | 過敏性結膜炎（約10-20%患者）、眼睛發紅、瘙癢 |
| <span style="color:#fb923c">**全身**</span> | 口乾、嗜睡（α₂中枢作用）|

---

## 碳酸酐酶抑制劑（局部）

### Dorzolamide（多佐胺）

<span style="color:#60a5fa">**作用機轉**：抑制碳酸酐酶II → 減少睫狀上皮細胞分泌碳酸氫鹽 → 減少房水生成</span>

| 特性 | 說明 |
|------|------|
| 製劑 | 2%眼藥水；每日3次 |
| 單獨使用療效 | 降低IOP約15-20% |

<span style="color:#f87171">**注意**：磺胺類過敏患者禁用（結構相關）</span>

### Brinzolamide（布林唑胺）

<span style="color:#60a5fa">**特點**：與dorzolamide相似；pH較低，舒適度可能較佳</span>

---

## 膽鹼激動劑（Pilocarpine，毛果芸香鹼）

<span style="color:#60a5fa">**作用機轉**：直接作用的膽鹼酯酶抑制劑；收縮瞳孔（miosis）→拉緊小梁網→增加房水外流</span>

| 特性 | 說明 |
|------|------|
| 濃度 | 1-4% |
| 給藥 | 每日2-4次 |
| 降低IOP | 約15-25% |

### 不良反應

| 系統 | 表現 |
|------|------|
| <span name="color:#fb923c">**眼睛**</span> | 瞳孔縮小（暗視力下降）、眉弓疼痛、視力模糊（晶狀體變凸）|
| <span style="color:#fb923c">**全身**</span> | 口腔發汗、唾液分泌過多；全身吸收可能引起心搏過緩 |

---

## 散瞳藥物（Mydriatics）與睫狀肌麻痺藥物（Cycloplegics）

| 藥物 | 作用 | 臨床用途 |
|------|------|---------|
| <span style="color:#fb923c">Tropicamide</span> | 快速散瞳（30-60分鐘）；短效睫狀肌麻痺 | 眼底檢查 |
| <span style="color:#fb923c">Cyclopentolate</span> | 散瞳+睫狀肌麻痺（24-48小時）| 驗光；葡萄膜炎 |
| <span style="color:#fb923c">Homatropine</span> | 散瞳+睫狀肌麻痺（2-4天）| 葡萄膜炎 |
| <span style="color:#fb923c">Atropine</span> | 散瞳+睫狀肌麻痺（7-10天）| 嚴重葡萄膜炎；<span style="color:#f87171">**兒童使用有窒息風險**</span> |

<span style="color:#60a5fa">**作用機轉**：抗膽鹼→阻斷虹膜括約肌（散瞳）和睫狀肌（睫狀肌麻痺）</span>

---

## 局部麻醉劑

### Proparacaine（Tetracaine）

<span style="color:#60a5fa">**作用機轉**：抑制神經細胞的鈉離子通道→阻止動作電位產生</span>

| 特性 | 說明 |
|------|------|
| 作用開始 | 數秒內 |
| 作用持續 | 10-20分鐘 |
| 用途 | 眼科操作（測量眼壓、移除異物、縫線拆除）|

<span style="color:#f87171">**注意**：長期使用可能延遲角膜癒合；不可用於治療眼睛疼痛</span>

---

## 抗感染眼科製劑

### 局部抗生素

| 藥物 | 適應症 |
|------|--------|
| <span style="color:#fb923c">Erythromycin 0.5%軟膏</span> | 新生兒眼炎預防（<span style="color:#c084fc">*Neisseria gonorrhoeae*</span>、<span style="color:#c084fc">*Chlamydia trachomatis*</span>）；常規新生兒處理後 |
| <span style="color:#fb923c">Gentamicin/ Tobramycin眼藥水</span> | 格蘭氏陰性菌感染（<span style="color:#c084fc">*Pseudomonas*</span>）|
| <span style="color:#fb923c">Ciprofloxacin/ Ofloxacin眼藥水</span> | 角膜潰痬；Fluoroquinolones穿透性佳 |

### 局部抗病毒藥物

| 藥物 | 適應症 |
|------|--------|
| <span style="color:#fb923c">Ganciclovir凝膠</span> | 皰疹性角膜炎 |
| <span style="color:#fb923c">Trifluridine眼藥水</span> | 皰疹性角膜炎 |

## 抗發炎眼科藥物

### 皮質類固醇

| 藥物 | 用途 |
|------|------|
| <span style="color:#fb923c">Prednisolone acetate 1%</span> | 葡萄膜炎；術後抗發炎 |
| <span style="color:#fb923c">Dexamethasone眼藥水/軟膏</span> | 過敏性結膜炎；術後 |

<span style="color:#f87171">**⚠️ 長期使用局部類固醇的風險**：白內障（皮質類固醇性）；眼壓升高（類固醇性青光眼）；角膜融解（皰疹性角膜炎時使用可能加劇）</span>

### NSAIDs眼科製劑

| 藥物 | 用途 |
|------|------|
| <span style="color:#fb923c">Ketorolac眼藥水</span> | 術後止痛；過敏性結膜炎瘙癢 |
| <span style="color:#fb923c">Nepafenac眼藥水</span> | 白內障術後抗發炎 |

## 老化相關黃斑部病變（AMD）治療

### 抗血管內皮生長因子（Anti-VEGF）治療

| 藥物 | 給藥方式 | 說明 |
|------|---------|------|
| <span style="color:#fb923c">Ranibizumab</span> | 玻璃體內注射 | 非常昂貴 |
| <span name="color:#fb923c">Bevacizumab</span> | 玻璃體內注射（仿單外使用）| 較便宜 |
| <span style="color:#fb923c">Aflibercept</span> | 玻璃體內注射 | VEGF trap |

<span style="color:#60a5fa">**適應症**：濕型（新生血管型）老化相關黃斑部病變</span>

## 全身性藥物的眼科不良反應

| 藥物 | 眼部不良反應 |
|------|-----------|
| <span style="color:#fb923c">Amiodarone</span> | 角膜沉著物（前囊下）；視力模糊 |
| <span style="color:#fb923c">Ethambutol</span> | <span style="color:#f87171">**視神經炎**</span>→視力下降、紅綠色盲 |
| <span style="color:#fb923c">Corticosteroids</span> | 白內障（後囊下）；眼壓升高（類固醇性青光眼）|
| <span style="color:#fb923c">Tamoxifen</span> | 視網膜病變；角膜混濁 |
| <span style="color:#fb923c">Vigabatrin</span> | <span style="color:#f87171">**不可逆性視野缺損**</span>；使用時需監測視野 |
| <span style="color:#fb923c">Phenytoin</span> | 眼球震顫（過量時）|

<span style="color:#f87171">**Ethambutol眼科監測**：建議治療前及治療中每2-4週進行視野及色覺檢查</span>

---

## 眼科用藥的使用技巧

| 技巧 | 說明 |
|------|------|
| 壓迫淚囊 | 點藥後輕壓內眼角2-3分鐘；減少全身吸收 |
| 等待時間 | 不同眼藥水間至少等待5分鐘 |
| 正確順序 | 水溶性→懸浮性→軟膏（最後）|
| 開瓶後保存 | 多劑量眼藥水開瓶後一般保存28天（不含防腐劑者更短）|
