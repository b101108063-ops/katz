## 章節導讀

本章介紹<span style="color:#60a5fa">鎮靜催眠藥物</span>的藥理學，包括<span style="color:#fb923c">Benzodiazepines</span>、<span style="color:#fb923c">Barbiturates</span>、<span style="color:#fb923c">Z類藥物</span>（Zolpidem、Zaleplon、Eszopiclone）及<span style="color:#fb923c">Ramelteon</span>、<span style="color:#fb923c">Buspirone</span>的作用機轉、藥物動力學、臨床應用與不良反應。

---

## 鎮靜催眠藥的化學分類

| 類別 | 代表藥物 |
|------|---------|
| <span style="color:#60a5fa">Benzodiazepines</span> | Diazepam、Alprazolam、Triazolam |
| <span style="color:#60a5fa">Barbiturates</span> | Phenobarbital、Secobarbital |
| <span style="color:#60a5fa">Z類藥物</span> | Zolpidem、Zaleplon、Eszopiclone |
| <span style="color:#60a5fa">其他</span> | Chloral hydrate、Meprobamate |
| <span style="color:#60a5fa">Melatonin受體激動劑</span> | <span style="color:#fb923c">Ramelteon</span> |
| <span style="color:#60a5fa">Azapirone</span> | <span style="color:#fb923c">Buspirone</span> |

---

## Benzodiazepines

### 作用機轉

<span style="color:#fb923c">Benzodiazepines</span>→結合<span style="color:#e2e8f0">GABA_A受體</span>上的<span style="color:#e2e8f0">BZ結合位點</span>（α與γ亞單位之間）→增加GABA介導的Cl⁻通道開放頻率→<span style="color:#60a5fa">神經元超極化</span>

### 主要效應

| 效應 | 說明 |
|------|------|
| 鎮靜 | 低劑量：減輕焦慮 |
| 催眠 | 高劑量：促進睡眠 |
| 抗焦慮 | 中樞抑制 |
| 肌肉鬆弛 | 脊髓層面的抑制 |
| 抗痙攣 | 抑制痙攣發作 |
| 順行性失憶 | 無法記憶藥物作用期間的事件 |

### Benzodiazepines藥物動力學

| 藥物 | 半衰期（小時） | 活性代謝物 | 特點 |
|------|-------------|-----------|------|
| <span style="color:#fb923c">Diazepam</span> | 20-80 | 有（長效） | 肝功能異常時累積 |
| <span style="color:#fb923c">Alprazolam</span> | 12-15 | 無 | 常用於焦慮、恐慌症 |
| <span style="color:#fb923c">Lorazepam</span> | 10-20 | 無 | 肝功能異常者可用 |
| <span style="color:#fb923c">Oxazepam</span> | 10-20 | 無 | 短效 |
| <span style="color:#fb923c">Triazolam</span> | 2-3 | 無 | 短效催眠藥 |
| <span style="color:#fb923c">Flurazepam</span> | 40-100 | 有（長效） | 早晨殘留抑制 |

### 臨床應用

| 用途 | 說明 |
|------|------|
| 焦慮症 | <span style="color:#60a5fa">急性焦慮、恐慌症</span> |
| 失眠 | 短期使用 |
| 肌肉痙攣 | <span style="color:#fb923c">Diazepam</span> |
| 癲癇 | <span style="color:#fb923c">Clonazepam</span>、<span style="color:#fb923c">Diazepam</span>（靜脈） |
| 麻醉前給藥 | <span style="color:#fb923c">Midazolam</span> |
| 酒精戒斷 | <span style="color:#fb923c">Chlordiazepoxide</span> |

### 副作用

| 副作用 | 說明 |
|--------|------|
| 嗜睡、認知障礙 | 白天殘留抑制 |
| 依賴性 | <span style="color:#f87171">長期使用風險</span> |
| 停藥反應 | 焦慮、失眠、反跳性失眠 |
| 呼吸抑制 | <span style="color:#f87171">過量時，特別與酒精合用</span> |
| 老年人 | <span style="color:#f87171">跌倒、認知受損風險增加</span> |

## Barbiturates

### 作用機轉

<span style="color:#fb923c">Barbiturates</span>→結合<span style="color:#e2e8f0">GABA_A受體</span>→增加Cl⁻通道開放時間→超極化

### 與Benzodiazepines的差異

| 特性 | Barbiturates | Benzodiazepines |
|------|-------------|----------------|
| 作用方式 | 增加Cl⁻通道開放時間 | 增加Cl⁻通道開放頻率 |
| 安全性 | <span style="color:#f87171">安全範圍窄</span> | 安全範圍較寬 |
| 抗痙攣 | 有 | 有（部分藥物） |
| 嗎啡拮抗 | 否 | 否 |
| 依賴性 | 強 | 中等 |

### 臨床應用

| 藥物 | 用途 |
|------|------|
| <span style="color:#fb923c">Phenobarbital</span> | 癲癇（首選之一）、鎮靜 |
| <span style="color:#fb923c">Thiopental</span> | 麻醉誘導（靜脈） |
| <span style="color:#fb923c">Secobarbital</span> | 失眠（已少用） |

### 副作用

| 副作用 | 說明 |
|--------|------|
| 嗜睡、認知受損 | 常見 |
| 依賴性 | <span style="color:#f87171">長期使用風險高</span> |
| 戒斷症狀 | <span style="color:#f87171">可威脅生命</span> |
| 呼吸抑制 | <span style="color:#f87171">過量主要死因</span> |
| 肝臟酶誘導 | 增加其他藥物代謝 |
| 過敏反應 | 皮疹（不常見） |

<span style="color:#f87171">警告：Barbiturates安全範圍窄，過量死亡率遠高於Benzodiazepines</span>

## Z類藥物

### 與Benzodiazepines的差異

<span style="color:#fb923c">Zolpidem</span>、<span style="color:#fb923c">Zaleplon</span>、<span style="color:#fb923c">Eszopiclone</span>選擇性結合含有<span style="color:#e2e8f0">α₁亞單位</span>的GABA_A受體

### 藥物特性

| 藥物 | 半衰期（小時） | 特點 |
|------|-------------|------|
| <span style="color:#fb923c">Zolpidem</span> | 1.5-3.5 | 快速入睡，減少睡眠維持 |
| <span style="color:#fb923c">Zaleplon</span> | 1-2 | 極短效，適用於睡眠中醒來 |
| <span style="color:#fb923c">Eszopiclone</span> | ~6 | 較長效，可維持睡眠 |

### 臨床應用

- <span style="color:#60a5fa">失眠（入睡困難或睡眠維持困難）</span>
- Zolpidem有雙相釋放配方（Ambien CR）

### 副作用

| 副作用 | 說明 |
|--------|------|
| 嗜睡 | 劑量相關 |
| 順行性失憶 | 高劑量時 |
| 睡眠駕駛/行為 | <span style="color:#f87171">無記憶的複雜行為</span> |
| 依賴性 | 較Benzodiazepines少 |

## Ramelteon（褪黑激素受體激動劑）

| 特性 | 說明 |
|------|------|
| 機轉 | MT₁/MT₂褪黑激素受體激動劑 |
| 作用部位 | 視交叉上核 |
| 半衰期 | 2-5小時 |
| 臨床用途 | <span style="color:#60a5fa">入睡困難型失眠</span> |
| 優點 | 無依賴性、非管制药品 |
| 副作用 | 眩暈、嗜睡 |

<span style="color:#f87171">禁忌：與CYP1A2抑制劑（如Fluvoxamine）合用</span>

---

## Buspirone（丁螺環酮）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">5-HT₁A部分激動劑</span> |
| 特點 | 無鎮靜、無成癮性、無交叉耐藥 |
| 臨床用途 | <span style="color:#60a5fa">廣泛性焦慮症（GAD）</span> |
| 缺點 | <span style="color:#f87171">需1-2週才見效</span> |
| 副作用 | 眩暈、頭痛、噁心 |

<span style="color:#f87171">注意：不適用於急性焦慮或恐慌症</span>

---

## Flumazenil（逆轉劑）

| 特性 | 說明 |
|------|------|
| 機轉 | <span style="color:#e2e8f0">GABA_A受體BZ位點競爭性拮抗劑</span> |
| 臨床用途 | <span style="color:#60a5fa">逆轉Benzodiazepine過量</span> |
| 半衰期 | 0.7-1.3小時（短） |
| 副作用 | 癲癇（戒斷症候群）、激動、混淆 |

---

## Benzodiazepine拮抗劑/逆轉劑

| 藥物 | 用途 |
|------|------|
| <span style="color:#fb923c">Flumazenil</span> | Benzodiazepine過量、麻醉恢復 |
