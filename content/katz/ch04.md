## 章節導讀

<span style="color:#e2e8f0">藥物生物轉化</span>是終止親脂性藥物作用的關鍵過程，本章介紹<span style="color:#60a5fa">Phase I</span>（氧化還原水解）與<span style="color:#60a5fa">Phase II</span>（結合反應）兩大代谢途径，以及<span style="color:#c084fc">Cytochrome P450</span>系統與藥物基因體學的臨床重要性。

---

## 為何需要藥物生物轉化

<span style="color:#f87171">Paracelsus 原則：「劑量決定毒性」</span>

親脂性藥物若僅靠腎臟排泄，會因為腎小管遠端被動擴散回血液而作用時間過長。肝臟代謝將親脂性藥物轉化為更<span style="color:#34d399">親水性</span>的代謝物以便排泄。

| 藥物 | 若不經代謝 | 實際半衰期 |
|------|---------|---------|
| <span style="color:#fb923c">Thiopental</span> | 可能達數天 | 8-12 小時（經肝代謝）|

---

## Phase I 反應：氧化、還原、水解

### Cytochrome P450 系統

<span style="color:#c084fc">Cytochrome P450（CYP）</span>是肝臟微粒體中最主要的藥物代謝酶系統：

| CYP 酶 | 臨床相關性 | 臨床例子 |
|--------|---------|---------|
| <span style="color:#c084fc">CYP3A4</span> | 約佔 30% 臨床相關代謝 | <span style="color:#fb923c">Ketoconazole</span>、<span style="color:#fb923c">Erythromycin</span>、<span style="color:#fb923c">Midazolam</span> |
| <span style="color:#c084fc">CYP2C9</span> | 約佔 20% | <span style="color:#fb923c">Warfarin</span>、<span style="color:#fb923c">Phenytoin</span> |
| <span style="color:#c084fc">CYP1A2</span> | 約佔 15% | <span style="color:#fb923c">Caffeine</span>、<span style="color:#fb923c">Theophylline</span> |
| <span style="color:#c084fc">CYP2D6</span> | 約佔 5% | <span style="color:#fb923c">Codeine</span>（需轉化為 morphine）、<span style="color:#fb923c">Metoprolol</span>、<span style="color:#fb923c">Propranolol</span> |
| <span style="color:#c084fc">CYP2C19</span> | 重要 | <span style="color:#fb923c">Omeprazole</span>、<span style="color:#fb923c">Clopidogrel</span>（活化）|

### 主要 Phase I 反應類型

| 反應類型 | 例子 |
|---------|------|
| 芳香烴羥化 | <span style="color:#fb923c">Phenytoin</span>、<span style="color:#fb923c">Warfarin</span> |
| 脂肪烴羥化 | <span style="color:#fb923c">Pentobarbital</span> |
| N-去烷基化 | <span style="color:#fb923c">Morphine</span>、<span style="color:#fb923c">Caffeine</span> |
| S-氧化 | <span style="color:#fb923c">Thioridazine</span> |
| 水解 | <span style="color:#fb923c">Succinylcholine</span>（膽鹼酯酶）|

---

## Phase II 反應：結合反應

Phase II 反應將內源性底物與藥物或其 Phase I 代謝物結合，產生<span style="color:#34d399">高極性、易排泄</span>的產物。

| 反應類型 | 酶 | 臨床例子 |
|---------|---|---------|
| <span style="color:#60a5fa">葡萄糖醛酸結合</span> | UGT（UDP-葡萄糖醛酸轉移酶） | <span style="color:#fb923c">Acetaminophen</span>、<span style="color:#fb923c">Morphine</span>、<span style="color:#fb923c">Lorazepam</span> |
| <span style="color:#60a5fa">硫酸化</span> | SULT（硫酸化轉移酶） | <span style="color:#fb923c">Acetaminophen</span>、<span style="color:#fb923c">Estrogens</span> |
| <span style="color:#60a5fa">穀胱甘肽結合</span> | GST | 毒性代謝物的解毒 |
| <span style="color:#fb923c">乙醯化</span> | NAT（N-乙醯轉移酶） | <span style="color:#fb923c">Isoniazid</span>、<span style="color:#fb923c">Sulfonamides</span> |
| <span style="color:#fb923c">甲基化</span> | 甲基轉移酶 | <span style="color:#fb923c">Dopamine</span>、<span style="color:#fb923c">Epinephrine</span> |

## 藥物基因體學

### Phase I 酶基因多型性

| 基因多型 | 臨床影響 |
|---------|---------|
| <span style="color:#c084fc">CYP2D6</span> 快/慢代謝者 | Codeine 鎮痛效果差（慢代謝者）；超快代謝者可能有毒性 |
| <span style="color:#c084fc">CYP2C9</span> | Warfarin 劑量需求差異可達 10 倍 |
| <span style="color:#c084fc">CYP2C19</span> | Clopidogrel 活化減少（心血管事件風險增加）|
| <span style="color:#c084fc">Pseudocholinesterase</span> 缺乏 | Succinylcholine 作用時間延長 |
| <span style="color:#c084fc">NAT2</span>（慢乙醯化者）| Isoniazid、Sulfonamides 毒性風險增加 |

### Phase II 酶基因多型性

| 基因多型 | 臨床影響 |
|---------|---------|
| <span style="color:#c084fc">UGT1A1</span> | Gilbert 症候群（輕微非結合性高膽紅素血症）|
| <span style="color:#c084fc">TPMT</span> | Azathioprine、6-Mercaptopurine 毒性風險 |

## 藥物-藥物交互作用（DDIs）

### CYP 酶誘導（CYP Induction）

<span style="color:#f87171">臨床意義：降低共給藥物血中濃度，療效下降</span>

| 誘導劑 | 影響的 CYP 酶 |
|-------|-------------|
| <span style="color:#fb923c">Rifampin</span> | CYP3A4（顯著）|
| <span style="color:#fb923c">Phenytoin</span> | CYP3A4、CYP2C9 |
| <span style="color:#fb923c">Carbamazepine</span> | CYP3A4 |
| <span style="color:#fb923c">Phenobarbital</span> | 多个 CYP 酶 |
| 吸菸 | CYP1A2 |

### CYP 酶抑制（CYP Inhibition）

<span style="color:#f87171">臨床意義：升高共給藥物血中濃度，可能達到毒性範圍</span>

| 抑制劑 | 影響的 CYP 酶 |
|-------|-------------|
| <span style="color:#fb923c">Ketoconazole</span> | CYP3A4（強效）|
| <span style="color:#fb923c">Erythromycin</span> | CYP3A4 |
| <span style="color:#fb923c">Cimetidine</span> | 多個 CYP 酶 |
| <span style="color:#fb923c">Grapefruit juice</span> | CYP3A4（腸道）|
| <span style="color:#fb923c">Disulfiram</span> | CYP2E1 |

## Acetaminophen 中毒機制

<span style="color:#f87171">中毒劑量：>150 mg/kg 或 >7.5g（成人）</span>

```
正常路徑（95%）：
Acetaminophen → 葡萄糖醛酸結合 / 硫酸化 → 無毒代謝物

毒性路徑（5%，由 CYP2E1、CYP3A4）：
Acetaminophen → NAPQI（N-乙醯苯亞胺基醌）→ 與 GSH 結合 → 無毒
                                    ↓
                            GSH 耗盡
                                    ↓
                            肝細胞蛋白質烷基化
                                    ↓
                            肝細胞死亡（中央靜脈周圍壞死）
```

### 解毒治療

| 解毒劑 | 機轉 |
|-------|------|
| <span style="color:#fb923c">N-acetylcysteine（NAC）</span> | 補充 GSH 前驅物；直接與 NAPQI 反應 |

<span style="color:#f87171">關鍵：早期使用（在 8 小時內）效果最佳</span>

## 首渡效應

口服藥物經肝臟首次通過時的部分代謝，導致<span style="color:#60a5fa">生物可用率降低</span>。

| 藥物 | 首渡效應程度 |
|------|------------|
| <span style="color:#fb923c">Lidocaine</span> | 極大，口服無法達到治療濃度 |
| <span style="color:#fb923c">Isoproterenol</span> | 完全，口服無效 |
| <span style="color:#fb923c">Nitroglycerin</span> | 顯著，需舌下或經皮給藥 |
